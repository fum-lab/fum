# План: последовательности и LLM в FUMA

Этот план фиксирует направление Направляющего; перечисленные возможности ещё не реализованы и не приняты.

1. Завершить минимальное ядро FUMA, написанное целиком на FUMA и не опирающееся на Swift-литерал.
2. Следующим шагом реализовать универсальный оператор преобразования одной последовательности в другую на базе LLM.
3. Затем реализовать универсальный оператор ленивого продолжения последовательности на базе LLM. Для следующего элемента предусмотреть приблизительную оценку стоимости вычисления.

Для обоих операторов результат проверяется универсальной проверкой типов. При отказе проверки запускается очередная итерация генерации до успешного прохождения проверки.

Проверка типов подтверждает соответствие результата выраженному в типах контракту. Смысловую правильность результата она подтверждает в той мере, в какой необходимые свойства заданы этим контрактом. Успех очередной генерации и завершение повторов заранее не гарантированы.
