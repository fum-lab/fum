# Память этапа жизненного цикла узла

Этап продолжен из исходного C `16692490de749b661ec466f65a2b040700da1ea9` в отдельном W и полном ref, указанном в [плане](план.json). Нативный чат `01a195e5-70bf-7a81-920f-d15df36fc90a` и execution turn `01a1972a-cafc-7c41-bdeb-bcd0117225b9` — разные идентификаторы. Текущая модель и усилие наблюдались как `gpt-6-luna` / `low` и сохранены приватной квитанцией SHA-256 `0a9f5786fd124476a8260b2c62d130a667eb8a6440c10401ae29e76c5446e3d7`; это не backend attestation и не основание переписывать предыдущие коммиты.

Исходники описывают адресный descriptor, собственный worklist и чистую функцию решения родителя. Descriptor связывает ROOT UUID, чат/turn, логический узел, полный FUM ref, физический W, source OID/tree, версию текущего состояния, checkpoint и границу полномочий. Typed receipt входящего сохранённого сообщения и receipt результата ребёнка не имеют публичного конструктора: доверенный provider/adapter в этой поставке отсутствует. Поэтому production-переходы, Native callback, publisher, runtime wiring и activation остаются за границей.

`queued`, `prerequisite`, `accepted` и `running` остаются неterminal; `unknown` возвращает только решение наблюдать без повтора. Checkpoint выбирает идентификатор шага, и worklist допускает его лишь при известном состоянии `разрешён`. Source fixture описывает два различимых узла, чужой ROOT current, сохранение перед возвратом к собственному списку, точный checkpoint шаг, queued/prerequisite и unknown. Она закрыта `#if FUM_LIFECYCLE_API_WIRED` и не вошла в выполняемый test target, потому что новый source API не включён в явный список `Package.swift`.

Source commit `fcdf5612bf4c314a4a5e7ec2512d6900f225207e` с tree `ac46a3b38d70dac67270a7c9fcc2a787afd3457a` доставлен в собственный ref через обычный точный push; независимый `ls-remote` вернул тот же OID. Это source checkpoint, не ROOT acceptance или production integration. Текущий `Package.swift` содержит явный список исходников target `МатериализацияУзлов`; этот этап не включает новые файлы в target. SwiftPM compile и тесты не запускались по поручению и остаются `NOT_RUN/UNKNOWN`. TDD RED/GREEN и автоматизированная защита не доказаны. Следующее действие требует отдельного допуска на target wiring и активные проверки.
