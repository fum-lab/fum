# FUM

FUM - `fraktaljnyij uzel myishleniya`, по-русски - фрактальный узел мышления. Название фиксируется как аббревиатура латинскими буквами.

Этот репозиторий служит памятью проекта FUM - открытого агента следующего поколения. Цель проекта - реализовать агента полного цикла разработки от выработки требований до написания кода; долгосрочный ориентир - FUM-агент, способный написать самого себя.

Проектируемый FUM должен уметь вести параллельную работу над задачами в разных ветках и затем объединять результаты через слияние, подобно командной работе людей над проектом.

Правила поведения агентов и рабочих сессий хранятся в [AGENTS.md](AGENTS.md).
