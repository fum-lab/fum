# FUM

FUM - `fraktaljnyij uzel myishleniya`, по-русски - фрактальный узел мышления. Название фиксируется как аббревиатура латинскими буквами.

Этот репозиторий служит памятью проекта FUM - открытого агента следующего поколения.

Правила поведения агентов и рабочих сессий хранятся в [AGENTS.md](AGENTS.md).

## Структура

- [AGENTS.md](AGENTS.md) - правила поведения в этом репозитории.
- [Запросы/](Запросы/) - исходные запросы, разложенные по дате и времени.
- [Документация/](Документация/) - структурированные производные описания разрабатываемого FUM.
- [Документация/00-обзор-проекта.md](Документация/00-обзор-проекта.md) - краткий обзор FUM.
- [Документация/01-модель-памяти-FUM.md](Документация/01-модель-памяти-FUM.md) - модель памяти FUM.
- [Документация/02-публикация-и-лицензия.md](Документация/02-публикация-и-лицензия.md) - требования к публикации и лицензии.
- [Документация/03-эволюция-и-мышление.md](Документация/03-эволюция-и-мышление.md) - проектное основание о тождестве эволюции и мышления.
