# Рабочий перенос выполнен

Руководство перемещено из кириллического имени в rukovodstvo-obsjhej-migracii.md через git mv. Автоматизация обновила одну действующую Markdown-ссылку и метки свежести потребителя. Текст руководства побайтно сохранён; защищённые 2784 байта оригинала запроса и пять прежних незакоммиченных изменений не изменены.

После предыдущего отказа ROOT вернул точные доаварийные байты индекса через собственный index.lock, а три резерва сохранил переносом в приватный карантин. Затем принято исправление режима индекса при umask 077 и сравнения NFC-путей Git с NFD-представлением Foundation. Ошибки воспроизведены на старом коде; прошли 20 адресных случаев Swift Testing и повтор трёх новых регрессий после поправки переносимости теста. Общий конфиг Git и опубликованная история не менялись.

Новый рабочий запуск завершился target/host 0/0 за 35,072636208 секунды. Все 152 объявленных неизменяемых входа сохранились; группа процессов после завершения отсутствовала. Максимальный наблюдённый RSS группы составил 338526208 байт по семи сэмплам; это наблюдаемый максимум, не пик ядра. Выход 913 байт совпал с ожидаемым, stderr пуст. Повтор закрытого запуска не выполнялся.

Независимая сверка подтвердила: прежний blob руководства и режим 100644, единственная замена пути в полном stage, режим индекса 0644, один href и recency в потребителе, отсутствие новых временных резервов. Это один проверенный перенос, а не завершение всей миграции файлов.

Stop-хук человек подтвердил как доверенный и включённый; его конфигурация на диске сохранилась. Фактический вызов приложения и квитанция callback остаются UNKNOWN. Прежний снимок истёк и устарел после изменения HEAD. Постоянная точка входа и отдельный актуализируемый допуск разрабатываются существующим владельцем; повтор старого допуска не выполняется.

Python, полный ROOT JSONL, полный smoke, чистый клон и полный SDK/dyld-контур исключены или UNKNOWN. Локальные проверки этого этапа не означают общей финальной приёмки узла. Новая карточка не изменяет предыдущие карточки для хронологической связности; старый потребитель изменён только из-за переноса его цели.
