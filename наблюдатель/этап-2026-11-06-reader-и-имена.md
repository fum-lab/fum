# Reader, имена и непрерывное наблюдение

Наблюдатель продолжает работу в текущей сессии: доступное дерево опрашивается примерно каждые 50 секунд, неизменное состояние не пересылается. Решения, баланс, приёмка и интеграция принадлежат Управляющему. Восстановление после старта приложения и хоста этим не доказано. Летописец виден работающим; резервная замена не назначалась.

## Reader

Подготовлены supplement для неизменного выбора .1, явный контекст HOME/XDG/system и ограниченный /usr/bin/git. Producer создаёт файл через O_EXCL и не выдаёт себе полномочия. Произвольные executable закрыты. Наблюдаемая macOS custody не доказывает SIP/ACL/привилегированные гонки/CLT и все зависимости.

IncludeIf остаётся безусловным отказом: marker подтвердил ошибку active pattern с завершающим слешем, но примеры не доказывают общий предикат для установленного Git. Limited gitdir patch не принят. Unknown не превращается в разрешение.

Ленивый Creator loader сохраняет module globals и подмены штатный; читательские функции не получают локального alias. По сообщениям Управляющего адресные тесты и буквальный холодный producer прошли. Это не допуск к ROOT JSONL и не проверка полного Creator.

Подготовлена synthetic .7/.1-фикстура полного reader: собственный Git plumbing, явные identity/date, независимые raw commit bytes/OID/index SHA; metadata источников и готовности явно синтетические, не настоящий допуск. Первый запуск выявил потерю __kwdefaults__ при types.FunctionType; Управляющий исправил её. По его сообщению full synthetic reader и kwdefaults test прошли 2/2. Прежние отказы не переименованы в успех; наблюдатель runtime не повторял.

Следующая предложенная регрессия меняет tracked bytes при неизменных commit/index/JSON и требует конкретную причину отказа без исправления файла. Python guards имеют ограниченный охват и не доказывают все native IO/ENV.

## Имена и письменности

Предложен versioned контракт: отдельные язык содержимого, письменность и алгоритм имени; свободная ASCII-kebab основа, языковой суффикс перед техническим расширением. ru-Latn — русский латиницей, не алгоритм транслитерации. Латинское имя при кириллическом теле само по себе не меняет тег ru.

Текущая projection v2 не гарантирует lower ASCII-kebab и не знает content-tag. AGENTS.md/SKILL.md/README.md/Package.swift, imports/test discovery требуют точных исключений и совместимых consumers. До переименования нужны классификация, old→new mapping, входящие ссылки, exact/NFC/casefold/prefix collisions и policy bridge. Проекция и переименования не запускались, W2 наблюдателем не менялся.

## Автоматизация и последующие зависимости

Повторялись порча NUL/backreference, потерянное определение и хвост старого метода в patch. Передан кандидат единой literal-генерации с exact base, round-trip и AST полного результата до передачи. Проверки proposed кода не переносятся на личную память: её тесты, ревью, hooks и readback запрещены исключением человека.

Кодовые предложения в private temp не равны code commit, интеграции или активации. Управляющий принимает exact snapshots/runtime и решает checkpoint/интеграцию. Наблюдатель отслеживает передачи и остатки без чужой личной памяти, host ENV и ROOT JSONL. Последний предэффектный Ruby запуск записи отказал при разборе US-ASCII; до Git/записи он не дошёл, повтор выполнен с явным UTF-8.
