# Долгосрочные цели FUM и FUMA

Долгосрочные цели связывают направление развития с тем, что нужно сделать сейчас. Изменение горизонта уточняет ближайшие шаги, сохраняя происхождение прежнего решения. Цель может оставаться полезной, даже когда её реализация ещё не определена.

Первое направление — [расширение сети FUM и затем FUMA](расширить-сеть-FUM-и-FUMA.md). Его ближайшие предпосылки: простой запуск на новой машине, проверяемая память, перенос принятых результатов и обучение человека взаимодействию с узлом.

Каждая цель описывает ожидаемый результат, текущую подтверждённую границу, связанные существующие шаги, наблюдаемые показатели и условия пересмотра. Отсутствие измерения обозначается явно. Запись цели не подтверждает готовность функции и сама не запускает работу.
