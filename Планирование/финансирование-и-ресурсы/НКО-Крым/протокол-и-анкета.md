# Учреждение FUM: поля решения и анкета учредителей

Черновик для нескольких учредителей; выбрана автономная некоммерческая организация (АНО). Поля в квадратных скобках заполняются после согласования. Подписание, нотариальное удостоверение и подача ещё не выполнялись.

## Протокол учредительного собрания № [номер]

Место: [населённый пункт, Республика Крым]. Дата: [дата]. Время начала и окончания: [время]. Присутствовали учредители: [перечень]. Председатель собрания: [ФИО]. Секретарь: [ФИО].

Повестка и решения:

1. Учредить Автономную некоммерческую организацию [согласованное полное наименование]. За: [число]; против: [число]; воздержались: [число]. Решение об учреждении принимается единогласно.
2. Определить место нахождения: [муниципальное образование]. Для регистрации указать действительный адрес [адрес по ГАР].
3. Утвердить устав в редакции приложения № 1. За: [число]; против: [число]; воздержались: [число].
4. Сформировать органы управления АНО согласно согласованному уставу: [наименования, состав, срок полномочий, решения и результаты голосования].
5. Назначить единоличный исполнительный орган: [наименование должности, ФИО, срок]. Уполномочить [лицо] оформить отношения с руководителем в пределах устава и закона.
6. Определить порядок формирования имущества: [деньги / имущество, стоимость, сроки и ответственные]. Отдельно зафиксировать, какие обязательства учредители действительно принимают; прогнозируемые пожертвования обязательствами не считать.
7. Определить заявителей и действия для государственной регистрации по применимым правилам Р11001: [состав, полномочия, представитель при необходимости]. Поручение представителю не заменяет подписи необходимых заявителей.

Подписи учредителей: [подписи и расшифровки]. Приложения: [устав, список участников, иные фактические документы]. Кредит, залог и поручительства этим протоколом не одобряются автоматически; конкретная сделка получает самостоятельное решение уполномоченного органа.

## Анкета для приватного заполнения

| Поле | Что требуется уточнить |
| --- | --- |
| Форма | АНО — собственная разработка и исследования |
| Название | Полное и сокращённое; проверить допустимость специальных слов |
| Учредители | Точное количество, физические или юридические лица, сведения для Р11001 |
| Место нахождения | Республика Крым и конкретное муниципальное образование |
| Адрес | Запись ГАР, основание использования, доступность связи |
| Цели | Исследования, разработка, просвещение; конкретный общественно полезный результат |
| Деятельность | Фактически планируемые операции и соответствующие ОКВЭД |
| Управление | Органы, полномочия, персональный состав, кворум, сроки, конфликт интересов |
| Имущество | Действительные вклады и сроки, подтверждение рыночной стоимости |
| Платные операции | Их содержание, связь с целями, отдельная правовая и налоговая квалификация |
| Подписи и подача | Заявители, УКЭП или бумажный маршрут, представитель при необходимости |

Паспортные данные, адреса проживания, подписи и реквизиты физических лиц в публичный репозиторий не заносятся. Этот открытый шаблон содержит только названия полей.
