# Принять формы runtime и реальный архив

## Задача

После интеграции принять первый явно разрешённый реальный архивный импорт и уточнить точный поддержанный набор форм Codex JSONL.

## Почему сейчас

Первая поставка адаптера проверена открытой синтетикой. Наблюдение живого процесса, UI и полное семантическое покрытие runtime остаются за её границей.

## Критерии завершения

- Получены отдельное разрешение на конкретный источник и ожидаемый UUID; другие сессии не читаются.
- Реальная форма проверена по устойчивому контракту и публикационно чистым фикстурам, а не по одному cli_version.
- Импорт, повтор, дополнение, replay и отказ при подмене подтверждены без публикации содержимого диалога или секретов.
- Возможность общего байтового читателя оценена по принятому commit/API статистики; семантика статистики и снимка остаётся раздельной.
- Неизвестные статусы и ограниченный охват сохранены; результат этапа не закрывает всё наблюдение macOS.
