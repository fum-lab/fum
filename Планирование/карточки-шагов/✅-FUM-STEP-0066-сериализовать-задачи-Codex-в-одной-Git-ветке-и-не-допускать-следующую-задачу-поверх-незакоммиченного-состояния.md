# Сериализовать задачи Codex в пределах одной именованной Git-ветки и не допускать начало следующей задачи поверх незакоммиченного состояния

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет один атомарный плановый шаг и его происхождение отдельно от веточного выбора.

## Задача

Сериализовать задачи Codex в пределах одной именованной Git-ветки и не допускать начало следующей задачи поверх незакоммиченного состояния.

## Результат

Первая POSIX-реализация с project hooks была завершена и проверена, а затем снята последующей миграцией на переносимую [FIFO-очередь](../../Инструменты/fum-ocheredj-zadach-git-vetki/SKILL.md). Историческое решение сохраняет происхождение требования, но больше не описывает активный механизм допуска.
