# Проверить контракт чистого модельного шага для исполняемого агентского цикла

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет один атомарный плановый шаг и его происхождение отдельно от веточного выбора.

## Задача

Проверить контракт чистого модельного шага для [исполняемого агентского цикла](../MVP-кандидаты/04-исполняемый-агентский-цикл/README.md): локальная LLM, проверяемая заглушка или режим `Codex CLI`, который работает как простой LLM-провайдер без собственного агентского цикла.

## Результат

Создан [контракт чистого модельного шага](../../Документация/41-контракт-чистого-модельного-шага.md) версии `1`, машинная JSON Schema и [Swift-прототип с детерминированной заглушкой](../../Прототипы/чистый-модельный-шаг/README.md). Контракт передаёт полный контекст явно, сверяет идентичность провайдера, запрещает инструменты, файлы и сеть, ограничивает вход, выход и время, связывает канонический ответ с входом и оставляет вывод инертным текстом для внешнего runtime.

Автономные тесты подтверждают повторяемость заглушки, UTF-8-метрики, изменение хэша вместе с контекстом, строгие поля, запрет эффектных capabilities, обязательное сообщение `user`, ошибку лимита и инертность shell-подобного текста. Проверка не подключает реальную LLM: локальный Ollama-контур остаётся частичным свидетельством, а `Codex CLI` не принят без доказанного model-only-режима, исключающего собственный агентский цикл.
