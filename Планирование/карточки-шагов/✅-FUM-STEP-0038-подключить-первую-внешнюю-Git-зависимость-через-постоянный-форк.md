# Подключить первую внешнюю Git-зависимость через постоянный форк

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет один атомарный плановый шаг и его происхождение отдельно от веточного выбора.

## Задача

Подключить первую внешнюю Git-зависимость через постоянный форк рядом с актуальным FUM и создать TDD-автоматизацию проверки всей Git-топологии.

## Результат

Форк `fum-lab/LinguisticKit` синхронизирован с оригиналом, выбранная совместимая ревизия подключена как submodule, а `fum-proverka-git-zavisimostej` автономно проверяет владельца форка, роли remote, достижимость ревизии из локально полученных refs форка, `.gitmodules`, чистоту и gitlink.
