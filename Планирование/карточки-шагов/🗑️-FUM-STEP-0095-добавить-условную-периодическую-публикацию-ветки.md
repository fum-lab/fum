# Добавить условную периодическую публикацию ветки

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет один атомарный плановый шаг и его происхождение отдельно от веточного выбора.

## Задача

После прояснения публикационной политики добавить отдельный адаптер условной периодической публикации. Он должен адресовать неизменяемый commit и полный ref, использовать заранее проверенный credential-free HTTPS GitHub push URL, запускать внешний эффект только через разрешённого исполнителя и восстанавливаться после пропущенного периода или неоднозначного сетевого результата без force, pull, merge или rebase.

## Результат

Карточка отозвана без реализации: автоматическая немедленная или периодическая публикация `refs/heads/master` исключена из траектории. Автоматические рабочие сессии продолжают создавать публикационно чистые локальные коммиты и передавать FIFO, а удалённая публикация выполняется только отдельным ручным push пользователя. Такой push подтверждает точный накопленный локальный результат, но не участвует в вычислении runtime-готовности и не предоставляет полномочий на провайдеры, секреты, затраты, раскрытие данных или иные внешние эффекты. Если автоматическая публикация понадобится для другого репозитория или ref, она потребует новой отдельно ограниченной и явно разрешённой карточки.
