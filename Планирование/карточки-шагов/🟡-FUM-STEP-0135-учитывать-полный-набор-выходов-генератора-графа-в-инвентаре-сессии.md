# Учитывать полный набор выходов генератора графа в инвентаре сессии

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет один атомарный плановый шаг и его происхождение отдельно от веточного выбора.

## Задача

Связать машинно объявленный полный набор канонических выходов генератора свежести графа Obsidian с инвентарём затронутых файлов рабочей сессии, чтобы оба выхода покрывались до закрытия независимо от исходного Git diff и перехода календарной даты MSK.

## Почему сейчас

Полный smoke-check текущей сессии пересёк полночь MSK. Замыкающий запуск генератора впервые изменил `.obsidian/fum-recency-reference-date`, тогда как запрос перечислял только `.obsidian/graph.json`; связность правильно отказала на неожиданном пути и потребовала возобновить уже закрытый машинный журнал. Ручное добавление sidecar восстанавливает одну сессию, но не предотвращает повтор на следующей календарной границе.

## Критерии завершения

- Красная интеграционная фикстура начинает с чистого sidecar даты `D`, формирует инвентарь только по исходному diff, переводит генератор на `D+1` в замыкающем ходе и воспроизводит неожиданный путь FUM-СБОЙ-0007.
- Генератор предоставляет закрытый машинно читаемый перечень своих канонических выходов с точными репозиторно-относительными путями `.obsidian/graph.json` и `.obsidian/fum-recency-reference-date`.
- Сессионная автоматизация до закрытия сопоставляет факт использования генератора с его перечнем выходов и требует покрытия каждого пути разделом `Повлиял на файлы`, не выводя перечень из текущего Git diff.
- Наличие в инвентаре объявленного, но побайтно неизменного выхода допустимо и не принуждает генератор к перезаписи; лишний путь, неизвестный выход, неверный регистр, символьная ссылка и выход за корень отклоняются.
- Фикстуры покрывают неизменную дату, переход через полночь MSK до smoke-check, переход между smoke-check и закрытием и повторный замыкающий запуск на той же дате.
- Ошибка до закрытия не создаёт снимок проверок; обнаружение после уже подготовленного снимка имеет идемпотентный документированный путь возобновления без потери машинных записей.
- Автономные тесты генератора графа, структуры запросов и связности рабочей сессии, регрессия FUM-СБОЙ-0007 и общий smoke-check проходят без сети и секретов.
