# Декомпозировать карточку максимально сырой записи событий устройств ввода по самостоятельно проверяемым контурам

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет один атомарный плановый шаг и его происхождение отдельно от веточного выбора.

## Задача

Декомпозировать карточку максимально сырой записи событий устройств ввода по самостоятельно проверяемым контурам.

## Результат

Родительская карточка сохранена как тонкое составное требование; отдельно оформлены общий контракт трассы, физические переходы клавиш, мышь, контактные поверхности, перьевые устройства и защищённый сбор. Для каждого контура закреплены собственные статус, критерии и двунаправленные связи.
