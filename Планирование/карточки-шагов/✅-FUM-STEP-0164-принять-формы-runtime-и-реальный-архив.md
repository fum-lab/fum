# Принять формы runtime и реальный архив

## Задача

После интеграции принять первый явно разрешённый реальный архивный импорт и уточнить точный поддержанный набор форм Codex JSONL.

## Почему сейчас

Первая поставка адаптера проверена открытой синтетикой. Наблюдение живого процесса, UI и полное семантическое покрытие runtime остаются за её границей.

## Критерии завершения

- Получены отдельное разрешение на конкретный источник и ожидаемый UUID; другие сессии не читаются.
- Реальная форма проверена по устойчивому контракту и публикационно чистым фикстурам, а не по одному cli_version.
- Импорт, повтор, дополнение, replay и отказ при подмене подтверждены без публикации содержимого диалога или секретов.
- Возможность общего байтового читателя оценена по принятому commit/API статистики; семантика статистики и снимка остаётся раздельной.
- Неизвестные статусы и ограниченный охват сохранены; результат этапа не закрывает всё наблюдение macOS.

## Результат

Поддержанные формы проверены публичными фикстурами дочерней поставки и двумя закреплёнными реальными префиксами разрешённой корневой задачи. Первая неуспешная попытка прежней версии остаётся историческим свидетельством; исправленный Swift-коммит `cffd4c52852da19d3e71c5a2d22e41712b3e734f` успешно импортировал источник. Подтверждены побайтный повтор, дополнение 451 строкой, восстановление отдельным процессом, отказ подмене и усечению без изменения принятого контейнера. Сырые данные не публиковались.

Общий читатель оценён по API статистики `85dccce282821a890e5e65539b4f22b895b52887`: он возвращает предметные события и не подменяет архивный читатель. Выделение общего слоя байтов, LF и SHA оставлено будущему самостоятельному решению.

Неизвестные статусы и ограниченный охват сохранены. Результат не закрывает живое наблюдение runtime/UI (FUM-STEP-0159) или отдельную приёмку подготовки SwiftPM (FUM-STEP-0163). Их исторические карточки сохраняются в исходных ветках. Действующая основная ветка получает только ограниченную архивную приёмку без изменения режима работы агентов.
