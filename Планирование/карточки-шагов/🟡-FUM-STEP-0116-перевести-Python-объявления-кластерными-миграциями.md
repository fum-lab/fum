# Перевести Python-объявления кластерными миграциями

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет один атомарный плановый шаг и его происхождение отдельно от веточного выбора.

## Задача

Перевести на русский язык кириллицей собственные объявления в собственном Python-коде FUM контекстно ограниченными кластерными миграциями. Каждый кластер должен строиться по машинному инвентарю областей видимости и связей, сохранять точные CLI- и wire-контракты, требования языка и внешних API и завершаться наблюдаемым уменьшением остатка без изменения поведения.

## Почему сейчас

Python-код распределён между локальными автоматизациями, генераторами, валидаторами, тестами и служебными точками входа. Одинаково написанные английские имена имеют разные доменные значения и области видимости, а рядом находятся обязательные специальные методы, внешние вызовы, аргументы CLI и поля машинных форматов. Глобальная текстовая замена не различает эти границы, поэтому остаток нужно переводить по независимым проверяемым кластерам.

## Критерии завершения

- AST-инвентарь перечисляет собственные Python-объявления классов, функций, параметров, переменных, атрибутов и вспомогательных типов, отличает импорты, ключевые слова, специальные требования Python и внешние API и фиксирует точный исходный остаток.
- До первой массовой записи допустимое переименование и опасный сценарий отказа закреплены падающими тестами стадии `red`; только после реализации, доведённой до прохождения этих тестов, массовая запись выполняется самой локальной автоматизацией, а не ручной серией замен.
- Остаток заранее разбит по локальной автоматизации или связанному пакету и общему CLI- либо wire-контракту на контекстно ограниченные кластеры, каждый из которых можно независимо изменить и проверить в одной рабочей поставке.
- Для каждого кластера до записи подготовлены однозначная карта старых и русских имён с учётом областей видимости, `dry-run`, SHA-256 входного снимка, проверка коллизий, затенения, динамических обращений и смешения письменностей.
- Имена импортируемых библиотек, внешних API, Python-протоколов и обязательных специальных методов сохраняются; собственные внутренние объявления и все статически и динамически обнаруживаемые обращения к ним мигрируются согласованно.
- Аргументы и команды CLI, переменные среды, имена файлов, JSON-, TOML- и иные wire-поля сохраняют прежние значения либо получают отдельную версионную миграцию с обратным чтением и golden-проверкой; перевод локального идентификатора не меняет этот интерфейс неявно.
- Текст исходных пользовательских запросов, каталог `Источники/`, дословные фикстуры и сохранённые внешние материалы не переписываются; тестовые данные меняются только там, где они проверяют собственное новое объявление, а не прежний внешний контракт.
- После каждого кластера повторный инвентарь доказывает строгое уменьшение exact-остатка, а итоговый прогон показывает нулевой необоснованный остаток; каждое сохранённое исключение имеет машинно проверяемый класс и происхождение.
- Автономные тесты затронутых автоматизаций, проверки CLI и wire-совместимости, компиляция Python-исходников и общий smoke-check проходят без сети и секретов.
