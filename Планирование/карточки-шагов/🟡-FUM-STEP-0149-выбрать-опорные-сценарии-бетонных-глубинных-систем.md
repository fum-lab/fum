# Выбрать опорные сценарии бетонных глубинных систем

## Задача

Выбрать один конкретный подземный объект и один короткий морской грузовой маршрут как опорную пару для проверки модели бетонных глубинных систем.

## Почему сейчас

Исследовательская модель разделяет известные технологии и гипотезы, но исходные условия, масштаб и обычные альтернативы ещё не закреплены. Без этого невозможно проверить полезную нагрузку, устойчивость и стоимость.

## Критерии завершения

- Названы объект и маршрут, объяснён выбор пары.
- Для объекта заданы назначение, геология, глубина либо явно ограниченный диапазон и обычный способ строительства для сравнения.
- Для маршрута заданы груз, расстояние, глубина, портовый цикл и обычный способ перевозки для сравнения.
- Данные имеют происхождение; пробелы и неопределённость названы явно.
- Сценарии оформлены по существующему шаблону и имеют проверяемый критерий полезности. Физические работы этим шагом не запускаются.
