# Ввести доверенную многомодульную загрузку runtime

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет обязательный безопасный предшественник разделения single-file runtime.

## Задача

Сохранить стабильные внешние пути и CLI очередей, но добавить закрытый манифест модулей и загрузчик, который читает каждый объявленный blob из одного literal `protocol_oid`, исполняет его под `python -I` и не использует `sys.path`, текущий рабочий каталог, dirty checkout, candidate HEAD или незаявленные локальные файлы.

## Почему сейчас

Монолит пула одновременно является доверенной границей: bootstrap получает один blob через `git show <protocol_oid>:<path>` и тем самым не исполняет код кандидата. Обычное разбиение на импорты из рабочего дерева разрушило бы это свойство. Сначала нужен общий проверяемый способ загрузить exact bundle одной ревизии без изменения поведения доменной логики.

## Критерии завершения

- Версионированный манифест перечисляет канонические repo-relative-пути, tree modes, OID или проверяемые хэши, имена модулей, разрешённые зависимости и одну ревизию bundle.
- Загрузчик получает только literal `protocol_oid`, читает все blobs через Git без replace-objects и локальных import-путей, проверяет манифест до исполнения и строит закрытое пространство модулей в памяти.
- Стабильные входные скрипты пула и обычной очереди, имена команд, wire/ref-схемы, коды ошибок и JSON-ответы не меняются.
- Отказы до исполнения покрывают отсутствующий или лишний модуль, повтор имени, traversal, symlink или неверный mode, цикл, незаявленную зависимость, смешение OID, candidate/worktree-подмену и попытку чтения за пределами checkout.
- Routing snapshot и reload-квитанции связывают `protocol_oid`, манифест и полный набор module OID; точный повтор восстанавливает тот же bundle.
- Characterization-набор FUM-STEP-0151 и все профильные тесты очередей проходят побайтно совместимо, а отдельная отрицательная suite доказывает отсутствие fallback к рабочему дереву.
- Карточка не переносит доменные функции по модулям; это выполняют FUM-STEP-0153–FUM-STEP-0155 после доказанной загрузки.
