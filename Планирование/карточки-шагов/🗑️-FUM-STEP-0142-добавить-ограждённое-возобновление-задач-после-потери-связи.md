# Добавить ограждённое возобновление задач после потери связи

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет историческое происхождение снятого шага.

## Задача

Расширить прежний heartbeat-диспетчер подпротоколом единственного восстановления уже созданной исполнительской задачи после наблюдаемого разрыва потока связи.

## Результат

Карточка снята без заявления о завершении. В новом контуре нет heartbeat, который мог бы читать прежнюю задачу и отправлять восстановительное сообщение: каждый подтверждённый коммит заранее связан с новой сессией-продолжением, а исчезнувший исполнитель остаётся явной границей ручного восстановления.
