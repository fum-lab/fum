# Автоматизировать подготовку репозитория на Linux

## Задача

Создать автоматизацию настройки репозитория и установки всех инструментов, необходимых для выбранного поддерживаемого сценария FUM на Linux, на новой либо частично подготовленной системе.

## Почему сейчас

Пользователь отдельно поручил запланировать подготовку Linux. Нужна общая с macOS и Windows модель зависимостей с явной платформенной реализацией, чтобы готовность среды не определялась предположениями агента.

## Критерии завершения

- Определена поддерживаемая матрица дистрибутивов, выпусков и архитектур, включая первый воспроизводимый сценарий. Автоматизация обнаруживает систему и доступный способ установки, а неподдерживаемое сочетание сообщает до изменений.
- Используется общее описание инструментов и профилей FUM с macOS и Windows. Для каждой зависимости зафиксированы назначение, совместимые версии, проверяемый источник и способ подтверждения установки; пакеты и команды не дублируются в независимых списках.
- Предварительная проверка оценивает место, права, сеть, установленные инструменты и состояние репозитория. План отделяет готовое окружение от нужной установки; повышенные права используются только для конкретных необходимых операций.
- Настраиваются Git, нужный Python, доступный поддерживаемый Swift и зависимости выбранных проверок; материализуется точный LinguisticKit. Учтены особенности файловой системы, регистр имён, кириллица, локаль и окончания строк.
- Существующие пользовательские настройки, окружения и незакоммиченные изменения сохраняются. Повтор идемпотентен, изменение входов требует обновить план; проверены прерывание, частичная установка и восстановление.
- Доступный профиль Linux отделён от компонентов, требующих API macOS. Отсутствие возможности собрать macOS-приложение не скрывается успешным результатом переносимой части. Собственные компоненты включаются по реальной поставке FUM-STEP-0176.
- Из чистого клона воспроизводятся проверка инструментов и выбранный smoke; тот же сценарий пригоден для согласованного Linux-окружения GitHub Actions. Готовность привязана к версии описания среды и точному набору проверок.
- Есть RED/GREEN, открытые фикстуры и подтверждение на поддерживаемой системе, профиль первичного/повторного запуска, анализ оптимизации и статистика с происхождением. Руководство помогает человеку понять состояние, устранить причину отказа и безопасно повторить подготовку.
