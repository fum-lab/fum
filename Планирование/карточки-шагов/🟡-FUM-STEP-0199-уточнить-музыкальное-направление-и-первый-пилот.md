# Уточнить музыкальное направление и первый пилот

Первый шаг выбирает творческую цель и форму самостоятельной музыкальной работы. Небольшой пилот должен дать материал для содержательной оценки и дальнейшего решения.

## Задача

Согласовать цель, форму, объём и критерий приёмки первого музыкального пилота, затем подготовить результат в выбранной форме и сохранить его разбор. Создание музыки, исполнение и работа со звуком являются вариантами, из которых выбирается конкретная ограниченная работа.

Для музыкального самоописания FUM использовать существующую жанровую карту и границу FUM-STEP-0010. Для совместной работы с художественным направлением отдельно определить вклад музыки и общий результат; самостоятельный план музыкального направления сохраняется.

## Почему сейчас

Пользователь отдельно назвал музыкальное направление. Конкретная цель, форма и пилот пока не определены. Существующее описание музыкальных форм самоописания FUM помогает начать выбор, но не заменяет отдельную программу музыкальной работы.

## Критерии завершения

- Сохранены согласованные творческая цель, форма, небольшой объём пилота и основание выбора. Невыбранные варианты не превращены в обязательный набор продуктов.
- До подготовки результата определены критерий приёмки и способ предъявления пилота, соответствующие выбранной форме.
- Пилот сохранён вместе с необходимыми для его повторного предъявления материалами. Замысел, исходное представление и фактическое звучание названы по их реальному состоянию.
- Зафиксированы разбор пилота по выбранному критерию, замечания и решение о продолжении либо пересмотре. Успех технической проверки не объявлен доказательством музыкальной ценности.
- При музыкальном самоописании FUM сохранены происхождение и статус художественных утверждений; применимая работа связана с существующим FUM-STEP-0010 без второго задания на тот же контракт.
- Если выбран совместный художественный результат, определены музыкальная часть и граница другой работы. Если такой результат не выбран, связь с художественным направлением не объявлена обязательной зависимостью.
