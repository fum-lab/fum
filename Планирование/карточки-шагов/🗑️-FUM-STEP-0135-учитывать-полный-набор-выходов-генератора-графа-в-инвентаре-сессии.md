# Учитывать полный набор выходов генератора графа в инвентаре сессии

[Карточка шага](../../Глоссарий/карточка-шага.md) сохраняет историческое происхождение снятого шага.

## Задача

Связать два прежних Git-выхода генератора свежести графа Obsidian с инвентарём затронутых файлов рабочей сессии, чтобы оба пути покрывались до закрытия при переходе календарной даты MSK.

## Результат

Карточка снята без заявления о завершении. По текущей политике корневой `.obsidian/` целиком является игнорируемым локальным состоянием checkout. `.obsidian/graph.json` и `.obsidian/fum-recency-reference-date` больше не являются Git-выходами и не входят в раздел `Повлиял на файлы`, staging или коммит. Генератор по-прежнему обновляет локальную пару, а проверка свежего checkout допускает полное отсутствие этих файлов. Поэтому прежняя цель связать их с инвентарём сессии утратила применимость; возврат этих путей в Git потребует нового явного требования и нового шага.
