# Спланировать профиль и пилот macOS VM для FUMA

## Задача

Подготовить технический план одного профиля macOS VM на Apple Silicon и конечного пилота FUMA: совместимый образ → установка → первый запуск → готовность SSH → точный гостевой клон → выбранный сценарий → остановка и повтор.

## Почему сейчас

Потребность в macOS VM принята отдельной командой. Linux-инструмент даёт соседний опыт жизненного цикла, но установку macOS, идентичность гостя и provisioning необходимо спланировать отдельно. Направление сохраняется без выделения ещё одного активного исполнителя или запуска машины в текущей границе.

## Критерии завершения

- Составлена матрица общего и отдельного поведения Linux/macOS; повторное использование опирается на конкретный принятый commit, а недоставленные части указаны как зависимости.
- Подготовлен паспорт одного пилота с условиями host/SDK/Swift/образа/ресурсов. Неизвестные поля явно перечислены вместе со способом их получения; гипотеза macOS 27+ Beta из переданного исследования не объявляется проверенной готовностью.
- Описан отдельный контракт восстановления прерванной установки через VZMacOSInstaller. Обычные pause/stop во время установки не объявлены поддержанным способом отмены.
- План первого запуска различает provisioning и повтор: пользователь не переинициализируется, аппаратная модель, идентификатор, вспомогательное хранилище и диск сохраняются.
- Выбран и назван один сценарий FUMA из чистого клона точного OID и существующая подготовка macOS/FUM-STEP-0179; сборка, запуск и полезный результат имеют отдельные критерии.
- Заданы синтетические проверки жизненного цикла и отдельный настоящий прогон совместимого гостя с SSH, штатной остановкой и повтором; входы и профиль воспроизводимы.
- Итоговый план перечисляет ограничения и зависимости для реализации. В этом шаге не создаются VM, учётные данные и новая активная задача; дальнейшая реализация и настоящее испытание получают отдельную явную границу.
