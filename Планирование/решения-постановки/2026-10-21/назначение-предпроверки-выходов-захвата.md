# Предотвратить коллизии выходов захвата

ROOT назначил существующий отдельный видимый чат «Предотвратить коллизии выходов захвата» для [Issue356](https://github.com/fum-lab/fum/issues/356) и STEP0174 на начальной базе N=7a35082adb12c77297902284faa9b9a022ef2ea4. Дубликат чата и повторное назначение той же реализации не создаются.

## Подтверждённая граница

Первый ответ API содержал только идентификатор подготовки. Поздним исходным сообщением ROOT подтверждены настоящий task ID 01a15f29-f773-7c11-8c11-e7fafafb8336, нативное происхождение agent_created_thread, начальный HEAD N и модель gpt-6.1-sol с усилием ultra. Эти сведения переданы координатором; planning не выдаёт их за собственное повторное наблюдение запуска.

На сообщённую границу checkout ребёнка был чистым detached, запись и ветка ещё не начались. Выбранный ROOT [обычный ACT](../../задачи/01a15f29-f773-7c11-8c11-e7fafafb8336/поручение-контрольной-точки.json) схемы fum.поручение-дочерней-контрольной-точки.1 сохранён точной копией: 1822 байта, SHA-256 2ab1353e8b17b8fe35a95d8edf20deb6421d38fa021e6d191fc9b1b8a927351c. Предложенный ref — refs/heads/codex/predproverka-vyikhodov-zakhvata; наличие ref не заявляется.

ACT относится к ordinary child-подготовке .10 с контрольной точкой. Конечный .19 не подходит к первоначальному prompt. Хэш первоначального нативного поручения в ACT — f949beb521202b3f1863d7d3b9d8675b83ba09b6f090bc560f4658b22daf76ad; exact scope и исходная ROOT-постановка заданы самим актом. Planning не создаёт эти полномочия по собственному смысловому выбору.

## Состав и следующий переход

C75 включает выбранные ROOT байты ACT и отдельный [S1 точного N](../../материалы-базиса-узла/2026-10-21/состав-принятого-журнала-fuma-7a35082a.json). Прежний S1(M) остаётся неизменным; новый снимок N нужен для полной ROOT-пары, добавленной после M. Первоначальное предположение ROOT «S1(N) не требуется» отменено поздней адресной поправкой до Prepare; оба оригинала сохранены с агентским происхождением.

По будущему опубликованному коммиту C75 ROOT отдельно выберет commit/path/blob/SHA акта и S1(N), проверит действительность ACT и передаст ребёнку независимый selector. Наличие этих плановых данных не объявляется исполнением ACT, началом записи ребёнка или приёмкой его результата.

Читатель ACT .1 допускает самостоятельный обычный акт без прежнего D. Отсутствующий D не создаётся задним числом, первое нативное поручение не переписывается. Установка S1 в ROOT или child checkout в этом этапе не выполняется. D22 остаётся остановлен.
