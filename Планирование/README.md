# Планирование FUM

Источники требований:

- [исходный запрос 2026-06-24 13:43:47 MSK](../Запросы/2026-06-24_13-43-47_MSK.md)

Этот каталог хранит материалы планирования развития [FUM](../Глоссарий/FUM.md). Он нужен для того, чтобы связывать уже зафиксированные требования, [открытые вопросы](../Глоссарий/открытый-вопрос.md), ближайшие рабочие шаги и дальние горизонты проекта в одном навигационном слое.

Плановые материалы не заменяют [исходные запросы](../Глоссарий/исходный-запрос.md), [производную документацию](../Глоссарий/производная-документация.md), [глоссарий](../Глоссарий/README.md) и [вопросы](../Вопросы/README.md). Если в планировании появляется новое требование, оно должно сохранять обычную цепочку: запрос -> документация -> изменение -> коммит.

## Материалы

- [Дорожная карта FUM](дорожная-карта.md) - сквозной обзор горизонтов развития проекта и ближайших проверяемых результатов.

## Правила использования

- Материалы планирования пишутся на русском языке кириллицей, кроме названия [FUM](../Глоссарий/FUM.md), технических имен и дословных цитат.
- Плановые шаги должны ссылаться на документы, запросы, вопросы или глоссарные статьи, из которых они вытекают.
- Неясные или противоречивые плановые развилки фиксируются как [открытые вопросы](../Глоссарий/открытый-вопрос.md), а не прячутся внутри дорожной карты.
- Дорожная карта обновляется при значимых изменениях требований, архитектуры, автоматизаций или при появлении новых плановых материалов.
