# Сделать Git-отпечаток независимым от сокращённых хэшей

Выявленный дефект подготовки контекстного checkpoint: при росте общей Git objectdb стандартный diff изменил сокращение OID с восьми до девяти знаков. Содержательный SHA остался прежним, а Git-отпечаток v4 изменился. Прежние записи и отказ готовности сохранены; диагностическое воспроизведение с процессным core.abbrev=8 не исправляет общий алгоритм и не гарантирует отсутствие будущей коллизии.

Источник зависимости: вычислить_отпечаток_снимка в scripts/отчёты_о_запусках_проверок.py внутри fum-otchyotyi-o-zapuskakh-proverok хэширует буквальные stdout двух git diff --binary для индекса относительно HEAD и рабочего дерева. Исторический v3-адаптер воспроизводит прежние байты; его нельзя менять без версии.

Следующий отдельный конечный допуск должен охватить четыре пути того же инструмента: основной скрипт, scripts/связь_отпечатка_с_коммитом.py, новый tests/test_детерминированный_гит_отпечаток.py и SKILL.md. Это план, не активация писателя или смена действующего v4.

Новый явно выбранный алгоритм .2 закрепляет полные OID, full-index/no-abbrev, отсутствие цвета, rename inference и внешнего diff/textconv, формат submodule и префиксы. Метка алгоритма включается в хэш; object format SHA-1/SHA-256 учитывается. Выбор задаётся до первой записи неизменяемым машинным контрактом. Старый вход сохраняет прежний алгоритм; неизвестный/смешанный формат отказывает. Старые v3/v4, SHA и Markdown не переписываются, изменение алгоритма после отказа автоматически не разрешается. Равенство содержательного SHA не заменяет проверку Git-состояния.

Регрессии в отдельной временной базе: заранее выбранная коллизия префикса blob меняет legacy-diff без изменения HEAD/индекса/файлов, но не .2; staged/unstaged/binary/gitlink; оба object formats; настоящий сдвиг HEAD, индексного объекта, режима и рабочих байтов; точные исключения отчётов/запусков/проекции; сохранение старых свидетельств и отказ смешанному контракту. Чужие настройки и refs не меняются. Тяжёлый 86-набор контекстного кэша не нужен для этой отдельной регрессии.
