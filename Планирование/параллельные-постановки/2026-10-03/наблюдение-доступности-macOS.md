# Наблюдение доступности macOS в отдельной ветке

Первый исполняемый срез системного наблюдения FUMA проверяет один вызов macOS — `AXIsProcessTrusted()` — и сохраняет его происхождение, результат и возможность повторного чтения. Он не означает охвата всех API macOS. Вызов не должен показывать системный запрос разрешения пользователю.

## Назначение

Отдельная видимая задача Codex Desktop начинает работу от точного коммита этой постановки в `fuma`, в собственном Git worktree и ветке `refs/heads/codex/...`. До записи исполнитель сверяет начальный `HEAD`, полный ref, физический корень, свой UUID и единственного писателя. Координатор после появления настоящего UUID выдаёт адресный акт с конечным перечнем файлов; первоначальное поручение само по себе не разрешает коммит. Корневой `Codex-Thread-ID: 01a07d3d-d376-7ad2-aafc-67e4c25a67eb` сохраняется в происхождении.

## Область первого среза

Новый самостоятельный SwiftPM-пакет `Приложения/FUMA/Packages/НаблюдениеДоступности/` использует существующий `КонтейнерНаблюдений`. До вызова системного API он записывает намерение, после вызова — типизированный ответ, монотонную длительность и исход. Читатель восстанавливает только подтверждённый результат; намерение без результата возвращает явно неизвестное состояние. Пакет содержит собственные исполняемую команду, тесты и понятный человеку `README.md`.

В тесте системный вызов заменяется подставной функцией. Проверяются оба булевых результата, сбой между намерением и ответом, повторное чтение и отсутствие повторного вызова при чтении. RED/GREEN предшествует реализации. Профиль раздельно измеряет системный вызов, обе записи и воспроизведение; решение об оптимизации основывается на этих измерениях. Команда проверки: `swift test --package-path Приложения/FUMA/Packages/НаблюдениеДоступности --build-system native --jobs 2`; затем проверяется release-сборка. Каждый прямой проверочный запуск проходит через отчётную обёртку собственной папки Журнала.

Предметная запись ограничена новым пакетом и новой собственной папкой Журнала. Общие `Приложения/FUMA/macOS/Package.swift`, Xcode-проект, `КонтейнерНаблюдений`, `СнимокАгентскойЗадачи`, файлы Telegram, libtorrent, старые папки Журнала, общий индекс и `Proyekcii/**` исполнитель не меняет. `СнимокАгентскойЗадачи` пока хранит синтетический тип снимка; запись факта доступности в него подменила бы контракт. Подключение к живому `FUMAXVisionSense`, охват других API и интеграция в общий runtime остаются последующими этапами.

## Доставка

Содержательный этап фиксируется в своей ветке и публикуется точным обычным push. Исполнитель открывает PR в `fuma`. Координатор проверяет исходную основу, точный diff, профиль, ограничения и документацию; принятый результат соединяет merge-коммитом с обоими родителями. Полная братиславская проекция временно отключена по команде пользователя, поэтому до её возобновления возможна контрольная точка с явным отставанием проекции, но не финальная приёмка.
