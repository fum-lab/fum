## Граница записи и проверки

Постоянный результат ограничен каноническим каталогом этого URL, новой журнальной папкой `Журнал/2026-10-04_00-32-02_MSK_сохранить-источник-настройки-Git/`, служебными составом/навигацией/recency прежнего запроса A3, `Журнал/README.md` и индексом времени Markdown. Необходимые штатному архиватору соседний `.git-config.staging-*` и приватный `fum-source-capture-*` разрешены лишь как его временные технические файлы, без включения в публикуемый состав; оставшийся staging означает незавершённую очистку, а не канонический снимок. Самостоятельные исходники, старые v3/v4, закрытые отчёты и данные процессов сохраняют байты. Публикуемые заголовки и тело очищаются штатным архиватором; его ограниченная очистка не заменяет смысловой просмотр. Не переносить приватные пути, request-id или сырые журналы Codex в канонический снимок.

Проверить фактический manifest, ссылки нового запроса и публикационную чистоту адресным контуром своей контрольной точки; сохранить длительности архивирования и обработки. Сырой HTML сохраняет конечные пробелы: для его единственного точного `response.body.html` разрешена адресная проверка Git с `core.whitespace=-blank-at-eol`, только при подтверждении равенства working/index SHA фактическому manifest. Остальные файлы проходят обычный diff check; общая Git-настройка не меняется. URL-фрагмент может создавать штатный вложенный `_fragment-*` внутри разрешённого URL-префикса. Обнаруженные `x-github-edge-region` и `x-served-by` требуют смысловой проверки публикационной чистоты; если штатная очистка не даёт допустимого снимка, сохранить точный первичник приватно, сообщить конкретный остаток и дождаться отдельного допуска на ремонт архиватора. Этот акт не разрешает незаметную ручную подмену manifest или расширение инструментального кода. Повторные сборки интерпретатора, полный smoke и повтор исторических тестов не нужны для этого материала. Отказы сохраняются; чужие области и общие настройки Git не меняются.
