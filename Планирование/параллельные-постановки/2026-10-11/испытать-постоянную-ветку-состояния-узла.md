# Испытать постоянную ветку состояния узла

Ближайшая цель — подтвердить одну настоящую запись состояния узла fum-lab/fum в отдельном дереве и читающее восстановление новым процессом без второго коммита.

Код генератора, наполнителя и нормативный допуск приняты в fuma до первого эффекта. Исходный коммит этой постановки будет выбран после её фиксации. Писатель получает отдельный видимый чат, физический worktree и настоящий native UUID. До выдачи независимого ACT2 допускается только чтение.

ROOT последовательно сохраняет полномочия A, независимый ACT2, конечное решение ROOT и назначение операции. Контроль A и контроль runtime-решения различаются. Они не подменяют друг друга. Писатель выполняет точный maker8 и preparation10 из исходного коммита: одну запись expected, проверку, фиксацию, обычный push точного OID и чтение удалённого ref. После этого новый процесс читает прежнюю операцию и подтверждает отсутствие второго коммита.

Первый expected имеет полнота=false. Допустим только один настоящий дочерний исполнитель с независимым ACT2; ROOT не выдаёт поручение самому себе. Недостаток наблюдений и неизвестные значения сохраняются явно. Эта проба не объявляет весь узел восстановленным.

Границы: refs/heads/fum-lab/fum, один писатель и один expected. ROOT остаётся в fuma. Приостановленные задачи, D22, проекция, массовое возобновление, heartbeat, dispatcher и autostart не запускаются. Код хранения повторно не реализуется.

При успехе дальнейший этап отдельно собирает свежие наблюдения текущих задач и адресные предложения восстановления. Само предложение не разрешает продолжение задачи.

Проверка имеет границу: существующая регрессия первого создания, READY, коммита и повтора новым процессом; затем отдельная живая проба. Фикстура не заменяет живого результата.
