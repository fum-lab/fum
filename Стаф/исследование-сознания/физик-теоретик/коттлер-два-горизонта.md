# Коттлер: два горизонта в одной геометрии

Проверочный пример в классической ОТО — вакуумное решение с Λ > 0, M > 0 и сигнатурой (−,+,+,+): ds² = −f(r)c²dt² + dr²/f(r) + r²dΩ², f(r) = 1 − 2GM/(c²r) − Λr²/3. Это статический участок между горизонтами, а не полная ΛCDM с материей и возмущениями. Введём m = GM/c². При 0 < 9m²Λ < 1 функция имеет два простых положительных корня r_b < r_c: чёрнодырный и космологический горизонты. f положительна между ними. Максимум расположен при r₀ = (3m/Λ)^(1/3), где f(r₀) = 1 − Λr₀²; условие положительного максимума эквивалентно 9m²Λ < 1. При равенстве корни сливаются при r = 1/√Λ, вырожденный предел Нария требует отдельного масштабирования координат; при большем значении двух положительных корней нет.

При M → 0 и фиксированном Λ малый корень стремится к нулю, а большой — к √(3/Λ): остаётся статический участок de Sitter. При Λ → 0⁺ и фиксированном M малый корень стремится к 2GM/c², а большой уходит на бесконечность: получается Шварцшильд при фиксированном конечном r. Это пределы параметров, а не динамическое исчезновение горизонтов.

Обе поверхности — причинные Killing-горизонты данной геометрии, но их причинные роли для статического наблюдателя между ними различны. В классической геометрии инвариант кривизны K = 48G²M²/(c⁴r⁶) + 8Λ²/3 конечен на обоих ненулевых корнях и расходится при r → 0 для M > 0: корни не являются локальными кривизновыми сингулярностями.

В применимом полуклассическом термодинамическом описании S_h/kB = A_h/(4ℓP²), A_h = 4πr_h²; площадь и энтропия различны. Для общей выбранной нормировки Killing-времени координат выше κ_h = c²|f′(r_h)|/2 и T_h = ħκ_h/(2πckB). Значения двух температур вообще различаются; общая нормировка не фиксируется единичной нормой на бесконечности, поскольку обычной пространственной бесконечности статического участка нет. Нельзя из их сосуществования автоматически заключить о единой температуре или равновесии: вывод зависит от состояния и постановки. См. [Gibbons и Hawking, 1977](https://doi.org/10.1103/PhysRevD.15.2738) и [Bousso и Hawking, 1996](https://doi.org/10.1103/PhysRevD.54.6312).

Этот пример не выводит ни тёмную материю, ни механизм сознания, ни переход между вселенными. Он демонстрирует два горизонта в одном известном решении; их тождественность и авторская ассоциация с тёмным сектором остаются открытыми гипотезами.
