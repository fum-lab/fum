## Цель и проверяемые решения

Создать воспроизводимый аудитор, который для адресного набора commit/tree/index/worktree-свидетельств извлекает из неизменяемых Git-объектов исходные author/committer и подписи model/effort, тему, ROOT trailer, число родителей merge, staged/actual-tree binding и различие авторства дочернего исполнителя и ROOT. Каждое решение должно ссылаться на точную версию контракта, действовавшую на момент проверяемого коммита; поздние правила не применяются ретроактивно.

Сначала проверить действующий FUMA/Swift-контракт и доступные текущие типы. Предпочесть FUMA-определение и read-only Swift Git adapter; новая реализация — Swift 6, complete strict concurrency, warnings-as-errors, Swift Testing. Добавить малую повторяемую регрессию: известный неверный и верный автор, английская и русская тема, ROOT trailer, merge-parent count и tree binding. Не дублировать уже опубликованный генератор автора.

## Начальная контрольная точка и следующий шаг

Этот коммит сохраняет только постановку и происхождение. После его readback первый проход адресно изучит действовавшие контракты автора/темы/trailer, selected ROOT source и ACK для входных примеров, а затем сверит immutable OID, parent, tree и message у ограниченного корпуса. Сначала будут опубликованы только проверяемые наблюдения и классификация; реализация следует после выявления точного пробела. Поставка этой ветки сама по себе не означает ROOT acceptance или интеграцию.
