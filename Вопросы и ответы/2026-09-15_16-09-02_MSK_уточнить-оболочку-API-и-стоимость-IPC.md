# Единый runtime FUMA и стоимость IPC

## Вопрос

````text
U nas gde-to zaplanirovano obyyedineniye vsekh zavisimostej rantajma FUMA v funkcii yedinogo ispolnyayemogo binarnika?

````

## Ответ

Прочитанная постановка FUM-STEP-0176 определяет доставку собственных исходников и воспроизводимость сборки; объединение зависимостей в один runtime-процесс она не подтверждает. Новое уточнение закрепляет цель минимизировать IPC. Горячий путь следует исследовать через прямые функции и общие буферы в одном процессе, сравнив его с исходным вариантом. Библиотека в том же процессе тоже не требует IPC для локального вызова; один файл поставки не гарантирует одного процесса.

Объединение пока не реализовано. Перед выбором состава нужны измерения переходов, сериализации, копирования, задержек и памяти, а также проверка возможности встраивания каждого компонента. Системные frameworks и SDK не обещаны частью собственного бинарника.
