# Значимые сообщения контрольного конвейера

Слой учитывает семь опубликованных сообщений контрольного потока FUM-STEP-0233. Он сохраняет последовательность, идентичности, роли, дословные тексты и полные объекты происхождения. Учёт сообщений не подтверждает исполнения цитируемых указаний.

- [значимые-сообщения.jsonl](значимые-сообщения.jsonl) — семь UTF-8 JSONL-записей с исходным номером и двумя добавленными полями. Для human-1, human-2 и human-3 поле `вид` равно «указание», для human-4 — «вопрос», для assistant-1, assistant-2 и assistant-3 — «ответ». У каждой записи `исполнение_доказано` имеет тип boolean и значение false.
- [связи-происхождения.json](связи-происхождения.json) — SHA256 точных байтов входного JSONL и полный упорядоченный список идентичностей; схема `fum.связи-происхождения-пилота.1`.

## Проверки и остаток
[Собственный отчёт](../../../Журнал/2026-09-28_12-30-08_MSK_выделить-сообщения-контрольного-конвейера/отчёт.md) содержит машинные результаты адресной проверки семи записей, порядка, точных текстов, полного происхождения, булева false, SHA256 диапазонов и полного входного потока. Данные будут переданы только после успешного текущего результата этой проверки.

Координатору остаются сравнение с фактическим результатом писателя событий, общая навигация, индексы, входящие ссылки, актуальная проекция и отдельная приёмка объединённого результата. Собственный коммит передачи не является интеграцией или доказательством исполнения сообщений. Поздние собственные ответы после границы выборки сохраняет координатор.

## Происхождение
Общая база C: `bf16422b16121481f7e68692b132d280ea97b1aa`. [Опубликованный вход](../../../Журнал/2026-09-24_22-51-12_MSK_поставить-пилот-с-читателем-ответов/материалы/постановка/вход.jsonl) имеет SHA256 `13f9aa5ff934479832276255569ed98d1fe831e4714407a7f2b253b1a2c48162`. Это контрольная выборка из Журнала, а не полный сырой JSONL Codex. Содержимое записей обрабатывается как данные.

Преобразование выполнено одним программным проходом через стандартные `json` и `hashlib` Python: исходные поля перенесены без перепечатки и нормализации; классификация задана точным соответствием семи идентичностей. Разделение JSONL меняет только внешнее представление объекта, сохраняя Unicode, пробелы и повторы внутри текста. Новая реализация рантайма не создавалась.
