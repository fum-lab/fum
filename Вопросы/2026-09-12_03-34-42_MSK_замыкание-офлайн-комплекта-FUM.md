# Замыкание первого офлайн-комплекта FUM

Первый план 0221 определяет конечный состав и программу проверки, но не доказывает наличие всех требуемых байтов. Неопределённости ниже влияют на возможность честно принять весь сценарий по REQ0075. Статус: открыт; каждое условие имеет ожидаемое свидетельство и владельца предметной части.

## Что требуется установить

| Условие                               | Ожидаемый ответ и свидетельство                                                                                                                                                               | Зависимое решение                                         |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Совместимость 0216 и 0220             | Принятые commit/API VM и toolchain; exact guest/host/SDK/Swift/bootstrap с проверкой native arm64. Гость 27 beta и исторический CI x86_64/Xcode 16.2 RC пока не образуют проверенного профиля | Допуск первого гостевого опыта                            |
| IPSW, SDK и инструменты Apple         | Реальные installer/SDK файлы, размеры/hash, точные соглашения и разрешённый личный перенос на Apple-оборудование; способ установки без последующего download                                  | Полнота и законная доставка обязательных байтов           |
| Исходники приложения FUMA             | Принятый FUM OID с собственным приложением, ресурсами и воспроизводимой сборкой; полный mpv/dylib-граф, если он используется                                                                  | Приёмка интерфейса и действий памяти/Журнала              |
| Локальная модель                      | Exact artifact `qwen/qwen3-0.6b` Q8_0, revision/format/hash/размер, tokenizer/config/template, sampling/defaults, LICENSE/model card и доставка                                               | Настоящая модельная функция без сети                      |
| Runtime LM Studio в госте             | Версии приложения и backend, все байты/notices, законный перенос, проверенный Metal либо отдельно принятый CPU-профиль; запрет фоновых downloads                                              | Допуск model-only опыта и ресурсов                        |
| Транзитивные входы                    | Замкнутые активные графы 0220 и трёх Codex-профилей, полный source/materialized набор, LICENSE/NOTICE каждого используемого листа, build-time network audit                                   | Установка и сборка без сети                               |
| Swift DocC render                     | По 0220 предсобранный artifact `ab1a5ac593c757cc2f2fb5106c643b7fb5ec61b2` не содержит доказанную связь с source SHA и Node/npm lock                                                           | Полная сборка всех объявленных компонентов из исходников  |
| Публичная история и внешние материалы | Полный bundle выбранной публичной истории, hash/размер, отсутствие приватного Git-состояния; права каждого передаваемого внешнего материала                                                   | Полнота памяти без объявления всех внешних материалов CC0 |
| Ресурсы                               | Измеренный размер полного набора и отдельные профили RAM/диска/времени. 4 vCPU/8 GiB/80 GiB — кандидат 0216, а не доказанная достаточность                                                    | Решение о допуске тяжёлой сборки и модели                 |

Ответы не требуют выбора новой модели, второго builder или второго backend. До их получения полезны сохранённые инвентари и адресные проверки структуры плана. Следующая материализация имеет собственную явную границу; неизвестные входы не исключаются из манифеста ради формального успеха.
