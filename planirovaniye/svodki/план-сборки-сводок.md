# План ежедневных сводок

**Состояние:** `PARTIAL`. Подготовлены детерминированный Swift-сборщик и один открытый частичный пример. Они пока не запускались: компилятор, runtime, полный профиль и глобальные проверки не входили в этот source-only этап.

## Контракт этапа

- Входная схема примера: `fum.daily-summary-input.v1`; выходная схема — `fum.ежедневная-сводка.1`.
- Сборщик принимает один JSON-файл, проверяет ISO 8601 и ровно 86400 секунд, применяет полуоткрытое окно `[начало, конец)`, сортирует события по разобранному instant и идентификатору, сохраняя исходную строку времени, и печатает JSON.
- Наблюдение без подтверждённого времени или вне окна не считается результатом окна; причина остаётся в `покрытие_источников.отсутствует`. Доставка, приёмка ROOT, интеграция `master` и runtime-активация — отдельные состояния.
- Для воспроизведения после отдельного допуска на компилятор: `swift planirovaniye/svodki/sobratj-svodku.swift planirovaniye/svodki/primer-vkhoda.json > planirovaniye/svodki/primer-svodki.json`. В данном этапе команда не запускалась.

## Пример и границы свидетельств

- Пример окна: `[2026-10-31T17:25:39+04:00, 2026-11-01T17:25:39+04:00)`, отображение `Europe/Saratov`.
- Вход включает закреплённую запись Sources: commit `6512dd4c3b17b27dbb764a7df7107fa92faca024`, артефакт SHA-256 `5848d1c587feac9dee8b647a88c49ce8adec77d9b5a96bcbe2e4da7173f620e7`. Время commit ровно совпадает с концом окна, поэтому пример намеренно исключает его из результатов по правой границе.
- ROOT-curated факты о F42, FUMA UI, Native Upper31 и дефектах Routine lifecycle/Names normalizer сохранены в примере с их ограничениями. У них нет подтверждённого времени события, поэтому они остаются вне выборки, а покрытие — `PARTIAL`.
- Это не полный ROOT-журнал, не статистика всех чатов/агентов, не доказательство поведения FUMA и не основание объявлять весь 24-часовой период покрытым.

## Ограничения и следующий шаг

- Адресный source-only допуск N32 разрешил пять файлов: сборщик, входной и выходной примеры, JSON состояния и этот план. Корень, ref и начальный OID сверены с grant `planning-daily-source-only-addressed-grant-20261101T1423-v1.json`.
- Исключённый Python-маршрутизатор, продолжение, recency, ROOT JSONL и legacy fallback не запускались и не объявляются пройденными. Общие проверки имеют статус `UNKNOWN`; compiler/runtime — `NOT_RUN` и требуют отдельного ресурсного допуска.
- Нет допуска на новую SQLite-выборку, ROOT-приёмку, runtime-активацию, глобальный профиль или изменение расписания `fum-5`.
- Следующий содержательный шаг — получить от владельцев подтверждённые временные метки и компактный агрегат событий с происхождением; затем отдельным допуском выполнить воспроизводимый запуск и проверить совпадение с `primer-svodki.json`.
- Доставка ветки, ROOT-приёмка, интеграция в `master` и активация остаются независимыми состояниями.
- Адресное уточнение ROOT после review убрало абсолютный путь рабочего дерева из публичного JSON, исправило сортировку времён с разными UTC-offset на сортировку по instant и добавило историю коммита по принципу add-only. Опубликованные коммиты `f9637b961…` и `16bf1590…` не переписываются; следующий коммит содержит точное поручение и root-thread trailer.
