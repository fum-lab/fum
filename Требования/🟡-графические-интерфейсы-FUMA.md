# Графические интерфейсы FUMA

<!-- FUM-REQUIREMENT-ID: FUM-REQ-0047 -->

FUMA должна поддерживать графические пути Metal, DirectX и Vulkan на применимых целевых платформах. Первоначально названный Mantle заменён на Vulkan по явному уточнению пользователя.

Графический интерфейс и набор его возможностей определяются для конкретного платформенного профиля. Требование не означает доступности всех трёх API на каждой платформе. Браузерный путь веб-версии выбирается и проверяется отдельно; наличие нативной реализации не подтверждает работу в браузере.

## Семантические связи

- **дополняет:** [запуск FUMA на целевых платформах](🟡-запуск-FUMA-на-целевых-платформах.md) — задаёт проверяемые графические пути приложения.

## Критерии проверки

- Матрица связывает платформу, устройство, API, версию и обязательные возможности. Для каждого API есть хотя бы один подтверждённый профиль выполнения.
- Диагностика показывает реально используемый путь и устройство. Прямое обращение, документированный бэкенд и слой перевода различаются; программный резервный режим обозначается явно.
- Согласованная сцена интерфейса FUMA проходит проверку отображения и взаимодействия. Межплатформенное сравнение использует обоснованный допуск, а не требует побитового совпадения всех GPU.
- Проверены отсутствие необходимых возможностей, ошибка инициализации и восстановление после потери графического устройства там, где это применимо.
- Общая логика, платформенные реализации, открытые сцены, тесты и инструкции хранятся в FUM. Точные внешние зависимости обозначены.
- RED/GREEN и профиль отдельно учитывают подготовку, кадр и ресурсы; решение об оптимизации опирается на сопоставимый сценарий.
- Веб-версия имеет собственные свидетельства работы в Safari, Chrome и Firefox. Успех нативной сборки их не заменяет.

## Уточнение общей реализации

Интерфейс FUMA по возможности полностью собственный: общие сцена и поведение описываются структурирующими операторами, платформенные исполнители используют Metal/Vulkan. Для Android планируется Vulkan; системные поверхность, ввод, доступность и жизненный цикл остаются явными платформенными адаптерами. Прежняя цель DirectX не отменена этим уточнением.

[Исходные команды](../Журнал/2026-09-15_20-33-17_MSK_принять-обновлённое-постоянное-планирование/запрос.md).

## Статус и границы

Первый графический путь Windows — Vulkan с Win32 surface; DirectX не является условием первого запуска. Для macOS, iOS, tvOS и visionOS выбран Metal. Для watchOS намерение сохраняется, но публичная документация Metal не включает эту платформу: доступный графический путь должен быть установлен отдельно. Общие сцена и операторная логика сохраняются при различии адаптеров.

Основание: [команды и ответы](../Журнал/2026-09-15_20-55-24_MSK_сохранить-медийный-план-и-запуски-платформ/отчёт.md), [Khronos](../Источники/URL/https/docs.vulkan.org/refpages/latest/refpages/source/VK_KHR_win32_surface.html/source-index.md) и [данные Apple](../Источники/URL/https/developer.apple.com/tutorials/data/documentation/metal.json/отчёт-об-извлечении.md).

Статус — `🟡`: принято и запланировано. Поддержка трёх графических API пока не подтверждена. Матрица и первые проверки входят в [платформенный план FUMA](../Планирование/карточки-шагов/🟡-FUM-STEP-0182-определить-платформенные-сборки-и-первый-сценарий-FUMA.md).

Существующее [требование Metal для интерфейса Apple silicon](🟡-отрисовка-интерфейса-через-Metal.md) сохраняет свою специальную область и прежние ограниченные свидетельства.
