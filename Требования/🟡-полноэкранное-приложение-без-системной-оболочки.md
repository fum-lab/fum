# Полноэкранное приложение без системной оболочки

[Коробочная реализация FUM](../Глоссарий/коробочная-реализация-FUM.md) на Mac Studio должна предоставлять человеку полноэкранное приложение без рамки окна, внутри которого находится весь основной [интерфейс FUM-узла](../Глоссарий/интерфейс-FUM-узла.md). После входа в рабочую сессию человек не должен нуждаться в Finder или стандартном рабочем столе для обычного взаимодействия с FUM.

## Критерии проверки

- приложение занимает доступную область каждого назначенного экрана без стандартной рамки окна;
- основной рабочий сценарий выполняется внутри приложения;
- выход к системной среде остаётся возможен только через явно предусмотренный административный путь.

## Статус и границы

Статус `🟡`: требование принято и запланировано, проверенная реализация ещё не подтверждена. Требование начинается после запуска пользовательской сессии и не распространяется на загрузочный экран, Recovery и boot picker.
