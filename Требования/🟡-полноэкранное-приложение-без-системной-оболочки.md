# Полноэкранное приложение без системной оболочки

[Коробочная реализация FUM](../Глоссарий/коробочная-реализация-FUM.md) на Mac Studio должна предоставлять человеку полноэкранное приложение без рамки окна, внутри которого находится весь основной [интерфейс FUM-узла](../Глоссарий/интерфейс-FUM-узла.md). После входа в рабочую сессию человек не должен нуждаться в Finder или стандартном рабочем столе для обычного взаимодействия с [FUM](../Глоссарий/FUM.md).

## Семантические связи

- **состоит из:** [отрисовки интерфейса через Metal](🟡-отрисовка-интерфейса-через-Metal.md) — графический слой приложения использует аппаратный путь Metal.
- **состоит из:** [скрытия Dock и строки меню](🟡-скрытие-Dock-и-строки-меню.md) — отсутствие видимой системной оболочки включает скрытие системных панелей.
- **дополняется:** [максимально сырой записью событий устройств ввода](🟡-максимально-сырая-запись-событий-устройств-ввода.md) — пользовательский контур получает воспроизводимый поток действий человека до их смысловой интерпретации.
- **требуется для:** [автозапуска интерфейса](🟡-автозапуск-интерфейса.md) — является приложением, которое должен открыть механизм автозапуска.
- **требуется для:** [фонового сервиса вычислений и восстановления интерфейса](🟡-фоновый-сервис-вычислений-и-восстановления-интерфейса.md) — является интерфейсом, состояние которого сервис наблюдает и восстанавливает.
- **требуется для:** [управляемого жёсткого киоск-режима](🟡-управляемый-жёсткий-киоск-режим.md) — является приложением, в котором киоск-режим удерживает человека.

## Критерии проверки

- приложение занимает доступную область каждого назначенного экрана без стандартной рамки окна;
- основной рабочий сценарий выполняется внутри приложения;
- выход к системной среде остаётся возможен только через явно предусмотренный административный путь.

## Статус и границы

[Статус требования FUM](../Глоссарий/статус-требования-FUM.md) — `🟡`: требование принято и запланировано, проверенная реализация ещё не подтверждена. Требование начинается после запуска пользовательской сессии и не распространяется на загрузочный экран, Recovery и boot picker.
