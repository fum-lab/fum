# Работа FUMA с децентрализованными сетями

<!-- FUM-REQUIREMENT-ID: FUM-REQ-0048 -->

FUMA должна предусматривать работу с Torrent, Tor, I2P, Bitcoin и подключение других сетей через расширяемые адаптеры. Возможности и результат каждой интеграции проверяются отдельно.

Сети не считаются взаимозаменяемыми: общий интерфейс сохраняет особенности передачи данных, связи и операций с реестром. Слово «другие» требует расширяемости, но не подтверждает поддержку произвольной сети заранее. Для обозначения Torrent исходным кандидатом является BitTorrent; точный протокол и сценарий закрепляются до реализации.

## Семантические связи

Прямые семантические связи пока не установлены.

## Критерии проверки

- Для каждой названной сети определены конкретные операции, протокол и версии, режим использования существующего узла либо управляемого процесса, совместимость с платформами FUMA.
- Адаптер сообщает возможности, состояние, результат, ошибки и ограничения. Повтор, отмена и восстановление имеют проверенный контракт.
- Приём данных, публикация или раздача, управление узлом, подписание и отправка транзакций различаются. Операция использует назначенные права; само подключение не разрешает публикацию приватной памяти или распоряжение средствами.
- Внешние данные проверяются перед включением в память. Происхождение и результат операции сохраняются в Журнале без секретов.
- Проверены недоступность узлов, повреждённые данные, разрыв связи, повтор, восстановление и ограничения ресурсов. Заявленные свойства приватности проверяются отдельно.
- Реализация и открытые фикстуры находятся в FUM. Адресные тесты работают без внешней сети по умолчанию; живая совместимость подтверждается отдельным сценарием, профилем и решением об оптимизации.
- Подключение нового адаптера не требует подменять семантику уже поддерживаемых сетей; человек видит поддерживаемые действия и способы запуска.

## Статус и границы

Статус — `🟡`: принято и запланировано. Первое действие — [определить адаптеры и сценарии](../Планирование/карточки-шагов/🟡-FUM-STEP-0183-определить-адаптеры-децентрализованных-сетей.md). Работа интеграций пока не подтверждена. Для Bitcoin объём операций задаётся явно; финансовые действия не выводятся из общего требования совместимости.

## Первый планируемый файловый профиль I2P

Первый профиль — получение открытого объекта FUM по BitTorrent через встроенную поддержку SAM в libtorrent-rasterbar. Собственный Swift-адаптер задаёт параметры, управляет операцией и отображает состояние; транспорт I2P выполняет библиотека. Метаданные torrent, ожидаемый хэш объекта, предел размера и место сохранения задаются явно. Будущий результат — проверенный локальный файл либо различимый отказ, с отменой и допустимым восстановлением. Это план, а не уже реализованная интеграция.

I2P-профиль использует явно заданный локальный endpoint SAM через i2p_hostname/i2p_port. allow_i2p_mixed=false и torrent_flags::i2p_torrent задаются и проверяются по точному контракту выбранной ревизии. Одних параметров недостаточно: будущая приёмка наблюдает фактическое отсутствие нежелательных соединений clearnet, DNS, DHT, трекеров, web seeds и peer-соединений вне принятой I2P-области. Ошибочные или смешанные метаданные не дают незаметного переключения в обычный Интернет. Отказ маршрутизатора не блокирует остальные локальные функции FUMA.

Публичный Destination, приватные ключи, прикладная идентичность FUM и состояние возобновления различаются. До реализации проверяется, как выбранный pin библиотеки поддерживает требуемый режим идентичности и её восстановление; отсутствующий API не выдумывается. Потеря ключа не разрешает молча создавать новую постоянную идентичность. Диагностика не публикует ключи и приватное состояние, успешная запись в сокет не доказывает приём объекта.

Собственный SAM 3.1 STREAM-клиент поверх SwiftNIO остаётся отдельным расширением для сервисов вне BitTorrent; первый файловый сценарий не дублирует встроенный транспорт libtorrent. Установка и управление маршрутизатором, HTTP/outproxy, SOCKS, I2CP, датаграммы, мобильная упаковка и обслуживание чужого трафика не входят автоматически. Все прежние критерии и остальные сети сохраняются.
