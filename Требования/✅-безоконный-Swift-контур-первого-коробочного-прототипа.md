# Безоконный Swift-контур первого коробочного прототипа

<!-- FUM-REQUIREMENT-ID: FUM-REQ-0019 -->

Первый инженерный [коробочный прототип FUM](../Глоссарий/коробочный-прототип-FUM.md) должен быть минимальным локальным Swift-контуром, полезный сценарий которого выполняется без WindowServer и GUI-фреймворков. Безоконность относится к начальному bootstrap, а не запрещает будущий интерфейс.

## Семантические связи

- **требуется для:** [воспроизводимого штатного пополнения памяти](🚧-воспроизводимое-штатное-пополнение-памяти.md) — задаёт собственный исполняемый носитель первого сценария памяти.

## Критерии проверки

- самостоятельный SwiftPM-пакет собирается без внешних зависимостей;
- исполняемый продукт и безопасная команда запуска работают без AppKit, SwiftUI, сети и реальной LLM;
- локальная фикстура проходит через внутренний API памяти и выдаёт канонический машинно читаемый отчёт;
- автономные тесты подтверждают детерминизм и отказ на недопустимом входе;
- README явно отделяет инженерный прототип от пользовательского релиза FUM.

## Статус и границы

[Статус требования FUM](../Глоссарий/статус-требования-FUM.md) — `✅`: критерии подтверждены [SwiftPM-прототипом воспроизводимого пополнения памяти](../Прототипы/воспроизводимое-пополнение-памяти/README.md) и его автономными тестами. Результат не подтверждает долговременное восстановление, реальный модельный провайдер или GUI.
