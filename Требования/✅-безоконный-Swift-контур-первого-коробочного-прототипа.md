# Безоконный Swift-контур первого коробочного прототипа

<!-- FUM-REQUIREMENT-ID: FUM-REQ-0019 -->

Первый инженерный [коробочный прототип FUM](../Глоссарий/коробочный-прототип-FUM.md) должен быть минимальным локальным Swift-контуром, полезный сценарий которого выполняется без WindowServer и GUI-фреймворков. Собственный GUI FUM может отсутствовать на всей начальной инженерной стадии: внешняя сессия Codex служит достаточной поверхностью для запуска, анализа и тестирования последовательных безоконных срезов через версионированные локальные команды и машиночитаемые результаты.

Безоконность относится к инженерному bootstrap и не запрещает будущий пользовательский интерфейс. Codex при этом остаётся внешним стендом: его агентский цикл и скрытое состояние сессии не становятся собственным runtime, памятью или интерфейсом FUM.

## Семантические связи

- **требуется для:** [воспроизводимого штатного пополнения памяти](🚧-воспроизводимое-штатное-пополнение-памяти.md) — задаёт собственный исполняемый носитель первого сценария памяти.

## Критерии проверки

- самостоятельный SwiftPM-пакет собирается без внешних зависимостей;
- исполняемый продукт и безопасная команда запуска работают без AppKit, SwiftUI, сети и реальной LLM;
- сборка, запуск, replay, восстановление и тесты реализованных срезов доступны Codex неинтерактивными командами без ручных экранных действий;
- входы передаются через аргументы, стандартный ввод или версионированные файлы; снимок и трасса имеют устойчивую машиночитаемую форму, а отказ различим по коду завершения и стабильной диагностике;
- локальная фикстура проходит через внутренний API памяти и выдаёт канонический машиночитаемый отчёт;
- автономные тесты подтверждают детерминизм и отказ на недопустимом входе;
- хотя бы один сквозной прогон из внешней сессии Codex сохраняет вызванные команды, результаты проверок и границу доказанного;
- README явно отделяет инженерный прототип от пользовательского релиза FUM.

## Статус и границы

[Статус требования FUM](../Глоссарий/статус-требования-FUM.md) — `✅`: критерии подтверждены [SwiftPM-прототипом воспроизводимого пополнения памяти](../Прототипы/воспроизводимое-пополнение-памяти/README.md), его автономными тестами и воспроизводимыми запусками из рабочих сессий Codex. Результат не подтверждает собственный агентский runtime FUM, реальный модельный провайдер или пользовательский GUI.
