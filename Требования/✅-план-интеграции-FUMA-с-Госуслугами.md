# План интеграции FUMA с Госуслугами

<!-- FUM-REQUIREMENT-ID: FUM-REQ-0070 -->

Подготовить проверяемый план интеграции FUM/FUMA с инфраструктурой Госуслуг для одного конкретного пользовательского сценария.

План различает вход через ЕСИА и получение разрешённых атрибутов, взаимодействие с конкретным сервисом ЕПГУ и обмен определёнными видами сведений через СМЭВ. Для выбранного сценария устанавливаются система подключения, оператор информационной системы, условия участия, необходимые данные и полномочия; единый универсальный публичный API не предполагается.

## Критерии проверки

- Выбран и обоснован один сценарий с понятными участниками, действием и ожидаемым результатом; он является предложением первого этапа, а не разрешением действующего подключения.
- Заполнена матрица «сценарий → система → оператор ИС → допуск → данные и полномочия → тестовая среда → приёмка».
- Для существенных условий указаны официальные документы, доступные версии и граница подтверждения. Недоступное содержание и исторические версии отделены от подтверждённых текущих условий.
- Указаны предполагаемый оператор, необходимый статус заявителя и основания участия. Неизвестные оператор, услуга, согласие или допуск сохранены как конкретные вопросы.
- Подготовлен конечный план локального адаптера или симулятора на синтетических данных, затем проверки в официальной тестовой среде при подтверждённом доступе.
- Критерии приёмки различают правильность локальной модели, подтверждение официального протокола и право на эксплуатационное подключение.
