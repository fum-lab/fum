# Требования FUM

Этот каталог хранит атомарные [карточки требований FUM](../Глоссарий/карточка-требования-FUM.md). Одна карточка формулирует одно требование, даёт критерии его проверки и сохраняет путь к исходному запросу и материалу, из которого оно выведено.

Первый эмодзи имени файла показывает [статус требования FUM](../Глоссарий/статус-требования-FUM.md):

- `⚪` — черновик: формулировка ещё требует решения;
- `🟡` — принято и запланировано: требование зафиксировано, но проверенная реализация не завершена;
- `🚧` — реализуется;
- `✅` — реализовано и подтверждено указанной в карточке проверкой;
- `⛔` — заблокировано;
- `🗑️` — снято с сохранением истории и основания.

Статус меняется переименованием файла через `git mv`. Эмодзи не заменяет содержательное основание: карточка со статусом `✅` обязана ссылаться на проверку, а `⛔` и `🗑️` — объяснять блокировку или снятие.
