# План воспроизводимой macOS VM для FUMA

<!-- FUM-REQUIREMENT-ID: FUM-REQ-0071 -->

Подготовить конечный план профиля macOS для общего инструмента виртуальных машин FUMA на Apple Silicon. Первый планируемый пилот связывает совместимый закреплённый образ, воспроизводимую установку, готовность гостя и один явно названный сценарий FUMA.

Общий жизненный цикл может использовать принятые части Linux-инструмента: проверку ресурсов, отдельное локальное состояние, владение, ограниченные ожидания, SSH, остановку и повтор. Переносимость каждой части подтверждается отдельно; наличие Linux-прототипа не доказывает macOS backend.

## Критерии проверки

- Задан паспорт пилота: точные host, SDK и Swift, происхождение IPSW, версия/build/хэш фактического образа, минимальные ресурсы и совместимость. Не выбранный или не проверенный образ остаётся неизвестным; latestSupported служит обнаружению кандидата.
- Различены создание конфигурации, установка, первый запуск с provisioning, готовность SSH, выполнение сценария, штатная остановка и повтор. Для каждой стадии заданы вход, результат, предел ожидания, ошибка и допустимое восстановление.
- Указаны сохраняемые при повторе hardwareModel, machineIdentifier, auxiliaryStorage и диск; другая машина получает собственную идентичность. Неизвестные существующие диски не пересоздаются при отказе.
- Проверены требования выбранного способа provisioning и его доступность на точных версиях host/guest. Переданный исследовательский срез macOS 27+ Beta не заменяет проверку конкретного окружения; Linux NoCloud/VSOCK не считается готовым каналом macOS.
- План проверки SSH подтверждает нужного гостя, архитектуру, build и доверенную идентичность. Доступ к общему каталогу задаётся явно и по умолчанию ограничивается чтением.
- Выбран один гостевой сценарий FUMA из точного клона FUM с объявленными зависимостями. Сборка, запуск и полезный результат проверяются раздельно; применяется существующая подготовка macOS, FUM-STEP-0179.
- Предусмотрены воспроизводимые фикстуры и отдельная настоящая проверка VM; получение образа, установка, первый запуск, SSH, сценарий и повтор имеют отдельные профили времени.

## Статус и границы

Статус требования — `🟡`.

Текущий результат — постановка и план пилота, а не реализация backend или запуск VM. Образ не скачан, машина не создана, provisioning не выполнен. Перед использованием Apple API требуется адресная сверка официальной документации и конкретного окружения. Собственные исходники последующей реализации остаются в монорепозитории FUM; образы, диски и секреты — вне Git.
