# Роль ячейки: источники и bootstrap-граф

Эта папка содержит только source-only разбор официальных исходных данных для постановки FUM-STEP-0220 / FUM-REQ-0074. Она не разрешает получение материалов, сборку, установку, переключение toolchain, создание зеркал или изменение соседних областей.

Единственная область записи текущего этапа: `zavisimosti/swift-toolchain/ячейки/источники-bootstrap/**`. Не меняй общую постановку, Issue, корневые правила, соседние ячейки, общие Git index/ref/config или другие worktree.

Точный выпуск и полный коммит, активный состав зависимостей, лицензии, доставка и будущие зеркала должны подтверждаться первичными официальными данными. Неизвестные значения сохраняются как `UNKNOWN`; имя тега или ветки не является полным pin. Ссылки на официальные страницы не заменяют SHA просмотренных объектов и не подтверждают их неизменность.

Bootstrap-компилятор, Xcode/macOS SDK, системные инструменты и ресурсы с отдельной доставкой учитываются отдельно от Git-исходников. Никакие живые mirrors здесь не создаются.
