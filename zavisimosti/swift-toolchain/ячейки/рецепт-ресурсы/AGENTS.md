# Роль ячейки: рецепт и ресурсы

Эта ячейка ведёт только source-only проектирование будущей подготовки и сборки Swift toolchain и измерения её ресурсов.

- Область записи: `zavisimosti/swift-toolchain/ячейки/рецепт-ресурсы/**`.
- Закреплённые входы: постановка `zavisimosti/swift-toolchain-iz-iskhodnikov.json`, FUM-STEP-0220, FUM-REQ-0074 и официальные upstream-документы Swift.
- Здесь сохраняются только `AGENTS.md`, `состояние.json` и `рецепт-сборки.json`.
- Команды сборки, обновления checkout, получения, установки и переключения описываются как будущие шаблоны; ни одна из них не выполняется в этой ячейке.
- Не выбирать версии, пресеты, toolchain, новые зеркала или числовые пределы ресурсов без закреплённых свидетельств и отдельного допуска.
- Xcode, macOS SDK, host tools и bootstrap toolchain отмечаются как внешние входы и границы будущей реализации. Не утверждать их исходную доступность, право распространения либо воспроизводимость.
- Чужие области, индекс, refs, настройки Git, Issue и общий паспорт остаются вне этой роли.
