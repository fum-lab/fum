# Роль ячейки: личность toolchain и переключение потребителей

Основа: `57ba89688b523eecc548a2b85b83843849206fba` (`fum.постановка-самосборного-swift-toolchain.1`), FUM-STEP-0220 и FUM-REQ-0074. Владелец — дочерний исполнитель корня; идентификатор корневого чата — `01a07d3d-d376-7ad2-aafc-67e4c25a67eb`.

Разрешены только три файла этой папки: `AGENTS.md`, `состояние.json`, `переключение-потребителей.json`. Результат — проект контракта, не действующий инструмент переключения и не одобрение будущего перехода. Пользователей, приложение, shell profile, Xcode selection и глобальный `PATH` сейчас не менять.

Контракт должен привязать локатор к конкретному физическому корню, закреплённой source/build provenance, полным version/build identity и хэшам исполняемых компонентов и ресурсов. Swift compiler/driver/resource directory/stdlib/SwiftPM отделяются от Apple SDK, linker и host tools. Хэш каталога должен определяться устойчивой версионированной процедурой с путями, типами файлов, байтами и symlink-целями; одного имени каталога, `--version`, symlink или одного хэша `swift` недостаточно.

Потребитель допускается только по точному исходному `Package.swift`/source path и будущей зафиксированной версии после identity-verification. Для каждого указать отдельный выбор, readback реально выбранных путей/версий/хэшей, сравнение со штатной конфигурацией на том же точном исходном снимке и откат к ранее зафиксированной конфигурации. Все критерии — предложение. Не запускать SwiftPM, сборку, тесты, Xcode, Swift-команды, Python или локальные проверки пользователя. Статический анализ ограничен текущим pinned Git tree; отсутствие materialization `Зависимости/LinguisticKit` не является выводом о невозможности собрать всё приложение.

Не использовать ROOT JSONL, legacy admission, загрузки, новые fork, переключение, пользовательские кэши/настройки, чужие checkout/ref/index/config. Все неизвестные явно остаются `UNKNOWN`. Git-коммит и публикация ограничены только тремя указанными файлами и назначенным ref.
