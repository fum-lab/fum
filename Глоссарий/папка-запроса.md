# Папка запроса

Папка запроса — адресуемая запись [журнала работ](журнал-работ.md), которая объединяет один [исходный запрос](исходный-запрос.md), отчёт связанной [рабочей сессии](рабочая-сессия.md) и принадлежащие только этому запросу материалы. Она хранится непосредственно в `Журнал/`, а её имя точно соответствует прежним правилам имени файла запроса без расширения `.md` и обязательно начинается с префикса московского времени `YYYY-MM-DD_HH-MM-SS_MSK`. Историческое имя может состоять только из временного префикса; новое имя дополняется кратким названием запроса в kebab-case.

Внутри папки `запрос.md` сохраняет дословный пользовательский ввод, `отчёт.md` описывает результат сессии, а необязательный каталог `материалы/` содержит артефакты с одним доказанным владельцем-запросом. Исторический запрос, созданный до появления отчётов журнала, не получает вымышленный `отчёт.md` задним числом.

Такая запись следует принципу массива структур: связанные элементы находятся рядом и адресуются общей идентичностью вместо синхронизации нескольких параллельных каталогов по совпадающим именам. Производная документация, глоссарий, требования, вопросы, планирование, код, прототипы и канонические URL-источники сохраняют собственную тематическую идентичность и связываются с папкой запроса ссылками, а не копируются в неё.
