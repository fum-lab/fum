# TDD

TDD - метод разработки, при котором ожидаемое поведение сначала фиксируется тестом или проверкой, затем реализация доводится до прохождения этой проверки, а после этого код и тесты уточняются без потери проверяемого контракта.

В [FUM](FUM.md) TDD используется как рабочий порядок для создания и изменения [автоматизаций FUM](автоматизация-FUM.md). Такой порядок помогает сохранять автоматизации локально воспроизводимыми в [памяти FUM](память-FUM.md): у поведения появляется явный проверочный пример, команда запуска и история изменения результата.
