# Описание FUM для адресата

Описание FUM для адресата - производный материал, который пересобирает содержание [документации](производная-документация.md) и [глоссария проекта](глоссарий-проекта.md) под задачи конкретного адресата или аудитории.

Такое описание помогает показать [FUM](FUM.md) с нужного угла: для инвесторов, исследователей, инженеров, пользователей, партнёров, регуляторов или других групп. Оно не заменяет [производную документацию](производная-документация.md) и не становится самостоятельным источником требований: требования продолжают выводиться из [исходных запросов](исходный-запрос.md), документации и коммитов.

Каждое устойчивое описание должно фиксировать адресата, цель, источники, примененную [автоматизацию FUM](автоматизация-FUM.md), статус обновления и ограничения. Если описание добавляет новую проектную мысль, которую нужно считать требованием, эта мысль должна быть отдельно перенесена в документацию или глоссарий через обычную цепочку требований.

Устойчивое описание не обновляется точечной ручной правкой. Его создают или исправляют через явный вызов закреплённой автоматизации и пересборку результата, чтобы изменение описания одновременно проверяло работоспособность этой автоматизации.
