# Агентский цикл

Агентский цикл в FUM - повторяемый контур работы, в котором агент принимает цель и состояние, выбирает действие, получает наблюдение, обновляет память и решает, продолжать ли работу, завершить ее, перейти в другую ветку или передать задачу другому агенту.

Для [FUM](fum.md) агентский цикл является не только механизмом исполнения, но и источником материала для [памяти FUM](pamyat-fum.md): следы наблюдений и действий должны становиться основой для поиска [паттернов памяти](pattern-pamyati.md).
