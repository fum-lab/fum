# Глоссарий проекта

Глоссарий проекта - отдельная часть памяти репозитория FUM, где ключевые термины фиксируются в виде коротких статей. Один термин хранится в одном Markdown-файле, а индекс глоссария связывает эти файлы между собой.

Глоссарий нужен, чтобы [производная документация](proizvodnaya-dokumentaciya.md) использовала единый язык и могла ссылаться на определения без повторного объяснения каждого понятия.
