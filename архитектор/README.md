## Предложения архитектора

1. Восстанавливать проверочный контур через ограниченный независимый bootstrap с закреплёнными входами и полномочиями; сохранять закрытый вход до проверки. Проверка кандидата не должна зависеть от самого недопущенного кандидата.
2. Согласовать всех участников общей блокировки, включая возврат писателя; доказать отсутствие старых писателей либо совместимость перехода, затем проверить конкуренцию, ссылки, сигналы и восстановление. Одной замены каталога недостаточно.
3. Инвентаризировать границы среды, временных каталогов и дочерних Git-вызовов во всех затронутых сценариях. Допускать явные входы и проверять отказы на неизвестных значениях, не раскрывая частные данные.
4. Отдельно восстановить совместимость маршрутизатора и P.1 с закреплёнными ресурсами и прежним профилем; ограниченные успехи не переносить на новый снимок.
5. Для сохранения контрольной точки определить разрешённое чтение источника либо сначала создать и проверить доверенный непрерывный индекс. Произвольная выборка не доказывает полноты. Фактическое восстановление Stop требует отдельной проверки порядка процессов, установки и события.

## Проект устойчивой петли

Постановка → допуск → исполнение → проверка → приёмка → Git-память → следующий шаг. На каждом переходе сохраняются владелец, основание допуска, точные входы, наблюдённый результат, свидетельство и условие продолжения. Неизвестный исход остаётся UNKNOWN; намерение не доказывает эффект. Повтор допустим только по проверенному контракту конкретной операции, а потреблённый одноразовый результат без вывода остаётся terminal HOLD.

Проверка, коммит, удалённая доставка, приёмка, интеграция и runtime подтверждаются отдельно. При ошибке фиксируются исходный отказ, причина и безопасный следующий шаг. Отсутствие прогресса выявляется сравнением наблюдений одного поручения, но само по себе не разрешает повтор или автоматический запуск. После принятого результата архитектор предлагает следующее проверяемое улучшение; это проект ручной обратной связи, а не доказанная автоматизация.
