# FUM-MAP-AUTO-01: Локальные автоматизации FUM

Эта карточка фиксирует локальные автоматизации FUM как исполняемый слой памяти. Автоматизация превращает повторяемую процедуру в проверяемый орган действия или восприятия: у неё есть входы, команда запуска, тесты, наблюдаемый результат и граница применимости.

## Карточка

- Идентификатор: `FUM-MAP-AUTO-01`.
- Объект сопоставления: локальные автоматизации FUM.
- Слой: исполняемый слой памяти.
- Наблюдатель: агент рабочей сессии, сопровождающий репозиторий человек и будущий FUM-узел, способный запускать локальные проверки.
- Соответствие общей схеме: скрипт выполняет действие, тест фиксирует ожидаемое поведение, fixture задаёт наблюдаемую среду, проверка выполняет отбор, служебные следы вроде `FUM-MD-RECENCY` связывают результат с состоянием памяти.
- Сохраняемые инварианты: процедура повторяема локально без секретов по умолчанию, поведение описано, результат проверяем, изменения проходят через TDD при развитии автоматизации.
- Потери наблюдаемости: автоматизация видит только формализованные входы и не заменяет смысловую ответственность рабочей сессии; внешние сервисы и модели могут требовать локального проверяемого слоя вместо полного воспроизведения.
- Переход к источнику: общие требования раскрыты в документе [Воспроизводимые автоматизации FUM](../17-воспроизводимые-автоматизации.md), а конкретные инструменты описаны в папке [Инструменты](../../Инструменты/README.md).
- Границы аналогии: карточка применима к устойчивым повторяемым процедурам; разовая ручная операция становится кандидатом на автоматизацию только после явной оценки повторяемости.
- Проверка: у автоматизации должны быть локальная команда запуска, тесты или проверочный сценарий, описание ограничений и запись в реестре инструментов, если она повторно используется в рабочих сессиях.
- Статус уверенности: частично закреплено существующими автоматизациями; нужна единая машинно проверяемая карточка для класса автоматизаций.
