# Прямая проверка P.1 и оставшиеся ограничения

Независимый обзор установил: прямая проверка уже существующей пары не вызывает установщик новой пары. Это устраняет только предполагаемую зависимость от установки новой пары; само по себе оно не разрешает запуск проверки и не подтверждает исполнение среза FUMA → Swift.

Общий маршрутизатор, публичная отчётная обёртка, полномочие на lock и требование Creator v4 остаются отдельными блокерами. Фактический терминальный результат опытной схемы штатный reader отклонил; этот отказ нельзя выдавать за успешную приёмку. Конкретный следующий шаг — совместно с наблюдателем установить по действующему контракту причину отказа reader и условия повторного допуска для существующей пары, сохраняя точный терминальный результат и не повторяя потреблённые эффекты. Проверка этой связи не подменяет допуск маршрутизатора, обёртки, lock или Creator v4.

Решение Направляющего «Пока не восстанавливать» сохраняется: 62 файла не материализовывать, маршрутизатор не запускать до нового прямого указания. Предметный граф и исполнение FUMA → Swift остаются NOT_RUN; не читать host ENV, ROOT JSONL и закрытые Source/captures, Unicode290 — terminal HOLD.
