# Проект: целое плюс один в Swift

Это проект ограниченного FUMA-оператора, не доставленный FUMA-код. Он принимает JSON-целое `n` от −1000 до 999, вычисляет `n + 1` в FUMA и формирует Swift `print(...)` с LF. Проектные байты — UTF-8 без BOM, одна строка JSON с одним завершающим LF:

```json
{"схема":"fum.определение-оператора.2","идентификатор":"увеличить-и-напечатать","версия":1,"правила":[],"определения":[],"шаги":[{"идентификатор":"вычислить","оператор":"вычислить-JSON","аргументы":{"граф":{"схема":"fuma.граф-JSON.2","числа":"целые64-без-дробей","переменные":[],"результат":["соединить","print(",["в-строку",["сложить",["потребовать-диапазон",["переменная","вход"],-1000,999],1]],")\n"]}}}]}
```

Независимый оракул для нового входа `41` — UTF-8 декодированного фактического Swift `print(42)\n`, hex `7072696e74283432290a`; stdout отдельно собранной программы `42\n`, hex `34320a`. Это ожидаемые байты, не результаты исполнения. Для 999 ожидается `print(1000)\n`; для 1000 и −1001 — отказ `диапазон-JSON` при успешном разборе графа. Прямой Probe статически возвращает `схема` для bool; это не код ошибки другого standalone-ядра. Обработка других числовых представлений не проверена.

Граф, новый ввод, сборка, исполнение и независимая приёмка — NOT_RUN. Происхождение исполняемого Probe и допуск его сборки и запуска пока UNKNOWN. Нужно заранее сохранить фактические байты и SHA графа, входа и оракулов, установить владение и историю эффектов, допущенный маршрут, затем зафиксировать исходники, бинарник и терминальный результат каждой стадии. После FUMA дважды декодировать фактическое наблюдение, сверить именно выданный Swift и отдельно собрать его без `-parse-as-library`; только его вывод сравнивать с оракулом. Не повторять чужие или закрытые Source/captures. Ранее запрещённые 62 файла не восстанавливать; Unicode290 — terminal HOLD.
