# Индексы памяти FUM

Этот каталог хранит производные навигационные индексы [памяти FUM](../Глоссарий/память-FUM.md), которые собираются локальными [автоматизациями FUM](../Глоссарий/автоматизация-FUM.md) и помогают видеть состояние репозитория поперёк обычной структуры папок.

Индексы не заменяют [исходные запросы](../Глоссарий/исходный-запрос.md), [производную документацию](../Глоссарий/производная-документация.md), [глоссарий](../Глоссарий/глоссарий-проекта.md) или [журнал работ](../Глоссарий/журнал-работ.md). Они являются навигационным слоем поверх уже сохранённых материалов.

## Доступные индексы

- [Markdown-файлы по времени редактирования](markdown-файлы-по-времени-редактирования.md) - автоматически обновляемый список всех `.md`-файлов от свежих к более старым.
