# Снимок цикла Codex на FUMA

Пакет выполняет один чистый шаг: проверенная проекция метаданных → собственный снимок → собственное событие snapshotObserved → семантическая дельта. Принимается конечный профиль первой фактической страницы Codex: один ход, восемь известных типов элементов, точные ключи, неизвестные модель и усилие, неподключённый поток app-server. Это не общий сборщик состояния Codex.

[Исходник](определение.json) является первичным FUMA-кодом. Восемь файлов [замороженных ожиданий](примеры/) сохраняют историческую отметку NOT_RUN; [фактические результаты](результаты-проверок.json) находятся отдельно. Все восемь случаев реально выполнены один раз: семь полных результатов совпали, восьмой дал ожидаемые код завершения 1, типовой код «схема» и пустой stdout. Новый девятый вызов по ранее сохранённой фактической проекции также совпал с полным подготовленным ожиданием.

[Фактический публичный снимок](снимок-фактической-проекции.json) исключает идентификатор нативного хода, тела сообщений, рассуждения, аргументы инструментов и частные пути. Сохраняются хэши источников, неизвестные поля и происхождение. Его Git-привязка относится к историческому наблюдению, а не к HEAD текущего исполнения. Событие snapshotObserved — собственная оболочка наблюдения, не событие нативного потока app-server.

## Воспроизведение

Из собранной загрузочной основы памяти структурирующих операторов передайте команду исполнить, параметры --определение с этим определением и --вход текст, затем один входной UTF-8 JSON через stdin до EOF. Вход берётся из поля «вход» выбранного файла примера. Проверьте схему fum.наблюдение-оператора.2, тип результата «текст», разберите целое JSON-значение результата и сравните его целиком с ожидаемым. Для восьмого случая проверяется объявленный типовой отказ, а не весь текст ошибки. Загрузочная основа и её сборка описаны в [существующем пакете](../../../Прототипы/память-структурирующих-операторов/README.md).

## Граница входа и публикации

Корень до каждого запуска проверяет ссылкаПроекции на ровно три поля: имя, байтов, sha256. Он независимо связывает реальный файл проекции с его хэшем и вычисляет SHA-256 UTF-8 идентичности хода. FUMA не имеет выдуманного SHA-примитива. Источник сохраняет всю ссылку проекции в собственном событии; отдельного exact3-guard внутри Source нет. Поэтому текущий успех конечного профиля не доказывает самостоятельный универсальный санитайзер. Произвольный вход и целое CLI-наблюдение не публикуются автоматически.

Четыре ошибочных профиля возвращают УДЕРЖАНО без нового снимка/события/дельты. Ссылки task/function/assignment/plan — явные Root-provided данные либо UNKNOWN, а не нативные факты. Неизвестные незавершённые эффекты не считаются доказанно пустыми. EffectsAllowedfalse сохраняется во всех результатах. Восстановление агента, Git-коммиты событий, новый native read и Host/GPU этим пакетом не выполняются.
