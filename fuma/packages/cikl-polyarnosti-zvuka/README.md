# Цикл полярности звука на FUMA

Первичный оператор `цикл-полярности-звука@2` выражает проверяемую композицию существующего структурирующего оператора FUM. Разбор получает исходные байты, изменение строит целевую модель, сборка порождает новые байты, повторный разбор наблюдает их, а сравнение сопоставляет наблюдение именно с целью.

## Состав

- [Исходник](определение.json): GraphJSON.2, девять замкнутых ацикличных определений.
- [Текущий контракт V2](контракт.json): схемы входа/выхода, явное состояние петли и границы приёмки.
- [Проверки](примеры/): шесть полных неизменённых V2-ожиданий и отдельные входы для CLI. Историческая метка EXPECTED_ONLY_NOT_RUN в исходных ожиданиях сохранена.
- [Фактические результаты](результаты-проверок.json): полные данные сохранённого finite6, отдельно от frozen ожиданий.
- [Структурирующий оператор FUM](../../../Глоссарий/структурирующий-оператор-FUM.md): общая сущность и более широкий контекст.

## Конечный профиль

Ровно четыре отсчёта PCM_S16LE: восемь байт, 16000 Гц, один канал, полярность 1 или -1. Значения и типы проверяются явно. При инверсии -32768 возникает типизированный отказ диапазона; клиппинга нет.

Во вложенном вызове возвращаются полные модели до изменения, цель, собранные байты, модель повторного разбора, сравнение и состояние одной итерации. Для следующего уровня можно использовать `допустить-цикл-звука@2` с точным замыканием девяти определений и новым корневым ключом. Это сохраняет явные входы и выходы; бесконечный controller или автоматический запуск агента не добавлен.

## Фактическая проверка

В 215 каждый V2-случай исполнен один раз существующим bootstrap: три подтверждённые pure-композиции и две целые семантические диагностики завершились raw0; четвёртый случай дал ожидаемый raw1, пустой stdout и ошибку `диапазон-JSON`. Во всех шести вызовах наблюдались единственный stdin.end, finish и завершение процесса.

Повторная DATA-сверка 225 выполнена тем же производителем 215, без новых запусков. Она не является вторым независимым runtime-ревью. Все пять возвращённых JSON-результатов целиком совпали с frozen ожиданиями; у typed failure проверен заранее закреплённый предикат кода ошибки. В трёх положительных native traces по 22 применения подтверждают передачу фактических моделей и байтов. Raw traces и окружение остаются в частном доказательном слое.

Исторический базовый контракт 207.v2 описывал первый лист @1 и NOT_RUN. Он сохранён как происхождение; текущий контракт этого пакета относится к @2, schema2 и фактическому finite215.

## Воспроизведение

Из корня FUM выбранный вход можно передать существующему исполняемому продукту:

```sh
swift run --package-path Прототипы/память-структурирующих-операторов \
  FUMStructuringOperatorMemoryProbe исполнить \
  --определение fuma/packages/cikl-polyarnosti-zvuka/определение.json \
  --вход текст < fuma/packages/cikl-polyarnosti-zvuka/примеры/вход-01.json
```

Это команда воспроизведения, а не выполненный в 225 запуск. В 215 использовался ранее собранный закреплённый bootstrap; чистый клон и новая сборка этой командой здесь не проверялись. Для сравнения берётся весь JSON из текстового результата observation. Случаи 02–06 имеют собственные входы и полные ожидания; случай 04 ожидает raw1, а не успех процесса.

## Граница

Профиль работает только с синтетическими raw-отсчётами. Кодек, контейнер, ASR, реальная запись или воспроизведение, общий агентский runtime, физический контур и Stop не подтверждены. Ветвь расхождения описана Source, но не испытана положительными MATCH-случаями. Эффекты возвращаемых данных запрещены; сохранение и следующий вызов организует вызывающая сторона.
