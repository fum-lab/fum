# Вывод сводки через существующую библиотеку FUMA

[Первичный FUMA-компилятор](определение.json) выдаёт небольшой Swift6-клиент, который исполняет определение сводки через существующий public API и выводит полный результат с его фактическими хэшами. Полная трасса, шаги наблюдения, планировщик и геометрические поля в stdout не попадают.

В принятом конечном составе выполнены6новых случаев кодогенератора,1сборка и1прямой вызов на неизменном историческом входе205. Все шесть полных JSON совпали с замороженными ожиданиями: один содержит полный Swift6116Б, пять — диагностики без исходника. Из положительного фактического stdout извлечён Swift, побайтно равный [полному эталону](эталон-клиента.swift). Этот файл сохраняет обе доказанные роли одинакового payload; первичным поведением остаётся FUMA, ручной Swift-компонент не добавлен.

Одна Swift6-сборка со строгой конкурентностью, warnings-as-errors и driver-j1 использовала совместимые existing object/module библиотеки. Она завершилась с кодом0 и пустыми потоками. Один вызов нового бинарника получил полный stdout14203Б, stderr0 и код0. Весь parsed результат сводки совпал с [независимым ожиданием](примеры/ожидание-прямого-вызова.json), включая canonical Sourcehash и hash исходных байтов входа. Исторический момент2026-11-04 13:00:28 MSK сохранён.

## Контракт и воспроизведение

[Машинный контракт](контракт.json) ограничивает AST схемой fum.программа-вывода-сводки.1, версией1 и узлом результат-сводки-197 с целым пределом16384. Строки не становятся Swift-кодом. [Шесть frozen случаев](примеры/) остаются независимыми от [шести фактических результатов](результаты/219/).

Сначала существующий FUMStructuringOperatorMemoryProbe вычисляет положительный вход через исполнить --определение <этот определение.json> --вход текст. После сравнения полного результата Swift извлекается только из ACTUAL поля исходник, не из эталона. Производный target линкуется с object/module существующего [bootstrap](../../../Прототипы/память-структурирующих-операторов/README.md), Foundation и совместимым SDK. Фактически проверенная форма использует `-swift-version 6`, `-strict-concurrency=complete`, `-warnings-as-errors`, `-j 1`, `-parse-as-library`, явные -I/-sdk, собственные module-cache/TMPDIR и -o. Реальные служебные пути выбирает и проверяет caller; бинарники, object/module и SDK в публичный пакет не входят. Чистый клон и иная ABI этой одной сборкой не квалифицированы.

У полученного клиента ровно2явных аргумента: путь определения [сводки](../сводка-по-агентам/определение.json) и путь одного JSON входа. Чтение ограничено65536/262144Б, проверяются UTF8 и JSONobject. Через ОпределениеОператора.разобрать и синхронный AutomationExecutor.выполнить получается ACTUAL .текст; его полный JSON со схемой fum.сводка-агентов.1 принимается при typedeffectsfalse. Вывод fum.исход-вычисления-сводки.1 ограничен16384Б вместе с LF. Ошибка даёт малый фиксированный JSON stderr и код1; частичный либо неизвестный исход не выдаётся за успех.

## Фактические данные и история

[Проекция результатов](результаты/проверки-219.json) связывает исходник, корпус, actualSwift, сборку и [полный прямой stdout](результаты/219/прямой-результат.json). [Текст](../сводка-по-агентам/срезы/2026-11-04-13-00-28-MSK/сводка.txt) и [машинный снимок](../сводка-по-агентам/срезы/2026-11-04-13-00-28-MSK/снимок.json) извлечены только из нового фактического вывода.

Сырые байты prepared и actual stdout различаются только порядком членов объекта поСтадиям: UNKNOWN стоит первым в Node-ожидании и последним после Foundation sortedKeys. Полные JSON-деревья равны; порядок массивов не менялся. Это различие и ранняя лишняя byte-equality проверка сохранены, oracle не исправлялся ради совпадения.

[Первоначальный отказ216](история/отказ-216/происхождение.json) и его непринимаемый исходник сохранены как история. В новом исходнике добавлены только2обязательных заголовка graph: схемаfuma.граф-JSON.2 и числацелые64-без-дробей. Удаление их побайтно восстанавливает старый исходник. Старый failedv1 не повторялся; новый219 был отдельным разрешённым job, fullSwiftgolden и все6ожиданий неизменны.

## Граница результата

Клиент не создаёт дочерние процессы, файлы, сеть, окно или GPU-задачу и не содержит нового интерпретатора. Подлинность и владение явными путями, SHA и право на вызов проверяет caller. Таймеры и bytecaps не объявлены ограничением всей CPU/RSS или абсолютным OS-deadline. Это конечное внедрение исторической сводки, не livecollector, generalrunner, автоматический Git, AOT/selfhosting или ремонт NativeStop.
