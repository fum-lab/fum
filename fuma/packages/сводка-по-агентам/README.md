# Сводка агентов

Первичный FUMA-оператор [сводка-по-агентам@1](определение.json) строит машинный снимок и развёрнутый текст из явно отобранных карточек. Он сохраняет имя, функцию, наблюдаемый статус, текущую задачу и результаты за указанный день. Подготовка, статическое ревью, проверка исполнения и доставка имеют отдельные стадии; UNKNOWN и NOT_RUN сохраняются.

В [фактическом историческом срезе](срезы/2026-11-04-13-00-28-MSK/сводка.txt) на2026-11-04 13:00:28 MSK находятся5карточек и12фактов:4статуса «работает»,1«ожидает»; стадии prepared3, static-reviewed3, runtime-checked4, delivered2. Это сохранённые наблюдения на указанную метку, а не текущая проверка активности агентов. Полнота среза остаётся UNKNOWN.

[Машинный снимок](срезы/2026-11-04-13-00-28-MSK/снимок.json), [полный результат](срезы/2026-11-04-13-00-28-MSK/сводка.json), [вход205](срезы/2026-11-04-13-00-28-MSK/вход.json) и [независимое ожидание](срезы/2026-11-04-13-00-28-MSK/ожидание.json) сохранены отдельно. Фактический результат получен одним новым вызовом существующей библиотеки через [FUMA-бэкенд вывода](../вывод-сводки-агентов/), без полной трассы наблюдения. Полные parsed JSON совпали. У отдельно сохранённых inner-сводка.json и ожидание.json различается порядок членов34 объектов. У полного прямого outer-stdout219 и его отдельного outer-ожидания отличается порядок только одного объекта поСтадиям. Во всех сравнениях порядок массивов и все значения совпадают; ожидания не переписаны.

## Вход и результат

[Контракт](контракт.json) задаёт день и момент снимка как явные строки, до6закрытых карточек и до3фактов на карточку. Факт содержит стадию, отдельные сведения об исполнении и исходе, а также адресный ref с SHA. Программа не получает часы, Native/JSONL/FS/ENV, модель или effort. Публикационную чистоту свободных строк, реальность фактов и происхождение ссылок проверяет вызывающий до входа.

Успех возвращает fum.сводка-агентов.1 со снимком и полным текстом. Несогласованные данные могут дать диагностический результат без частичной сводки; грубая ошибка типа или обязательного поля — typed error существующей библиотеки. ЭффектыРазрешеныfalse является данными, не правом исполнения.

[Шесть исходных ожиданий](примеры/) сохранены без подгонки. [Фактическая проверка212](результаты/проверки-212.json) выполнила каждое один раз и сравнила полные JSON; все rawexit0 и stderr0. Case5 с другим днём дал именно ожидаемую диагностику, поэтому код0 не назван положительной сводкой. Точные исходные stdin и decoded результаты находятся в результатах212.

[Отказ209](история/отказ-209.json) был ошибкой кода запуска: stdin/EOF не отправлены, процесс остановлен по таймеру. Это не отказ FUMA197. Оригинальная ошибочная константа stdinEOFRequested и её исправление отражены отдельно. [Усечение212](история/усечение-212.json) произошло на другом вызове205: rawexit0, но поток104841Б превысил capture65536. Его39305несохранённых байтов не восстановлены; старая попытка не объявлена полной. Новый output-only интерфейс219 получил полный результат14203Б без повышения лимитов.

## Использование и граница

Для вычисления нужен существующий bootstrap из [пакета памяти операторов](../../../Прототипы/память-структурирующих-операторов/README.md). Буквальный интерфейс: исполнить --определение <этот определение.json> --вход текст; передаётся точный выбранный JSON во stdin до EOF. Публичные файлы входов212 позволяют повторить байтовую привязку без реконструкции форматирования. Для большого фактического среза используется output-only интерфейс, поскольку полный bootstrap observation включает дополнительные трассы.

Это конечный алгоритмический генератор выбранной сводки. Автоматический сбор состояния, восстановление runtime, постоянный цикл и запись в Git этим оператором не запускаются. Передача пакета и Root-интеграция имеют отдельные проверки.
