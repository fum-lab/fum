# Ограниченный перевод строкового литерала в Swift

[Программа FUMA](определение.json) принимает строку длиной до трёх Unicode-скаляров из конечного алфавита: `A`, кавычка, обратная косая, NUL, `e` и комбинируемый U+0301. Каждый скаляр преобразуется в экранированную запись Swift; результат обрамляется кавычками. Значения вне алфавита, длинные входы и нестроковые значения отклоняются. Unicode не нормализуется.

Одиннадцать входов исполнены фактическим ядром со скаляром: восемь результатов и три ожидаемых отказа совпали с предварительными [ожиданиями](ожидания.json). [Фактические результаты](результаты.json) сохранены отдельно. Восемь реально выданных литералов включены в [проверочный Swift-файл](проверка-свифт.swift), собраны строгим компилятором и восстановили исходные последовательности скаляров; [ожидаемый вывод](проверка-свифт-ожидание.txt) закреплён до запуска.

## Воспроизведение

Соберите [ядро со скаляром](../ядро-доступа-к-юникод-скаляру/README.md). Для каждого случая сохраните поле `входJSON` из ожиданий в отдельный файл и передайте ядру пути программы и входа. Для восьми успешных результатов составьте проверочный Swift-файл из фактически полученных выражений; соберите его `swiftc -swift-version 6 -strict-concurrency=complete -warnings-as-errors -j 1` и сравните вывод с заранее рассчитанной последовательностью кодовых точек. При запуске используйте отчётную обёртку и ограничение срока.

Это ограниченный профиль, а не кодирование полного Unicode, общий переводчик FUMA или завершённый рантайм. Проверочный Swift-файл — обвязка из фактических литералов; собственное преобразование задано на FUMA.
