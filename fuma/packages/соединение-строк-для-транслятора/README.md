# Соединение строк для транслятора FUMA

Первичная [программа FUMA](определение.json) соединяет от нуля до трёх строк с заданным разделителем. Она предназначена для конечного стыка транслятора; произвольная длина массива и кодирование строковых литералов Swift пока не реализованы. Unicode не нормализуется.

Девять заранее заданных [ожиданий](ожидания.json) проверены фактически полученным самостоятельным ядром с вложенными определениями: пять успешных результатов и четыре ожидаемых отказа совпали по коду и полным байтам стандартных потоков. [Фактические результаты](результаты.json) сохранены отдельно. Ошибки являются ожидаемыми проверками, а не успешными кодами процесса. [Контракт](контракт.json) описывает ограниченный профиль и происхождение.

## Воспроизведение

Соберите самостоятельное ядро из фактически полученного исходника [ядра с определениями](../самопоставка-ядра-с-определениями/README.md). Для каждого случая сохраните поле `вход` в отдельный JSON и вызовите бинарник с двумя путями: `определение.json` и этот вход. Сверяйте код процесса и полные стандартные потоки с заранее закреплённым ожиданием; ограничивайте срок и группу процесса отчётной обёрткой. Это не является ограничением всей памяти или сети.
