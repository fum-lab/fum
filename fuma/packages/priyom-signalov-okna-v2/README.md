# Приём сигналов окна с ранним закрытием

[Исходник FUMA](определение.json) версии2 расширяет [первую версию](../priyom-signalov-okna/README.md): закрытие с номером2 или3 снимает кандидат кадра до сообщения пикселя. Следующий номер становится3 или4, закрыто=true, кандидатКадра=false, пиксельНаблюдался=false. После такого закрытия поздние пиксель и открытие игнорируются без нового входа планировщика.

[Контракт](контракт.json) различает семь канонических состояний. Обычные четыре перехода остаются допустимыми; версия входа и состояния теперь2, старые схемы1 диагностируются явно. Восемь вложенных определений используют существующие графовые операции. Только принятое открытие выдаёт DTO [планировщика кадра](../okno-metal/README.md). Данные не разрешают физический эффект. Caller обязан передавать последнее фактически принятое состояние.

[Восемь полных ожиданий](примеры-проверок.json) закреплены до исполнения и сохранены неизменными со своим историческим статусом NOT_RUN. Отдельные [фактические результаты](результаты-проверок.json) подтверждают8/8 полных совпадений: четыре обычных перехода, два ранних закрытия, поздние пиксель и открытие. Каждый CLI-вызов выполнен один раз, код0, stderr пуст. Закрытия не требуют полей чтения пикселя.

Для исполнения используется существующий bootstrap [памяти структурирующих операторов](../../../Прототипы/память-структурирующих-операторов/README.md), без изменения его Swift-исходников. Его интерфейс: `FUMStructuringOperatorMemoryProbe исполнить --определение fuma/packages/priyom-signalov-okna-v2/определение.json --вход текст`; stdin — конечный UTF8 JSON одного поля вход из корпуса, затем EOF. stdout имеет схему fum.наблюдение-оператора.2: проверить результат.тип=текст, разобрать JSON из результата.значение и сравнить весь объект с ожидаемымРезультатом. Сборка bootstrap в этом этапе повторно не запускалась; чистый клон и полный профиль здесь не проверялись.

Результат относится к чистой обработке синтетических сигналов. Раннее закрытие в ОС, resize, смена поколения, живая обратная связь и видимые пиксели окна этим набором не подтверждены. Старый исходник v1 и его фактические свидетельства сохранены.
