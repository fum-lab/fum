# Компилятор сплошного цвета FUMA → Metal

[Первичный исходник FUMA](определение.json) переводит закрытую программу кадра в текст Metal Shading Language. Два вложенных определения проверяют каналы RGBA8 и порождают vertex/fragment функции для треугольника, закрывающего кадр. Входные каналы действительно меняют литералы в MSL. Это узкий компилятор сплошного цвета, не общий AOT и не интерпретатор графа внутри Swift-обёртки.

## Вход

Объект имеет ровно поля `схема: fum.программа-кадра.1`, `версия: 1`, `узел: сплошной-цвет`, `цвет`. Цвет имеет ровно `красный`, `зелёный`, `синий`, `альфа`: целые0..255. Строки и логические значения не приводятся к числу. Четыре конечных массива по64 значения проверяют принадлежность диапазону существующими операциями графа; существующая операция `в-строку` кодирует только принятые целые.

Неподдержанные схема, версия и узел возвращают диагностику до чтения недостающих нижних полей. При полной форме дополнительные поля дают диагностику. Отсутствующее обязательное поле, не-объект или испорченный JSON могут дать типизированный отказ загрузочного исполнителя; такой отказ не выдаёт MSL.

## Результат

Успех содержит исходник MSL, профиль `сплошной-цвет-восемь-бит.1`, функции `вершинаЦвета`/`фрагментЦвета`, число вершин3 и исходный закрытый цвет. Fragment возвращает `float4(R.0, G.0, B.0, A.0) / 255.0`; альфа сохраняется без premultiplication. Диагностика содержит точный код и поле, исходника в ней нет.

Флаги `компиляцияВыполнена: false` и `выполнениеРазрешено: false` сохраняют границу: генерирующая программа сама не вызывает Metal-компилятор или GPU и не выдаёт прав на эффект. После неё потребителю нужны отдельные фактические компиляция MSL, совместимый pipeline, drawable и вызов draw. UTF-8 имена приняты настоящим Metal-компилятором для красного случая: получен IR, stderr пуст. Получена также библиотека `.metallib`6382 байта. Это ещё не показ кадра. Верхняя граница текста этого профиля695 байт — оценка вывода, не RSS/время всей задачи.

## Проверки и воспроизведение

[Примеры](примеры-проверок.json) сохраняют подготовленные полные ожидания для четырёх цветов и шести отрицательных случаев. Их исходный статус `NOT_RUN` — исторический снимок. [Фактические результаты](результаты-проверок.json) фиксируют последующие10 вызовов: все10 полных JSON совпали, четыре разных MSL и шесть диагностик без исходника. Ожидания не менялись; каждый вход выполнен один раз. Независимое ревью проверило30 IO-файлов,10 terminal-записей и все4 производных MSL-файла. Проверяется весь JSON, включая полные байты MSL; отрицательная диагностика — нормальный результат CLI, без исходника и без исполнения.

Используется существующий продукт `FUMStructuringOperatorMemoryProbe` из [пакета загрузочной основы](../../../Прототипы/память-структурирующих-операторов/Package.swift). Пример формы вызова уже собранного исполнителя:

```text
<исполнитель> исполнить --определение fuma/packages/metal-cvet/определение.json --вход текст
```

На stdin передаётся один конечный UTF-8 JSON из поля `вход` примера и EOF. Проверяется схема наблюдения `fum.наблюдение-оператора.2`, `результат.тип == текст`, затем JSON из `результат.значение` сравнивается целиком с `ожидаемыйРезультат`. Отдельного режима `--вход json` нет и не требуется.

## Настоящая компиляция Metal

Первый реально порождённый MSL красного кадра691 байт скомпилирован локальным Apple Metal-компилятором в IR4016 байт, raw0, stdout/stderr пусты. Исходник не переписывался после генерации. Полученный IR отдельно упакован в настоящую Metal-библиотеку6382 байта, raw0, stdout/stderr пусты; SHA256 `3b47a4c7c868ce03de36f188e56223008ac9d0ae7db189644495128799c7fa1a`. Библиотека остаётся временным производным артефактом вне Git. Ещё три цветовых MSL сопоставлены с полными ожиданиями, отдельные Metal-вызовы для них не выполнялись.

Форма команды компиляции и последующей упаковки взята из [официальной документации Apple](https://developer.apple.com/documentation/metal/building-a-shader-library-by-precompiling-source-files). IR, библиотека, создание pipeline, GPU-исполнение и показ окна — разные результаты. Эта запись не обещает ещё не наблюдавшиеся следующие стадии.
