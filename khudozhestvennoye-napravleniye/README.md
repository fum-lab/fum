# Художественное направление FUM

Этот каталог — локальный пилот направления с собственными происхождением, приёмкой и журналом. Первый пакет содержит рассказ [«Те, кто не вернулся»](proizvedeniya/te-kto-ne-vernulsya/rasskaz.txt) и его [паспорт](proizvedeniya/te-kto-ne-vernulsya/pasport.md). Исходный текст подготовлен без служебных вставок: его SHA-256 равен `9bb1c2acc0a4d9b246503048715ff43348ca1787a0a6b3b9edb4120ea7c8ff2e`.

[Постановка](postanovka.json) связывает пакет с точной основой и адресом ветки. [Журнал этапа](zhurnal.md) различает выполненную работу, проверки, доставку и ещё не состоявшуюся приёмку ROOT. Машинная запись FUMA хранится в каталоге [`zhurnal/`](zhurnal/).

Пакет тематически продолжает [художественное самоописание FUM](../Документация/30-художественное-самоописание-FUM.md) и пилот направлений из [модели направлений](../Документация/направления-агенты-и-пучки-поставок.md). Он не меняет историческую вселенную [«Право на ветвь»](../Документация/53-вселенная-FUM/README.md), рассказ «Один свидетель» или их историю и автоматически не становится их каноном.

## Статус

Это подготовленный к адресной приёмке пакет в ветке `fum-lab/fum/khudozhestvennoye-napravleniye/master`. Локальная проверка и публикация собственной ветки не означают слияния в `master`, приёмки ROOT либо фактического отчёта о свойствах машинного сознания.
