## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
На вопрос «Yestj li gotovyiye neintegrirovannyiye vetki?» подтверждены Клавиатура и Telegram как кандидаты приёмки; Лингвистика и экономический паспорт уже доставлены. Дополнительная ограниченная RO-сверка14 текущих файлов поставок не нашла иных свежо подтверждённых готовых результатов. У libtorrent, наблюдения доступности macOS и переводчика Swift остаются открытые проверки; полнота общего списка неизвестна. Старый README со снимком4октября не считается текущим доказательством. В C325 сохранены все отказавшие RAW и промежуточные границы. Финальный RAW9 прошёл все4 настоящие проверки после полного stage и точного preview. Заключительная сверка, создание и доставка прошли отдельно. Существующему исполнителю STEP0235 отправлена точная регрессия повторной подготовки: существующие RAW исключать из ожидаемых отсутствующих только после проверки; после fill ставить весь разрешённый состав, затем preview терминальных записей до следующей coherence. Текст и подтверждение API сохранены рядом с приёмкой; дубликат задачи не создавался. Отдельный адаптер raw HTML не включён в его ACT. Читающий контракт подтверждён независимо. Сохранённый профиль Клавиатуры второй версии относится к прежнему тестовому SHA; исправление фикстуры проверяется заново и не подменяет историю. Физический перехват клавиш, LEAP, редактор и приложение остаются вне среза. Повторный поиск API остановки чатов не нашёл подходящего инструмента; архивирование вместо остановки не применяется. Читающий остаток после C325 возвращает3:982 сообщения и3 неизвестных происхождения; ROOT не объявляется завершённым. Наблюдён лишний повтор полного приёма истории модели при каждом новом этапе из-за привязки курсора к файлу назначения; курсор вручную не переносится и не подменяется, системная оптимизация требует отдельного проверяемого контракта.
