# Сохранить кооперативную проверку плана

Для опытного явно заданного контракта проверки плана добавлены два коротких lock-среза в порядке root → session. Первый проверяет отсутствие controlled active и снимает отчёт и историю; Git-контекст вычисляется после освобождения обоих lock; второй повторно проверяет active, отчёт и историю до решения штатного планировщика. Доступ других legacy-действий через новый контракт не включён; прежний default-маршрут и общий guard не меняются.

Тест точного кандидата использует шесть валидированных synthetic v3 записей и настоящий планировщик. Git и чтение истории заменены mock: проверена доступность root flock во время Git callback, а появление active и изменение отчёта между фазами приводят к отказу. Terminal SHA-256 `9404d98ad9d6e26601c1f0ab33858a151495f8af91351314a34a792218f55613` независимо сверен. Реальный Git, полная кооперация legacy writers, ABA, непрерывная custody и production admission этим тестом не подтверждены.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
