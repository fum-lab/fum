# Отчёт 2026-07-17 12:20:17 MSK - Создать скрипты запуска прототипов

Два действующих Swift-прототипа получили единообразные исполняемые точки входа `запустить.sh`. Для запуска больше не нужно помнить имя Swift-продукта, длинный `--package-path` или предварительно переходить в каталог пакета: каждый скрипт сам определяет своё расположение и передаёт дополнительные аргументы прототипу.

Теневой редактор запускается как графическое приложение, принимает необязательный путь к текстовому файлу и поддерживает справку без открытия GUI. Клавиатурный прототип по умолчанию выводит безопасную воспроизводимую матрицу источников; через тот же скрипт доступны проверки среды и устройств, а запись физических событий по-прежнему требует отдельной явной команды.

Новый контракт распространён на будущие прототипы через `AGENTS.md` и индекс `Прототипы/README.md`. Чтобы правило не осталось только текстом, создана локальная автоматизация `fum-prototype-launch`: она проверяет наличие `запустить.sh` у каждого каталога-прототипа с паспортом, исполняемый бит, shebang `#!/bin/sh` и корректность POSIX shell-синтаксиса. Проверка включена в общий smoke-check.

## Решение по автоматизации

Проверка точек входа реализована через TDD. Автономные тесты покрывают корректный скрипт, отсутствие каталога прототипов, отсутствие файла, отсутствие исполняемого бита, неверный shebang, синтаксическую ошибку и игнорирование служебных каталогов без паспорта прототипа. Smoke-check получил отдельный обязательный шаг, поэтому новый прототип без простой точки входа не пройдёт общий проверочный контур.

## Проверки

- Красный TDD-цикл подтвердил отсутствие проверяющего скрипта и шага smoke-check до реализации.
- Шесть тестов `fum-prototype-launch` прошли без ошибок.
- Пять тестов `fum-smoke-check` прошли без ошибок.
- Структурная проверка приняла обе точки входа.
- `теневой-редактор-продолжений/запустить.sh --help` успешно выполнен из `/tmp` без запуска GUI.
- `физические-состояния-клавиш/запустить.sh` успешно собрал пробник из `/tmp` и вывел воспроизводимую матрицу.
- `swift test` прошёл 30 тестов теневого редактора и 16 тестов клавиатурного прототипа; GUI-продукт редактора отдельно собран.
- Плановый реестр, recency-метки, индекс Markdown-файлов и тепловая карта Obsidian пересобраны и проверены.
- `git diff --check`, связность рабочей сессии и полный smoke-check из 17 шагов прошли без ошибок.

## Продолжение

Отдельного следующего шага для инфраструктуры запуска не требуется: правило и автоматическая защита уже действуют. При создании каждого следующего прототипа его полезный безопасный сценарий без аргументов нужно выбрать по смыслу и описать в паспорте; потенциально чувствительные действия должны оставаться только явно включаемыми командами.
