[Журнал работ](../Глоссарий/журнал-работ.md) хранит человекочитаемые высокоуровневые отчёты о проделанной работе. Он помогает читать развитие [памяти FUM](../Глоссарий/память-FUM.md) как связную историю, не восстанавливая каждый раз контекст только по диффам, коммитам и файлам [исходных запросов](../Глоссарий/исходный-запрос.md).

Отчёт в журнале не заменяет [исходный запрос](../Глоссарий/исходный-запрос.md), [производную документацию](../Глоссарий/производная-документация.md), проверки или Git-коммит. Он фиксирует смысл работы на более обзорном уровне: что изменилось, зачем это сделано, какие материалы затронуты, какие решения приняты и какие продолжения стали видны.

## Правила именования

Отчёты рабочих сессий размещаются в этой папке с именами вида `YYYY-MM-DD_HH-MM-SS_MSK.md`. Если отчёт связан с пользовательским запросом, временной префикс совпадает с файлом этого запроса в `Запросы/`.
