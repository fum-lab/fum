## Проверки

Первый адресный запуск отклонил оставшийся маркер шаблона внутри ещё не сформированного блока и отсутствие точного имени инструмента времени. Имя добавлено, блок заменяется штатным предпросмотром; отказ сохранён машинной записью. Терминальные результаты адресных запусков учитываются обёрткой. Проверка архивов обнаружила неверный перечень файлов нового PDF-манифеста: список не был отсортирован и не включал сам манифест. Исправлено штатным перечислением `snapshot_relative_files`; исходные PDF-байты не изменены. После завершения запусков выполняется предпросмотр, recency, проверка точного diff и отдельный допуск `--контрольная-точка`. Код не менялся; тесты реализации и профиль оптимизации не требуются для этой документационной поставки. Сбой применения патча из-за неверного заголовка не изменил документы; подготовленный текст затем восстановлен без смысловой правки. Отдельная ошибка извлечения JSON исправлена использованием границы полного значения, до записи целевого файла.

Независимый RO-аудитор сверил пакеты MWS/Beget с архивами: существенных ошибок не обнаружено; кабинет, индивидуальный допуск и выполнение сценария не проверялись. Boosty и Apple проверены корнем отдельно.

Проверка `git diff --check` обнаружила только конечные пробелы в сыром HTML Boosty. Снимок не нормализован ради проверки; Первый повтор дополнительно выявил конечные пробелы в двух новых HTML MWS и производном PDF-тексте. Производный текст отформатирован, сырые HTML не нормализованы. Заключительная проверка исключает ровно три сырьевых файла: Boosty payment-terms-cis, MWS hub_oferta.html и welcome-grant.html, сохраняя проверку остальных изменений. Ошибка имени пути при запросе справки не запустила проверочный процесс.

Первый заключительный допуск контрольной точки завершился кодом 1: список затронутых файлов не включал текущий запрос, весь каталог материалов и архивов, хотя ссылки на источники были в отдельном разделе. Покрытие дополнено точными каталогами; отказ сохранён [отдельным выводом](материалы/отказ-контрольной-точки-001.txt). Иные ошибки этот запуск не сообщил.
