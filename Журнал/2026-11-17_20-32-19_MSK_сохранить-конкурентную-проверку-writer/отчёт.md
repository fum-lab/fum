# Сохранить конкурентную проверку writer

Добавлен synthetic межпроцессный тест cooperative legacy writer и controlled CLI с общей областью замка. При записи непустого v1 отчёта первый процесс удерживает root-lock; второй процесс подтверждает занятость flock, после освобождения создаёт active через CLI, а последующий writer получает отказ. Первый controlled cycle заменён mock, поэтому это не испытание двух полных реальных циклов. При неопределённой ошибке launcher удерживает test и fixture.

Тест live W завершился успешно; terminal SHA-256 `d7a671fcf9f1e9271eaa85482a029954cbb5fbce945aa20fd2cb21fefd0842a2` независимо сверен. Отдельной raw wait-квитанции child нет. Точный selective diff теста и исходная база сверены отдельно; перенос результата live W на полный exact lifecycle не утверждается. Default writers, ABA, custody и production admission не подтверждены.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
