## Проверки

11 регрессий объединённой реализации прошли. Первый импорт отказал при подготовке коммита после позднего дописывания живого JSONL; история уже была сохранена. Повтор тем же курсором завершился кодом 0: 141 наблюдение, четыре события, пропусков нет; последние наблюдаемые поля — gpt-6-astra и ultra. Поля коммита подготовлены этим же импортом. Проверочный вызов через stdin не исполнил переданный сценарий, поскольку захват не передаёт stdin дочернему процессу; его код 0 не принят за проверку. Повтор использует явный аргумент -c. Все попытки остаются в машинном отчёте. Независимый обзор конечного cf7e92eb подтвердил исправление двух обнаруженных дефектов: сохранение буквальных маркеров в теле коммита и создание приватного файла сразу с правами 0600. Источник сохраняет RED/GREEN, 74,97 МБ синтетического профиля и четыре исторических события. Решение оптимизации: сохранить проверенный инкрементальный алгоритм; повтор API на синтетическом входе занимает 0,000830 с против 0,844690 с первичного приёма, при этом эти значения относятся к измерениям автора, а не к новому полному замеру корня. Повтор по неизменному stat не является независимой повторной проверкой содержимого и не доказывает отсутствие невидимых переключений.

Первый заключительный допуск обнаружил неполный перечень затронутых путей: в нём не были указаны каталоги материалов источника, исходников и перенесённой проекции. Перечень дополнен по точному индексу, без отключения проверки статуса.

Профиль сверён по трём точным SHA исходников, структура объединённого Журнала прошла. git diff --cached --check прошёл. Публикационный сканер вернул только два прежних срабатывания в test_устойчивые_свидетельства.py, строки 183 и 199: проверяемые суффиксы в тестах, не локальные пути. В принимаемой дельте новых нарушений нет. Точные объявления этих двух случаев уже опубликованы владельцем планирования в d1f6e7d2 и будут приняты вместе с его веткой.
