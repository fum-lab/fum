## Проверки

Проверенный полный clone существующего `fum-lab/libgit2` и `libgit2/libgit2` содержит одинаковый `main` OID `42a89d7cc9374a19e72fa57011e5fe3a99c7b3bf`; тег `v1.9.7` в обоих remotes указывает на `49e408b3208bc3093757a1c2db938d3590f3f412`. У pin совпадает дерево `29b18aa9210376513c391185b355e696856f9261`; локальные refs обоих remotes включают pin в `maint/v1.9`. Blob `COPYING` — `80788a3ed790689b5b30918d17ec67ccd24e7a20`, его SHA-256 — `e0938121c0554985fe17196ac38fc590d149268e9c46e0c0e7a2eae1354fae71`; текст содержит GPL version 2 и linking exception.

На macOS arm64 с CMake 4.4.4 и Apple Clang 21.0.0 CMake configure завершился успешно через обёртку, запись `89a1c8f4-1484-427b-928e-29c6584fa19e`, код 0, 19,072,664,125 нс. В кэше зафиксированы Release, `BUILD_SHARED_LIBS=OFF`, `BUILD_TESTS=OFF`, `BUILD_CLI=OFF`, `USE_SSH=OFF`, `USE_HTTPS=SecureTransport`. Итоговый список функций подтверждает SecureTransport и отключённый SSH. CMake сообщил о несовместимом с будущими версиями старом минимуме, а GSSAPI и PCRE не найдены; они не остановили configure. Несмотря на обнаружение установленного OpenSSL при проверке окружения, выбранный HTTPS backend — SecureTransport.

Configure завершился до получения адресной корректировки. После того как `df` показал 33 GiB свободного места, `cmake --build` не запускался; статического архива libgit2 и поставочных заголовков этим этапом не получено и не проверено. Каталог исходника и успешно созданная конфигурация сохранены во временной области для возобновления; тесты, CLI, SSH, интеграция и полный smoke-check не запускались.

Ограниченный read-only аудит выбранных исходников FUMA не нашёл объявленного потребителя libgit2. Это не доказывает отсутствие потребителя за пределами проверенной области.

Требуемый полный беззаписный проход по JSONL корневой задачи завершился кодом 3; после него остаются 1 779 необработанных сообщений. Полный вывод сохранён вне checkout, а компактный обработчик отказал из-за предела размера; тексты сообщений не копировались сюда. Чтение закончено и сейчас не удерживает процесс. Остаток блокирует ROOT-финализацию по текущему правилу, но не эту ограниченную source-программу.

## Решения и ограничения

Проверять только необязательный статический build точного pin из существующего `fum-lab/libgit2`; не создавать fork повторно, не использовать Homebrew libgit2 и не менять `.gitmodules`, gitlink, FUMA-манифест или общий корневой `Package.swift`. Исходник и конфигурация созданы в собственном временном каталоге; компиляция не запускалась при 33 GiB свободного места по адресной корректировке текущего этапа.

В ROOT передано состояние пожелания к диагностике: в существующей записи есть план маршрутизации владельцу инструмента, но свидетельства фактической передачи не обнаружено. Статус — передача не подтверждена.

Чтение root JSONL выявило прямое противоречие между ограничением постановки bootstrap и текущим правилом AGENTS.md; ни тексты сообщений, ни их производное содержание не разбирались в этом checkpoint. Сейчас источник не читается; остаток 1 779 сообщений остаётся неурегулированным. ROOT-приёмка и завершение всей задачи не заявляются.
