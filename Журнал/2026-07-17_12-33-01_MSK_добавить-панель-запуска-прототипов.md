# Отчёт 2026-07-17 12:33:01 MSK - Добавить панель запуска прототипов

В корне репозитория появилась единая терминальная панель `prototipyi.sh`. Её имя намеренно записано русским транслитом латиницей: команду можно набрать в уже используемой латинской раскладке, а для выбора прототипа достаточно цифры.

Без аргументов панель автоматически находит все точки входа `Прототипы/*/запустить.sh`, показывает их пронумерованный список и принимает номер либо безопасный выход `q`. Она не зависит от текущего рабочего каталога. Для проверок и сценариев доступны `--list` без запуска и прямой выбор номером с передачей остальных аргументов выбранному прототипу. Благодаря автоматическому обнаружению будущий устойчивый прототип появляется в панели сразу после добавления принятого `запустить.sh`.

## Решение по автоматизации

Контракт включён в локальную автоматизацию `fum-prototype-launch` через TDD. Проверяющий скрипт требует от корневой панели исполняемый бит, shebang `#!/bin/sh` и корректный POSIX shell-синтаксис. Тесты выполняют панель только на временных безопасных фикстурах: проверяют сортированный список из другого каталога, интерактивный выбор и передачу аргументов без запуска настоящих Swift-прототипов.

## Проверки

- Красный TDD-цикл подтвердил отсутствие корневой панели и её валидатора до реализации.
- После реализации десять автономных тестов `fum-prototype-launch` прошли без ошибок.
- Список и прямой выбор с передачей `--help` успешно выполнены из `/tmp`, независимо от текущего каталога.
- Интерактивная панель показала оба прототипа и безопасно завершилась по `q`.
- Структурная проверка приняла одну корневую панель и две точки входа прототипов.
- Плановый реестр, recency-метки, индекс Markdown-файлов и тепловая карта Obsidian пересобраны и проверены.
- `git diff --check`, связность рабочей сессии и полный smoke-check из 17 шагов прошли без ошибок.

## Продолжение

Отдельного следующего шага для панели не осталось. Новые прототипы должны продолжать получать собственный безопасный `запустить.sh`; общая панель обнаружит их без ручного изменения списка.
