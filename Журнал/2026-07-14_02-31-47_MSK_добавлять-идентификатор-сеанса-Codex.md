# Отчёт 2026-07-14 02:31:47 MSK - Добавлять идентификатор сеанса Codex

В памяти FUM закреплён новый слой происхождения: каждый новый файл исходного запроса хранит корневой `CODEX_THREAD_ID`, а тело сообщения Git-коммита заканчивается тем же машинно читаемым trailer `Codex-Thread-ID`. Первым применением стал текущий [исходный запрос](../Запросы/2026-07-14_02-31-47_MSK_добавлять-идентификатор-сеанса-Codex.md).

Источником значения служит корневая пользовательская задача Codex. В корневом агенте он наблюдается через `CODEX_THREAD_ID`; у субагентов эта переменная содержит дочерний ID, поэтому корневое значение передаётся проверке явно. В публикуемую память попадает только этот корреляционный идентификатор; скрытые инструкции, журналы, секреты и прочее приватное состояние не публикуются.

Повторяемая часть решения автоматизирована по TDD. Новые тесты сначала зафиксировали ожидаемые ошибки для отсутствующего поля и обязательных аргументов, неверного дочернего ID, переноса UUID на другую строку, повторного раздела, лишнего текста, псевдотрейлера и отсутствующего, дублированного или несовпадающего Git trailer. После падения тестов `fum-session-coherence` получил порог обратной совместимости, строгую проверку формата и совпадений, а `fum-smoke-check` - условно обязательный контекст и проброс новых параметров.

Исторические файлы запросов не переписывались: новое поле обязательно с текущего запроса, а прежние снимки среды сохранили историческую форму. Новых открытых вопросов и отдельных проектных предложений изменение не создало.

## Проверки

- `fum-session-coherence`: новые отрицательные тесты первоначально упали, после реализации 27 тестов прошли.
- `fum-smoke-check`: новые тесты первоначально упали, после реализации 5 тестов прошли.
- Полный `fum-smoke-check` прошёл 14 шагов и 69 тестов.
- Плановый реестр, recency-метки и тепловая карта графа Obsidian пересобраны и прошли собственные проверки.
- Связность сессии и совпадение Git trailer с корневым `Codex-Thread-ID` в файле запроса подтверждены на подготовленном сообщении коммита.
