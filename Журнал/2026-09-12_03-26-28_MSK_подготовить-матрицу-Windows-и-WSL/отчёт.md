# Отчёт 2026-09-12 03:26:28 MSK - Подготовить матрицу Windows и WSL

Подготовлены [конечная матрица Windows/WSL, контракт готовности и паспорт](../../Планирование/подготовка-Windows-и-WSL.md). Первый кандидат — Windows 11 Pro 25H2 ARM64 в будущей UTM VM; отдельный WSL2-профиль использует Ubuntu 24.04 LTS и Linux-клон. Нативный POSIX-контур обозначен неподдержанным текущими байтами. Полный [поздний план Windows VM](../../Планирование/Windows-на-macOS.md) сохранён; широкая STEP0181 остаётся active.

## Промежуточная поставка и остаток

Новое [указание координатора](материалы/диалог.json) `01a07d3d-d376-7ad2-aafc-67e4c25a67eb` заменило ожидание персонального full промежуточной контрольной точкой по FUM-ПРАВИЛО-000188. Это координация действующего поручения, не новая человеческая команда. Сохраняются подготовленные матрица/паспорт, точные входы, очищенные источники, исходники узкой меры, RED/GREEN и профиль. Открытый отчёт содержит только терминальные прямые записи и точный предпросмотр; итоговая read-only-связность вызывается с `--контрольная-точка` после последней записи. Локальный коммит и exact push выполняются после этого допуска; точные C/T/parent, удалённый OID и чистота проверяются по Git и передаются координатору.

Full и новая проекция не выполняются. Исторические закрытые отчёты сохраняются. Подготовка документа не является окончательной приёмкой: все финальные критерии первого среза остаются непогашенными до совместного допуска по правилам master в интеграционном дереве. Полная реализация STEP0181, установка Windows/WSL и VM остаются вне данного конечного состава. Вершина поставки удерживается для интеграции.

Публикационный scanner текущего допуска обнаружил две абсолютные локальные ссылки в сохранённых ответах. Их адреса обезличены существующей функцией очистки материалов; хэши исходных строк и явные пометки редакции сохранены. Первичный JSONL остаётся частным. Ненулевой исход сохранён в открытой истории; [повтор scanner после очистки](материалы/запуски-проверок/19_a1c76370-b64d-47c4-810d-ff70e02d4e3e.json) завершился кодом 0.

Точный состав поставки задаётся diff от родительского коммита запуска до контрольного C; полный список путей читается той же Git-командой, а дерево T фиксирует все байты. Whitespace-проверка охватывает изменённый канонический diff и метаданные источников; только сырые response.body.html и внешние LICENSE исключены ради сохранности исходных байтов. Их происхождение и редакции проверены отдельно.

Первая заключительная read-only-проверка checkpoint завершилась кодом 1: Markdown-ссылка на существующий производный манифест была отклонена связностью. Ссылка заменена текстовым путём; каноническое свидетельство сохраняет точные идентификаторы. После recency выполняется повтор той же заключительной проверки, без full и генерации проекции.

## Покрытие поручения

- Разделены ОС, архитектура, редакция, нативный режим и WSL; сроки Microsoft не объявлены поддержкой FUM.
- Показаны обнаружение уже имеющихся инструментов, точные версии-кандидаты, источники, права, место, перезапуск и повтор. Python ARM64 Experimental и автоматическая установка через Python alias выделены заранее.
- Сохранены пользовательские Git-настройки и чужие состояния; пути/кодировки/LF/CRLF/регистр/блокировки и атомарная запись входят в будущую квалификацию.
- Отделены переносимые проверки, POSIX-ограничения, Swift/SDK и macOS-only компоненты. Готовность STEP0176 и CI не предполагается.
- Паспорт сохраняет неопределённые ISO/build/язык/хэш, VM backend и гостевой канал. Первое будущее испытание свежей .utm проверяет фактические UEFI, TPM 2.0 и Secure Boot.
- Общая Linux-поставка не импортирована. Точный промежуточный README прочитан из 0f62797675ddbcd3c68bceefe6793de95c5d20b8; координатор отдельно подтвердил отсутствие принятого общего OID/API. Вторая библиотека и Linux backend не создавались.
- Для принципа сообщения 252 различены источники, версии, неизменные данные, результат и неизвестные поля; полная реализация принципа не заявлена.
- Архивированы 14 официальных HTML-страниц и полные LICENSE UTM/QEMU двух точных upstream OID. Это исследовательские источники; LICENSE/NOTICE будущих бинарных комплектов ещё предстоит проверить.

## Проверки

Адресно подтверждены точные исторические входы, плановый реестр, публикационные пути, сохранность полного VM-плана и восьми широких критериев. Первая связность отказала из-за нематериализованного LinguisticKit; штатный init восстановил точный gitlink в своём worktree, без изменения .gitmodules, gitlink и общих настроек. Повторная адресная связность после материализации прошла кодом 0; финальный smoke остаётся незапущенным. Исход каждого запуска сохранён ниже, включая ожидаемые RED; готовность определяется последним машинным допуском, а не этим описанием.

При публикационном аудите найдены повторные [пропуск служебных заголовков](../../Сбои/FUM-СБОЙ-0020-публикация-служебного-CF-Ray-в-снимке-источника.md) и [диагностика HTML](../../Сбои/FUM-СБОЙ-0081-сохранение-служебных-данных-запроса-в-HTML.md). Общий архиватор расширен только на наблюдённые формы. Синтетические RED воспроизвели пропуски; GREEN подтверждает оба входа, регистр, продолжения, идемпотентность и сохранность содержательных метаданных/публичных примеров/хэшей статических ресурсов. [Очистка 14 снимков](материалы/очистка-источников.json) выполнена общей функцией без сети, изменённое тело Microsoft извлечено заново; реальные служебные значения не включаются в доказательства. Read-only-ревью после очистки подтвердило отсутствие ранее найденных служебных полей в 14 снимках. [Терминальная GREEN-запись](материалы/запуски-проверок/13_dbd37b6a-c656-45a2-ac5f-d1bf60c200b5.json) связывает точечный запуск с наблюдённым снимком. Профиль повторной локальной очистки составил 0.693172 с на 14 снимках; он не выявил основания усложнять алгоритм ради этого объёма. Оптимизация завершена решением сохранить простую общую очистку; ускорение не заявляется. После приведения смысловых имён теста к канонической кириллице две регрессии повторно проверяются на окончательных байтах. Полный цикл приёмки кода и источников остаётся незавершённым до совместного допуска. Общее устранение вне перечисленных форм не заявлено.

Первое окно было освобождено без запуска smoke/проекции. Затем координатор явно заменил персональный полный прогон промежуточной контрольной точкой. Прежние 16 прямых записей сохранены, дополнительные адресные результаты текущего допуска показаны в машинном блоке. Факт контрольного коммита и публикации подтверждается последующим чтением Git; финальная приёмка откладывается до совместного допуска. Установщик Windows/WSL и ресурсный профиль его выполнения в этом срезе не реализованы.

## Решения и ограничения

Это первый плановый срез, а не завершение автоматизации STEP0181. Остаток реализации сохраняет адаптер native/WSL, общий API по принятой поставке, источники/лицензии точных комплектов, свежую .utm и установку, гостевой доступ, повтор и восстановление, чистый клон, CI и профиль. Конечный [план этой разовой задачи](../../Планирование/задачи/01a092ff-dda8-7a01-a7a5-31823deb22d8/план-этапа.json) содержит непогашенные критерии совместной приёмки и окончательной принятой поставки. Отчёт остаётся открытым по явному разрешению контрольной точки; публикация checkpoint не закрывает эти критерии. Master и старые приёмы не изменялись.
