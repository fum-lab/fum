## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
Контрольная точка сохраняет разрешённый этап, а не завершение постоянной задачи. После публикации актов координатор выдаёт семь команд продолжения и проверяет фактическую работу. Обычный дочерний checkpoint не получает конечного допуска автоматически; этот пробел остаётся отдельным предметом исправления. Новая русификация не создаёт второй Swift V2 backend; положительный Swift путь ждёт принятого переноса. Предметные области изолированы; общие навигация и индекс принимаются отдельно. Дальнейшие приоритеты: приёмка готовых PR, документирование многфоркового сценария, возобновление внешней D22 по последней наработке без интеграции или публикации, конечная постановка Bitcoin. Android имеет ограниченный консольный запуск; Windows подготовку без Swift-запуска; Linux VM проверена, FUMA Swift на Linux не подтверждена; iOS и другие Apple-платформы остаются планами. Обновление Navitel возможно проверить после появления накопителя, прошивка не подтверждена; установки, покупки и запись устройства не выполнялись. Старые heartbeat/dispatcher не активируются; периодическая сверка выполняется в текущем ходе. Первый вызов обёртки отклонён до запуска: пустой журнал v4 не принимает исходный commit перехода. Исправленный вызов выбирает приёмочные раунды без миграционной границы. Повторный предпросмотр между ними выявил пустой каталог истории без запуска; он не был принят как свидетельство. После настоящего первого запуска предпросмотр продолжается штатно. Читающий обзор семи ACT не обнаружил дефектов: Git blob, хэши буквальных поручений, начальные C и области совпали. Первый прямой допуск связности отказал: четыре относительные ссылки новой постановки поднялись на один каталог выше корня. Исправлена глубина ссылок; неуспешная запись 3 сохраняется и не принимается за успех. Новая приёмка проверяет исправленный снимок.
