## Решение по переключению модели

Для новых видимых задач переключение задаётся непосредственно в `create_thread`: профиль передаётся как `model=gpt-6-luna`, `thinking=low`, без дополнительного промежуточного переключения после старта. Версия `.5` также сверяет фактическое наблюдение модели до подтверждения ребёнка. Для уже запущенной корневой задачи доступного API смены модели нет; попытка переключить её через UI остановлена самим инструментом управления приложением. Последнее проверенное наблюдение этой задачи — `gpt-6-astra/max`, поэтому Luna для неё не заявляется как исполненный факт. Это не препятствует запуску двух новых задач с Luna/Low.
