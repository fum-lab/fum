# Отчёт 2026-07-31 18:05:50 MSK - Закрепить исполнимый токен бюджет model only профиля

Рабочая сессия заменила неисполняемое значение `max_output_tokens = unknown` отдельным бюджетным LM Studio REST v0-профилем, не меняя смысл совместимого CLI-контура версии `1`.

## Результат

Профиль версии `2` независимо закрепляет режим, provider/interface/endpoint, model/runtime/tokenizer identity, disclosure и шестимерные ceiling/reservation. До JSON/SHA абсолютные UTF-8-пределы ограничивают profile identity, disclosure-списки, `invocation_id`, purpose и input; ранний отказ не создаёт reservation или terminal ledger entry и возвращает `request_sha256 = nil`. Actor-ledger атомарно проверяет affordability, сохраняет reservation до inference, согласует доверенные token counters и локально измеренное время, а для неоднозначных provider-исходов удерживает консервативный расход без автоматического повтора. Долговечность явно ограничена жизнью process; межпроцессное восстановление не заявлено.

Локальный REST v0-transport допускает только точный loopback endpoint, передаёт `max_tokens` из профиля и отделяет model/runtime/usage от недоверенного текста. Изолированная ephemeral-сессия не наследует cookie, credentials, cache или proxy, не следует redirect, повторно сверяет конечный URL и ограничивает абсолютные deadline и размер тела. SHA-256 тела сохраняется только для успешно согласованной completed-попытки; post-provider-отказы имеют отдельные типизированные исходы без digest.

Автономные фикстуры проверяют бюджет, конкурентность одинакового `invocation_id`, terminal outcomes, replay и HTTP-границы без модели. Повторные opt-in-вызовы уже сохранённой модели подтвердили точные `qwen/qwen3-0.6b`, runtime `llama.cpp-mac-arm64-apple-metal-advsimd 2.27.1`, `max_tokens = 1`, `prompt_tokens = 14` и `completion_tokens = 1`. После финальной проверки server LM Studio остановлен, список загруженных моделей пуст.

Карточка FUM-STEP-0108 завершена и удалена из веточного whitelist. Все остальные корректные кандидаты сохранены: рабочий набор содержит `26` карточек, из которых единственной вычисленной `ready` является FUM-STEP-0109, `24` остаются `paused`, одна — `blocked`.

Граница профиля: от немедленного FIFO-допуска до завершения итогового полного smoke-check. Стадийные длительности не складываются с call-time прямых запусков, а параллельные субагентские интервалы не суммируются между собой. Вложенные стадии полного smoke-check не прибавляются к его внешнему времени. После smoke-check recency, граф, связность и `git diff --check` повторно замыкают изменившийся отчёт; staging и атомарный локальный commit+handoff выполняются после них без автоматического push.

## Границы

Бюджетный ledger не является crash-durable: `process_memory` означает только атомарность и идемпотентность внутри конкретного actor/process. Исполнима ровно одна exact-tokenizer-фикстура для заранее закреплённого prompt; произвольные входы, remote transport и ненулевая тарификация закрываются отказом. Фактические model/runtime identity подтверждаются только структурированным provider-ответом. Профиль не разрешает внешнюю сеть, новые модели, секреты, платный доступ, пользовательские данные, инструменты модели или исполнение её текста. Совместимый CLI-профиль сохраняется, но не выдаётся за обладателя исполнимого token limit.
