# Наблюдение адресной регистрации

Полный первоначальный остаток содержал 179 человеческих экземпляров и пустую историю. Шесть решений выбраны по экземплярам из вывода принятого CLI, а не по SHA сырых строк адресной карты. Все 179 идентификаторов включены в контекст каждого решения; у самого раннего вопроса рассмотрены 74 поздних человеческих сообщения. Список не изменился при последующих чтениях.

Фактическая обработка выполняется существующим CLI из [закреплённого комплекта](контур-0177.md), отдельные [основания](основания.md) ограничивают решение состоявшимся историческим ответом. Командные свидетельства включают полный LF; третий ответ сохраняет отсутствие конечного LF.

## Промежуточное состояние

Первые пять решений последовательно сохранены; после первых четырёх получен полный остаток с исключением только уже выбранных экземпляров. После пятой записи два контрольных чтения не подтвердили полноту из-за дописи служебного хвоста; первое сохранило 5066 непроверенных байт. В прочитанном индексе оставались те же 179 человеческих экземпляров, а рассчитанный остаток содержал 174. Это не доказательство полноты непрочитанного хвоста. Шестая запись была отложена до свежего полного чтения; сохранённая история не переписывалась. Повторное чтение содержало 5339 непроверенных байт. После получения полного снимка выполнена шестая запись и итоговое чтение.
