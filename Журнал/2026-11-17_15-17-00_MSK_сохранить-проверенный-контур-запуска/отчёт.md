# Сохранить проверенный контур запуска

Зафиксирован source-only bootstrap checkpoint двух существующих файлов инструмента отчётов: контролируемый профиль Git с отдельным доменом и отложенным отпечатком, owner-scoped удержание дублированных FD, проверка argv/env и FD/path, а также раздельные private intent, terminal и release с no-clobber, fsync и readback. Неопределённый исход остаётся UNKNOWN; исторический отпечаток не подменяется, публичные guard остаются закрытыми. Сторонний потоковый worker и побочный сравнитель в этот checkpoint не входят.

Основание — прямое поручение корня в запросе. Это не обычная дочерняя контрольная точка: ACT/S и nativebirth не подтверждены, Creator и полный ROOT JSONL не использовались. Утверждение приёмки, интеграции и готовности production отсутствует.

Перед фиксацией exact candidate от HEAD `d6c40ab5b330bdf3f0dcf55ba14dcd55f8d8da66` был независимо сверен по составу и обратному применению; 31 адресный synthetic/mock тест прошёл. Один synthetic Git→observer lifecycle точных байтов завершился с восьмью сырыми статусами 0 и тремя private квитанциями UNKNOWN. Отдельная controlled-сессия собственного рабочего дерева с CLT Git и legacy observer завершилась с восьмью сырыми статусами 0 и readback квитанций. Сохранённые terminal SHA-256: `fdef943e64ce1ec5337432df4722922037121145adce967f86dd7e331966a883`, `b82bd5f9dc4f67a9d9319cd8d86ed6005377d7becac7444e12dfa3b890875088`, `dfb4c401c66ed30253ae8c78359c105fcc6d17dc4ae18cbcec2c1928de497c54`. Полный regression, production admission, trace и доказательство непрерывной custody не выполнены.

Собственные метаданные текущего хода через `nodeRepl.requestMeta`: модель `gpt-6.1-terra`, effort `low`, дочерний thread `01a1dfe1-bacd-7383-8724-c5bfa460a8c1`; это наблюдение не объявляется чтением native JSONL. Автор checkpoint задан по прямому поручению корня; полная история моделей неизвестна.

Осталось: утверждённая отдельная схема controlled history и право на source set/custody, подтверждённая семантика группы и ограничений observer, durable terminal admission и рабочее подключение consumer. Доказательств отсутствия ABA, actual exec image и power-loss durability нет.
