# Первый подготовитель вызовов этапа

Повторяющиеся ошибки выбора CLI, смешанного регистра пути, роли, времени, SHA строки вместо экземпляра сообщения и приватного кэша дают отказы до содержательной работы. Первый конечный срез — `./fum этап план --вход <приватный-JSON>`: сформировать приватный проверяемый план точных argv и входных JSON существующих start, наполнения и подготовки коммита. Записи checkout и Git в этом срезе нет.

Переиспользовать канонический генератор времени и короткого имени этапа, закрытые роли управляемых блоков, готовое поле экземпляр первичного индекса и строгий создатель коммита. Реестр разрешённых входов связывает операции с точными локальными CLI и SHA; произвольные команды и shell-строки запрещены. Смысл, выбор команд и независимое разрешение целей остаются явными. Git-status не становится разрешением.

Приёмка: четыре ранее наблюдённые ошибки, повтор одного текста в разных экземплярах, отказ при дрейфе источника/реестра и доказанное отсутствие изменений checkout/Git. Сначала подготовка; исполнение сохранённого плана — отдельный срез. Реализация ещё не начата.
