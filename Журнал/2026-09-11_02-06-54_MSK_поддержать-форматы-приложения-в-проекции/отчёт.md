# Отчёт 2026-09-11 02:06:54 MSK - Поддержать форматы приложения в проекции

Проекция принимает шесть фактических форматов переносимого приложения FUMA с точным сохранением содержимого. `.c` и `.h` относятся к коду; `.modulemap`, `.pbxproj`, `.plist` и `.entitlements` — к прочим точным форматам. Технический суффикс отделяется от преобразуемой основы имени. Вложенный `.gitignore` допускается только по полному пути `Приложения/FUMA/macOS/.gitignore`.

Это проверенная на адресных сценариях наработка для интеграции корнем. Общая приёмка и актуальное поколение проекции ещё не выполнены. Изменение не затрагивает правила агентов, LinguisticKit, внешние зависимости и исходники приложения. Поддержка `.xcscheme` и `.js` не добавлена.

## Проверки и принятые решения

Первый RED запустил четыре новых сценария против прежней реализации: все шесть форматов в нижнем и верхнем регистре и точный вложенный `.gitignore` были отвергнуты; проверка имени также показала неотделённый технический суффикс. Это действительный отказ требуемого поведения. После синхронизации точных списков второй запуск выявил ошибку самой новой фикстуры: корень цели был дважды добавлен к репозиторно-относительному пути. Исправление затронуло только чтение тестового выхода; третий запуск завершился успешно.

Адресная регрессия прошла семь сценариев: четыре новых, отказ неизвестного текстового файла, строгие машинные поля и сохранность трёх файлов версии 1 по прежним закреплённым хэшам. CLI проверки контракта завершился успешно. После приведения смыслового имени одного нового теста к кириллице отдельно подтверждён его запуск. Все прямые процессы, включая промежуточный неуспех, находятся в машинном журнале ниже.

Фикстура создаёт семь файлов в частном временном Git-дереве, передаёт подставной преобразователь, применяет и независимо проверяет поколение. Сверяются байты с `ё` и CRLF, точные технические суффиксы, регистрация классов и узость пути `.gitignore`. Отказ сохраняется для другого приложения, вложенного каталога, неверного регистра пути, `.xcscheme`, `.xyz`, `.h.bak` и самовольного расширения контракта. Живое поколение репозитория и Swift не используются.

Отдельная проверка Git-зависимости отклонила разрешённый для исторических ссылок самостоятельный клон: штатный контракт требует связанный `.git`-файл в Git-каталоге worktree, тогда как локальный клон имеет собственную `.git`-директорию. Это честно сохранённый отказ топологической проверки, а не готовность зависимости к живой генерации. В том составном вызове проверка diff и связности ещё не запускались; далее они выполняются отдельно. Топология не перестраивается за пределами разрешения, валидатор не ослабляется. Полная инициализация для общего smoke-check остаётся корню.

Проверка связности обнаружила лишнюю пустую строку непосредственно перед trailer временного сообщения коммита. Добавлена явная итоговая строка контрольной точки с каноническим отделением trailer; два исходных пользовательских текста сохранены без изменения. Отказ также учтён отдельно.

## Профиль и решение об оптимизации

[Машинное измерение](материалы/профиль-форматов-до.json) сохраняет исходные пути и байты, SHA-256 реализации и контракта, базовый commit, Python 3.14.7 и архитектуру arm64. Вход — семь коротких UTF-8 файлов без NUL; каждый из пяти повторов выполняет 2000 циклов по семи путям. Измерение использует `perf_counter_ns`, включает создание `Path('.')` и проверку результата каждого вызова. Чтение файлов, импорт модуля, Git, сборка, LinguisticKit и генерация поколения не входят во внутреннюю стоимость классификации.

Медиана — 4.280310 мкс на вызов. Загрузка и валидация политики заняли 0.185916 мс. Выбранный до запуска ориентир — менее 100 мкс на классификацию; это порог решения для данного синтетического случая, а не продуктовый SLA. Изменение алгоритма или кэширование не оправданы: новый код расширяет конечные небольшие перечни, а наблюдённая стоимость существенно ниже ориентира. Ускорение не заявляется. По уточнению координатора повтор профиля без изменения алгоритма не выполнялся; корректность подтверждена последующей регрессией.

Для воспроизведения запустить следующий Python-фрагмент из корня чистого клона через отчётную обёртку своей сессии с классом `адресная`; стандартная библиотека достаточна. Фрагмент печатает пять внутренних длительностей и медиану в наносекундах, без сети и Swift:

```python
from pathlib import Path
import importlib.util, statistics, time
каталог = Path('Инструменты/fum-bratislavskaya-proyekciya-pamyati')
спецификация = importlib.util.spec_from_file_location(
    'проекция', каталог / 'scripts/братиславская_проекция_памяти.py')
модуль = importlib.util.module_from_spec(спецификация)
спецификация.loader.exec_module(модуль)
политика = модуль.загрузить_политику(каталог / 'контракт-v2.json')
пути = [f'Приложения/FUMA/macOS/Пример{суффикс}' for суффикс in
        ('.c', '.h', '.modulemap', '.pbxproj', '.plist', '.entitlements')]
пути.append('Приложения/FUMA/macOS/.gitignore')
данные = 'Точные байты: ё\r\n'.encode('utf-8')
замеры = []
for повтор in range(5):
    начало = time.perf_counter_ns()
    for цикл in range(2000):
        for путь in пути:
            assert модуль.классифицировать_содержимое(
                Path('.'), путь, политика, данные)[1] == 'сохранить_байты'
    замеры.append(time.perf_counter_ns() - начало)
print(замеры, statistics.median(замеры) / 14000)
```

## Граница интеграции и остаток

Корень принимает четыре файла `fum-bratislavskaya-proyekciya-pamyati`: контракт версии 2, Python-валидатор, файл адресных тестов и SKILL.md, а также текущую папку Журнала. Навигация предыдущего запроса, индекс Журнала и индекс свежести согласованы только в изолированной ветке; при интеграции корень пересобирает их по своему актуальному дереву. Новых правил и широких исключений нет.

Сохранено унаследованное поколение из базы `aeae18cb146a34563ff39c84d9bc5ef59fffab91`: хэш файла манифеста `cc02a0482eeddea16d44b9049b9f062dc9004f3c09f97b47c9b71c288b7dde98`, записанный хэш входного инвентаря `sha256:544a1e4a110118a3a9e8957b50a3c4a8330380136ef524186f0892861bf62ff2`, хэш прежней политики `sha256:9f262153c9de986270cec76ad3c37da34c99ace0c187474ba8a1bc736222220a`. Это наблюдение сохранённого свидетельства, а не повторная независимая проверка поколения. От новых канонических файлов оно отстаёт; обновление требует штатного применения корнем после интеграции.

Для известных исторических ссылок восстановлен только отсутствующий игнорируемый граф (574 байта), а уже зарегистрированный LinguisticKit материализован отдельным полным клоном форка на прежнем gitlink с origin и upstream. Эти локальные входы не включаются в diff; содержание зависимости, ревизия и общая Git-конфигурация FUM сохранены.

Контрольная точка сохраняет открытый терминальный журнал без финального снимка. Дальнейшие обязанности корня: независимое чтение diff, интеграция с адаптацией приложения, общие индексы, стандартный smoke-check, обновление и независимая проверка проекции, финальная приёмка поставки FUM-STEP-0176. Этот отчёт не закрывает всю корневую задачу.
