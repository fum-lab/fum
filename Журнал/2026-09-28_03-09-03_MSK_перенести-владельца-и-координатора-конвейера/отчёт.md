## Проверки

RED: шесть новых сценариев завершились шестью отказами из-за отсутствующего модуля перехода; 72,453 с. Первый GREEN: 6/6, 120,338 с. Расширенные сценарии: 9/9 прошли, но ошибочный адрес дополнительного legacy-теста дал отказ загрузчика; весь запуск не принят. В следующем запуске используется фактическое имя класса и проверка ошибок загрузчика до исполнения. Запуски отражены в машинном блоке; реальный переход пока не выполнялся. Второй RED подтвердил два обхода первого сохранения (неверная вложенная схема и повторное запечатывание чужим UUID): 25,905 с, три ожидаемых отказа тестов. Оба пути теперь проверяются строгим валидатором. Итоговый адресный набор прошёл 15/15 за 211,367 с. Затем отдельный RED выявил запрет многострочной исходной команды; после исправления все три сценария изолированности и дословности прошли за 39,216 с. Профиль сохранён в [машинном материале](материалы/профиль-перехода.json).

## Решения и ограничения

- Подготовитель контрольного коммита отказал до записи подготовки: в этом этапе ошибочно создана история проверок v3 вместо v4. Строгий переход требует изменения самой отчётной обёртки, которого здесь нет. Восемь исходных записей сохраняются без преобразования; отдельный следующий этап фиксирует код по адресным проверкам текущего индекса.
- Реальный общий реестр занимает 259 549 155 байт. Профиль малой фикстуры не доказывает скорость переноса этих данных и полного нативного JSONL.

- Сохраняются два незавершённых диагностических этапа прежнего координатора; закрытые терминалы не доказывают их завершения.
- Старое отсутствие активной привязки не исправляется ручной заменой JSON. Перенос проверяет Git, источник команды, состав архива и неизменность закрытой цепочки под замком.
- При фиксации предыдущего этапа `создать` был вызван до завершения процесса `готово`; штатный отказ сохранён приватно, затем готовность и создание завершились успешно. Последовательность должна проверять фактический exit code перед зависимым действием.
- Проверка предыдущей квитанции ошибочно искала поле `коммит` вместо `результат.коммит`; независимая повторная сверка подтвердила OID, родителей, автора, чистое дерево и удалённый OID. Дальнейшие зависимые команды останавливаются на первой ошибке.
- Stop установлен в пользовательский файл hooks; подтверждение Trust со стороны интерфейса пока не получено. Нативное предотвращение раннего завершения ещё не доказано.
