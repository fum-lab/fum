# Отчёт 2026-07-27 20:10:35 MSK - Разрешить начальную коробочную FUM без GUI через Codex

Начальная инженерная часть коробочной стадии теперь явно может оставаться без собственного GUI FUM. Codex достаточен как внешний стенд запуска, анализа и тестирования, пока сами входы, результаты, трассы и проверки остаются версионированными, наблюдаемыми и воспроизводимыми вне конкретной агентской сессии.

## Результат

Уточнена реализованная карточка FUM-REQ-0019: последовательные безоконные Swift-срезы допускают полный неинтерактивный инженерный цикл через Codex. Паспорт начального прототипа закрепляет файловые и CLI-интерфейсы, коды завершения, канонические отчёты и автономные тесты как достаточную поверхность до GUI. Глоссарий и описание коробочной стадии теперь различают начальную инженерную часть и первую пользовательскую версию единого приложения.

Вопрос о развилке Git + Codex и собственного агентского цикла получил частичное прояснение. Быстрый внешний путь принят для всей начальной инженерной части, но не засчитан собственным runtime, событийным входом во время активной работы или model-only-провайдером FUM. Отдельная карточка требования и новый плановый шаг не создавались: это дублировало бы реализованное требование и завершённые FUM-STEP-0073/0074.

Описание стадии также синхронизировано с уже действующим прототипом: восстанавливаемые поколения сохраняются между процессами. Прототипный README прямо показывает, что Codex использует те же документированные команды, которые доступны обычному неинтерактивному процессу.

## Проверки

Структурная проверка подтвердила корневую панель и девять безопасных точек запуска прототипов. Внешняя сессия Codex вызвала действующий `запустить.sh`, разобрала канонический JSON схемы `2`, увидела три шага трассы и флаг `view_model.headless = true`. Автономный пакет прошёл 14/14 Swift-тестов. Отдельный отрицательный CLI-прогон различил отказ ненулевым кодом и стабильным префиксом диагностики; версионированный JSON-конверт ошибок остаётся возможным усилением, а не условием текущего безоконного допуска.
