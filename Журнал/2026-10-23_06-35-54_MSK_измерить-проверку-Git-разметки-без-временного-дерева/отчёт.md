## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
Полные материалы и ограничения сохранены вместе с исходными наблюдениями. Переписывание H ради материализации и кэш split отвергнуты по малой наблюдённой доле; кэш соединения Path не реализован: все миллионы конструкторов ему приписывать нельзя. Предложение свернуть несколько свежих filesystem-наблюдений в одно не принято за эквивалентное: статический контрсценарий с временным перенаправлением предка выше корня может различать варианты; это анализ, не исполненный эксперимент. Старые проверки и их временная модель сохранены. Следующий шаг — после N10 рассмотреть крупные интервалы N9 связности 75.820430542 с и готовности 68.108286834 с; дополнительный адресный профиль без Create нужен только если сохранённых данных недостаточно. Приоритет приемлемой скорости перед ограниченным Swift-опытом сохраняется. C84/S1 точного N9 принят как вход: selector/commit/tree/1407 записей/1347 пар/2754 Q-R, семь API и readback/replay сверены; полные 20GB ROOT не пересканировались при этой отдельной RO-передаче. Для конечного C84 был заново выбран полный Kfix, собственный exporter отсутствовал; старое правило не переносилось автоматически. Собственная установка S1 заново закрепила все 13 ресурсов из Git N9, полную собственную открытую границу и пять изменённых файлов. План/применение/наблюдённое завершение/свежий повтор успешны, запись только двух индексов, replay ноль записей, Git-индекс и own-пара сохранены. C84 остановлен без новой интеграции. Один RO-запрос ps попал на уже завершившийся PID и получил код 1; исход применения подтверждён терминалом 0, не ps. Неудачная попытка угадать путь markdown_recency не нашла файл; фактический канонический путь найден через rg --files. Эти диагностики не влияли на исполненные проверки. Новые исходники помощников сначала компилировались; параметризация выполнялась AST, а не склейкой кавычек. Приватные pstats и полные native вне Git, оригиналы сохраняются. Новый полный APFS-префикс и модель привязаны штатными dry/apply без пропусков; модель берётся из наблюдений. Все новые видимые ответы добавляются по диапазонам и хэшам; прежние 1712 событий не дублируются. В сохранённом результате обязательного чтения 1320 сообщений; полнота не доказана, три неизвестных происхождения остаются открыты; контрольная точка не завершает корень, не активирует узел, D22 или Swift.
