# Точки подключения прямого наблюдателя

Карта подтверждена независимым чтением исходников от `d9e432c6` в [текущем этапе](../запрос.md). Это проект подключения, а не выполненный перенос.

| Источник | Места и владение |
| --- | --- |
| [Исполнитель.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/Исполнитель.swift) | МетрикиМашины.команда, строки 147–150: контекст создаётся внутри измерить после появления UUID командного события. Метрики сильно удерживают Хранилище. |
| [ПодготовкаUbuntu.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/ПодготовкаUbuntu.swift) | Восемь мест метрик: Homebrew 59, curl 90, gpg/gpgv 101/105/107, qemu-img 170/173/174. Сохраняются пределы 1200/950/60/60/60/60/600/300 с. |
| [NoCloud.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/NoCloud.swift) | Ещё два места метрик: ssh-keygen в цикле 80 и hdiutil 113, по 60 с. Будущее получение public пока не живой вызов. |
| [ГотовностьГостя.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/ГотовностьГостя.swift) | Один отправитель 56–59: первичная команда 1100 с, экспорт 60 с. Владелец — хранилище службы VZ; проверка идентичности нужна до восстановления прежней истории. |
| [ДоступКГостю.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/ДоступКГостю.swift) | SSH по NAT 40, 180 с; контроль VSOCK 47, 20 с. Нужен отдельный личный каталог попытки и его flock, не повторный захват VM-lock. |
| [Хост.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/Хост.swift) | Прямые команды версий 47 и sw_vers 51 заменяются чтением Foundation/Darwin и наличия файлов. План уже использует только ресурсы. |

Всего шесть прямых вызовов Исполнитель.выполнить и десять мест метрики.команда. Счёт мест отличается от числа исполнений цикла. Нынешние пределы, stdin и явные Homebrew-переменные сохраняются; наследованная среда формируется у вызывающего слоя до передачи точного словаря.

[Хранилище.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/Хранилище.swift) владеет FD каталога и уже захваченным замком. Контекст заимствует их при живом сильном владельце до завершения наблюдателя и проверки квитанций. ЧтениеХранилища имеет только читающий FD: его нельзя сочетать с замком другого каталога. Повторное открытие VM-lock не заменяет заимствование удержанного FD.

В [КлиентМашины.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/КлиентМашины.swift) Process.run на строке 33 запускает службу с отдельным жизненным циклом. Подчинение её каналу жизни короткого CLI изменило бы поведение. Execv на строке 79 не исполняет defer при успехе: предварительная личная попытка проверки ключей должна завершиться до него.

[АдаптерVZ.swift](../../../Проекты/ВиртуальнаяМашина/Sources/ЯдроМашины/АдаптерVZ.swift) удерживается readiness-замыканием, но завершить на строке 214 вызывает exit даже при работающей utility queue. Наследованный flock должен оставаться у наблюдателя до очистки группы. Запись «остановлена» не доказывает освобождение замка; существующие проверки остановки на строках 59/67 КлиентМашины сохраняются.

Выбор runtime в [main.swift](../../../Проекты/ВиртуальнаяМашина/Sources/Машина/main.swift) нужен до создания состояния подготовки на строке 58. Состояние и остановка остаются доступны без Python и проверки ключей. Номера строк относятся к прочитанному d9e432c6 и не заменяют поиск точных объявлений после изменений.
