# Ограничить состояние Git helper

Git с `-C` запускает credential helper в checkout. На синтетике helper без XDG создал `.local` в тестовом checkout; отдельный Swift-кандидат задаёт helper private cwd и XDG_STATE_HOME, и фиктивный helper создал marker в state без `.local` в checkout. Production-профиль ограничен одной точной read-only операцией; push запрещён.

Ранняя версия выполнила ls-remote code-ветки exit 0 и отдельный credential fill exit 0 с выводом в `/dev/null` в фикстуре с пробелом и Unicode; после этого проверка `.local` в checkout и cwd прошла. Позднее кандидат ограничен по argv и взаимному расположению каталогов, synthetic marker и два отказа по overlap проверены; actual helper для этих новых байтов NOT_RUN. Pin gh, custody и TOCTOU каталогов, bounded wait/EOF и подключение к push UNKNOWN. Это не общий guard и не интеграция автоматизации агентов.
