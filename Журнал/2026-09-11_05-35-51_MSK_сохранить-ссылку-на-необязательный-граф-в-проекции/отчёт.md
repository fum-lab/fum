# Отчёт 2026-09-11 05:35:51 MSK - Сохранить ссылку на необязательный граф в проекции

Проектор допускает точную игнорируемую ссылку на отсутствующий `.obsidian/graph.json`, пересчитывает её из производного файла до канонического слоя и не создаёт граф либо его каталог. Существующий пользовательский граф сохраняется. Для каждой исходной ссылки переиспользуется неизменный предикат связности 0203; анализатор переименований, контракт поколения и остальные отсутствующие цели не изменены.

### Этап оптимизации по измеренному решению

[Профиль до оптимизации](материалы/профиль-проекции-графа.json) измеряет уже корректную первоначальную поддержку. [Профиль после](материалы/профиль-проекции-графа-после.json) использует тот же [сценарий](../../Инструменты/fum-bratislavskaya-proyekciya-pamyati/tests/профиль_необязательного_графа_проекции.py): пять тёплых серий по пять формирований двух выходов из готового плана, отдельно первый вызов. Положительный Markdown содержит 25 одинаковых ссылок и 986 байт; отрицательный содержит 1086 байт. SHA-256 сохраняют вход, код, предикат и сценарий. Измеритель — `perf_counter_ns`, Python 3.14.7 на Darwin arm64. Импорт сценария, создание синтетического Git-checkout, построение плана, установка поколения и Swift находятся вне замера; преобразователь подставной.

Заданный до замеров ориентир решения — 100 мс на это формирование. Первоначальная реализация вызывала Git для каждой допустимой отсутствующей цели и превысила ориентир. После согласования с корнем результат Git-ignore используется только в одном вызове `сформировать_выходы`, а перед возвратом проверяется повторно. Предикат физического адреса выполняется для каждой ссылки. Отдельные регрессии отвергают снятие игнорирования между двумя вызовами и во время одного формирования. Измеренное решение — сохранить эту ограниченную оптимизацию; глобальный кэш не вводится. Малое время отказа не означает ускорения обработки 25 ссылок: отрицательный случай заканчивается раньше. Результат не оценивает Swift, полную память FUM или общий smoke.

## Проверки

Первоначальный RED `a7b2f734-8f03-4162-b814-838d57198766` воспроизвёл отказ отсутствующей цели при полной синтетической установке с отсутствующим и существующим каталогом `.obsidian`, а также при выводе ссылки. Первый GREEN `74c77cf5-2ab0-49d8-ae9a-1a4f02d131f7` подтвердил шесть сценариев. Отдельный RED `337e207a-e130-4a0e-9a1a-19184788f024` показал, что снятие ignore во время формирования ранее не отклоняло выход. Итоговый GREEN `a79dbda0-1d5a-4ec7-8756-df9cf67f10aa` подтвердил все семь сценариев, включая этот поздний отказ и отсутствие повторного использования между вызовами.

Положительные сценарии проходят `применить_поколение` и независимый `проверить_манифест` в синтетическом checkout; проверяются отсутствие создания графа и каталога, сохранение байтов, inode и mtime существующего графа. Ссылка производного Markdown разрешается ровно к каноническому графу. Отрицательные сценарии сохраняют отказ для иных отсутствующих имён, несовпадения регистра адреса и физического предка, символических ссылок, абсолютного пути, выхода из checkout, пути через отсутствующий промежуточный каталог и снятого ignore. Собственные объявления двух новых исходников проверены отдельным запуском `97cf46e6-bd18-4f65-b5da-6190d3068d88` без новых латинских имён. Обновлённый изолированный diff прочитан корнем без дополнительных замечаний.

## Решения и ограничения

Это узкое расширение ранее выполненного исправления FUM-СБОЙ-0052 / FUM-STEP-0203 до проекции. Предикат из `28f51c58fa8df4d20d33ef2f05dab758cb7a6f83` уже присутствовал в `8609003af7fdb6ef5dddf21c51cd6607ddb34088`; его отсутствие не было причиной нового отказа. Прежний проектор ещё вызывал строгую проверку существования физической цели до политики исключённого канонического графа. Локальный файл `{}`, созданный математической задачей для ограниченного восстановления до уточнения координатора, не доказывает устранение механизма и не используется здесь как исправление.

Для интеграции достаточно diff одного исполняемого файла проектора при двух предпосылках: сохранён текущий проектор с прежними зависимостями и неизменным анализатором переименований; в локальной связности имеется точный предикат 0203. Адресные тесты и профиль используют существующую тестовую основу проекции. Контракты, схемы, rename-анализатор, канонический адаптер, математические карточки и чужие деревья не менялись. Точные исходные blobs и SHA-256 указаны в [происхождении](материалы/происхождение.json).

Полный smoke не запускался. Унаследованное производное поколение своего checkout не пересобиралось и не выдаётся за актуальную проекцию этого коммита. Машинный журнал остаётся открытым терминальным предпросмотром; перед фиксацией выполняется допуск `--контрольная-точка`. Смысловая приёмка общей задачи, актуализация карточек и применение в математическом дереве остаются у корня.
