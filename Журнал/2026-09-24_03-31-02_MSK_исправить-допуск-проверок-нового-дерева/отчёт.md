# Отчёт 2026-09-24 03:31:02 MSK - Исправить допуск проверок нового дерева

Исправлена подготовка закреплённой Git-зависимости в новом linked worktree: общая конфигурация superproject больше не меняется при инициализации. Конечный писатель получает отдельный начальный сценарий после раннего назначения и до установки Журнала. Он сверяет C, HEAD, индекс, gitlink и собственное назначение, сохраняет намерение в своём Git-каталоге и допускает повтор только как проверку уже подготовленного окружения без fetch. Неизвестная или неуспешная попытка не повторяется автоматически.

Рассмотренный допуск пустой «неиспользуемой» зависимости отклонён: неизменность каталога не доказывает неприменимость зависимости произвольной проверке. Отпечаток v4 и обычный создатель коммитов не изменены. Дополнение НОВОЕ-000019 разрешает только ограниченную подготовку окружения; 000210 сохраняется. Декларация и валидатор правил включают пятый CLI подготовки.

Результаты обоих остановленных писателей сохранены в двух приватных пакетах. Повторное чтение пакетов и исходных рабочих/index-снимков совпало. Это не восстановление, приёмка результатов или разрешение возобновить старое поколение. Новый запуск, реальные дочерние коммиты, их слияние и обратная доставка ещё предстоят.

## Проверки

Итоговый набор прошёл: **54 теста**, валидатор **223 правил в 11 темах** и воспроизводимый профиль. Сквозная фикстура проверяет свежий нерекурсивный clone, linked worktree, подготовку окружения, первую v4-проверку и конечный дочерний коммит. До исправлений наблюдались RED для общей конфигурации, отсутствующего сценария, внешнего Git-hook, скрытых индексных флагов и синхронизации родителя квитанции. Итоговый GREEN подтверждает исправления.

Независимое чтение выявило регрессию прежней диагностики: ранний выход по всем ошибкам скрывал расхождение remote после ошибки `.gitmodules`. Теперь ранний выход ограничен небезопасной топологией, остальные диагностики сохраняются. Финальное чтение ревьюером не выявило блокирующих замечаний; он тесты не запускал.

Сохранены и не выданы за успех: первый экспериментальный набор завершился по тайм-ауту 120 с из-за лишних импортированных тестов; промежуточный GREEN выявил слишком общий валидатор пути зависимости; один общий прогон прерван после обнаружения регрессии диагностики. В итоговом наборе включён failfast. Неуспешная редакторская операция не изменила файлов; сбой служебного обновления инвентаря после изменения нормы исправлен, затем маршрут и валидатор прошли. Читающая сводка записей однажды отказала на ещё активной записи с пустой длительностью; это не результат тестов и не изменение их данных.

## Решения и ограничения

Чужие checkout, индексы, refs и общая конфигурация Git не записывались. Вызовы Git очищают переменные `GIT_*`, отключают hooks, replace и fsmonitor; скрывающие флаги индекса не принимаются. Это не универсальная песочница. Сырые байты перед коммитом проверяются прежним строгим допуском. Порядок fsync проверен тестом; физическое отключение питания не моделировалось.

Следующий этап: терминально сохранить неудачное поколение с уже сохранёнными пакетами, подготовить новые точные C и поручения с явной подготовкой окружения до Журнала, затем проверить реальные поставки. Для обратного получения потребуется отдельное конечное назначение получателя; старое дочернее поручение само по себе его не разрешает. Остальные направления и проекция остаются на паузе.

После прерывания предыдущего хода работа возобновлена с тем же HEAD и сохранёнными файлами. Прерывание остановило чтение остатка JSONL и оставило пустой служебный вывод; этот вывод не использован как свидетельство. Новая сверка выполняется по отдельному неизменяемому префиксу. Причина отсутствия дальнейшего движения в том ходе — завершённый ответ координатора до фиксации этапа, а не новый отказ проверенного кода.
