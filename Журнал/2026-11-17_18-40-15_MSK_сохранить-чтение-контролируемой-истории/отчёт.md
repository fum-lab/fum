# Сохранить чтение контролируемой истории

Добавлена отдельная CLI-команда чтения сохранённой controlled-истории. Она проверяет заданные run и policy, ограниченные квитанции terminal и release и точное содержимое history; печатает типизированный UNKNOWN и возвращает код 3. Ошибки открытия, чтения и закрытия в CLI сообщаются без частного пути. Общий guard запуска не изменён.

Один read-only вызов на сохранённых private квитанциях собственного worktree вернул ожидаемые UNKNOWN и exit 3; terminal SHA-256 `a8299fb571e37bb04e4ae712997edfd2a633a172b370be1f7265abb9de4e66a1`. Адресный тест точного кандидата проверил код UNKNOWN, подмену и ошибки с сокрытием пути. Результаты и точный состав независимо сверены. Согласованность файлов не доказывает их происхождения, полного cleanup, непрерывной custody или production-допуска; обычная команда запуска остаётся закрыта.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
