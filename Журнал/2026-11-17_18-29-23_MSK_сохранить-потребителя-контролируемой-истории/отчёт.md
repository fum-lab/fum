# Сохранить потребителя контролируемой истории

Добавлен потребитель, который после освобождения удержания сверяет identity открытого каталога и точные байты terminal, release и history с этим владением. Результат типизирован и содержит UNKNOWN, run и хэш истории; его нельзя использовать как булев успех. Это не доказывает непрерывную custody, отсутствие ABA или пригодность production. Общий guard остаётся закрытым.

Один controlled lifecycle собственного рабочего дерева с Git CLT и тестовым legacy observer завершился с восемью raw 0; потребитель прочитал историю и вернул UNKNOWN. Terminal SHA-256: `3d96d1f6d7f814778215825fd72e6a437690e8eea71464b8b879a8c8841bd890`. Отдельный exact тест фактической подмены private файла прошёл и подтвердил отказ; первый вариант launcher завершился exit 1 из-за ошибки одноэлементного tuple и сохранён отдельно. Выводы независимо сверены. Полный regression, syscall trace, exec image и production admission не подтверждены.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
