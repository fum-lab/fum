# Разбирать JSON скалярами

Разбор входного JSON переведён на Unicode-скаляры. Буквальный и экранированный U+0301 после открывающей кавычки обработаны, одиночный суррогат и повторный ключ отклонены. Четыре новых наблюдения и сохранённые статусы независимо сверены.

Интерфейс передаёт данные через argv; поддержка JSON неполна, bool и null во входном парсере отсутствуют. Raw wait, независимый argv readback, полная custody, чистый клон, общий smoke и TDD не подтверждены. Фактический FUMA-граф на этой версии не исполнялся.
