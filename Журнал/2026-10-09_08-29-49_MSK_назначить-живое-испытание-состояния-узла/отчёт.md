## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
Приёмка кода не доказывает восстановление всех живых сессий. Испытание переиспользует expected, доверие, ACT, решение ROOT и контейнер; второй реестр не вводится. ROOT назначает устойчивые идентичности и отдельный state ref; настоящий UUID писателя, физическое дерево, ACT, Git-назначение, кандидат и каталог операции ещё требуют оформления. Публичность абсолютного корня назначения и подготовка соседней навигации проверяются до эффекта. Ordinary-ребёнку пока не найден штатный конечный допуск завершения этого этапа: запись прекращена, глобальные обязательства ROOT не объявляются закрытыми. Широкий repair предложил нормализацию URL в 489 старых файлах и не применён. При повторении избыточного захвата нужен отдельный публичный режим только навигации. Источники наблюдений, native JSONL и служебные адреса остаются приватными. RO-разбор подтвердил настоящий публикационный блокер: назначение .1 обязано содержать физический домашний путь, который отвергается error.posix-user-home. Сохранена отдельная постановка совместимого публикуемого назначения без ослабления сканера. Bootstrap с отдельным контрольным ref не содержит self-SHA; обычная открытая пара готовится ROOT до исходного C, без закрытого снимка запусков. Для исправления собственной конфигурации применяется подготовить-повтор с новыми приватными выходами. Готовность отсутствует, поэтому отзыв поколения не выполняется. Старые неисполненные future-цели исключены, три терминальных свидетельства сохранены. Нужен автоматический вывод первого позиционного аргумента публикационной проверки из поля запроса, чтобы исключить повтор этой ошибки.
