# Сохранить контролируемую историю

Сохранён отдельный опытный issuer для явно назначенного корня, с проверкой identity каталога по удержанному FD при выдаче и потреблении. Одноразовая заявка связана с владельцем, запуском, потоком и сроком; эти проверки не доказывают authority, непрерывную custody или отсутствие ABA.

После readback квитанции освобождения в отдельный private каталог тем же способом EXCL, fsync и readback записывается `history.json`: версия наблюдения, UNKNOWN и хэши terminal и release без отпечатка снимка. Запись выполняется до закрытия FD каталога и не доказывает полного cleanup. Публичный guard остаётся закрытым, legacy история не переинтерпретируется.

Exact candidate прошёл три адресных теста. Отдельный synthetic lifecycle точных байтов с Git CLT и observer прошёл: семь пакетов и observer завершились с raw 0, history проверена при чтении. SHA-256 terminal: `45bb7cf1ed461e3f48647499c8d3048bcbb06ca743244bdc55c07e6b0c820e7c`. Независимая проверка исходного кандидата и границ выполнена; полный regression, production admission, непрерывная custody, exec image и power-loss durability не подтверждены.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна.
