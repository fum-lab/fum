## Решения и ограничения на checkpoint до уточнения ROOT

- За основу остаётся C68 merge-коммит; новый C координатора не требуется для назначенной пары исходников.
- Задача ребёнка ограничена чистым typed request builder и regression-источником. Настоящий Native вызов, runtime-разрешение ID и любые тестовые запуски в его области не выполняются.
- В том же builder поручено сохранить явно переданный полный ref выбранного FUM namespace и отклонять пустые компоненты/коллизии; объяснительного текста без исправления генерации недостаточно. Указанный FUM ref является примером delivery, а не `startingState` Native-задачи.
- Родительское сообщение отмечает C64 применимость `UNKNOWN`; в текущую ветку C64 не восстанавливается.
- В гранте v1 ROOT разрешил только материализацию отсутствующих target ref и W. Тогда ref уже существовал, поэтому v1-этап остановился без эффекта. Это исторический исход; он заменён отдельным ACT v2, выполненным в текущем итоге ниже.
