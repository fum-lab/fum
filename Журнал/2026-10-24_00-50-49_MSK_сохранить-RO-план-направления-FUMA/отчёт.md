## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
- Плановый сценарий использует ограниченный синтетический журнал для предложения о вызове без результата. Факты и гипотеза LLM разделены, команды ответа не исполняются. Будущий replay использует сохранённый результат без API; неизвестный исход отправки не повторяется автоматически.
- Пять проверок ещё предстоят: нулевой API при replay; подмена входов/происхождения; пара/пропуск/дубликат/хвост; журнал до отправки и неизвестность после неё; раскрытие/бюджет. Ни один исход реализации не объявляется наблюдённым.
- Препятствия: аттестация prompts/токенизация, отсутствие сырых API-байтов около client.post, RAM-ledger и необходимость единого актуального допущенного OID вместо H408. Кодовые зависимости не восстанавливаются и начальный commit чужого native не меняется.
- Чат Самостоятельное направление FUMA остаётся существующим независимым направлением; его W/ref прочитаны и остались на H408, чистыми. Чужой checkout/индекс/ref и его Журнал не менялись. STOP предметной записи сохраняется без архивации, возобновления или циклического опроса.
- Служебный guard того RO-этапа отказал с диагностикой точного регистра пути; это ограничение, а не завершение направления. В настоящем этапе предметные проверки FUMA, сборки и API не выполнялись.
- Выполнен только собственный постановочный checkpoint. Старые D95, новый D с bootstrap, S, код, правила, policy, общий реестр, master и ROOT/fuma не менялись. Проекция и full не запускались; реализация, ускорение, ROOT-приёмка и интеграция не объявляются. Остаток постоянной задачи сохранён.
