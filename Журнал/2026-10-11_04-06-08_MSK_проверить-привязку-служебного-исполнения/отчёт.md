## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
Код закрепляет настоящий dataclasses code object до hooks и допускает только непосредственный кадр, поток, исходные байты и filename. Pending погашается до проверки; native object не регистрируется для дальнейшего исполнения. Сравнение выполняется по полной сериализации marshal protocol 2 с конечными точными типами констант. Общего bypass рекурсивных событий и нового native eval нет. Независимый читающий обзор нашёл обход через поддельный filename движка: он закрыт непосредственным sys._getframe(1), отрицательный тест прошёл. Финальный RO обзор блокирующих дефектов не нашёл, сам ничего не запускал. U/A/ACT/T8/C429 сохраняются; чужой checkout не менялся. По измерениям дальнейшая оптимизация загрузчика не обоснована: рабочий цикл узла ещё не измерен. Сверены связанные пояснения; пользовательский сценарий README этим внутренним ремонтом не меняется. Вспомогательное заполнение отчёта сначала отказало до записи: приватный reader ошибочно применён к публичным RAW. Повтор использует чтение обычного канонического JSON; оба исхода сохранены. Длительное начальное наблюдение ROOT JSONL в подготовке сохраняется как отдельное наблюдение для оптимизации, а не переносится в стоимость dataclass. Следующий этап: полный Q и его ресурсный guard, затем адресный запуск владельцем и новый читающий процесс.
