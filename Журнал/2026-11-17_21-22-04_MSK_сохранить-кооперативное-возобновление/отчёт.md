# Сохранить кооперативное возобновление

Для явного опытного контракта добавлено возобновление непустой legacy истории под root → session lock с проверкой отсутствия controlled active. Штатный путь принимает v1 и v2 к начальной проверке; исторический snapshot v2 при возобновлении штатно отклоняется, успешная поддержка v2 не заявляется. Default, старые writers и общий guard не изменены.

Точный synthetic test с непустой v1 историей проверил реальное закрытие private отчёта, отказ возобновления при active и успешное возобновление после его удаления. Popen и Git были fail-mock и не вызывались. Terminal SHA-256 `8ef65270fd4353c9bf5cf033d612ca5044d50fa58dff6e2bc96f96fd5755e6dd` независимо сверен. Межпроцессная конкуренция этого действия, default writers, ABA, custody и production admission не доказаны.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
