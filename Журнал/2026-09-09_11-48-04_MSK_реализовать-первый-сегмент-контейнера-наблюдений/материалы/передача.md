# Передать незавершённую реализацию контейнера

По указанию корневой задачи работа передаётся отдельной видимой задаче Codex Desktop. Исполнитель прекращает записи после подготовки этой передачи. Коммит и GREEN отсутствуют; готовность контейнера не объявляется.

## Сохранённое состояние

- Код: базовый HEAD `39eb66a29c0be6844e73bcb8072e68b914ea7387`, ветка `refs/heads/codex/observation-container-01a07d3d`. Семь новых исходных файлов пакета ещё не поставлены в индекс. Внешний origin отсутствует; публикации не было.
- FUM: базовый HEAD `ba6f1c7907478a638c9f0fda6d93f6da37a7fcf5`, ветка `refs/heads/codex/контейнер-наблюдений-01a07d3d`. Созданы запрос, отчёт, план и четыре терминальные записи v4; автоматизация старта также обновила индекс Журнала и навигацию предыдущего запроса.
- Только собственный pinned `Зависимости/LinguisticKit` материализован полноценным клоном из fork на `837e2ce107b97ee7b9d3344c9fe99142281fe393`; его origin и upstream настроены внутри этого клона. Gitlink, общие refs и конфигурация не менялись.

## Файлы кода

Все пути ниже относительны `Packages/КонтейнерНаблюдений` внешнего репозитория:

- `Package.swift`: tools 6.0, macOS 14, язык Swift 6; библиотека, два CLI и тестовая цель.
- `Sources/КонтейнерНаблюдений/Контракт.swift`: описания, квитанция, ошибки, внедряемые операции записи и синхронизации, лимиты и метка профиля.
- `Sources/КонтейнерНаблюдений/Файлы.swift`: первоначальный файловый слой Darwin, полный pread, повтор EINTR, no-follow обход корня через directory fd.
- `Sources/КонтейнерНаблюдений/Формат.swift`: первоначальное кодирование и потоковое сканирование кадров.
- `Sources/ПисательКонтейнера/main.swift` и `Sources/ЧитательКонтейнера/main.swift`: ещё пустые заглушки.
- `Tests/КонтейнерНаблюденийTests/СегментTests.swift`: семь подготовленных тестов.

Класс `Сегмент` пока отсутствует: первоначальная RED-заглушка удалена при начале реализации, исполняемая реализация ещё не добавлена. Последняя кодовая правка не собиралась. Исходники являются незавершённым черновиком.

## Фактические проверки

1. Default swiftbuild Swift 6.4 не дошёл до тестов: codesign кириллического XCTest bundle завершился отказом.
2. Native SwiftPM собрал исходную заглушку; четыре теста записи/байтов/ENOSPC/fsync получили предметный RED на отсутствии реализации.
3. RED усечения и повреждения получен; межпроцессная проверка первоначально ошиблась при поиске CLI относительно тестового runner.
4. После исправления пути на `.build/debug` отдельный процесс действительно запустился; предметный RED подтвердил пустой ответ писателя и отсутствие исходных 256 байтов у читателя.

Все четыре реальные процесса сохранены через v4-обёртку. Предварительный отказ обёртки до запуска Swift из-за отсутствовавшего подмодуля не создавал запись и не считается RED. Тестовых процессов к моменту передачи нет.

## Продолжение

1. Реализовать `Сегмент`: неблокирующий flock на всё время владения, full write с short-write/EINTR/zero-write, sync файла и directory fd до каждого ack, poisoned state после I/O-отказа, явный truncate только неполного хвоста, стабильный ID с проверкой metadata+payload и повторной успешной sync перед ack.
2. Реализовать отдельные CLI с явным корнем данных и только выбранным синтетическим входом.
3. Довести семь RED до GREEN и расширить регрессии: второй писатель/читатель, symlink и спецфайл, лимиты до выделения памяти, согласованно перехэшированные неправильные последовательности, ошибки sync имени, частичный ENOSPC, EINTR/zero-write, повтор после неопределённого fsync.
4. Добавить профильные метки исполнения и воспроизводимый профиль throughput/latency/RSS/recovery; пока профиль и оптимизация не выполнены.
5. Закончить README и формат, привязку источников, recency, публикационные и адресные проверки; получить независимое ревью. Общая карточка 0156 остаётся за корнем.

Архивные официальные manpages Apple прочитаны для границ fsync и advisory flock; перенос их сырого материала и закрепление ссылок ещё не сделаны. `fsync` и авария процесса не доказывают потерю питания. Ротация сегментов и подключение сенсоров остаются вне этой первой реализации.
