# Проверить ядро контейнера

Семь базовых сценариев прошли после реализации. Первый вызов этого исполнителя с тем же набором выявил ENOTDIR: Foundation сокращал физический путь временного каталога до символьного /var. Тестовый корень теперь получается через POSIX realpath. Второй вызов прошёл: сборка 1,60 с, семь тестов 0,844 с по выводу SwiftPM. Полную длительность процесса хранит v4.

## Воспроизводимый вызов

Из корня внешнего репозитория:

```sh
swift test --package-path Packages/КонтейнерНаблюдений --build-system native --jobs 2 --filter СегментTests
```

Оба запуска выполнены через локальную обёртку FUM с классом адресная и тайм-аутом 120 с. Рабочий каталог обёртки — собственное FUM-дерево; значение --package-path указывало на абсолютный путь назначенного пакета. Хэши испытуемых файлов для успешного вызова сохранены в [снимке ядра](исходники-ядра.json). V4 отпечаток FUM сам по себе не включает отдельный кодовый репозиторий; этот снимок отдельно связывает результат с кодом.

## Остаток

Прямой заключительный допуск контрольной точки вернул код 1 из-за исторических ссылок на отсутствующий в изолированном worktree игнорируемый пользовательский .obsidian/graph.json. Файл не создаётся и пользовательское состояние не копируется. Отказ не объявляется успехом; по явной границе правила 000178 требуется проверить остальные диагностики. Допуск выполняется вне таблицы прямых тестов как заключительная проверка контрольной точки согласно 000188.

Расширенные регрессии, профиль, решение об оптимизации и документация ещё не завершены. Связность проверяется в режиме контрольной точки. Общий smoke и проекция переданы планировщику; этот коммит не является их приёмкой. Существующее поколение Proyekcii сохранено из базового FUM-коммита ba6f1c7907478a638c9f0fda6d93f6da37a7fcf5 и отстаёт от новых журнальных файлов; независимо в этой задаче оно не проверялось.
