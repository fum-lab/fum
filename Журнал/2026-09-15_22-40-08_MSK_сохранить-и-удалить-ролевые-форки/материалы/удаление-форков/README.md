# Архивирование ролевых форков

Сценарий сохраняет явно перечисленные ролевые репозитории FUM перед отдельно разрешённым удалением. Он использует установленный Git, Git LFS и авторизованный GitHub CLI. Основной репозиторий и зеркала зависимостей исключены точным списком.

Запуск выполняется из корня FUM. Передайте действие `подготовить`, абсолютный физический каталог вне Git через `--архив`, существующий локальный FUM через `--объекты` и точные полные имена после `--репозитории`. Отдельное действие `удалить` использует тот же архив; само наличие архива разрешением на удаление не является. Полный пример аргументов доступен через `--help`.

Для каждого репозитория сохраняются независимый Git mirror, все наблюдаемые Git refs, ответы GitHub и журнал отдельных вызовов с длительностью и SHA-256. Проверяются Git-объекты, равенство ссылок и отсутствие зависимости от другого object store. Непустые Issues, PR, релизы, развёртывания, Actions, wiki и LFS требуют расширения архива; сценарий не выдаёт неполный архив за полный.

Перед удалением повторно проверяются идентичность, метаданные, Git refs и перечисленные ресурсы. Файлы и каталоги архива синхронизируются с постоянным носителем. Намерение сохраняется до вызова GitHub CLI. После известного успешного ответа проверяются HTTP 404 целевого репозитория и доступность основного FUM. Неизвестный исход или отказ оставляют намерение и запрещают автоматический повтор; оператор сначала разбирает сохранённый ответ и текущее состояние.

GitHub CLI требует право `delete_repo`. Сценарий не получает его самостоятельно. API удаляет по точному имени после сверки ID; атомарного серверного условия на этот ID он не обещает. Граница — согласованная работа владельца без конкурирующего переименования либо изменения удаляемых репозиториев. Работающие процессы и чужие локальные клоны сценарий не меняет.

В этой сессии подготовлено 15 архивов с 258 Git refs. Первая попытка удаления получила HTTP 403 из-за отсутствия нужного права. После команды пользователя удалить форки самостоятельно автоматическое удаление прекращено; процесс обновления авторизации отменён. Ни один успешный результат удаления агентом не заявляется.

Проверки выполняются через штатную отчётную обёртку: `python3 -B -m unittest discover` с этим каталогом и шаблоном `test_*.py`. Автономный набор не обращается к GitHub и проверяет допустимые цели, изменившиеся источники, отсутствие архива, точный CLI-вызов и запрет повторной попытки. Реальные внешние запуски сохраняются отдельно в отчёте задачи. Это ограниченный прототип на Python/CLI; он ещё не подключён к Swift-адаптеру и графу структурирующих операторов.
