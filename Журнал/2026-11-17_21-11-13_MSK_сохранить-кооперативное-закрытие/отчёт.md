# Сохранить кооперативное закрытие

Для опытного opt-in контракта добавлено закрытие непустой legacy истории v1/v2 под root → session lock. Существующий controlled active отклоняет действие до записи. Git-контекст для v1/v2 не вычисляется; обычный default и другие писатели не изменены, общий guard остаётся закрытым.

Точный synthetic test с непустой v1 историей проверил отсутствие записи при active, затем реальное создание snapshot и обновление private отчёта без active; mock Popen и Git не вызывались. Terminal SHA-256 `6db4cbeec8108b45fa68595b4911bbfe31962fe4e5a2f2f08513dfaf011f3e7c` независимо сверен. Default и старые writers, межпроцессная конкуренция этого закрытия, ABA, custody и production admission не доказаны.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
