## Решения и ограничения

Первое уточнение включает внутри оболочки запросы модели и вызовы инструментов/ОС. Ответ «Оба потока» сохранён отдельно с точным вопросом и происхождением формы. Чтение stdout само по себе не доказывает охват API.

На вопрос о едином бинарнике: прочитанная постановка FUM-STEP-0176 не задаёт эту цель. Она теперь явно сохранена как снижение IPC; функции и библиотеки в одном процессе рассматриваются при выборе реализации. Единый файл не гарантирует единственного процесса. Системные frameworks не обещаны частью собственного бинарника; выбор компонентов требует измерений и проверки пригодности встраивания.

Применяется узкая граница000178 из запроса только для прежних282ссылок графа. Общий допуск не объявляется успешным, новая проекция и полная приёмка не выполнены. Финальная интеграция требует устранения граф-отказа0203. Код, карточки с новыми ID и чужие ветки не изменялись.
