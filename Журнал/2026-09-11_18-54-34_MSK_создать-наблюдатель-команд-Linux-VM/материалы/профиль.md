# Профиль наблюдателя команды

До измерения принят критерий: медиана полного запуска трёх одинаковых настоящих фикстур меньше 250 ms. Каждая фикстура создаёт родителя, наблюдатель через `python -I -S -B -c` и обычную команду; передаёт `точные байты\n`, принимает stdout и stderr, проверяет успешную конечную квитанцию и освобождённый flock. UUID и личный временный каталог различаются, содержательная команда одинакова. Время измеряется `time.monotonic_ns()` от запуска родителя до его `communicate()` и проверки квитанции; внутреннее время наблюдателя берётся отдельно из квитанции. Перекрывающиеся длительности не складываются.

Сценарий выполняется адресной отчётной обёрткой после GREEN восьми тестов. Оценка относится к запуску команды на текущем macOS, а не к производительности гостевой VM. Решение об оптимизации принимается только после сохранения результата.

Результат первого измерения сохранён в [профиле JSON](профиль.json): медиана 204,274416 ms. Критерий выдержан; реализация сохранена без оптимизации, поскольку профиль не выявил оправданного изменения ресурсов или алгоритма.

## Воспроизведение

В адресной команде обёртки из [отчёта](../отчёт.md) имя заменяется на «Профиль наблюдателя: три одинаковые настоящие команды», тайм-аут — на 20 секунд, а команда после `--` — на `python3 -B -c` со следующим точным аргументом. Входом служит открытая фикстура из того же checkout; два SHA-256 привязывают результат к исполняемым байтам.

```python
import runpy,time,json,hashlib,platform,sys,statistics
from pathlib import Path
путь=Path("Проекты/ВиртуальнаяМашина/Tests/ГостевыеПроверки/test_наблюдатель.py").resolve()
модуль=runpy.run_path(str(путь)); замеры=[]
for номер in range(3):
    случай=модуль["ПроверкиНаблюдателя"](); случай.setUp()
    try:
        описание=случай.описание(); начало=time.monotonic_ns()
        процесс=случай.запустить(описание); _,ошибки=процесс.communicate(timeout=5)
        assert процесс.returncode==0,ошибки.decode()
        итог=json.loads(случай.квитанция(описание).read_bytes())
        assert итог["исход"]=="успех" and итог["группа_исчезла"] and случай.свободен()
        assert (случай.корень/"вывод").read_bytes()=="точные байты\n".encode()
        замеры.append({"повтор":номер+1,"полный_нс":time.monotonic_ns()-начало,"наблюдатель_нс":итог["длительность_нс"]})
    finally: случай.doCleanups()
результат={"схема":"fum.профиль-наблюдателя.1","python":sys.version.split()[0],"система":platform.system(),"архитектура":platform.machine(),"исходник_sha256":hashlib.sha256(модуль["наблюдатель"].read_bytes()).hexdigest(),"фикстура_sha256":hashlib.sha256(путь.read_bytes()).hexdigest(),"измерения":замеры,"медиана_нс":statistics.median(замер["полный_нс"] for замер in замеры),"критерий_нс":250000000}
print(json.dumps(результат,ensure_ascii=False,sort_keys=True,indent=2))
assert результат["медиана_нс"]<результат["критерий_нс"]
```
