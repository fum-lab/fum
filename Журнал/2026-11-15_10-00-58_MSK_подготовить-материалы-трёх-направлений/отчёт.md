# Подготовить материалы трёх направлений

Подготовлены два предметных файла в области `Проекты/ниокр/`: программа сооружений и атрибутированный свод сооружений, рюкзака и транспортёра. Это исследовательские документы с неопределёнными параметрами; они не подтверждают выполненных испытаний, инженерной пригодности или цены. Коммит и публикация на момент подготовки отчёта не выполнены.

В собственном частичном checkout по прямому адресу ROOT восстановлены ранее отсутствовавшие отслеживаемые файлы: навык структуры папок запросов, сценарии свежести и связности, сценарий московского времени. Они установлены из stage-0/HEAD через исключительное создание, режим 0644; Git blob-хэши совпали с индексом. Индекс и флаги skip-worktree не менялись. Каталог `.local/` сохранён вне предметной области и не открывался. Это не полная материализация checkout.

Полный ROOT JSONL и Creator не использовались по прямому ограничению. Первичные пять команд переданы ROOT как неполный перечень. Обычный start меняет соседние записи и индекс, поэтому не запускался. Пара установлена в checkout по O_EXCL; штатный установщик и общая свежесть индекса остаются неисполненными; обычная приёмка и интеграция не проведены. Контрольные проверки и длительности не измерены, в отчёте не выдумываются.

Ограниченная свежесть предметной пары подготовлена в отдельной fixture: первая попытка с системным Python 3.9.6 завершилась ошибкой при построении приватного индекса; вторая отдельная попытка с закреплённым Python 3.15.2 завершилась update exit 0 и check exit 0. Тела сверены побайтно, preimage сохранены O_EXCL с fsync и проверкой хэша, два отдельных patch завершились exit 0 с совпадением результата. Публичные SHA предметных файлов после обновления: программа ac0813c0225ae6d20ba947c43dc21652b26e0e45a3e135e0b562681a9de06431, свод 321ef751e61a0ae16b83311c92a56509d16d6b98511aebec1a6e365add13e670. Общий индекс и полный smoke не выполнялись. Независимая сверка Поставки подтвердила SHA и сохранность тел; семантическая приёмка не проведена.


В частной fixture были созданы четыре файла с расширением `.py` как точные копии отслеживаемых исходников из Git blob и использованы при ограниченных прогонах; наличие отдельного разрешения на такие копии в свете запрета создания Python-файлов остаётся UNKNOWN. ROOT уведомлён. Файлы и квитанции сохранены, дальнейшее использование копий прекращено.

## Профиль времени выполнения

Стадии подготовки и проверок не измерены раздельно; их длительности UNKNOWN. Граница наблюдения ограничена адресными действиями и сообщениями текущей задачи, время ожидания и финальной передачи отдельно не измерено.
