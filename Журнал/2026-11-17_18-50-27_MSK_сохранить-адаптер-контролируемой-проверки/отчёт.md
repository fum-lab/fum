# Сохранить адаптер контролируемой проверки

Добавлен внутренний одноразовый адаптер для подготовленных collector и owner-scoped владения: он связывает вершину с тестовым observer, исполняет заданную команду, собирает её код и возвращает типизированный UNKNOWN после terminal и чтения истории. На некорректных аргументах с подготовленным владением pending гасится и повтор запрещён. Публичная команда запуска остаётся закрытой; адаптер требует подготовленного внешнего контура и ещё не является самостоятельной точкой входа.

Один synthetic lifecycle с Git CLT и observer выполнил проверку `test -f .git`: код цели 0, семь Git-пакетов и observer имеют raw 0, итог UNKNOWN. Terminal SHA-256 `b8b86318a81ca0d027e3943efa25314b60624ab9c8783e4afb52bb01dc2c3799` независимо сверен. Адресный тест точного кандидата проверил инвалидирование при неверных аргументах и запрет повтора. Полный regression, непрерывная custody, фактический exec image и production admission не подтверждены.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
