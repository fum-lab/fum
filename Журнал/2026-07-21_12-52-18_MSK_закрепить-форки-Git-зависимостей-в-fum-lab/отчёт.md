# Отчёт 2026-07-21 12:52:18 MSK - Закрепить форки Git зависимостей в FUM lab

Для внешних Git-зависимостей закреплена единая управляемая точка публикации: постоянные форки в организации `fum-lab`. Основной репозиторий FUM больше не должен ссылаться сабмодулем непосредственно на оригинальный upstream зависимости.

## Контракт источников зависимости

Локальная копия зависимости клонируется из форка `fum-lab`, который получает роль `origin`. Оригинальный репозиторий сохраняется отдельным `upstream` для сверки и переноса обновлений. Перед регистрацией зависимости выбранный коммит должен быть опубликован и достижим из форка; `.gitmodules` указывает на этот форк, а gitlink фиксирует точный проверенный коммит.

Проверка перед коммитом охватывает роли обоих remote, URL и путь сабмодуля, достижимость ревизии, чистоту клона, лицензию, видимость и публикационную допустимость. Изменения зависимости и обновления из upstream сначала публикуются в управляемом форке, после чего FUM отдельным изменением обновляет gitlink.

## Граница текущей сессии

Конкретный репозиторий, путь и ревизия для подключения этим запросом не назначены, поэтому внешний форк и новый submodule не создавались. Заблокированный живой режим LinguisticKit остаётся отдельным плановым продолжением: сначала нужно создать или подтвердить его форк в `fum-lab`, затем подключить именно этот источник и провести уже запланированную миграцию имён.

Существующее предложение об автоматизации первого подключения расширено до полной цепочки `форк -> clone origin -> configure/fetch upstream -> verify publication -> submodule add`. Автономные тесты будущего помощника должны моделировать оба remote локально без сети, а внешнее создание GitHub-форка остаётся явно проверяемой предпосылкой.

## Проверки

- Плановый реестр пересобран и валиден; запись ветки подтверждает точную пару `refs/heads/master` и `master-prepare-first-boxed-slice-passport-v3`.
- `.gitmodules` и gitlink отсутствуют, поэтому текущий коммит не маскирует неподтверждённое подключение зависимости.
- Recency, граф Obsidian и связность сессии проходят; предфинальный полный smoke-check завершился результатом `33/33`.
