## Проверки

Семь адресных тестов подтверждают чтение закреплённых объектов вопреки изменённому рабочему дереву источника, сохранение режимов, отсутствие импорта untracked, отказ повторного применения, конфликт до записи, подмену SHA, выход за корень, символические ссылки и объединение одинаковых путей. Первый запуск выявил ошибку самой тестовой фикстуры (кириллица в bytes literal); после её исправления подтверждён RED отсутствующего модуля, затем GREEN реализации. Ошибка сохранена в машинном учёте и не выдана за целевой RED.

Сценарий сначала проверяет полный набор, затем пишет; источник read-only. Профиль показывает около 3,23 с на 71 файл и 0,51 МБ. Решение об оптимизации: сохранить простой последовательный алгоритм, поскольку стоимость ограничена одним переносом, а повторное чтение подтверждает целостность. Ускорение не заявлено. После двух замечаний независимого ревью добавлены адресные RED/GREEN для верхнего происхождения и подмены commit деревом. Окончательный профиль: план 1,191 с, применение 2,199 с; усиление проверки сохранено без оптимизации, сравнение не объявляет ускорения. Дополнительная проверка упаковки сначала ошибочно предположила отсутствие recency во всех четырёх исходных README; после сверки исходных байтов исправлено только условие сравнения, сами пакеты не менялись. Итог: 68 файлов побайтно равны, у трёх изменена только служебная упаковка. [Канонические хэши](материалы/каноническая-упаковка-пакетов.json) и [окончательный профиль](материалы/профиль-переноса-после-ревью.json) сохранены. Тяжёлые Swift-проверки будут выполнены после сохранения этапа.

## Упаковка и локальная подготовка

Машинный аудит показал 33 ранее не зарегистрированных точных строки импортируемых файлов: пути открытой синтетики, расположение собственных бинарников в процессных тестах, примеры временного профиля и shebang тестовой фикстуры. После предметного чтения добавлены только [типизированные декларации](материалы/декларации-путей.json) штатным обновителем политики. Они не разрешают новые соседние строки и сохраняют исходные байты.

Новый worktree не содержал игнорируемый `.obsidian/graph.json`; существующие исторические ссылки вызвали отказ глобальной связности. В собственный ранее отсутствующий игнорируемый путь скопирован пользовательский файл primary без изменения primary и без включения копии в Git. По назначению координатора сохранены [сбой 0052](../../Сбои/FUM-СБОЙ-0052-связность-требует-локальный-граф-Obsidian.md) с двумя подтверждёнными проявлениями и [шаг 0203](../../Планирование/карточки-шагов/✅-FUM-STEP-0203-отвязать-связность-от-локального-графа-Obsidian.md); исправление воспроизводимости общего документационного контура этим действием не заявлено. Чистый клон для проверок новых пакетов не будет использовать ни пользовательский граф, ни прежние исходные каталоги.

Первый вызов генератора планового реестра был выполнен напрямую как запись и обнаружил неверную форму статуса новой индексной строки. Наблюдаемая длительность не записана обёрткой и не восстанавливается задним числом. Строка исправлена, повторная сборка выполнена через обёртку. Это ограничение полноты машинного учёта данного контрольного этапа; финальная приёмка будет иметь отдельную полную границу.

LinguisticKit материализован в собственном дереве полным клоном опубликованного форка, синхронизирован с origin и upstream и установлен на прежний закреплённый 837e2ce107b97ee7b9d3344c9fe99142281fe393. Gitlink и публикационные URL FUM не менялись.

## Решения и ограничения

- [Манифест](материалы/манифест-переноса-пакетов.json) сохраняет исходные commits, trees, пути, blob OID, SHA-256, размеры и режимы. [Профиль](материалы/профиль-переноса-пакетов.json) содержит новые измерения.
- Три исходных README получили только служебные блоки recency штатным генератором; README архива уже содержал корректную метку и остался побайтно неизменным. Канонический SHA и вид этой упаковки сохраняются отдельно; остальные файлы должны совпадать побайтно.
- Независимый анализ приложения установил: все его 39 blob OID отсутствуют в исходном FUM. Прототип физических клавиш имеет другой контракт, поэтому не заменяет приложение. Остаток приложения включает старые локальные пути, незакреплённую libmpv и отсутствие тестов. Все 39 файлов сохраняются следующим этапом с явной адаптацией и происхождением.
- Исходный набор признан собственным прямым поручением и переносится под общую CC0 FUM. Отдельного LICENSE в пакете нет. Это не меняет лицензий внешних API и библиотек. LinguisticKit и его gitlink не менялись.
- Код пакетов пока сохраняет исторические имена и ограничения Swift tools 6.0 / Swift 6 / macOS 14; общий перевод объявлений, другие ОС и SwiftNIO не входят в данный этап.
- Сохранённое поколение `Proyekcii/Bratislavskaya-pamyatj/manifest-proiskhozhdeniya-v2.json` относится к стартовому HEAD 406c6ba1; новых исходников в нём пока нет. Контрольная точка не объявляет проекцию актуальной и не заменяет финальную приёмку.
- Содержательные ответы координатору: стартовые идентичности переданы; необходимость добавления recency согласована; независимые номера и чужие деревья не изменяются. После этого коммита работа продолжается: приложение, адаптация, чистый клон, проверки и профили, финальная проекция и доставка.

После подготовки собственной локальной среды связность и точная публикационная политика путей прошли. Проверка уже поставленного индекса `git diff --cached --check` отдельно обнаружила один конечный пробел в дословной исходной команде пользователя; он сохранён по требованию неизменного происхождения. Остальные пути проверяются обычным `diff --check`, точный файл запроса — с отключением только `blank-at-eol` и отдельным сравнением дословной области с первоисточником. Это адресная проверка контрольной точки; пакетные Swift-тесты и финальный допуск остаются следующим этапом.
