# Сохранить кооперативный предпросмотр

Для явного опытного контракта добавлен root-lock → session-lock при legacy предпросмотре. Controlled active блокирует запись; допускаются только непустая история v1/v2 и прежний файловый writer без Git. Прежний default, другие legacy writers и публичный guard не изменены. Старые процессы не обязаны соблюдать этот opt-in; общая миграция и защита от ABA не доказаны.

Точный synthetic test с непустой v1 историей реально обновил private отчёт и подтвердил отказ повторной записи при active; mock Popen не вызывался. Terminal SHA-256 `d081b9f78503e388562bac694c87d1827423867eec4cbde0c27e78763e22b1ad` независимо сверен. Межпроцессная конкуренция этого writer с controlled CLI ещё не испытана; полный regression, custody и production admission не подтверждены.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
