## TDD-проверка README

Новая автоматизация [fum-readme-index](../Инструменты/fum-indeks-readme/SKILL.md) получает проектный инвентарь через `fum-project-files` и требует прямые ссылки внутри единственного раздела `## Документация по темам` на верхнеуровневые `Документация/NN-*.md` и `Документация/NN-*/README.md`.

Красная фаза прошла последовательно:

- тесты были запущены до появления сценария и завершились ошибкой отсутствующего файла;
- после реализации интеграционный тест обнаружил семь фактических пропусков README: документы и папочные входы `28–33`;
- дополнительные регрессионные тесты воспроизвели ложные зелёные результаты для многострочного inline-code, заголовков с допустимым отступом, следующего H1 и indented code block.

Зелёная фаза закрыла все случаи. Валидатор игнорирует HTML-комментарии, fenced- и indented-code, одно- и многострочные code spans, завершает H2-раздел на следующем H1/H2, сохраняет точный регистр и проверяет URL-декодирование с лексической нормализацией. Набор содержит 16 автономных тестов, а текущий README проходит с результатом `required=37 indexed=37`. Отдельный шаг добавлен в общий smoke-check и защищён тестом его плана.
