# Проверить конкуренцию synthetic адаптера

Добавлена проверка исполнения synthetic адаптера при конкуренции с отдельным процессом controlled CLI. Точный тест подтвердил занятость общего root-lock во время записи, затем controlled CLI вернул UNKNOWN и active запретил следующий вызов. Сбор вывода дочернего процесса ограничен 4096 байтами на поток; неизвестный исход сохраняется в HOLD.

Точный запуск включал только конкурентный тест; отдельный отрицательный тест pin проверен ранее на другом полном снимке. Controlled Git cycle был заменён mock. Старые писатели, независимый raw wait, custody и source-at-exec не подтверждены. Публичный guard не менялся. Предыдущий HOLD сохранён.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна.
