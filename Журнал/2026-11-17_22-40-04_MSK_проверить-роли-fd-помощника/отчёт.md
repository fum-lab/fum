# Проверить роли FD помощника

В native protocol добавлен строгий разбор четырёх объявленных ролей FD с отказом при неканонических номерах и коллизиях, включая переданный набор занятых дескрипторов. Это проверка чисел; открытость, тип, происхождение и реальная передача FD не подтверждаются. Public guard не изменён.

Swift typecheck прошёл; один именованный Swift Testing тест прошёл в отдельном private пакете с копиями проверенных исходников. Команда задавала env -i, HOME, TMPDIR, PATH и LC_ALL; отдельной квитанции её аргументов нет, отсутствие системных эффектов Swift не доказано. Живой helper, custody и image-at-exec не проверены; старый HOLD не затрагивался.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
