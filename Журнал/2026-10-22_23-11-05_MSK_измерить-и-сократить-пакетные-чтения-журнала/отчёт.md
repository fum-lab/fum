## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
Три пары выполнялись в шести новых процессах на одном неизменном W/H с объявленной собственной открытой парой. Сравнивались точное прежнее тело из Git N5 и новое тело; AST вне функции и двенадцать остальных зависимостей совпадали, состояние и исходники всех работников сверены. Setup и импорт вне wall; одинаковые счётчики входят в оба окна. CPU измеряет SELF без CPU Git; RSS включает setup и postvalidation. Кэш ОС не сбрасывался. Ускорение этого полного прохода — 2,46 раза, сокращение длительности около 59,4%; это не коэффициент всего S1/READY/Create. Начальный cProfile одного чистого N5 занял 25,12 с с оснасткой, показал 572 Git и 571 batch, около 9 с во вложенном reader; вложенные интервалы не суммируются. Полный пакет повышает временную память, дедуплицирует OID в пределах прохода и получает один timeout 120 с. При конкурентной недоступности Git момент отказа может отличаться; атомарный снимок ФС не обещается. Физический корень в исходном cProfile занимал около 0,53 с и не выбран первым объектом ускорения. RO-ревью блокеров не нашло; preflight выходов не доказывает отсутствия всех файловых alias. N5 e88f7136 доставлен обычным Create574,907 с и свежим повтором3,977 с; это один прежний этап, не контрольный опыт. C80 независимо доставил S1 точного N5; полный узел не активируется. При подготовке собственной пары литерал заголовка не совпал с каноническим регистром: отказ до записи W сохранён, заголовок теперь выводится штатной функцией из метки. Перенос модели отказал из-за отсутствующего собственного каталога материалов; каталог подготовлен после проверки своего плана до повторного запуска, исходный отказ сохранён. Обнаружен незавершённый общий стык S1→ROOT9→Create/push/resume: существующие генератор и фасад уже есть, ближайшие планы связаны с Issues327/328; второй генератор не создаётся. Приоритет приемлемой скорости полного цикла до ограниченного Swift-опыта сохраняется. Ресурсный контракт операторов FUMA уже сохранён C79 по Issue14/359; его реализация и общий автоматический вывод сложности не объявляются готовыми. Новая дельта видимых сообщений сохраняется без повтора прежних вставок; весь backlog не объявляется разобранным, закрытый предыдущий этап не переписывается. Текущая модель по native-префиксу: gpt-6.1-sol/ultra. Предварительная публикационная проверка до первого Prepare выявила три служебные метки cProfile для встроенных функций: их представление совпало с синтаксисом домашнего каталога. Исходный профиль и отказ сохранены приватно; в производном публичном JSON метки автоматически заменены на «встроенная функция», с явным пояснением границы. Сканер и политика не ослаблялись; парный профиль и производственные исходники не изменились. Штатные S1 и 55 тестов установщика по этой правке представления не повторяются. Проверка публичных меток закреплена перед фиксацией.
