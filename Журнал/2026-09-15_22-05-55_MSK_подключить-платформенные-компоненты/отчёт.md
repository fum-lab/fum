## Проверки

- Общий пакет: 156 XCTest и 33 Swift Testing успешно. API и поведение проверены существующими наборами.
- Python: первоначальный RED после перемещения выявил старые пути; после исправления 17 тестов успешно. Исторический манифест продолжает проверяться по исходному commit; текущие назначения связывает явная карта переноса, а не подмена старых SHA. Проверка исходников использует отслеживаемый Git-инвентарь и не сканирует кэши сборки.
- Xcode: первый отказ из-за старого пути CMpvShim, второй — отсутствующих аргументов системного mpv. После исправления пути и передачи документированных `FUM_MPV_INCLUDEDIR/FUM_MPV_LIBDIR` сборка FUMA.app успешна. Подписание отключено, приложение не запускалось; штатная сборка регистрирует bundle в LaunchServices.
- Общий macOS бинарник подтвердил текстовый и байтовый оператор, повтор, накопление и отрицательные случаи; [профиль](материалы/оператор.json). MCP status и [обнаружение](материалы/обнаружение.json) проверены с подставным pgrep, без живого приложения. [C-адаптер](материалы/C-адаптер.json) использовал подставные загрузчик и символы.
- [Android](материалы/Android-прогон/манифест.json): Release CLI собран после подключения macOS targets; API 23 target, реальный AVD ARM64 API 36. Три корректных входа дали точные выход/повтор, четыре некорректных UTF-8 отклонены без сегмента. Собственный эмулятор остановлен; AVD и данные сохранены.

Независимый read-only обзор текущего diff не нашёл регрессий путей, ресурсов и условий. Ограничение теста runner: сравнение существования `.build` доказывает только отсутствие создания каталога, не неизменность его прежнего содержимого; явные аргументы внешнего scratch-path проверены.

## Решения и ограничения

[Карта переноса](материалы/перенос.json) сохраняет исходные хэши, [прежний manifest](материалы/прежний-манифест-macOS.swift) — происхождение. README-команды и каталоги сценариев обновлены. Исходники и лицензии внешних зависимостей не менялись; для локального Crypto обязателен `SWIFTCI_USE_LOCAL_DEPS=1`.

Проверка из полного холодного клона ещё не проведена. Холодная установка Android среды, app UID/JNI/GUI, Windows/iOS остаются отдельными границами. Приватный ACL Telegram отсутствует в этой базе, не переносился и не ослаблялся. Успех выбранного Android продукта не доказывает переносимость всех продуктов общего manifest.

Новая повторно применимая автоматизация объединения manifests остаётся следующим этапом; нынешний пакетный перенос её не заменяет. Полная проекция и smoke отложены: сохранено устаревшее поколение базового `1e6676b97ae992c22ea7112f68d05fff2d38fb09`. Это контрольная точка, не финальная приёмка, интеграция master или завершение задачи. Код 2 собственного continuation registry не считается разрешением завершения.
