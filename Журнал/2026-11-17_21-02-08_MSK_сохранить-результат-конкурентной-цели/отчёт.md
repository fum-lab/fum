# Сохранить результат конкурентной цели

Усилен synthetic межпроцессный тест cooperative legacy writer и controlled Git → observer: исправлена synthetic Git fixture, при ошибке Git сохраняется ограниченный stderr, а результат child сохраняется отдельно и проверяется код цели. Квитанции остаются вне очищаемой fixture.

Один новый независимый тест на live W прошёл: восемь START/REAP имеют совпадающие PID и raw 0, child и parent зафиксировали exit 3, сохранённый результат observer/CLI содержит UNKNOWN и код цели 0. Terminal SHA-256 `8380d29b28aa3e2d62a356e9b447ccdf3d1b0f5337ed5769a0cd78a7e095ae4a` независимо сверен. Код цели получен через observer/CLI, отдельной raw wait-квитанции цели нет; целый exact test file отдельно не запускался. Default legacy writers, ABA, custody и production admission не подтверждены.

Прежний независимый HOLD с raw 32768 сохранён и не тронут; его stderr и причина неизвестны. Исправление synthetic fixture не устанавливает причину старого отказа.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
