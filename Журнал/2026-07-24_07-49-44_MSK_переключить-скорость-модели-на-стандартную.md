# Отчёт 2026-07-24 07:49:44 MSK - Переключить скорость модели на стандартную

Проектный слой Codex больше не запрашивает повышенную скорость Fast. Новые ходы в доверенном репозитории используют стандартную скорость по умолчанию, а закреплённые модель `gpt-5.6-sol`, рассуждение `ultra` и изоляция локальных навыков сохранены.

## Изменение конфигурации

В `.codex/config.toml` значение `service_tier = "fast"` заменено на `service_tier = "default"`. Отдельное значение `standard` не используется: схема Codex называет базовый стандартный сервисный уровень `default`. Явное проектное значение не даёт нижележащей пользовательской настройке Fast стать значением репозитория по умолчанию. Флаг `features.fast_mode = true` оставлен как возможность ручного выбора Fast через интерфейс Codex и сам по себе не включает повышенную скорость.

Реестр системных приложений и инструментов синхронизирован с новым состоянием конфигурации и наблюдаемыми версиями поверхности, встроенного runtime и самостоятельного CLI. Исторические запросы и отчёты, описывающие прежний Fast-снимок, не переписывались.

## Проверки

- Локальный разбор TOML подтверждает `service_tier = "default"` и сохранность остальных проектных инвариантов.
- Встроенный и самостоятельный runtime Codex проходят строгую загрузку обновлённой конфигурации и модельного каталога.
- Recency-метки, граф Obsidian, сессионная связность, `git diff --check` и полный smoke-check проходят.
