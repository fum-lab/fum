Один разбор Markdown обслуживает всё множество целей; каждое изменяемое описание устанавливается один раз. ## Проверки

- Начальный RED: отсутствовал пакетный API. Затем24 теста прошли: прежние18 и новые6.
- Независимый обзор обнаружил две гонки. Отдельные RED-тесты подтвердили приём изменённого индекса между preflight и snapshot и потерю внешней правки Markdown после первого mv. Исправления связывают исходный exact index с итоговым планом, сверяют ранние source snapshots и повторно проверяют Markdown непосредственно перед установкой.
- После исправлений26 тестов прошли; заключительный набор с реальным CLI и отказами для Markdown/HEAD —28 тестов без ошибок. Сохраняются бинарные байты/CRLF/исполняемый режим, обновляются две цели в одном Markdown, отклоняются stale hash/коллизии/wiki/symlink/защищённая цитата. Внедрённые сбои второго mv и установки восстанавливают пути, индекс и несвязанные staged/unstaged байты. Внешняя обнаруженная правка сохраняется.
- [Профиль открытой фикстуры](материалы/профиль.json) сравнивает83 одиночных плана и один пакет, затем проверяет применённые83 результата по хэшам. Независимый повторный обзор не обнаружил дополнительных actionable-регрессий; это чтение кода, не второй запуск тестов.

## Решения и ограничения

Пакет ограничен1–1000 файлами без `.md`, существующими реальными каталогами назначения, отсутствием цепочек/циклов и переносимых коллизий. JSON со строгими полями связывает HEAD и хэши исходников. Apply требует SHA256 просмотренного полного плана, включая diff Markdown и снимок прочитанных байтов. Отмена защитных повторных чтений не входит в оптимизацию.

Все mv остаются штатными Git-операциями. При ошибке отменяются в обратном порядке; Markdown подготавливается с резервными копиями до первой записи. При внешнем изменении нельзя обещать возврат всего окружения к исходному снимку: изменённые внешние байты сохраняются, диагностика указывает неполный откат общей среды. Сбой питания, принудительное завершение и враждебные гонки остаются за прежним контрактом гарантии. Автоматизация не меняет Swift/Xcode/Python пути внутри кода.

Дальше требуется применить просмотренный пакет к FUMA, адаптировать машинные пути и повторить поведенческие проверки. Контрольная точка инструмента не является финальной приёмкой общего пакета. Сохранена явно устаревшая проекция базового `1e6676b97ae992c22ea7112f68d05fff2d38fb09`; новое поколение не запускалось. Собственный continuation guard возвращает код2 из-за отсутствующего точного пути; это не разрешение завершить согласованный объём.
