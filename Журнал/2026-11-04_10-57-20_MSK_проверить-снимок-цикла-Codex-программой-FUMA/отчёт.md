# Отчёт 2026-11-04 10:57:20 MSK - Проверить снимок цикла Codex программой FUMA

Первичный FUMA-пакет вычисляет собственный снимок, собственное snapshotObserved и семантическую дельту из проверенной проекции метаданных Codex. Все восемь синтетических случаев исполнены по одному разу: семь целых результатов совпали с замороженными ожиданиями, восьмой завершился ожидаемым кодом завершения 1, типовым кодом «схема» и пустым stdout. Затем выполнен один новый чистый проход по ранее сохранённой фактической проекции: whole JSON совпал с подготовленным до запуска ожиданием. Новых вызовов Codex, сборок, Host или GPU не было.

Независимый потребитель183 целиком проверил все 36 новых исходных IO, канонический хэш определения, исходные входы, frozen expectations, подготовленный actual wrapper и все стыки результата. Идентичность нативного хода отсутствует в целом actual observation и результате. Приватные входы и оригиналы снимков не опубликованы. Сохранён отдельный публичный выход FUMA.

Поздние прямые решения приняты в требования: агенты назначаются только для нужных функций; задачи распределяются по их зонам ответственности; включение и выключение имеют отдельные постоянные элементы управления. Кнопка и словесная команда задают явное целевое состояние. Повтор достигнутой либо исполняемой цели не создаёт второго процесса. Асинхронный контракт различает команду, переход и событие результата.

Последняя уточнённая цепочка выключения во время включения: сначала попытка остановить включение, затем при завершённой попытке с любым исходом отдельный процесс выключения, затем подтверждённый OFF. Успешная остановка не подменяет подтверждение конечного состояния. Это заменяет раннее предположение «успех остановки сразу означает OFF». Поручение185 готовит отдельный чистый FUMA-шаг; его Source/runtime и Native Stop здесь не принимаются. Принцип конструирования малых программ с явными контрактами является архитектурным направлением, а не доказательством готового самосборщика.

Поздние уточнения расширили текстовый контракт: внутренняя модель клавиш, наблюдаемая раскладка и предполагаемый язык разделены; языковые диапазоны сопоставляются с видимым текстом и LEAP. Рассматриваются Unicode language tags (с известным deprecated-статусом), расширенный Markdown и публичная модель AttributedString. Собственный аналог должен быть FUMA-кодом. Поручение188 готовит сравнение; форматы и системный ввод в этом этапе не включены.

## Решения и ограничения

- Actual9 — новый FUMA-проход по историческому метаданному снимку, без нового чтения приложения. Git-привязка aaddd относится к моменту того наблюдения и не подменяет текущий HEAD. Логические IDs с префиксом ПРЕДЛОЖЕНО приняты корнем как буквальные идентификаторы; неизвестные функция/назначение/план сохранены, нативный grant из них не выводится.
- Whole actual expectation находился в поле fullExpectedResult подготовленной оболочки. ROOT сначала обратился к неверному уровню, получил TypeError до actual CLI, затем исправил выбор на тех же буферах. Исходный инцидент сохранён; FUMA и native вызовы не повторялись.
- Два пользовательских изображения подтверждают смену символа отправки на символ остановки в одной области внешнего приложения. Сохранение курсора там сообщено человеком; случайная остановка не доказана. Изображения частные, внешнее приложение не изменялось.
- Восстановление176, автомат событий177, архивные предложения178/181/186, штатный переводчик182 и команда целевого состояния185 сохраняются отдельными областями. Их статические пакеты не объявляются исполненными этим этапом.
- Полный глобальный smoke-check, native app-server stream, самосборка программ, видимые пиксели и исправление Native Stop не доказаны. Это промежуточный Sourcepoint по 000178/000188; доступная работа продолжается новыми этапами.
