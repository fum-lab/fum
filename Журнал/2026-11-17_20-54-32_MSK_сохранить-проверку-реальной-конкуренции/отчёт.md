# Сохранить проверку реальной конкуренции

Добавлен synthetic межпроцессный сценарий: cooperative legacy writer удерживает root-lock при непустой v1 истории; второй процесс видит занятый flock и затем выполняет настоящий controlled Git → observer. Process и durable квитанции сохраняются отдельно от очищаемой fixture. После controlled active следующий cooperative writer получает отказ. Default и старые writers этим не охвачены.

На live W сценарий прошёл: восемь прямых REAP raw 0, child exit 3 и UNKNOWN, четыре durable квитанции; terminal SHA-256 `fa938db16ec09006ab442833a57cdfd64e6092e1e64f4360632ab7602798bfd2` независимо сверен. Код цели в сохранённом результате тест отдельно не проверял; target 0 не утверждается. Точный selective тестовый файл отдельно не запускался; перенос результата на него не утверждается. Syscall trace, custody, ABA, power-loss durability и production admission не доказаны.

Прежний независимый HOLD сохранён: первый Git имел raw 32768, его stderr не сохранён, причина неизвестна. Вторую fixture подготовили с synthetic Git objects, но это не устанавливает причину прежнего отказа; прежние процессы не сигнализировались.

Это source-only bootstrap по прямому поручению корня, не обычная приёмка. ACT/S, Creator и ROOT JSONL не проверялись. Модель собственных метаданных: gpt-6.1-terra, effort low; полная история моделей неизвестна. Посторонний WIP не включён.
