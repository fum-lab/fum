## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
Это продолжение двух дословных человеческих оригиналов, не новое сообщение человека. Новый акт разрешает только последующий остаток предметной работы, не переписывает историю подготовительных попыток. Общий add и Telegram lifecycle не дублируются; live-регистрация, auth/backend/канал остаются закрытыми. ROOT ещё не принял PR18: пауза проекции соблюдается, стандартный smoke пока без её режима; GitHub server merge не позволяет задать author.name, вопрос о способе направлен пользователю, ответа пока нет. Первое создание папки отклонено до записи из-за моего неверного --label; при правильном slug start успешен. Чтение childclock сначала ошибочно ожидало строковый output; фактический список текстовых блоков разобран, проверена единственная exit0 пара. Все исходы сохранены native; успех не отменяет отказы. Закрытые отчёты не возобновляются. Контрольная точка не завершает весь ROOT объём. Сухой план наполнения сначала отказал отсутствующей ещё истории модели, затем пустому перечню стадий. История сформирована штатным создателем; две реально выполненные стадии помечены «не измерено», длительности не сочинены.
