## Решения и ограничения

<!-- FUM-КАРТОЧКА:НАЧАЛО решения -->
Предел 65 536 значений каждого вида ограничивает число элементов, не точное число байтов Python. Переполнение сохраняет прежнюю проверку новых значений; ошибки не запоминаются. Успешный чистый результат повторяется внутри одного доказательство без новых посимвольных циклов; чужой контекст не наследуется между независимыми доказательство. Это не доказательство линейности всего FUM или худшего случая хеш-таблиц. Базовый профиль исполняет точные прежние тела двух функций из Git N6 и прежний доказательство без нового декоратора; остальной текущий контур общий, дельта ограниченаAST. Прямые импорты и подготовку стенда вне wall, ленивые импорты и одинаковый наблюдатель argv внутри. CPU толькоSELF, RSS максимум всего работник; кэш ОС не сбрасывается. ВременноеH создаётся внеW; неизменность W не означает отсутствия всех временных записей внеGit. Один предыдущий cProfile112,53 с показал 625205 вызовов путь и 662950 строка; вложенные интервалы не суммируются и не приравниваются к обычному времени 42,29 с. Предварительная одна пара обёртки в памяти 45,20→37,26 с имела более широкую границу и не объявлена измерением нынешнего производственного контура. Отдельная regex-проба не выбрана самостоятельным изменением. N6 уже доставлен: Prepare102,417 с, READY275,396 с, Create570,242 с и свежий повтор без новых эффектов3,996 с; ускорение установщика не означало ускорения этого пути. Новый коэффициент всего цикла будет наблюдаться отдельно. C81 независимо доставил и ROOT установил S1 точногоN6; активация всего узла не выполнена. Ресурсные контракты FUMA с отдельными объявлено/измерено/доказано уже сохранены C79 в Issue14/359; здесь их реализация, формальные доказательства, Swift-опыт и изменение правил не выполнялись. Приоритет приемлемой скорости полного цикла перед ограниченным Swift-опытом сохраняется. Для адаптации финального helper обнаружена опечатка SHA в сводке; исходный приватный файл перечитан и закреплён фактическим SHA, проверка не ослаблялась. Два широких чтения однострочных Issues JSON и ответа чата дали избыточный вывод; первичный поток сохранён в нативный JSONL. Для следующих обращений используются существующие компактный_JSON.py, адаптер_ответа.cjs, ограничение байтов и компактные wait-снимки; новый общий reader не создаётся. Общий стык генератораROOT9/резюме уже отслеживается Issues327/328. Новые 23 видимых сообщения сохраняются без повторения прежних 1622 вставок. Весь остаток сообщений не объявляется разобранным, неизвестные происхождения и общий guard3 не закрываются, предыдущие закрытые этапы не переписываются. В прежней подготовке входов глобальный Markdown-индекс предполагался ещё неизменённым. Полный профиль требует предварительной свежести; генератор теперь учитывает ровно этот уже штатно обновлённый производный индекс вместе с двумя индексами Журнала. Исходный отказ до выдачи входов сохранён; иные пути не разрешены. К измеренным пяти предметным файлам добавлена только политика публикации с одним точным исключением для ранее существовавшего относительного суффикса. Остальные исключения и метаданные побайтно восстанавливаются прежней сериализацией. Шесть измерений предшествовали этой JSON-добавке и наполнению отчёта; измеренные Python-исходники не менялись. Это не повторный замер окончательного целого коммита. Текущая модель по native-префиксу: gpt-6.1-sol/ultra.
