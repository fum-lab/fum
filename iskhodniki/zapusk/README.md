# Корневой запуск FUMA

Из корня клона FUM выполните `swift run`. Корневой пакет содержит один исполняемый продукт `fuma`; вложенные пакеты и приложение macOS остаются отдельными. Этот вход использует исходники существующего [контейнера наблюдений](../../Приложения/FUMA/Packages/КонтейнерНаблюдений/Sources/КонтейнерНаблюдений/Сегмент.swift) и не требует GUI, mpv, Homebrew или сетевых зависимостей. Текущий контейнер использует Darwin и CryptoKit, поэтому проверяемая платформа этого среза — macOS 14 и новее; переносимость на Linux не заявляется.

Первый цикл сохраняет намерение открытия локальной истории, закрывает writer, вновь открывает reader и побайтно проверяет запись и квитанцию. Состояние ответа — `ожидает подключения адаптера`: Git-worktree, чат, SDK/auth и восстановление всего узла этим действием не создаются.

По умолчанию история находится в `/Users/Shared/fuma-zapusk-<UID>`, где UID берётся у текущего системного пользователя. Каталог принадлежит этому пользователю и имеет режим `0700`; существующие права не исправляются. HOME не используется, поскольку он сам может быть Git-репозиторием. UUID нового события генерируется для текущего запуска; он не объявляется UUID узла. Источник `fuma`, версия, тип, фактическое UTC-время и спецификация передаются в контейнер явно.

Входы доступны через `fuma --помощь`. В следующих командах `$1` — абсолютный физический каталог сборки вне Git, `$2` — заранее созданный пустой приватный каталог свидетельств. Для отдельной сборки:

```sh
: "${1:?Задайте абсолютный приватный каталог сборки вне Git}"
swift build --scratch-path "$1" --jobs 2 --product fuma
"$1/debug/fuma" --помощь
```

Флаги команды: `--хранилище <абсолютный путь>`, `--событие <канонический lowercase UUID>`, `--намерение <непустая строка до 4096 байтов UTF-8>`, `--профиль`. Для проверки точного повтора передайте в двух процессах одинаковые хранилище, ID и намерение. Второй процесс сохраняет первоначальное время принятого события. Те же байты возвращают прежнюю квитанцию без дописывания; другие байты того же ID дают типизированный отказ с кодом процесса `2`.

Символические компоненты, Git-предок, неприватный каталог, повреждение и неполный хвост закрывают цикл без автоматического ремонта. Ошибка после начала записи сохраняет `исходНеизвестен` либо подтверждённую квитанцию; программа не откатывает историю и не повторяет неизвестный эффект вслепую. Каталог или файл могут уже существовать. Выдача отказа не равна доказательству отсутствия файлового эффекта.

Собственные цели и тесты настроены на Swift 6, `strict-concurrency=complete`, `warnings-as-errors` и проверки изоляции actor при исполнении. Новые тесты используют Swift Testing; контейнер целиком принадлежит actor, а между файловыми шагами цикла приостановки нет.

Для процессных проверок нужны отдельное тестовое хранилище и приватные RAW:

```sh
: "${1:?Задайте абсолютный приватный каталог сборки вне Git}"
: "${2:?Заранее создайте пустой физический приватный каталог вне Git}"
env "ФУМА_БИНАРНИК_ЗАПУСКА=$1/debug/fuma" \
  "ФУМА_СВИДЕТЕЛЬСТВА_ЗАПУСКА=$2" \
  swift test --scratch-path "$1" --jobs 2 --filter ПроверкиКорневогоЗапуска
```

Отдельный фильтр `малыйПрофильКорневогоЗапуска` сохраняет три пары процессов и все образцы. Интервал процесса — от `Process.run` до обнаружения `isRunning == false`, с polling 5 мс и ожиданием планировщика; подготовка, pin-IO и синхронизация RAW вызывающей стороны исключены. Полезный цикл измеряется отдельным `ContinuousClock` внутри actor; это вложенное время, его не складывают с процессным. Свежую сборку измеряют отдельно. Кэш ОС не очищается, pin читает бинарник. Малый профиль не доказывает ускорения.

RAW Codex доступен подкомандой `fuma архив-codex`; [инструкция архива](../arkhiv-codex/README.md) описывает импорт, восстановление и публичные проверки. Корневой пакет сохраняет один исполняемый продукт, поэтому штатный `swift run` остаётся однозначным; пустой запуск и `--помощь` сохраняют прежнее поведение.
