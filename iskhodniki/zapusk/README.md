# Корневой запуск FUMA

Из корня клона FUM выполните `swift run`. Корневой пакет содержит один исполняемый продукт `fuma`; вложенные пакеты и приложение macOS остаются отдельными. Этот вход использует исходники существующего [контейнера наблюдений](../../Приложения/FUMA/Packages/КонтейнерНаблюдений/Sources/КонтейнерНаблюдений/Сегмент.swift) и не требует GUI, mpv, Homebrew или сетевых зависимостей. Текущий контейнер использует Darwin и CryptoKit, поэтому проверяемая платформа этого среза — macOS 14 и новее; переносимость на Linux не заявляется.

Первый цикл сохраняет намерение открытия локальной истории, закрывает writer, вновь открывает reader и побайтно проверяет запись и квитанцию. Состояние ответа — `ожидает подключения адаптера`: Git-worktree, чат, SDK/auth и восстановление всего узла этим действием не создаются.

По умолчанию история находится в `/Users/Shared/fuma-zapusk-<UID>`, где UID берётся у текущего системного пользователя. Каталог принадлежит этому пользователю и имеет режим `0700`; существующие права не исправляются. HOME не используется, поскольку он сам может быть Git-репозиторием. UUID нового события генерируется для текущего запуска; он не объявляется UUID узла. Источник `fuma`, версия, тип, фактическое UTC-время и спецификация передаются в контейнер явно.

Входы доступны через `fuma --помощь`. В следующих командах `$1` — абсолютный физический каталог сборки вне Git, `$2` — заранее созданный пустой приватный каталог свидетельств. Для отдельной сборки:

```sh
: "${1:?Задайте абсолютный приватный каталог сборки вне Git}"
swift build --scratch-path "$1" --jobs 2 --product fuma
"$1/debug/fuma" --помощь
```

Флаги команды: `--хранилище <абсолютный путь>`, `--событие <канонический lowercase UUID>`, `--намерение <непустая строка до 4096 байтов UTF-8>`, `--профиль`. Для проверки точного повтора передайте в двух процессах одинаковые хранилище, ID и намерение. Второй процесс сохраняет первоначальное время принятого события. Те же байты возвращают прежнюю квитанцию без дописывания; другие байты того же ID дают типизированный отказ с кодом процесса `2`.

Маршрут пакета путей имеет формы `fuma пакет-путей построить --корень <абсолютный путь> --вход <абсолютный путь>` и `fuma пакет-путей сверить|применить --корень <абсолютный путь> --план <абсолютный путь> --sha256 <64 строчные hex-цифры>`. Парсер проверяет действие и полный набор аргументов до адаптера. Тестируемый обработчик передаёт файлы как точные байты `Data`; успешная сверка не печатает тело, а применение сохраняет исходные байты квитанции. Код `0` выдаётся только для `завершено`; `откат-проверен`, `частичный`, `неизвестно` и повреждённая квитанция завершаются ненулевым кодом. Ошибка адаптера при применении сообщает неизвестный исход и не повторяет операцию.

Исполняемая команда пока закрыта до принятой композиции backend: она распознаёт маршрут, пишет причину в stderr и завершается кодом `2` до вызова адаптера. Командная строка не запускает backend и не применяет план. Подключение production backend требует отдельной приёмки его точной исправленной основы.

Символические компоненты, Git-предок, неприватный каталог, повреждение и неполный хвост закрывают цикл без автоматического ремонта. Ошибка после начала записи сохраняет `исходНеизвестен` либо подтверждённую квитанцию; программа не откатывает историю и не повторяет неизвестный эффект вслепую. Каталог или файл могут уже существовать. Выдача отказа не равна доказательству отсутствия файлового эффекта.

Собственные цели и тесты настроены на Swift 6, `strict-concurrency=complete`, `warnings-as-errors` и проверки изоляции actor при исполнении. Новые тесты используют Swift Testing; контейнер целиком принадлежит actor, а между файловыми шагами цикла приостановки нет.

Для процессных проверок нужны отдельное тестовое хранилище и приватные RAW:

```sh
: "${1:?Задайте абсолютный приватный каталог сборки вне Git}"
: "${2:?Заранее создайте пустой физический приватный каталог вне Git}"
env "ФУМА_БИНАРНИК_ЗАПУСКА=$1/debug/fuma" \
  "ФУМА_СВИДЕТЕЛЬСТВА_ЗАПУСКА=$2" \
  swift test --scratch-path "$1" --jobs 2 --filter ПроверкиКорневогоЗапуска
```

Адресные тесты пакетного маршрута и ограниченный профиль фикстуры запускаются отдельно:

```sh
: "${1:?Задайте абсолютный приватный каталог сборки вне Git}"
: "${3:?Задайте новый абсолютный путь профиля внутри iskhodniki/zapusk/zhurnal}"
swift test --scratch-path "$1" --jobs 2 --filter ПроверкиПакетаПутей
env "ФУМА_ПРОФИЛЬ_ПАКЕТА_ПУТЕЙ=$3" \
  swift test --scratch-path "$1" --jobs 2 --filter ПрофильПакетаПутей
```

Профиль использует контролируемый адаптер и малые фиксированные байты, а не production backend. Путь результата должен быть новым: профиль сохраняется без перезаписи.

Отдельный фильтр `малыйПрофильКорневогоЗапуска` сохраняет три пары процессов и все образцы. Интервал процесса — от `Process.run` до обнаружения `isRunning == false`, с polling 5 мс и ожиданием планировщика; подготовка, pin-IO и синхронизация RAW вызывающей стороны исключены. Полезный цикл измеряется отдельным `ContinuousClock` внутри actor; это вложенное время, его не складывают с процессным. Свежую сборку измеряют отдельно. Кэш ОС не очищается, pin читает бинарник. Малый профиль не доказывает ускорения.

## Языковой допуск перед коммитом

Из корня FUM выполните `swift run fuma язык индекс --корень "$(pwd -P)"`. Команда читает действующий индекс Git, включая `GIT_INDEX_FILE`, и закреплённые OID объектов. Новые и изменённые строки собственных `.swift` проверяются по содержимому стадии 0; противоположное содержимое рабочего файла результат не подменяет. Точная область `Proyekcii/` исключена. Ответ содержит основу, SHA256 индекса, число проверенных файлов и нарушения с координатами. Код `0` означает успех конечного профиля, `1` — нарушения имён, `2` — закрытый допуск из-за неподдержанного ввода, дрейфа, политики или ошибки чтения.

Для адресных Swift Testing и настоящего Git hook используйте заранее собранный `fuma` вместе с ресурсами его каталога сборки. `$1` ниже — абсолютный приватный каталог сборки вне Git:

Перед сборкой в чистом клоне требуется зарегистрированный локальный подмодуль `Зависимости/LinguisticKit` ревизии `837e2ce107b97ee7b9d3344c9fe99142281fe393`; его подготовка описана в [локальном навыке зависимостей](../../Инструменты/fum-proverka-git-zavisimostej/SKILL.md).

```sh
: "${1:?Задайте абсолютный приватный каталог сборки вне Git}"
swift build --scratch-path "$1" --jobs 2 --product fuma
env FUM_SWIFT_LANGUAGE_GATE_BINARY="$1/debug/fuma" \
  swift test --scratch-path "$1" --jobs 2 --filter ПроверкиЯзыкового
env FUM_SWIFT_LANGUAGE_GATE_BINARY="$1/debug/fuma" \
  git -c "core.hooksPath=$(pwd -P)/iskhodniki/zapusk/hooks" commit
```

`FUM_SWIFT_LANGUAGE_GATE_BINARY` — точное имя входа POSIX shell для пути исполняемого файла. Последняя команда активирует версионный `pre-commit` для одного вызова Git; постоянная общая настройка hooks не меняется. Hook использует указанный бинарник. Перед приёмкой отдельно связываются исходники сборки, бинарник, ресурс и staged-состав; сборка из рабочего дерева сама по себе эту связь не доказывает.

Профиль распознаёт простые именованные типы, функции, одиночные `let`/`var`, параметры, простые generics, непосредственные enum cases, привязки `for`, параметры замыканий и методов доступа и наблюдателей, именованные элементы кортежа. Строки и вложенные комментарии сохраняют дословный текст; выражения активной интерполяции разбираются. Координаты Swift различают LF/CR/CRLF; карта добавленных строк следует байтовым LF Git. Неизвестные формы закрывают допуск: в частности slash/regex, неизвестные Unicode-формы, macro/operator/precedencegroup, варианты enum с явными raw values, составные и повторные привязки `let`/`var`, пакеты параметров и списки захвата. Это конечный лексический профиль, без доказательства полного AST или разрешения типов.

Русский алфавит проверяется после NFC, с цифрами и `_`. Обязательная `ё` проверяется конечными формами из `ОрфографияОбъявлений.swift`; это ограниченное усиление, без общего словаря русской орфографии. Исторический снимок **46 387** объявлений и прежний перечень исключений сохраняются по точным байтам. Python, Mermaid, JS/CJS, встроенный код и прежнее полное сравнение инвентаря этим допуском не проверяются. Четыре старых SwiftJSON-исключения пока не применяются.

Новая конечная политика `ВнешниеИмена.json` разрешает только `encode`, `to`, `from` в точном полном `ВнешнийКонтракт.swift`: путь, владелец, сигнатуры, хэш полного исходника и положения токенов закреплены вместе. Изменение контекста закрывает допуск всего этого файла. Основание — первичный [Codable.swift Swift 6.0](https://raw.githubusercontent.com/swiftlang/swift/swift-6.0-RELEASE/stdlib/public/core/Codable.swift), SHA256 `46f2edd58179baa834c64405b282291e072a39a71bb17684cd6c77150b168820`. Произвольные обязательные члены внешних протоколов и CodingKeys требуют отдельного расширения.

## Сухой план адресного перевода Swift

Команда `swift run fuma язык перевод план --корень <физический-каталог-исходников> --карта <абсолютный-путь-карты>` возвращает форматированный JSON с будущими байтами в Base64, исходными и будущими SHA256 и каждой заменой. Файлы команда не записывает. Для подготовки карты доступна команда `swift run fuma язык перевод лексемы --файл <абсолютный-путь.swift>`; необязательный `--до-байта <число>` ограничивает её префикс. При успехе код равен `0`, при отказе — `2`.

[Карта контроллера Стоп](zhurnal/карта-перевода-контроллера-стоп.json) демонстрирует схему `fum.карта-позиций-свифт.1`: файл, полный SHA256, явные привязки с ID, старым и русским именем, байтовой позицией объявления и массивом употреблений. Отсутствующее `объявление` означает межфайловые употребления уже выбранной привязки. Каждая привязка имеет ровно одно объявление во всей карте. Смещения UTF-8 начинаются с нуля; начало относится к имени внутри backtick. Это новый контракт, его позиции не совпадают с Unicode-смещениями исторической Python-карты `2`.

План проверяет точные токены, объявленные роли, русский идентификатор, NFC, хэши и консервативные коллизии во всём файле. Полный инвентарь ролей распознаёт параметры, циклы, замыкания, составные `let`/`var` и варианты enum с литеральными raw values; строковые значения сохраняются. Выбранное употребление, являющееся объявлением, отвергается. В режиме переводчика условие после запятой отличается от привязки кортежа по конечному профилю; метка `for:` поддержана как первый аргумент вызова по цепочке имён. Неподдержанные контексты остаются закрытыми. Связь обычного употребления с конкретной привязкой задаёт автор карты: разрешение имён, полнота употреблений и внешний API из совпадения слова не выводятся. Простые интерполяции имени, цепочки свойств и неявного `$0` поддержаны; вложенные строки, вызовы и другие сложные интерполяции, raw/multiline и slash/regex закрывают выбранный профиль. Неизвестные роли объявления также закрывают план. Поддержка инвентаря ролей переводчика отдельно от прежнего staged-допуска не расширяет его языковую приёмку.

Необязательный `конецПрофиля` карты разрешает выбирать токены только в явно заданном префиксе до границы строки. SHA256 закрепляет весь файл; хвост и все промежутки вне замен копируются исходными байтами без нормализации. Коллизии проверяются полным лексическим инвентарём, который сам не доказывает допустимость перевода хвоста. План сохраняет границу, хэш последовательности промежутков с их длинами и будущий SHA256. Для трёх точных исходников `b294845c0f1d06708b97adc929bc047cdf63766b` сохранены [план](zhurnal/план-перевода-контроллера-стоп.json) и [патч](zhurnal/перевод-контроллера-стоп.patch). Это частичный переход: 33 свойства DTO, отдельные параметры, составные и теневые роли и собственные смешанные имена остаются в явном остатке. JSON-ключи этой картой не мигрируются. [Конечный инвентарь контрактов](zhurnal/остаток-контрактов-контроллера-стоп.json) отдельно различает новые DTO и выходы от подтверждённых унаследованных форматов; стандартное принятие `null` и неизвестных ключей декодером не объявляется новым запретом. Актуальное состояние проверки и конкретная причина закрытия плана приведены в [передаче](zhurnal/передача-перевода-контроллера-стоп.json); исторический успешный план не означает успех текущего классификатора.

План и успешные тесты не устанавливают чужое дерево и не разрешают производственный запуск. Владелец отдельно проверяет точную основу, состав патча, исходные и будущие хэши, применяет результат в своей области и подтверждает фактические байты. Общего атомарного установщика нескольких файлов этот интерфейс не предоставляет.

## Карта первого переноса

Исторический `Инструменты/fum-perevod-obyyavlenij-koda-na-russkij-yazyik/scripts/перевести-объявления-кода.py` использован только как спецификация. Его исполнение, изменение и обновление снимка в этом этапе запрещены.

| Историческая область               | Нативная граница                                                                                            | Остаток                                                                     |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| Swift-токены, строки, комментарии  | `ЛексерЯзыковогоДопуска.swift`                                                                              | Конечный профиль, без полного AST                                           |
| Собственные объявления и параметры | `СканерОбъявлений.swift`, `ЯзыковойДопуск.swift`                                                            | Неподдержанные формы закрывают допуск                                       |
| Латиница и допустимое русское имя  | `ОрфографияОбъявлений.swift`                                                                                | Конечная проверка `ё`, без общего орфографического словаря                  |
| Снимок и исключения                | `ДопускИндекса.swift`, `ИсключенияЯзыковогоДопуска.swift`, `КонтекстВнешнихИмён.swift`, `ВнешниеИмена.json` | Исторический инвентарь не пересчитан; прежние разрешения сняты              |
| Файловый обход и прежний CLI       | `ЧитательГитЯзыка.swift`, `ИзменённыеСтроки.swift`, `КомандаЯзыковогоДопуска.swift`, `hooks/pre-commit`     | Адресный потребитель индекса; прежний общая комплексная проверка не заменён |

Лексический примитив и системный адаптер реализованы на Swift; композиция этого допуска операторами FUMA остаётся отдельным следующим слоем. Общий генератор автора и выбора модели с усилием принимает его единственный владелец после своей приёмки; этот срез сохраняет только точку будущего подключения и не вводит второго производителя.
