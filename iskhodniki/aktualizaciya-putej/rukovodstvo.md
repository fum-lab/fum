# Сухой план актуализации путей

Компонент общей Swift-основы инвентаризирует выбранные области Git-worktree, вычисляет новые имена **каталогов и файлов**, показывает препятствия и позволяет повторно сверить сохранённый план. Команд переноса, удаления и изменения refs в этом срезе нет. Поле `применение_разрешено` всегда равно `false`.

Поддержанная среда — macOS и Swift 6. Исходные пути, stage0, Git OID, режимы и SHA байтов входят в снимок; машинный корень передаётся только при запуске. Публичный результат использует относительные пути и логическую идентичность корня. План относится к наблюдённому физическому дереву: изменение HEAD, индекса, байтов, режима, имени или inode требует нового плана.

## Сборка первого среза

Все команды выполняются из физического корня FUM. Подготовьте закреплённую зависимость по [штатному навыку Git-зависимостей](../../Инструменты/fum-proverka-git-zavisimostej/SKILL.md). Нужна ревизия LinguisticKit `837e2ce107b97ee7b9d3344c9fe99142281fe393`.

Общий корневой Package.swift отдельно принят в `67175fb2831691a4757a2a2f65b8f1968d54189c`. Данный компонент пока не включён в его targets. Для ограниченного среза используется прямой компилятор; отдельный пакет не создаётся. Пример для zsh:

```zsh
сборка=$(mktemp -d /private/tmp/fum-puti.XXXXXX)
swift build --package-path Зависимости/LinguisticKit --product LinguisticKit \
  --scratch-path "$сборка/linguistickit" -j 2
swiftc -swift-version 6 -strict-concurrency=complete -warnings-as-errors \
  -enable-actor-data-race-checks -parse-as-library -D ФУМ_КОМАНДА_ПУТЕЙ \
  -module-cache-path "$сборка/modules" \
  -I "$сборка/linguistickit/debug" -L "$сборка/linguistickit/debug" \
  -lLinguisticKit -Xlinker -rpath -Xlinker "$сборка/linguistickit/debug" \
  iskhodniki/aktualizaciya-putej/*.swift -o "$сборка/proveritj-puti"
```

Зависимость сохраняет собственный прежний режим сборки; перечисленные строгие флаги относятся к новым исходникам. Принятые 19 файлов запуска этим сценарием не переименовываются и не пересобираются.

## Вход и результат

Сохраните форматированный UTF-8 JSON вне Git. Поля `владелец` и `писатель` содержат наблюдённый UUID исполнителя; при штатном CLI поле `писатель` повторно берётся из `CODEX_THREAD_ID`. Совпадение строк не выдаёт полномочий: назначение и единственный писатель предварительно проверяются координатором.

```json
{
  "схема": "fum.запрос-актуализации-путей.1",
  "контекст": {
    "корень": "узел/репозиторий/направление",
    "владелец": "UUID-исполнителя",
    "писатель": "UUID-исполнителя",
    "целевая_ветка": "refs/heads/codex/example",
    "ветки": [],
    "занятые_пути": []
  },
  "области": ["iskhodniki/aktualizaciya-putej"]
}
```

`ветки` при запуске заменяются свежим читающим наблюдением Git. `занятые_пути` — конечные записи `путь`/`владелец` из отдельно выбранного существующего состояния узла; это вход операции, а не новый реестр владельцев. Неизвестное владение сохраняет препятствие.

```zsh
"$сборка/proveritj-puti" план --корень "$(pwd -P)" --вход "$сборка/input.json" > "$сборка/plan.json"
"$сборка/proveritj-puti" diff --корень "$(pwd -P)" --вход "$сборка/input.json"
"$сборка/proveritj-puti" сверить --корень "$(pwd -P)" --вход "$сборка/input.json" \
  --план "$сборка/plan.json" --sha256-плана SHA256_ВЫБРАННЫХ_СЫРЫХ_БАЙТОВ
"$сборка/proveritj-puti" профиль --корень "$(pwd -P)" --вход "$сборка/input.json"
```

`diff` показывает пары прежних и новых адресов; это не исполняемый Git patch. `сверить` заново выполняет весь читающий путь, сверяет независимо переданный SHA и точные полные байты плана. Нельзя заменять её проверкой одной подписи снимка. Код `0` означает успешное чтение/сверку, а препятствия перечисляются в JSON. Код `2` означает отказ; stdout не выдаётся за корректный план. `профиль` сохраняет три последовательных наблюдения одного процесса с раздельными монотонными границами; первый включает подготовку таблицы.

## Единый порядок имён

Исходный Unicode-компонент сначала разбивается на границах CamelCase/PascalCase, сокращений и цифр. Затем выполняется настоящий LinguisticKit `.Cyrl → .Latn`, таблица `.ru`; результат проверяется на ASCII **до** lowercase и дополнительной нормализации. Пробелы, подчёркивания и повторные дефисы становятся одной границей слова. Технические точки расширений сохраняются. Неподдержанный алфавит и непредставимый результат дают отказ.

`ModeljPlana.swift → modelj-plana.swift`, `XMLParser → xml-parser`, `JSON2Value → json2-value`, `foo2bar → foo2bar`. `XMLHTTP` не делится по предполагаемому смыслу сокращений. Кириллические Swift-идентификаторы внутри файлов не переименовываются.

Конечный перечень исключений этого среза: точное `Package.swift` для SwiftPM; точное `AGENTS.md` для инструкций агента; точное `Инструменты/<имя>/SKILL.md` для канонического обнаружения навыка. Причина и источник каждого использованного исключения входят в план. Похожий Unicode-символ, иной регистр или произвольный суффикс исключения не получают. Перечень не объявляет завершённым аудит остальных доменных форматов.

## Защитные границы

Физические имена и Git-имена сохраняются раздельно. NFC служит только поиском единственного кандидата; точный Git-путь дополнительно открывается через `openat/O_NOFOLLOW` и обязан обозначать тот же inode/тип. Casefold не даёт льготы связывания. Коллизии проверяются отдельно. Индекс с ненулевой стадией, missing tracked, symlink и выход за корень закрывают чтение. Поздний обход метаданных заново проверяет весь прочитанный состав.

Проверяются соседи посещённых каталогов без обхода чужих поддеревьев: существующее назначение, перенос неполного родителя, перенос занятого пути и его предка, циклы, только-регистр и Git ref prefix conflict сохраняются как препятствия. Внешние и производные границы сохраняют адреса; классификация использует закреплённый [существующий контракт проекции](../../Инструменты/fum-bratislavskaya-proyekciya-pamyati/контракт-v2.json), без второго перечня.

Поиск ссылок возвращает **кандидатов** Markdown, кода и конфигурации. Синтаксическая полнота и безопасная замена пока не доказаны. Источники, Журнал, RAW и дословные области сохраняются; глобальная строковая замена отсутствует. Проверяемое применение, откат и адаптеры ссылок остаются следующими отдельными срезами.

В pin837 обнаружен [FUM-СБОЙ-0032](../../Сбои/FUM-СБОЙ-0032-общие-изменяемые-таблицы-LinguisticKit.md): изменяемые общие кэши таблицы. Все экземпляры нового фасада используют один общий actor; внутри нативного вызова нет `await`. Это ограничивает обращения данного компонента и не объявляет исправленной закреплённую библиотеку либо все сторонние потребители.
