# Indeksyi pamyati FUM

Etot katalog khranit proizvodnyiye navigacionnyiye indeksyi [pamyati FUM](../Glossarij/pamyatj-FUM.md), kotoryiye sobirayutsya lokaljnyimi [avtomatizaciyami FUM](../Glossarij/avtomatizaciya-FUM.md) i pomogayut videtj sostoyaniye repozitoriya poperyok obyichnoj strukturyi papok.

Indeksyi ne zamenyayut [iskhodnyiye zaprosyi](../Glossarij/iskhodnyij-zapros.md), [proizvodnuyu dokumentaciyu](../Glossarij/proizvodnaya-dokumentaciya.md), [glossarij](../Glossarij/glossarij-proyekta.md) ili [zhurnal rabot](../Glossarij/zhurnal-rabot.md). Oni yavlyayutsya navigacionnyim sloyem poverkh uzhe sokhranyonnyikh materialov.
