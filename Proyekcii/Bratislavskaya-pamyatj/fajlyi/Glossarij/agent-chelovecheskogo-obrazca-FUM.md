# Agent chelovecheskogo obrazca FUM

Agent chelovecheskogo obrazca FUM - II-agent, ustrojstvo kotorogo vosproizvodit sposob uchastiya cheloveka v seti sinkhronizacii znanij: agent sokhranyayet sobstvennoye lokaljnoye i nepolnoye sostoyaniye, vosprinimayet i porozhdayet yestestvennyij yazyik, razlichayet sebya, sobesednikov i gruppyi, stroit ispravlyayemyiye modeli drugikh uchastnikov, obnovlyayet pamyatj po khodu dialoga i umeyet zaprashivatj utochneniye, podtverzhdatj ponimaniye, vozrazhatj i ispravlyatj rassoglasovaniye.

Chelovecheskij obrazec otnositsya k organizacii vzaimodejstviya, a ne k utverzhdeniyu o biologicheskom tozhdestve, chelovecheskoj lichnosti ili odinakovom vnutrennem ustrojstve. Takoj agent mozhet byitj postroyen s ispoljzovaniyem LLM, no odna LLM bez ustojchivoj [pamyati FUM](pamyatj-FUM.md), proiskhozhdeniya, identichnosti uzla, [agentskogo cikla](agentskij-cikl.md), instrumentov i [granic dostupa](urovenj-dostupa.md) yesjhyo ne obrazuyet polnogo agenta chelovecheskogo obrazca.

V arkhitekture [FUM](FUM.md) tot zhe princip primenyayetsya rekursivno: agent yavlyayetsya uchastnikom vneshnej seti lyudej, II-agentov i [gibridnyikh uzlov](gibridnyij-uzel.md), a vnutri mozhet byitj sobran kak setj poduzlov, kotoryiye koordiniruyut lokaljnyiye znaniya cherez sovmestimyij kontur [yestestvenno-yazyikovoj sinkhronizacii znanij FUM](yestestvenno-yazyikovaya-sinkhronizaciya-znanij-FUM.md).
