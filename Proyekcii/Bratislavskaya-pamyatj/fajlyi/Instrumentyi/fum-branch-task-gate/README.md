# Snyatyij barjyer zadach Git-vetki

Prezhnyaya hook- i POSIX-zavisimaya avtomatizaciya snyata. Etot katalog ne soderzhit `SKILL.md` i ne yavlyayetsya aktivnyim navyikom. Fajl ostavlen kak celj istoricheskikh ssyilok i tochka obyyasneniya perekhoda.

Dejstvuyusjhij kontrakt ruchnoj posledovateljnoj rabotyi zakreplyon v `AGENTS.md`; [perenosimaya FIFO-ocheredj](../fum-ocheredj-zadach-git-vetki/SKILL.md) takzhe snyata s aktivnogo marshruta i sokhranena kak istoriya. Minimaljnyij `scripts/branch-task-gate.py` toljko bezvredno zavershayet uzhe kyeshirovannyij staryij loader v otkryitoj zadache; novyiye zadachi yego ne ispoljzuyut.
