ALT Linux Team

Cообщество, объединяющее разработчиков
свободного программного обеспечения

Много лет «Базальт СПО» поддерживает развитие ежедневно обновляемого репозитория (хранилища) свободных программных пакетов проекта Sisyphus («Сизиф»). Проект ведет ALT Linux Team — международная, преимущественно русскоязычная команда разработчиков свободного программного обеспечения. Большинство разработчиков «Базальт СПО» участвуют в работе ALT Linux Team, репозиторий работает на серверах, принадлежащих компании.

Весь код, созданный участниками ALT Linux Team, распространяется под свободными лицензиями: его можно использовать в любых целях, изучать и вносить изменения, распространять. Сотрудничество по принципу «вклад каждого — достояние всех» позволяет создавать программные продукты на основе лучших мировых достижений.

«Базальт СПО» тщательно тестирует программные пакеты, которые включает в свои продукты, обеспечивая их надежную защиту.
