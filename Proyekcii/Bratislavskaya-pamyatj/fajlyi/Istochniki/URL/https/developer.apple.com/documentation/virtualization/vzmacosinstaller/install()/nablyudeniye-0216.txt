# Ограничение установки macOS

Адресное чтение официального Markdown 12 сентября 2026 года: установка начинается при stopped на очереди VM; экземпляр installer используется один раз. Пауза и остановка VM во время установки не являются допустимым контрактом отмены. Восстановление с прежнего процента не обещано.

Короткий дословный фрагмент:

> During the installation operation, pausing or stopping the VM results in an undefined behavior.
