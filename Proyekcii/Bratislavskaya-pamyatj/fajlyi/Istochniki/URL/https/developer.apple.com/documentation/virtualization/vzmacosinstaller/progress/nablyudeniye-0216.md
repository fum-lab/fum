# Отмена installer через progress

Адресное чтение официального Markdown 12 сентября 2026 года подтвердило объект Progress для наблюдения и отмены установки. Отмена до начала установки вызывает исключение; завершение отмены и состояние VM проверяются отдельно.

Короткий дословный фрагмент:

> Canceling the progress object before starting an installation raises an exception.
