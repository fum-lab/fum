# Инцидент: широкий поиск 15 ноября 2026

При поиске прежних helper для bootstrap документации сознания Главстрой запустил слишком широкий поиск, затем прервал его:

```sh
find /Users/Shared/FUM-worktrees /Users/fum/.codex/worktrees -type f \( -name 'struktura-papok-zaprosov.py' -o -name 'независимый_журнал.py' \) -exec shasum -a 256 {} + 2>/dev/null | rg '^(17b8856f|4a190f1f)'
```

`find` обходил имена и метаданные под двумя указанными корнями. `shasum` читал байты найденных файлов с указанными именами для вычисления хэшей; содержимое не выводилось. Совпадений в выводе не было. Конкретный посещённый закрытый каталог неизвестен. Автоматизация fum-4, её расписание и target не проверялись и не менялись. ROOT уведомлён о границах и неопределённости.

Предотвращение: искать только по точному заранее согласованному списку папок, исключая запрещённые области; до запуска проверять и сами корни обхода, и то, что команда чтения хэшей открывает содержимое каждого совпавшего файла. Широкий поиск не повторять.
