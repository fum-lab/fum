# Адресный срез описаний FUM

Эта область ведёт навигацию, происхождение и состояние задачи по адресу fum-lab/fum/opisaniya/master. Она не создаёт новых требований к продукту: постановка и границы среза находятся в [исходной постановке](postanovka.json), канонические требования — в Документация/ и Глоссарий/.

## Владение и снимок

В этой задаче разрешены только файлы opisaniya/**. Историческое Описания/** остаётся неизменяемым источником для чтения. На исходном снимке 5f5337e2fc13dd792e88c47ce2354a8bce8ce004 в Описания/ находится 18 отслеживаемых файлов:

- корневое описание и три адресных текста, JSON сообщений иерархии;
- описание базовой автоматизации подготовки текста;
- README, входные данные и три определения операторов/входов пакета FUMA;
- пять модулей сборки пакета и два теста их расчёта.

Это инвентарь файлов снимка, а не подтверждение текущей свежести или повторного исполнения этих автоматизаций. [Состояние узла](состояние-узла.md) фиксирует точную основу и границы.

## Проверяемая цепочка: пакет FUMA

Существующее [описание пакета](../Описания/пакет-FUMA/README.md#что-посчитано) говорит, что [входное содержание](../Описания/пакет-FUMA/содержание.json#L1010-L1018) проходит через [определение оператора](../Описания/пакет-FUMA/оператор-пакета.json), которое задаёт граф представлений и расчёта. В строке Mac Studio указаны статус «Требуется КП» и null для рублёвой цены и долларового ориентира. Указанный там URL имеет сохранённый [индекс источника](../Источники/URL/https/www.apple.com/mac-studio/specs/source-index.md) и [отчёт извлечения](../Источники/URL/https/www.apple.com/mac-studio/specs/extraction-report.md); присутствие снимка в Git не означает свежей загрузки страницы или появления отсутствующей цены. README пакета также ссылается на отдельный источник мощности Mac Studio, не на цену этой строки.

В исходниках основного приложения [FUMApp](../Приложения/FUMA/macOS/Sources/FUMApp/FUMApp.swift#L15-L31) выбирает операторный режим и передаёт его [командному исполнителю](../Приложения/FUMA/macOS/Sources/ИсполнениеОператора/КомандноеИсполнение.swift#L65-L123), который вызывает движок из прототипного Swift-пакета. Контракт описан в [документе исполнения](../Приложения/FUMA/macOS/docs/исполнение-оператора.md#исполнение-оператора-в-fuma). Это связка файлов и исходников, а не результат нового запуска: в этих срезах пакет не собирался, оператор не исполнялся, цены не выводились. Неизвестная цена из источника остаётся неизвестной.
