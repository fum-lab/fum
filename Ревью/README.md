# Ревью проделанной работы

Этот каталог хранит сохранённые ревью рабочих срезов [памяти FUM](../Глоссарий/память-FUM.md). Ревью фиксирует, что именно проверялось, относительно какой Git-базы, какие находки обнаружены или не обнаружены, какие проверки запущены и какие остаточные риски остаются после просмотра.

Ревью не заменяет [исходный запрос](../Глоссарий/исходный-запрос.md), [журнал работ](../Глоссарий/журнал-работ.md), локальные тесты или Git-коммит. Оно служит отдельным обзорным слоем качества: помогает увидеть состояние уже проделанной работы и сохранить вывод ревьюера в воспроизводимой форме.

## Автоматизация

Типовые отчёты ревью создаются локальной [автоматизацией FUM](../Глоссарий/автоматизация-FUM.md) [fum-work-review](../Инструменты/fum-work-review/SKILL.md). Конфигурации запусков хранятся в `Ревью/Автоматизации/`, а итоговые Markdown-отчёты - в этом каталоге.
