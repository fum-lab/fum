# Ревью проделанной работы

Этот каталог служит навигационным индексом сохранённых ревью рабочих срезов [памяти FUM](../Глоссарий/память-FUM.md). Само ревью и его одноразовая конфигурация имеют одного владельца и лежат вместе в `материалы/ревью/` соответствующей [папки запроса](../Глоссарий/папка-запроса.md). Ревью фиксирует, что именно проверялось, относительно какой Git-базы, какие находки обнаружены или не обнаружены, какие проверки запущены и какие остаточные риски остаются после просмотра.

Ревью не заменяет [исходный запрос](../Глоссарий/исходный-запрос.md), [журнал работ](../Глоссарий/журнал-работ.md), локальные тесты или Git-коммит. Оно служит отдельным обзорным слоем качества: помогает увидеть состояние уже проделанной работы и сохранить вывод ревьюера в воспроизводимой форме.

## Автоматизация

Типовые отчёты ревью создаются локальной [автоматизацией FUM](../Глоссарий/автоматизация-FUM.md) [fum-revjyu-prodelannoj-rabotyi](../Инструменты/fum-revjyu-prodelannoj-rabotyi/SKILL.md). Автоматизация кладёт конфигурацию запуска и итоговый Markdown-отчёт в `материалы/ревью/` папки запроса-владельца, а этот индекс сохраняет устойчивые ссылки на результаты.
