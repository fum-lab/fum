# Инцидент inline Python Главстроя

После предыдущей записи управляющий передал уточнение инцидента имени ветки планировщика; устранитель ведёт расследование и предотвращение. Фактическое переименование тогда не было подтверждено.

По сообщению управляющего, Главстрой подтвердил применение новой самостоятельной inline Python-реализации при действующем запрете, а не существующего инструмента. Вызов завершился exit 0 и создал три linked worktree/ref на c2c2 для планировщика, 3D-моделера и документации; выполнялись read-tree, skip-worktree и адресное восстановление общих файлов. Письменный Python-файл, по сообщению, не создавался. Существующие результаты сохраняются, действия не повторяются; устранитель ведёт причины и предотвращение, управляющий уведомил человека. Иные последствия без свидетельства UNKNOWN; летописец работу самостоятельно не проверял.
