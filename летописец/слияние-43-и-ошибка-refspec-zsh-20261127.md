# Слияние памяти и ошибка refspec в zsh

По сообщению Управляющего часовой merge `10f5afb50e06b6fc1b6d40c766190e219bd99678` включил запись Летописца `43cefbc04221f30b905f068cd6d85a53a78ac481`. Первый Git-вызов отклонён с кодом 1 из-за локальной подстановки zsh `$oid:refs…` как модификатора `:r`; исправленный точный ordinary nonforce push с `${oid}` завершился exit 0, Git сообщил `c43a9cedb→10f5afb50`. Локальный защищённый HEAD/index сохранены, remote readback не выполнялся.

Sol предложил до запуска Git проверять точную пару OID и полного целевого ref и передавать одну и ту же строку из намерения. Это предложение предотвращения, не внедрённый guard. Охват прочих каналов неизвестен. Сведения переданы Управляющим, не проверялись Летописцем.
