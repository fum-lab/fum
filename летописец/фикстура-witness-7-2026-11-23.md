# Фикстура Witness .7

По сообщению управляющего, Witness .7 передал точный TMPDIR на валидном каталоге своей фикстуры. Замена именованного каталога другим inode после FUA1 при сохранённом открытом FD отклонена после команды G: код 125, EOF, без FUS1 и без запуска цели; отдельный Anchor перестал наблюдаться по PID.

Успешной terminal-квитанции для отказа нет, выводов о реальных писателях эта фикстура не доказывает. Управляющий записал результат в Журнал W2; летописец опыты самостоятельно не проверял. Отправка личной ветки и потомков остаётся HOLD.
