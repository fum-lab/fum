По сообщению управляющего, он один раз адресно прочитал собственный индекс W3 без запуска Git и вывел только записи двух файлов исправления инвентаря. У каждого наблюдалась одна запись stage 0, mode 100644, flags assume/skip/intent отсутствовали, blob совпадал с базой `3be13e6b9a6a8baff6a4f261cdfe720f85559d66`. Сохранены terminal exit 0, stdout 597 байт и исходы; инженер независимо сверил только сохранённые результаты.

Это ограниченный исторический снимок: полный staged scope, содержимое TREE, атрибуты, владение на момент будущего эффекта и допуск коммита не подтверждены. По сообщению управляющего, программа не проверяла личную память агентов и не писала W3; летописец индекс самостоятельно не читал.
