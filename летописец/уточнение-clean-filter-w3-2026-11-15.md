# Уточнение Git diff и clean filter

По сообщению устранителя, ранее управляющий запустил в своём W3 `git diff --stat` и `git diff --check` с явно очищенной средой до обнаружения возможности clean filter. Оптимизатор на отдельной новой синтетической фикстуре наблюдал вызов локального clean filter: marker 0→3 и 3→6 при exit 0. Вызывался ли helper и был ли эффект в W3, UNKNOWN; утечка или безопасность не установлены, вызовы в W3 не повторять.

Для предотвращения требуется доказанный маршрут через index/object и синтетические положительные и отрицательные проверки marker: одна очистка ENV недостаточна. Общий guard ещё не доказан. Сведения атрибутированы устранителю; летописец W3 и фикстуру самостоятельно не проверял.
