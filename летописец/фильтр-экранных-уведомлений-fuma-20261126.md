# Фильтр экранных уведомлений FUMA

По сообщению Управляющего FUMA фильтрует экранные уведомления по точному пути своей рабочей области, вызовы без строки пути игнорируются. Xcode-сборка прошла; SHA-256 FUMA.debug.dylib: `e4d874ee4a74e95d3e8699d101d1d0dec1e32cc7550546b6c4df594b5ff5d37e`.

Живой стенд подтвердил квитанции, очистку, отдельные области и получение квитанции для сообщения без уведомления через периодическое чтение. По квитанции нельзя отличить уведомление от периодического чтения. Код и Журнал локальные, `diff --check` прошёл. Это переданные сведения, не самостоятельная проверка Летописца.
