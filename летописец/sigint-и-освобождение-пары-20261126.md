# SIGINT и освобождение пары замков

По сообщению Управляющего адресный нативный стенд раздельной отчётной обёртки подтвердил два сценария SIGINT за 5,273 с: до GO цель не стартовала, active побайтно сохранён и оба замка заняты; после терминала результат сохранён и оба замка доступны. Процесс дал exit 0, но при завершении пары тестов Python напечатал необработанную ошибку освобождения пары замков из генератора `удержать_начало`.

В отдельном диагностическом случае до GO предупреждения не было; причина и судьба ресурсов в общей серии остаются открытыми. Первые два вызова не дошли до сценариев из-за настройки стенда, условия исправлены. Публичная обёртка закрыта, код не менялся, Журнал локальный. Это переданные сведения, не самостоятельная проверка Летописца.
