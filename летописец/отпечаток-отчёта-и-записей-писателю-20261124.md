# Отпечаток отчёта и записей писателю

По сообщению Управляющего обёртка W2 передаёт с active отпечаток отчёта и всех записей. При повторном захвате пары писатель отказывает до U/Git при изменённом отчёте или новом файле даже с прежней active. В нативном опыте контроль дошёл до намеренно отсутствующего U, три подмены остановлены и в каждом отрицательном случае active сохранена. Четыре сценария дали exit 0, два адресных теста и восемь нативных прошли.

Это сверка байтов на передаче; непрерывность замков и рабочие полномочия не доказаны. Публичная обёртка закрыта, изменений кода в Git нет. Это переданные сведения, не самостоятельная проверка Летописца.
