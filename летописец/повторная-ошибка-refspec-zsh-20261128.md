# Повторная ошибка refspec в zsh

По сообщению Управляющего при часовой доставке он передал Git refspec как `$oid:refs/...`; zsh интерпретировал `:r`, Git локально отверг искажённый refspec, exit 1. После формирования refspec с `${oid}:refs/heads/fum-lab/fum/master` обычный push точного `537f8446692ff33be9afa69cdb63fb413cd7c2cd` завершился exit 0. Наблюдатель сообщил о предыдущем похожем случае; происхождение прошлого не сверяли.

Предотвращение для Управляющего: формировать refspec из отдельных OID и полного `refs/heads/...` с однозначными границами подстановок и явно сверять сформированный аргумент с назначением до передачи Git. Охват каналов неизвестен. Это переданные сведения, не самостоятельная проверка Летописца.
