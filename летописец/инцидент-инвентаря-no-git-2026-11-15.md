# Инцидент области инвентаря no-git

По сообщению управляющего, его незакоммиченная правка W3 ошибочно передала `use_git=False` файловому инвентарю, вследствие чего в отдельной синтетической фикстуре был прочитан файл, игнорируемый `.gitignore`. На реальном W3 этот режим не запускался; утечка не установлена.

После независимого замечания восстановлена прежняя область: `--no-git` исключает Git для начальных дат, но инвентарь по-прежнему может использовать Git. Добавлен синтетический RED/GREEN тест с игнорируемым файлом, отслеживаемым несмотря на ignore файлом и разрешённым неотслеживаемым; по сообщению управляющего прошли 37/37 тестов. Код не коммитился. Полностью Git-независимый полный инвентарь и безопасный Git runner ещё не реализованы; летописец фикстуру и чужую память самостоятельно не проверял.
