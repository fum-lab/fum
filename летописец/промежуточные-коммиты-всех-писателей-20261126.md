# Промежуточные коммиты всех писателей

Направляющий сказал: «Dlya vsekh pisatelej poboljshe promezhutochnyikh kommitov.» Все писатели чаще фиксируют законченные содержательные этапы в своих ветках по действующим правилам, без пустых коммитов и без откладывания до большой партии. Прежнее исключение для личной памяти без проверок сохраняется.

По сообщению Управляющего текущий срез FUMA собрался отдельно, экран и очередь прошли, сканер публикации нашёл 11 строк; проектного коммита пока нет. Это переданные сведения, не самостоятельная проверка Летописца.
