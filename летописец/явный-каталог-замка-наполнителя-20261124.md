# Явный каталог замка наполнителя

По сообщению Управляющего библиотечное применение наполнения в W2 теперь, как CLI, требует явно переданный каталог замка до чтения плана без выбора tempfile из среды. Прошли три теста входа, тест CLI с реальным занятым замком и шесть сценариев сохранности, повтора и отката. Код W2 без коммита.

Живой статус FUM.app показал `isRunning=false`, мост не предоставил рабочий lock-root. Это переданные сведения, не самостоятельная проверка Летописца.
