# Внутренний запуск true и свидетельство

По сообщению управляющего, на отдельной синтетической фикстуре настоящий запуск внутреннего кандидата отчётной обёртки с `/usr/bin/true` достиг terminal, но существующий тест ошибочно прочитал защищённое свидетельство после освобождения замка и завершился ошибкой. Старый владелец удержан (session 33678); состояние его FD и потомков UNKNOWN, не трогать.

Управляющий исправил только существующий тест: свидетельство снимается до штатного close без ослабления guard. По новой точной версии отдельный синтетический тест в session 4356 завершился exit 0, stdout `PASS: one test completed`, stderr пуст; результаты сверил наблюдатель. Это один внутренний путь без конкурентов и без открытия public guard. Тестовая правка W2 ещё не закоммичена; летописец фикстуру и чужую память не проверял.
