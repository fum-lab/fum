# Транспорт .8 и UUID исполнителя

По сообщению Управляющего актуальный W2 уже поддерживает передачу пары замков при наполнении v2 и проверенный синтетический ACT2; этот аудит повторно их не запускал. Управляющий собрал действующие Witness и Anchor из исходников со строгим Swift 6, проверил подписи; профиль реального транспорта .8 прошёл два сценария за 1,582 с.

При синтетическом CODEX_THREAD_ID в собственном процессе Witness целевой процесс его не получил. Точная функция проверки исполнителя приняла только совпадающее отдельное наблюдение и отказала без значения и с чужим: три адресных случая. В рабочем маршруте обёртка запускает Witness с пустой средой, штатный транспорт не предоставляет отдельного источника UUID. Полный рабочий запуск не выполнялся, обёртка закрыта. Это переданные сведения, не самостоятельная проверка Летописца.
