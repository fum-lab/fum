# Очередь вопросов в локальном FUMA.app

По сообщению Управляющего проверен тот же Xcode Debug-пакет FUMA.app со встроенным MCP, реальным окном и закреплённой синтетической очередью. В режиме присутствия ask_in_chat без записи. Штатная CLI-команда включила накопление, MCP принял два вопроса; чужая задача и устаревшая ревизия отклонены без изменения байтов. После остановки и нового запуска номера сохранились. Возвращение вернуло вопросы по порядку, подтверждение второго оставило первый; оба запуска штатно закрылись.

Первый стенд ошибся в поле проверяемого результата после успешной команды; исправленная проверка прошла в новой фикстуре, код приложения не менялся. UI-клики и вывод текста на экране не проверены, чат Codex uncovered. Локальный Журнал W2 и свежесть обновлены. Это переданные сведения, не самостоятельная проверка Летописца.
