# Проверка исполнителя и пары

По сообщению Управляющего проверка пары в W2 сопоставляет U, G2, ACT и нативного исполнителя до Git. Настоящий Witness .8 не передал UUID и получил точный ранний отказ. Прямой инструментированный CLI подтвердил отсутствие вызовов Git при отсутствии UUID и при UUID координатора. С явно переданным только для фикстуры UUID исполнителя выполнены два читающих Git-вызова под тремя замками, затем получен ожидаемый отказ по Q.

Метаданные Управляющего относятся к исходному защищённому W; реальный источник UUID исполнителя не установлен. Асинхронный after-effect на FD и неожиданный сигнал пары проверены с имитацией и сохранением active. Прошли 18 адресных тестов. Код и Журнал W2 не закоммичены. Это переданные сведения, не самостоятельная проверка Летописца.
