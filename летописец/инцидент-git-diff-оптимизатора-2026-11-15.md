# Инцидент среды Git diff оптимизатора

По адресному сообщению устранителя, оптимизатор выполнил read-only `git diff` в W3 по двум путям без явно очищенной среды; diff наблюдал, отдельный exit и влияние унаследованной Git ENV UNKNOWN. Значения ENV, по сообщению, не выводились и не анализировались; повторного вызова нет. Ни утечка, ни безопасность этим не доказаны; исходное правило и причина уточняются.

Предложена профилактика: закрытая среда и доверенный Git-контекст, запрет ext-diff/textconv/helpers и отрицательная синтетическая проверка. Это предложение, общий работающий guard не доказан. Летописец исходные файлы и чужую память не читал.
