# Сигналы при проверке отпечатков

По сообщению Управляющего проверка отпечатков перед допуском в W2 замечает отложенные SIGINT/SIGTERM между порциями файлов и во время ожидания Git. В трёх нативных сценариях цель не стартовала, терминальные коды −2/−15 подтверждены; при задержанном чтении возврат занял около 0,21 с. Прошли десять подслучаев полного тестового маршрута.

Код W2 без коммита, штатный вход остаётся закрытым. Это переданные сведения, не самостоятельная проверка Летописца.
