# Сверка опор запуска и Git

По сообщению управляющего, `сверить-опоры-запуска` подтвердил два закреплённых временных замка на отдельной Git-базе с кодом 0 и отверг неверный inode с кодом 1. После обоих случаев замки доступны, файлы Журнала/индекса и метки совпали.

В диагностике ограниченного Git `/usr/bin/git` вернул 71 с ошибками кэша xcrun и запуска xcodebuild; прямой закреплённый Git Xcode вернул точный ключ. Bootstrap и engine в текущем HEAD W2 отличаются от рабочих байтов, поэтому положительный манифест писателя не запускался. Запись в Журнале W2 проверена управляющим; летописец опыт и чужую память самостоятельно не проверял. Личная отправка и отправка потомков остаются HOLD.
