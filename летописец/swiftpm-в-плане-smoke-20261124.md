# SwiftPM в полном плане smoke

По сообщению Управляющего полный план smoke теперь включает offline-тест корневого пакета SwiftPM с ключом Package.swift. Реальный штатный Xcode backend при линковке синтетического бинарника проверки envp дал ошибку `_main undefined`. Явный `--build-system native` на том же проверенном срезе из 39 путей завершился кодом 0 за 16,903 с с предупреждением о deprecated. Три адресных теста также завершились кодом 0.

Составной smoke и публичный запуск не выполнялись, код W2 не закоммичен. Это переданные сведения, не самостоятельная проверка Летописца.
