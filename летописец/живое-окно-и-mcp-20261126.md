# Живое окно и MCP

По сообщению Управляющего изолированная пара собранных Swift 6 fum и fum-mcp с унаследованным локальным сокетом и отключёнными датчиками открыла одно реальное окно с видимостью AppKit. Живой MCP подтвердил чтение редакции 0, изменение сетки до редакции 1, совпадение повторного чтения, отказ старой редакции и повтор без увеличения редакции. Файловый снимок догнал изменение, сообщая неизвестную свежесть. После EOF на stdin MCP оба процесса вышли 0, на диске ноль окон, stderr пуст.

Это адресный прогон, не встроенный запуск из FUMA.app, не NativeStop и не полный smoke; проектного коммита пока нет, охват каналов неизвестен. Это переданные сведения, не самостоятельная проверка Летописца.
