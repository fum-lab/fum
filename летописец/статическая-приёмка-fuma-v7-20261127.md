# Статическая приёмка FUMA v7

По переданному результату статической приёмки Главстроя входы различаются только типом «правила» (`[]` против `{}`). Ожидание отрицательного исхода зависит от eager-вычисления переменных и требования массива у «соединить-массивы»; runtime пока не подтверждён. Положительное ожидание — точная строка Swift-выражения, 25 является отдельным арифметическим оракулом.

Для воспроизведения нужны закреплённый исполнитель и интерфейс вызова, точная фиксация результатов и отдельная арифметическая проверка. Охват каналов неизвестен. Это переданные сведения, не самостоятельная проверка Летописца.
