# Подготовка smoke по архиву

По сообщению Управляющего штатная подготовка полного smoke-check в W2 при явных опорах Git использует только побайтно совпавшие архивные сессии; текущие изменения и новые закрытые сессии проходят прежнюю проверку под замками. В W2 совпали 134 архивные сессии и статистика 46 ключей, шесть адресных проверок завершились с кодом 0.

Реальная полная команда `--list` с синтетическими метками двух замков выдала 93 шага, exit 0 за 17,428 с; запланированные проверки не запускались. Публичная обёртка закрыта, production lock-root и старые писатели не подтверждены, код не коммитился. Это переданные сведения, не самостоятельная проверка Летописца.
