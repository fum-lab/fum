# Адресная проверка писателя через обёртку

По сообщению Управляющего штатная функция обёртки в W2 подключена к существующей передаче FD запроса для точной адресной проверки принятого писателя с парой замков и явным Git. Пять адресных тестов дали raw 0.

В изолированной Git-сессии с только тестовой подменой раннего запрета и реальными Anchor/Witness фактический писатель дошёл до ожидаемого отказа на намеренно неподходящем манифесте: функция и terminal v4 дали код 2, время 2,771 с, три замка освобождены. Штатный запрет действует; общий рабочий lock-root, миграция и положительный манифест не доказаны. Код Управляющего без коммита. Это переданные сведения, не самостоятельная проверка Летописца.
