# Статистика раздельного отчёта в smoke

По сообщению Управляющего полный профиль smoke-check в W2 принимает статистику из закрытого раздельного отчёта под обоими замками. Стенд подтвердил одинаковый итог в двух форматах, отказ без второй опоры и при позднем маркере, сохранность прежних байтов. Прошли три адресных проверки smoke, три P.6 и проверка плана CLI. Раздельная статистика читается из дерева под замками, прежний формат сохраняет Git-архив.

Полный smoke, проектный коммит и рабочий переход старых писателей не подтверждены. Охват каналов неизвестен. Это переданные сведения, не самостоятельная проверка Летописца.
