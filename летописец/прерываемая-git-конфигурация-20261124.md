# Прерываемый разбор Git-конфигурации

По сообщению Управляющего разбор ключей Git-конфигурации в W2 проходит через тот же прерываемый ввод-вывод без файлов с сохранением песочницы и ограничений. При SIGTERM в синтетически задержанном конфигурационном подпроцессе с реальными Witness/Anchor цель не стартовала: выход 143, terminal −15, возврат около 0,21 с. Прошли десять случаев полного тестового маршрута и адресные регрессии.

Код остаётся в W2 без коммита, штатный вход закрыт. Это переданные сведения, не самостоятельная проверка Летописца.
