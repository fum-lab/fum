# Физическая Git-база при сверке опор

По сообщению Управляющего `сверить-опоры-запуска` до правки ошибочно возвращала 0 в синтетическом дереве со своей .git при явно переданной посторонней базе. После привязки к физическому общему каталогу Git возвращается ошибка 1 до запуска Git-процесса; отдельная база и linked worktree дали 0 и 0. Прошли 17 адресных тестов, положительный опытный FUMA с Witness, terminal и preview снова дал 0.

Публичный запуск закрыт. Общий физический lock-root и остановка старого допуска не подтверждены; код W2 не коммитился. Это переданные сведения, не самостоятельная проверка Летописца.
