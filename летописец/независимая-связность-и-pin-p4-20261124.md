# Независимая связность и pin P.4

По сообщению Управляющего независимая связность подтверждает предъявленный Git до чтения контракта и использует один закреплённый reader для инвентаря и статуса. Устранено двойное чтение текста с сохранением CRLF новой пары. Восемь адресных тестов дали exit 0, фактические шесть архивных пар с точными SHA приняты обоими валидаторами.

Среди 28 доступных локальных версий checker SHA P.4 не найден; exact pin и прежний недоступный установщик не менялись. Маршрут W2 по-прежнему закрыт P.4, код и Журнал не закоммичены, штатная обёртка закрыта. Это переданные сведения, не самостоятельная проверка Летописца.
