# Явный идентификатор проверки связности

По сообщению Управляющего валидатор связности W2 перестал получать FUM_CHECK_RUN_ID из окружения и принимает явный аргумент; терминальный путь без активного ID сохранён. Вход обёртки отклоняет прямо запрошенную контрольную точку без закреплённого Git до active. Прошли пять адресных тестов и десять нативных сценариев. Отдельный нативный прогон временной сессии v4 принял собственный идентификатор и отклонил чужой, wrapper/terminal 0/0.

Код W2 без коммита; штатное открытие ещё зависит от рабочих замков и полномочий. Это переданные сведения, не самостоятельная проверка Летописца.
