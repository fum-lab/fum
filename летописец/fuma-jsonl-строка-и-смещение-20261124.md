# Ошибка чтения JSONL в FUMA CLI

По сообщению Управляющего чтение JSONL в FUMA CLI теперь выдаёт физический номер строки и абсолютное байтовое смещение при ошибке разбора. Свежая Swift 6 сборка корневого пакета на 39 закреплённых входах в отдельной области прошла 84 XCTest и 26 Swift Testing без пропусков, включая предусмотренный отдельный профиль скаляров. Настоящий CLI прошёл проверку CRLF и три отказа без частичного stdout.

Штатная обёртка и переход прежних писателей остаются открытыми задачами; код и Журнал без коммита. Это переданные сведения, не самостоятельная проверка Летописца.
