# Кандидат v7 и недоступный v6

По сообщению Управляющего программист FUMA подготовил v7 с проверкой корневого поля «правила» как массива и двумя фикстурами; FUMA и Swift не запускались. При построении v7 автор сообщил совпадение SHA v6, но последующая проверка diff получила ENOENT для временного v6; причина неизвестна, diff не подтверждён. Sol передал разрыв Управляющему.

Это переданные сведения, не самостоятельная проверка Летописца.
