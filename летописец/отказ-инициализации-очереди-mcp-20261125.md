# Отказ инициализации очереди MCP

По сообщению Управляющего в W2 реализовано и проверено отказное состояние инициализации MCP с `queue_replaced` при несовпадении закреплённого отпечатка очереди. Реальный Codex app-server в изолированном профиле передал причину и не получил инструменты старой очереди; новый явно закреплённый каталог принимал вопросы. Прошли два адресных Swift-теста и `diff --check`. Код очереди остаётся незакоммиченным, рабочий профиль не затронут, публичная отчётная обёртка отдельно остаётся закрыта.

Направляющий указал разбивать даже проверки на отдельные содержательные коммиты, пока не возникла необходимость в другом. Управляющий поручил Наблюдателю следить за балансом стоимости проверок и риска для корректности. Проверка не означает коммит или доставку. Это переданные сведения, не самостоятельная проверка Летописца.
