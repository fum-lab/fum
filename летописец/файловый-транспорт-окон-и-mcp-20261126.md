# Файловый транспорт окон и MCP

По сообщению Управляющего файловый транспорт окон FUMA отклоняет повтор адреса, нулевое или повторное поколение и окна из разных реестров до публикации и при чтении. Живой клиент MCP проверяет длину запроса и диапазон акцента. Прошли 17 тестов рабочего состояния и два теста MCP, включая 16 вариантов адресного обмена. Собранный fum-mcp на синтетическом входе принял корректный снимок, отказал при дубле и явно вернул ошибку при отсутствии live-канала.

Графическое окно не открывалось, W2 без проектного коммита. Локальный mpv предупреждает о более новой целевой macOS; совместимость с минимальной macOS не подтверждена. Результат передан из Журнала W2, охват каналов неизвестен. Это не самостоятельная проверка Летописца.
