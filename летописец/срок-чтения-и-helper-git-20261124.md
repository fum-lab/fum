# Срок чтения входов и тестовый helper Git

По сообщению Управляющего прямые чтения входных файлов перед G в W2 используют тот же срок, что и Git, с проверкой между порциями по 64 КиБ. В тесте истечение срока после первой порции остановило следующие чтения и закрыло FD. Прошли три адресных теста, четыре сквозных случая и девять подслучаев полного маршрута.

Первый запуск выявил старый helper, делавший пять Git-вызовов во временном дереве без буквального `-C` и трёх Git-переменных. Управляющий исправил helper и перевёл тест на явную Git-базу; повтор прошёл, исходный инцидент записан в Журнал W2. Штатный вход закрыт, код без коммита. Это переданные сведения, не самостоятельная проверка Летописца.
