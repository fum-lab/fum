# Локальный FUMA.app и рабочая область

По сообщению Управляющего 26 ноября Xcode Debug arm64 собрал локальный FUMA.app; запущен встроенный `fum-mcp --открыть-рабочую-область`. Помощник создал отдельные каталоги 0700, сам открыл окно без глобальных датчиков; AppKit сообщил `наЭкране=true`, MCP — `workspaceLive=bound`, `codexChat=uncovered`, `deferredQuestions=not_configured`. Проверены чтение, изменение сетки 0→1, обратное чтение, отказ устаревшей команды и повтор без изменения. После EOF помощник exit 0 подтвердил штатный выход дочернего процесса, сохранённый список окон пуст.

Сохранены диагностика `sandbox_extension_issue_file_to_process / Operation not permitted` и предупреждение линковщика о libmpv для более новой macOS. Это локальный пакет; проверка пикселей, очереди и совместимости macOS 14 не выполнялась. Запись в Журнале W2 локальная, адресная свежесть и `diff --check` прошли. Это переданные сведения, не самостоятельная проверка Летописца.
