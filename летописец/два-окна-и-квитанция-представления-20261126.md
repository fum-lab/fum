# Два окна и квитанция представления

По сообщению Управляющего два встроенных fum-mcp из проверенного локального Xcode Debug-пакета открыли отдельные окна. Первому отправлены два синтетических screen_present; для каждого приложение записало квитанцию view_attached с точным UUID и SHA-256, после screen_clear статус unavailable. Второе окно оставалось unavailable, в его области не было экранного файла и квитанции. Оба помощника и окна завершились штатно.

Общее распределённое уведомление macOS могло дойти другим получателям, их охват неизвестен. Квитанция означает подключение представления; пиксели и прочтение человеком не проверялись. Диагностика sandbox extension повторилась, Журнал локальный. Это переданные сведения, не самостоятельная проверка Летописца.
