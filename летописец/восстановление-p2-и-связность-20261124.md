# Восстановление P.2 и связность

По сообщению Управляющего его предыдущая правка закреплённого файла вызвала отказ маршрутизатора P.2. Он перенёс Git-контекст в существующий CLI и восстановил точные байты P.2; маршрутизатор вновь дал 0. В связности `нет` допустимо без ретроактивной ссылки, явно заданные ссылки проверяются по полю; независимая пара с собственным маркером не считается соседом. Четыре теста и адресная реальная проверка трёх запросов дали 0.

Ранняя общая проверка структуры остаётся у неизменяемого P.2 и требует совместимого версионного маршрута. Исторические файлы не менялись, W2 не коммитился. Это переданные сведения, не самостоятельная проверка Летописца.
