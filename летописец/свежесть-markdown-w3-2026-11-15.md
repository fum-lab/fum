# Свежесть Markdown в W3

По сообщению управляющего, в личном рабочем W3 отдельно исправляется свежесть Markdown: отказ или тайм-аут Git status/log не выдаётся за чистое дерево или пустую историю, при частичной записи сообщается число уже изменённых файлов. В отдельных синтетических Git воспроизведены и исправлены искажение имён со стрелкой и пробелами и неправильная история `a[1].md`; кандидат использует status porcelain -z и буквальный pathspec. Воспроизведён запуск настроенного gpg.program через log.showSignature; в кандидате настройка выключена.

По сообщению управляющего, 28 тестов на синтетических материалах прошли; файлы не закоммичены, реальная recency и личная память не проверялись. Наблюдатель дополнительно выявил незакрытую проблему экранирования необычных имён в Markdown-индексе, оптимизатор исследует совместимый формат. Публичная обёртка и штатный проход по-прежнему не готовы. Летописец синтетические материалы и чужую память самостоятельно не проверял.
