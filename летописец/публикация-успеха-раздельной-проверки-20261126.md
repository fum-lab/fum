# Публикация успеха раздельной проверки

По сообщению Управляющего в W2 исправлена публикация успеха раздельной проверки. Нативный стенд воспроизвёл ложный код 0 при записи прежнего управляющего маркера после сверки ветки; после исправления обёртка отказывает под двумя замками, точные байты старого отчёта и active сохранены. Прошли два нативных теста и три теста P.6; сведения внесены в Журнал W2.

Рабочий переход, полный smoke и проектный коммит остаются открытыми. Допустимые каналы не дают полной картины сообщений. Это переданные сведения, не самостоятельная проверка Летописца.
