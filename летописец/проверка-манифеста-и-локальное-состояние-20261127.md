# Проверка манифеста и локальное состояние

По сообщению Управляющего он проверил совмещённый частный P.7 с адресным запуском под двумя замками; штатная обёртка закрыта, W2 не изменён. Путь проверки манифеста с временным Swift-кэшем вернул 2 по неизвестному формату локального неотслеживаемого состояния GitHub CLI внутри дерева. До классификации исходник валидатора читает байты для инвентарного хэширования и сверки; содержимое в вывод не попало.

Новый частный кандидат отказывает при наличии каталога состояния до сборки и чтения входных файлов; этот отказ проверен за 0,101 с. Причина появления файла и автор его создания не установлены, файл не меняли и не удаляли. Это переданные сведения, не самостоятельная проверка Летописца.
