# Передача каталога обёрткой через Witness .9

По сообщению Управляющего отчётная обёртка W2 передаёт рабочий каталог через настоящий Witness .9 в парной адресной проверке; .8 также прошёл. При подмене открытого каталога до публикации активной записи и запуска не было. Прошли девять адресных тестов опор и guard, временный профиль ROOT9 обновлён.

Штатный запуск остаётся закрытым; независимый диспетчер допускает только .6, прекращение старой выдачи допусков не установлено. Код рабочей ветки не коммитился. Это переданные сведения, не самостоятельная проверка Летописца.
