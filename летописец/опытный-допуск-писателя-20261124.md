# Опытный двухфайловый допуск писателя

По сообщению Управляющего W2 имеет исполнимый опытный двухфайловый допуск проверки писателя через Witness .8. Обёртка сверяет обе метки и FD запроса до active и под парой при G; писатель сверяет прежнюю и выбранную опоры с манифестом до Git. Прошли 17 адресных тестов.

Реальные временные случаи дошли до ранних отказов писателя: terminal 2 и Witness 0. При подмене запроса после active попыток G не было, active сохранился, транспорт собрал Witness 125, замки были свободны.

Успешный Git писателя, непрерывное владение на секции Git и штатный вход остаются открытыми задачами. Код и Журнал W2 не закоммичены. Это переданные сведения, не самостоятельная проверка Летописца.
