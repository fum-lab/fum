# Структура, Git-контекст и исторический отказ

По сообщению Управляющего штатный W2 `--list` вывел 25 шагов. Ранняя проверка структуры получает тот же закреплённый Git-контекст, что охват и связность. Прошли шесть адресных тестов. CLI в Git-фикстуре дал 0/0 для обычного и явного чтения, 1/1 для подмены SHA и дубликата.

Реальный W2 дошёл до старого отказа по «Следующий запрос: нет» исторического HEAD-файла. Его побайтное совпадение с HEAD подтверждено; исторический файл не правили. Публичный запуск и составной smoke не выполнялись, W2 не коммитился. Это переданные сведения, не самостоятельная проверка Летописца.
