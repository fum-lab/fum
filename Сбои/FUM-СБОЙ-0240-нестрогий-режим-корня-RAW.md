# Нестрогий режим корня RAW

## Наблюдаемый сбой

RED: существующий корень 0755 принимался маской 0022 вопреки заявленной границе приватного конечного корня. Раскрытия содержимого не наблюдалось: сегменты 0700, файлы 0600.

## Граница повторения

Текущий компонент RAW Codex по Issue №378. Новое проявление при изменении соответствующего адаптера или API возвращает внимание; свой коммит не означает приёмки ROOT или интеграции.

## Механизм и системное устранение

Конечный корень требует ровно 0700. Допустимый родитель проверяется отдельно; чужие права автоматически не меняются.

## Критерии закрытия и результат

Регрессия: `приватныйКореньНеПринимает0755` в [публичных проверках](../proverki/arkhiv-codex/). RED сохранён; GREEN отвергает 0755 и подтверждает неизменность этих прав. Статус ограничен этой проверяемой реализацией в ветке; неизвестные ошибки, 21 ГБ ROOT и общая устойчивость ОС не объявляются проверенными.
