# Пакет диагностики терял права публичных файлов

## Наблюдаемый сбой

Штатный пакет диагностики создал публичные карточки и заменил индекс с режимом 0600. Подготовка коммита отказала: обычная Markdown-разметка требует 0644.

## Граница повторения

Атомарная установка через mkstemp без явного fchmod. Повтор по совпавшим байтам не восстанавливает режим уже созданного файла.

## Проявления

Одно наблюдённое препятствие Prepare; адресные тесты воспроизводят неверный режим новой карточки и потерю прав при обновлении. Старый неуспешный исход сохранён.

## Ожидание и классификация

Устранена в текущем этапе. Регрессии выполняются при изменениях писателя и пакета диагностики; новый отказ по режимам требует повторного разбора этого механизма.

## Механизм и системное устранение

Новые публичные файлы явно получают 0644 до fsync/replace. Существующий режим сохраняется; новые приватные состояние и маркеры остаются 0600. Три собственных файла восстановлены по точным SHA открытых FD, без изменения байтов, inode и mtime.

## Связанные шаги

Исправление выполнено в текущей контрольной точке без отдельного ожидающего шага.

## Критерии закрытия

Новая карточка 0644 при umask 077; сохранение 0600/0644/0755 при обновлении; приватное состояние 0600; восстановление после прерывания.

## Подтверждение устранения

В общем запуске 41 тест хранилища прошёл; один из 16 тестов пакета выявил неадаптированную обёртку нового аргумента. Обёртка исправлена, повтор всех 16 тестов пакета прошёл. Исходные RED и промежуточный отказ сохранены.
