# Пустой override в первом тесте runner допустил запуск установленного helper

## Наблюдаемый сбой

Первый RED runner при пустом override выбрал существовавший установленный helper. Процесс получил пустой stdin; инструментальные команды, GUI и runtime-записи не наблюдались.

## Граница повторения

Нарушена заявленная изоляция одного проверочного запуска. Намеренный RED переносимости сам по себе не является отдельным сбоем; ранний запуск нельзя задним числом объявить синтетическим. Последующие RED №3 и №10 не подтверждают повторного вызова настоящего helper.

## Ожидание и классификация

Проверка переносимости использует только подставной helper и Swift во временной области. Это ошибка изоляции проверки; дополнительно устранён неявный выбор прежней установки в runner.

## Механизм и системное устранение

INSTALLED_HELPER получает только явно переданный FUM_MCP_APP_HELPER. Фикстура задаёт явно отсутствующий helper, подставной Swift и временные каталоги сборки и исполнения; проверяется свежая сборка вместо прежнего бинарника. Явный временный helper проверяется отдельно. Исправление — 9d39f45a344af3d99d8402c8e7631e58e239c6fa; проверенный публичный исходник — 9c39c9b3fde83c4ce11ba101897c1298c68d436d.

## Связанные шаги

Отдельный новый шаг не требуется для устранённой границы; исправление выполнено в FUM-STEP-0176.

## Критерии закрытия

Неявный выбор прежней установки удалён из runner. Исправленная фикстура из чужого cwd получает результат своей свежей подставной сборки; явный подставной helper работает без сборки. Ограниченное доказательство не утверждает отсутствия любых возможных внешних эффектов прежнего запуска.

## Подтверждение устранения

Изолированные RED №3 f16aa2e1-7e07-4ded-a44b-679973222a5d и №10 f05673db-9720-48d2-a748-1a26e4579bbd предшествуют [GREEN №11 dabe685e](https://github.com/fum-lab/fum/blob/6599fe4837ef54efc7f871d2bfe6f8d9d07b4d95/Журнал/2026-09-11_01-45-23_MSK_адаптировать-приложение-FUM-для-монорепозитория/материалы/запуски-проверок/11_dabe685e-12bc-4224-b16a-beb428ee6d78.json). Итоговая передача фиксирует GREEN №35 ab4bcb6d-f37a-4f42-8f37-1687edd6342c, 12 Python-тестов. Отдельный GREEN именно с пустым override не записан: удаление этого fallback подтверждается чтением runner, а GREEN проверяет исправленную изолированную фикстуру.
