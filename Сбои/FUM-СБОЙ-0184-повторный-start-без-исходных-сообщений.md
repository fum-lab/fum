# Повторный start без исходных сообщений

## Наблюдаемый сбой

При C272 дополнительный читающий вызов `подготовить_начало` получил пустой список, извлечённый из descriptor источников вместо оригинальных строк. Вызов завершился кодом 1: «messages JSON must be a non-empty array of non-empty strings». Установка не выполнялась; сохранённый штатный план фасада оставался действительным.

## Граница повторения

Лишнее повторное построение начала уже подготовленного этапа из неполного описания источников. Это не отсутствие пользовательской команды, не угадывание пути0009 и не отказ штатного фасада. Создание нового этапа с действительными исходными сообщениями остаётся отдельной операцией.

## Ожидание и классификация

Дополнительная сверка должна читать сохранённый план и результат подготовки без повторного start и без подмены исходных сообщений пустым массивом. Нарушение находится в частном вызывающем коде; штатная проверка непустого массива отказала корректно.

## Механизм и системное устранение

Частный дополнительный вызов исключён из продолжения; первоначальный план не исправлялся ради обхода отказа. Требуется поддержанный читающий вход0245, который использует готовую подготовку и не реконструирует сообщения из descriptor. Реализация и автоматическое предотвращение пока не доказаны.

## Критерии закрытия

- На отдельной регрессии готовая контрольная точка сверяется по сохранённой подготовке без вызова `подготовить_начало` и без реконструкции массива сообщений; отсутствие необходимой подготовки даёт читающий отказ без start и записей. Возврат к случаю — до следующей дополнительной сверки подготовленного этапа.
