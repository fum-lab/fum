# Неподдержанное значение вида коммита

## Наблюдаемый сбой

Существующий параметр --вид-коммита получил значение `контрольная-точка`, отсутствующее в его enum. CLI завершился кодом 2 ещё до проверки плана. Это ошибка значения, а не неизвестный флаг.

## Граница повторения

Один эпизод вызова команды продолжения с неподдержанным значением перечисления. Неверные основания плана учитываются отдельно в 0102.

## Проявления

### FUM-СБОЙ-0103/ПРОЯВЛЕНИЕ-0001

Нативный вывод 2026-09-11T20:30:20.397Z, chunk `466aa0`, сообщает: `argument --вид-коммита: invalid choice: 'контрольная-точка' (choose from 'контрольный', 'итоговый-этапа')`. Принятая команда checkpoint использует `контрольный`; сама команда и её допустимые значения не менялись.

## Ожидание и классификация

Смысл контрольной точки должен выражаться фактически поддержанным значением CLI. Название режима связности не переносится автоматически в enum другой команды. Парсер правильно остановил неподдержанный ввод.

## Механизм и системное устранение

Подтверждённая ошибка вызова: обозначение режима другой проверки перенесено в значение enum команды продолжения. Ограниченная мера — сверить фактическую справку этой команды, выбрать поддерживаемое значение контрольный и проверить его реальным вызовом. Интерфейс CLI и его парсер не меняются.

## Связанные шаги

Новых STEP нет: ограниченное восстановление конкретного вызова выполнено. Новое проявление после устранения потребует реактивации.

## Критерии закрытия

Допустимое значение контрольный подтверждено справкой действующей команды. Реальный вызов с этим значением и принимаемым планом завершается кодом 0; результат не подменяет допуск остальных работ.

## Подтверждение устранения

Критерий — сверить опубликованный интерфейс команды, передать значение `контрольный` и подтвердить успешный фактический вызов для принимаемого плана. [Успешная адресная запись](../Журнал/2026-09-11_23-32-06_MSK_исправить-основания-плана-продолжения/материалы/запуски-проверок/7_279404b5-de84-48b5-9a9b-83d5dbd7575e.json), сохранённая в 0c1a992a5f9adb197cfe0c87031cab34426e640f, и последующий read-only результат `961492` с кодом 0 выполняют этот критерий. Исправление enum-значения и устранение ошибки данных плана подтверждены отдельно; будущая невозможность ошибочного ввода не обещается.
