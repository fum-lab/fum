# Ручной приватный вход ссылается на журнал внутри Git

## Наблюдаемый сбой

Оба писателя третьего живого поколения вручную передали исходный native JSONL в поле источника модели. На этой машине исходник находится внутри Git-каталога Codex. Создатель правильно отказал до подготовки коммита: «Приватный путь дочерней передачи находится в Git». Коммитов и push детей нет.

## Граница повторения

Подготовка конечного дочернего входа v3, когда raw JSONL находится под Git-предком, а адрес заполняет LLM. Права на чтение исходника не разрешают включать его в приватный контракт создателя напрямую.

## Проявления

### FUM-СБОЙ-0163/ПРОЯВЛЕНИЕ-0001

Исполнитель `01a0d438-f8b2-7131-8ba3-225959f37a4d`: отказ подготовки за 1,942688083 с; пять рабочих файлов сохранены отдельно без stage-0.

### FUM-СБОЙ-0163/ПРОЯВЛЕНИЕ-0002

Исполнитель `01a0d43c-70c5-7622-8791-e33c4cb003fd`: отказ подготовки за 1,916300959 с; пять рабочих файлов сохранены отдельно без stage-0. Повторение одного механизма требует автоматической подготовки входа.

## Ожидание и классификация

Нативное происхождение сохраняется, приватные адреса вычисляются вне Git автоматически. Это пробел подготовительного API и ошибка ручного заполнения; валидатор не ослабляется.

## Механизм и системное устранение

Обёртка сохраняет точный неизменяемый снимок и собирает прежний v3 из проверенного назначения. До новых действий сверяются живой источник, ранее принятый хвост, управляющие транспорты и модель. Квитанция уже созданного коммита восстанавливается штатным путём; послеоперационное наблюдение не скрывает состоявшийся эффект.

Открытая холодная регрессия создаёт один коммит через автоматический вход и восстанавливает его после позднего указания; отрицательные проверки защищают native источник. Следующий реальный пилот из новой C проходит эту границу. Фикстура ещё не закрывает реальную приёмку.
