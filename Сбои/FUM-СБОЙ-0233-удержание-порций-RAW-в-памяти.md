# Удержание порций RAW в памяти

## Наблюдаемый сбой

Первый настоящий профиль 264 МиБ дал RED по RSS: приём 287522816 байт, повтор 305627136 байт при пределе 200 МиБ. Побайтное восстановление уже совпадало.

## Граница повторения

Текущий компонент RAW Codex по Issue №378. Новое проявление при изменении соответствующего адаптера или API возвращает внимание; свой коммит не означает приёмки ROOT или интеграции.

## Механизм и системное устранение

FileHandle.read(upToCount:) удерживал возвращённые NSData в autorelease-контуре. Прямой ограниченный native read заменил источник; память не накапливается по всему файлу.

## Критерии закрытия и результат

Регрессия: `настоящийПереход256МиБИНовыйПроцессБезИсточника` в [публичных проверках](../proverki/arkhiv-codex/). RED профиль-до.json; GREEN [профиль ранней сверки](../Журнал/2026-10-26_00-11-30_MSK_сохранить-многосегментный-raw-codex/материалы/профиль-ранняя-сверка.json): RSS приём 20824064, повтор 37748736, восстановление 18841600 байт. Статус ограничен этой проверяемой реализацией в ветке; неизвестные ошибки, 21 ГБ ROOT и общая устойчивость ОС не объявляются проверенными.
