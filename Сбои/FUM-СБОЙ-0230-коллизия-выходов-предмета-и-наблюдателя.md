# Предметный результат пересекается с метаданными наблюдателя

## Наблюдаемый сбой

Предметный JSON и метаданные наблюдателя получили одно имя. В ROOT C73 после отказа строгого читателя файл предполагаемого входа заняли метаданные внешнего наблюдателя с кодом 1; следующий helper ожидал отсутствующую цель. В C74 предметный публикационный API сохранил результат с кодом 0, после чего внешняя обвязка получила FileExistsError при O_EXCL записи одноимённого JSON. Ни один исход не является отказом Creator.

## Граница повторения

Возвращать внимание немедленно при пересечении выходных ролей, ошибке внешней квитанции после producer или подготовке нового запуска приватной обвязки. До следующего такого запуска нужен полный адресный план всех предметных и служебных выходов. Условие прежнего наблюдения 6 октября уже выполнено.

## Проявления

Учитываются два новых раздельно сохранённых проявления: ROOT C73 и C74. Метаданные ROOT C73 имеют SHA25620b26959a0b8b68d9a6d6997ae490a86fcd0ff95905696d7412bb8f8943f256e. Сводка C74 — SHA2562dd893de15e6e1ecb79a07d645ad191c3fe800dfb934691d7f23b5da1aad2458. В C74 отдельные наблюдённые код дочернего процесса и длительность неизвестны; успешный API не заменяет их. Исторический C296 сохранён источником ниже и не включён в число двух новых проявлений.

## Ожидание и классификация

Активный дефект повторяемой обвязки и неполного плана выходов. Имена текущих сценариев разведены, первичные файлы сохранены. Это устраняет препятствие этих двух запусков, но не доказывает доставку общего предотвращения коллизий.

## Механизм и системное устранение

Проверять до producer непересечение всех предметных целей и prefix.stdout/prefix.stderr/prefix.process/prefix.json, наличие прежних файлов, роли и режимы. Сохранить допустимый argv и запрет нового запуска при неизвестном исходе. Общая проверка должна работать при Python -O, без отключаемых assert. Переиспользовать имеющийся канонический захват. Внутренний результат API и внешний исход хранить раздельно; успешную работу не повторять лишь ради метаданных.

## Связанные шаги

[FUM-STEP-0174](../Планирование/карточки-шагов/🟡-FUM-STEP-0174-описывать-применение-автоматизаций-без-чтения-кода.md) — конкретный ближайший срез общей предпроверки. СБОЙ-0229 сохраняет прежнее ограниченное закрытие: отсутствие режима запуска и structuredClone не подменяются этой новой причиной.

## Критерии закрытия

Общий preflight реально подключён к используемой обвязке. Каждый вариант пересечения и существующей цели даёт ранний отказ без запуска; допустимый план исполняет producer ровно один раз. Проверены полный захват потоков, PID и фактических кодов, сохранение прежнего API0/внешнего отказа, отдельные интервалы и восстановление неизвестного исхода. Два частных исправленных имени и сама карточка не являются выполнением.
