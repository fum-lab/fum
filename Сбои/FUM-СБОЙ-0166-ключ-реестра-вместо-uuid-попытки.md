# Ключ реестра вместо UUID попытки

## Наблюдаемый сбой

### FUM-СБОЙ-0166/ПРОЯВЛЕНИЕ-0001

Во входе завершения корень записал ключ записи из плана в поле «попытка», которому нужен UUID самой попытки. Предпросмотр отказал кодом 2 с «Чужой сохранённый писатель» до записи терминала. В новом входе UUID прочитан из той же записи реестра, после чего предпросмотр и запись прошли.

## Системное устранение и критерии закрытия

Собрать типизированный вход завершения из проверенного реестра без ручного выбора между ключом и UUID; регрессия должна отклонять ключ до тяжёлого чтения native. Причина — смешение двух идентификаторов в частной оркестрации; контракт проверки не ослабляется.
