# Неоднозначный корневой swift run

## Наблюдаемый сбой

Добавление второго executable дало фактический отказ SwiftPM без имени продукта: multiple executable products available: fuma, arkhiv-codex. Хранилище было защищено внешним запретом записи.

## Граница повторения

Текущий компонент RAW Codex по Issue №378. Новое проявление при изменении соответствующего адаптера или API возвращает внимание; свой коммит не означает приёмки ROOT или интеграции.

## Механизм и системное устранение

Сохранён единственный executable fuma; RAW принимает подкоманда архив-codex. Барьер читает реальные продукты SwiftPM; прежние пустой вход и помощь покрыты отдельно.

## Критерии закрытия и результат

Регрессия: `пакетИмеетОдинИсполняемыйПродукт; прежнийПустойВходИПомощь` в [публичных проверках](../proverki/arkhiv-codex/). До исправления код 1 SwiftPM; после исправления выбран прежний startup с ожидаемым кодом 2 из-за внешнего запрета записи; автоматические проверки GREEN. Статус ограничен этой проверяемой реализацией в ветке; неизвестные ошибки, 21 ГБ ROOT и общая устойчивость ОС не объявляются проверенными.
