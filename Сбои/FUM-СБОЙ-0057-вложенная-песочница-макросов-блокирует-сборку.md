# Вложенная песочница макросов SwiftUI блокировала приёмочную Xcode-сборку

## Наблюдаемый сбой

Первый Xcode build публичного чистого клона под внешней песочницей завершился кодом 65. swift-plugin-server получил sandbox_apply: Operation not permitted; отсутствие реализации макроса State было следствием.

## Граница повторения

Препятствие подтверждено в приёмочной среде macOS 27 arm64, Xcode 27 beta, Swift 6.4. Исправление платформы, подписи, всех конфигураций песочниц и других сред не подтверждается. Это другая граница, чем ошибки codesign.

## Ожидание и классификация

Макросы должны исполняться при сохранении внешнего запрета чтения прежних каталогов. Наблюдена несовместимость вложенных песочниц в проверочной среде; первый отказ не был намеренным TDD RED.

## Механизм и системное устранение

Локальная справка frontend подтвердила -disable-sandbox. Параметр OTHER_SWIFT_FLAGS="-Xfrontend -disable-sandbox" передан только приёмочному вызову; повтор использовал новый DerivedData и сохранил внешнюю песочницу. Исходники, проект и системные настройки не изменялись; условие воспроизведения записано в руководстве.

## Связанные шаги

Отдельный новый шаг для принятой среды не требуется: совместимый вызов проверен и описан в FUM-STEP-0176.

## Критерии закрытия

Тот же опубликованный исходный коммит в новом DerivedData даёт BUILD SUCCEEDED и код 0 при сохранённом запрете чтения прежних каталогов. Исходный код 65 и условие совместимости сохраняются отдельно.
