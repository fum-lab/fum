# Повторное индексирование уже удалённых старых путей

## Наблюдаемый сбой

При подготовке индекса этапа 07:44 перечень из diff относительно HEAD содержал прежние имена карточек 0202 и 0203, уже удалённые из индекса штатным переименованием. Передача всех таких имён в `git add -A` завершилась отказом на первом прежнем пути 0202.

## Граница повторения

В перечень для повторного индексирования попадает прежний путь, отсутствующий и на диске, и среди текущих отслеживаемых путей индекса, но уже представленный индексированным удалением относительно HEAD. Прежние имена были действительными, поэтому это не вымышленный путь 0009. Область запроса и удаления проекции 0035 здесь не являются причиной.

## Ожидание и классификация

Это недоработка подготовки конкретного списка индексирования. Список должен выражать действительные допустимые цели и сохранять уже подготовленные удаления. Отказ Git корректен; по нему не выводится дефект Git, переименования или карточек.

## Механизм и системное устранение

Исходный список смешивал различие с HEAD и текущие цели индекса. Проверяемое ограниченное восстановление выбирает путь, если он существует либо ещё отслеживается в индексе; остальные подтверждённые уже индексированные удаления сохраняются без повторной передачи. В данном снимке исключены ровно прежние 0202/0203. Общая автоматизация всех будущих команд staging не вводилась.

## Связанные шаги

Отдельный STEP не требуется для выполненного ограниченного восстановления этого списка. Новое требование универсально предотвращать ручные ошибки здесь не формулируется; такая более широкая мера не объявляется завершённой.

## Критерии закрытия

Восстановленный список данного снимка содержит 22 текущих пути и исключает ровно два уже индексированных удаления 0202/0203. Их эффект остаётся в индексе. Подготовленный индекс проходит проверку пробельных ошибок, рабочее дерево не содержит неиндексированных изменений, и сохранён его точный diff. Одного успешного `git add` для этого критерия недостаточно.

## Подтверждение устранения

[Первичное свидетельство](../Журнал/2026-09-11_09-36-55_MSK_сохранить-оставшуюся-диагностику-приёма/отчёт.md) сохраняет явную проверку ровно двух исключений, успешное индексирование 22 путей и результат `already_staged_deletions` с прежними 0202/0203. Затем успешная цепочка `git diff --cached --check` и `git diff --quiet` предшествует вычислению SHA-256 индексированного diff `49cb1c225eb9dab4b96e00917aa2a3362b75434731b1f80adce07f9795b696e3`. [Отчёт этапа](../Журнал/2026-09-11_07-44-52_MSK_принять-математику-и-рабочий-контекст/отчёт.md) фиксирует способ восстановления и отсутствие потери файлов. Статус относится к этому проверенному восстановлению индекса, а не к отсутствию будущих аналогичных ошибок.
