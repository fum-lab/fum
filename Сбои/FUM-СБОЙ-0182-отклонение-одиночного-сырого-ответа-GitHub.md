# Отклонение одиночного сырого ответа GitHub

## Наблюдаемый сбой

Публикационная проверка этапа J250 отклонила неизменённый исходный JSON-ответ API о PR №209. Архив обсуждений штатно принимает один объект Issue или PR, но сканер распознавал только массив. Шесть открытых URI-шаблонов исходной записи остались обычными находками вместо проверяемых внешних данных; это заблокировало допуск этапа.

## Граница повторения

Карточка относится к отказу распознавания одного исходного объекта Issue или PR при доказанных пути, SHA-256 и принадлежности репозиторию. Она не покрывает произвольные JSON-объекты, чужие обсуждения, отсутствующее тело, подменённые байты, машинные пути соседних документов либо неполный охват API. Отказы искусственных отрицательных фикстур являются ожидаемыми проверками и не учитываются как новые проявления.

## Проявления

1. `FUM-СБОЙ-0182/ПРОЯВЛЕНИЕ-0001` — [проверка J250 №3](../Журнал/2026-10-05_07-51-15_MSK_принять-исправление-выбора-модели/материалы/запуски-проверок/3_11e31b93-f574-47db-9d32-375f1e7ce4d8.json), код 1. [Исходные байты PR №209](../Issues/fum-lab/fum/данные/2f583358f92afba6645ac9493062e16d1f01a71c66e025602e94ab8c625961fe.json) сохранены без изменения; SHA-256 совпадает с именем. Воздействие: публикационный допуск потребовал исправления сканера. Восстановление выполнено изменением распознавания формы объекта с сохранением проверок происхождения; первоначальный отказ остаётся в истории. Подтверждено одно реальное проявление.

2. `FUM-СБОЙ-0182/ПРОЯВЛЕНИЕ-0002` — 26 октября исходный ответ REST `pulls/379` не распознан как обсуждение: у объекта PR нет поля `pull_request`, по которому текущий reader отличает `html_url` [PR379](https://github.com/fum-lab/fum/pull/379) от Issue. Два параметра ref внутри публичных URI-шаблонов `head.repo.archive_url` и `base.repo.archive_url` стали одной находкой `error.posix-absolute`. [Точные исходные байты](../Issues/fum-lab/fum/данные/e75e4317b01903b3cced048d9e8812f9737d1bf0e906c07f7efdcb0b02de126f.json) сохранены без изменения. [Отчёт ROOT](../Журнал/2026-10-26_03-08-32_MSK_сохранить-приём-путей-и-границу-raw/отчёт.md) сохраняет первоначальный код1 и предел восстановления. Штатный updater добавил только конечное `allow.nonpath-syntax` для этой строки/пути с автоматически выведенными SHA и числом2; её изменение закрывает fence. Это проверяемое ограничение экземпляра, а не исправление общего распознавания API. Карточка возвращена в активное состояние; новый Python не вводится, продолжение приёма GitHub на Swift/FUMA должно учесть обе формы PR.

## Ожидание и классификация

Штатно принимаемый архивом объект обсуждения должен проходить ту же проверку внешних данных, что элемент массива. Это подтверждённая недоработка сканера на границе двух существующих инструментов; причина не приписывается GitHub или пользовательским данным.

## Механизм и системное устранение

В `_сырое_обсуждение` допустимый одиночный словарь помещается в список перед общей проверкой записей. Проверки точного имени и SHA-256 файла, репозитория, идентичности, номера, тела и запрещённых байтов сохраняются. Дополнены открытые регрессии; отдельные конечные декларации их URI-шаблонов не разрешают исключать соседние документы. Исходный ответ API не нормализован и не переписан.

Повторный отказ на той же допустимой форме либо падение соответствующей регрессии возвращает эту карточку в состояние `активна` и актуализирует основной шаг. Изменение формата архиватора или сканера является основанием заново проверить применимость критерия. Отдельной фоновой проверки вне активного хода этим документом не заявлено.

## Связанные шаги

Шаг остаётся активным: исправление этой границы не закрывает всё направление и ненаблюдённые разделы GitHub.

## Критерии закрытия

- Один исходный объект Issue, PR или комментария принимается при доказанном происхождении; соответствующие RED/GREEN сохранены.
- Чужой репозиторий, неверные байты или путь, некорректные идентичность и номер, отсутствующее тело, неполный массив, скаляр и NUL не обходят проверку.
- Публикационный допуск настоящего исходного PR №209 проходит без изменения его байтов; исправление и регрессии доставлены проверенным коммитом.
- Сохранён воспроизводимый профиль того же открытого входа; отсутствие доказанного ускорения не заменяется утверждением о нём.

Окончательная публикационная проверка №17 имеет код 0. Исходники и регрессии включены в опубликованный merge-коммит [64fc76b91ff4e15d68021c9083f43d4236a94899](https://github.com/fum-lab/fum/commit/64fc76b91ff4e15d68021c9083f43d4236a94899). Устранена только указанная форма отказа. Полная публикационная чистота накопленного репозитория и автономность всех разделов GitHub этим результатом не доказаны.
