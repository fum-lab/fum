# Предпросмотр завершения с незакреплённым кодом

## Наблюдаемый сбой

### FUM-СБОЙ-0167/ПРОЯВЛЕНИЕ-0001

Корень вызвал предпросмотр завершения с координаторским D до коммита изменённых инструментов. Проверка exact Git diff отказала кодом 2 «Не удалось прочитать Git: diff» до чтения детей и записи терминала. После ff008522 подготовлен отдельный новый вход с этим точным D.

## Системное устранение и критерии закрытия

Перед сборкой входа алгоритмически устанавливать совпадение исполняемого контура с D; регрессия должна останавливать подготовку при изменённых инструментах. Состояние Журнала и регистрация терминала не заменяют закреплённой версии исполняемого кода.
