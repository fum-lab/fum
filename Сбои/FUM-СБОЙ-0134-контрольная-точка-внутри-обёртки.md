# Проверка контрольной точки внутри активной обёртки

## Наблюдаемый сбой

Частный вызов `check-session-coherence.py --контрольная-точка` выполнен внутри отчётной обёртки. Сам режим контрольной точки запрещает активные записи, поэтому корректно отклонил запись, созданную обёрткой этого вызова. Проверяющие инструменты, код поставки и снимки не повреждены.

## Граница повторения

Несогласованный выбор режима проверки с жизненным циклом её отчётной обёртки. Это не осиротевшая запись 0056, изменение входа 0043 или пропуск проверки индекса 0044. Обычная адресная проверка внутри обёртки и отдельная заключительная проверка контрольной точки имеют разные условия.

## Ожидание и классификация

Внутри активной обёртки используется обычный режим связности. `--контрольная-точка` применяется к отдельной заключительной проверке разрешённого checkpoint после терминализации записей и обновления предпросмотра. Номер выделен координатором по событию `context-checkpoint-coherence-inside-wrapper-01a0930d-run24`.

## Механизм и системное устранение

Из частного вызова убран неподходящий флаг. Повтор прошёл на том же каноническом снимке; библиотека не изменялась. Это восстановление текущего вызова. Нужен проверенный способ выбора двух режимов по состоянию отчёта до запуска длительной связности, без ослабления запрета активной записи для контрольной точки.
