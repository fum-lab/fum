# Временная метка передана вместо словесной метки этапа

## Наблюдаемый сбой

При создании этапа в аргумент `--label` инструмента структуры папок передана временная метка MSK. Инструмент ожидает словесную метку из имени папки и отклонил вызов до записи.

## Граница повторения

Ошибка применения поля создания этапа: одноимённое поле результата генератора времени имеет другой смысл. Штатные генератор времени и валидатор структуры исправны. Карточка0065 ограничена аргументами публикационного сканера и не объединяется с этим проявлением.

## Проявления

### FUM-СБОЙ-0132/ПРОЯВЛЕНИЕ-0001

Вызов для этапа2026-09-15_01-49-18_MSK завершился кодом1 с сообщением `start session stem label does not match --label`. [Наблюдение](../Журнал/2026-09-15_01-49-18_MSK_сохранить-границы-приёмки-и-продолжения-контекста/материалы/наблюдения-подготовки.json) сохраняет неверный смысл поля и точное исправление. Проверка согласованности выполняется в начале `start_session`, до подготовки файлов.

## Ожидание и классификация

Папка создаётся штатной автоматизацией с согласованными prefix, словесной меткой и каноническим заголовком. Это ошибка вызывающего; поведение API не объявляется дефектным. Номер выделен по событию `root-start-label-time-instead-of-slug-01a07d3d-014918`.

## Механизм и системное устранение

Для ограниченного восстановления `--label` взят из словесного окончания того же stem; временной prefix сохранён. Обёртка и штатный валидатор не изменялись. Новый универсальный конструктор команд этим не реализован.

## Связанные шаги

Ограниченное восстановление завершено в [текущем этапе](../Журнал/2026-09-15_01-49-18_MSK_сохранить-границы-приёмки-и-продолжения-контекста/запрос.md); отдельный незавершённый шаг по нему не требуется. Готовность автоматической композиции всех подобных интерфейсов не заявляется.

## Критерии закрытия

Повтор с согласованным словесным label и тем же временным prefix успешно создаёт ровно заданную папку без замены существующих документов. Штатный код сохраняется. Критерий относится к этому восстановлению, не к отсутствию будущих ошибок применения.

## Подтверждение устранения

Повтор вернул код0, `mode=start`, `idempotent=false` и точное имя текущего этапа. Первый отказ предшествовал созданию.
