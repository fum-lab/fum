# Индекс Data-среза при replay

## Наблюдаемый сбой

Статическая трасса выявила subdata с индексом от нуля для допустимого Data-среза с ненулевым startIndex; это могло завершить процесс trap. Старый trap отдельно не исполнялся.

## Граница повторения

Текущий компонент RAW Codex по Issue №378. Новое проявление при изменении соответствующего адаптера или API возвращает внимание; свой коммит не означает приёмки ROOT или интеграции.

## Механизм и системное устранение

Диапазон повторяемой порции смещается от данные.startIndex. Публичный повтор проверяется также срезом с начальным индексом 2.

## Критерии закрытия и результат

Регрессия: `порцииКодировкиХвостПустотаИПовтор` в [публичных проверках](../proverki/arkhiv-codex/). GREEN проверяет ненулевой startIndex, точный повтор и неизменность сохранённого курсора. Первичное свидетельство статическое; самостоятельный RED старой версии отсутствует. Статус ограничен этой проверяемой реализацией в ветке; неизвестные ошибки, 21 ГБ ROOT и общая устойчивость ОС не объявляются проверенными.
