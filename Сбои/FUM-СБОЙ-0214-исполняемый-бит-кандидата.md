# Проверка кандидата принимала неподходящий исполняемый бит

## Наблюдаемый сбой

При core.filemode=false файл режима 0641 принимался вместо индексного 100755: проверялся любой x-бит.

## Граница повторения

Вернуться при изменении проверки режимов Git или повторном расхождении индексного и действительного исполняемого режима.

## Проявления

Наблюдение ревью или реального вызова сохранено; адресный RED воспроизвёл дефект.

## Ожидание и классификация

Устранена в этом этапе. Связанные регрессии запускаются при изменениях соответствующего механизма.

## Механизм и системное устранение

Сверка использует stat.S_IXUSR. Кандидат без пользовательского исполняемого бита отказывает до запуска команды и записи результата.

## Связанные шаги

Исправление завершено в текущей контрольной точке, отдельный ожидающий шаг не нужен.

## Критерии закрытия

Исходный RED сохранён; исправленный код проходит адресную регрессию и независимый обзор.
