# Отказ подключения переименованного Git-форка

## Наблюдаемый сбой

Штатный add отклонил согласованное зеркало fum-lab/TDLib с upstream tdlib/td до клонирования: «имена репозиториев форка и upstream должны совпадать». GitHub API подтвердил публичный форк с parent tdlib/td; равенство имён не является условием родства.

## Граница повторения

Учитывается ложный отказ из-за различия имён проверенной явной пары URL. Тайм-аут сети, чужой владелец, недостижимый OID и подмена remote имеют другие механизмы.

## Проявления

- `FUM-СБОЙ-0087/ПРОЯВЛЕНИЕ-0001`: первый add в [этапе реализации](../Журнал/2026-09-11_20-22-21_MSK_реализовать-клиент-Telegram-TDLib/отчёт.md) вернул код 1. Исходный OID TDLib d1085f9cebc5a62379991ae1652673954f229c1f. Подключение не произошло. Последующий автономный RED воспроизвёл тот же отказ на локальных Git-репозиториях; это проверка одного проявления, а не новый случай.

## Ожидание и классификация

Подтверждённая недоработка: [поручение](../Журнал/2026-09-11_20-22-21_MSK_реализовать-клиент-Telegram-TDLib/запрос.md) прямо требует принять существующий переименованный форк. Правила внешних зависимостей задают точные URL, владельца и опубликованный OID, но не равенство имён.

## Механизм и системное устранение

Причина установлена в validate_repository_topology: сравнение basename отвергало переименованные форки. Удалено только это сравнение; сохранены проверки владельца FUM, разных GitHub-владельцев, HTTPS, точных URL/refspec, достижимости, gitlink, чистоты и путей. Родство по GitHub по-прежнему проверяется отдельно. Для завершения нужны проверенные add/check, свежий clone/init и адресные отрицательные сценарии.

## Связанные шаги

- [FUM-STEP-0222](../Планирование/карточки-шагов/🟡-FUM-STEP-0222-реализовать-Swift-клиент-TDLib-и-синтетический-контур-каналов-FUM.md) — устранение препятствия подключения TDLib; основание `FUM-СБОЙ-0087/ПРОЯВЛЕНИЕ-0001`. Общий объём Swift-клиента этим исправлением не завершён.

## Критерии закрытия

- Переименованный форк проходит add/check и fresh clone/init на точном опубликованном OID.
- Иной владелец, неверный URL и недостижимая ревизия по-прежнему отклоняются.
- Профиль ограниченной доработки и решение об оптимизации сохранены, реальные TDLib gitlink и upstream подтверждены отдельно.
