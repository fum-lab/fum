# Карточки сбоев FUM

Этот каталог хранит канонические [карточки сбоев](../Глоссарий/карточка-сбоя.md), замеченных во время работы над задачами FUM. Карточки не подменяют первичные записи в `Журнал/`: они собирают проявления одного механизма из разных сессий, сохраняют границу повторения и порождают отдельные атомарные шаги исследования и устранения.

## Правила ведения

- Идентификатор `FUM-СБОЙ-NNNN` назначается один раз, не выводится из имени файла и после снятия или поглощения не переиспользуется.
- Имя файла имеет вид `FUM-СБОЙ-NNNN-<краткое-описание>.md` и не кодирует изменяемый статус, поэтому обычное изменение жизненного состояния не требует переименования.
- Новое проявление добавляется в существующую карточку только при общей мере предотвращения и общей регрессионной границе. Одинаковый симптом без такой связи хранится отдельно.
- Ряд проявлений является источником первого наблюдения, последнего наблюдения и частоты. Поглощение сохраняет локальные номера, а каноническая карточка включает ссылки на все проявления транзитивно поглощённых карточек; агрегаты считаются по этому объединению без дубликатов и циклов.
- Второе подтверждённое проявление считается повтором и обязательно порождает новый либо актуализирует существующий шаг. Точный локальный номер записывается как основание связи в карточке сбоя и в источниках карточки шага; произвольная метка регулярности или неизменённая общая ссылка не заменяет доказательства.
- Активная недоработка, не устранённая с доказательством в той же сессии, имеет двустороннюю ссылку хотя бы на одну актуальную карточку шага. Неясный механизм может породить исследовательский шаг.
- Карточка сбоя не участвует в прямом веточном выборе и не предоставляет полномочий на действие. Исполняются только отдельные карточки шагов после их обычных проверок готовности.
- Карточки со статусами `устранена`, `поглощена` и `снята` остаются в индексе. Завершение связанного шага не меняет статус автоматически; повтор после устранения повторно активирует прежнюю карточку.
- Сырые логи, секреты и машинно-локальные пути в карточку не копируются. Она ссылается на публикационно допустимое доказательство и кратко фиксирует наблюдаемый эффект.

| ----------- | -------------------------------------------------------------------------------------------- |
| `активна`   | Наблюдаемое проявление и актуальный путь исследования либо системного устранения.            |
| `устранена` | Устойчивая мера, выполненные необходимые шаги и проверка против критериев закрытия карточки. |
| `поглощена` | Общий механизм, каноническая карточка и включение всех проявлений под исходными номерами.    |
| `снята`     | Доказательство ошибочности наблюдения либо формальной неприменимости прежнего ожидания.      |
