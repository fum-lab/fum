# Перенабор приватного пути вывода

## Наблюдаемый сбой

Shell отказал при создании нового файла вывода вне checkout: в уже закреплённом UUID каталога d U+0064 заменена на д U+0434. Подготовитель не запускался.

## Граница повторения

Новый приватный адрес вручную повторён вместо получения каталога из проверенного входа. Внешняя файловая система и новый объект исключены из границы 0009; объединение не доказано.

## Проявления

### FUM-СБОЙ-0169/ПРОЯВЛЕНИЕ-0001

Источник — инструментальный ответ `2c9eac` корневой задачи, сохранённый в [наблюдении](../Журнал/2026-09-28_08-08-30_MSK_применить-закрытие-остановленных-задач-конвейера/материалы/наблюдения-путей.json). Повтор с subprocess argv и каталогом из JSON успешен. Это восстановление, а не системное устранение.

## Ожидание и классификация

Это ошибка корневого диагностического исполнения, не отказ исправленного кода закрытия. Скрытое состояние модели не выводится.

## Механизм и системное устранение

Приватная оркестрация получает пути вывода только из проверенного входа, передаёт их без реконструкции и закрыто отклоняет подмену похожей буквы на регрессионной фикстуре. Пока сохранены постановка и отдельное восстановление.
