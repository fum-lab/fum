# Неклассифицированные указатели и фикстура пути

## Наблюдаемый сбой

Первый стандартный прогон остановился на шаге 6 проверки машинно-локальных путей. Восемь строк двух JSON Pointer и одна строка открытой абсолютной фикстуры не имели точных деклараций действующей политики. Пользовательских путей в этих строках нет.

## Граница повторения

Подготовка нового содержимого пропускает типизированную классификацию строк, похожих на машинно-локальные пути. Два проявления разделены по роли: определение адресов полей JSON и обезличенная тестовая фикстура. Это не раскрытие приватного адреса и не основание ослабить общий сканер.

## Проявления

### FUM-СБОЙ-0138/ПРОЯВЛЕНИЕ-0001

[Отказ 17](../Журнал/2026-09-15_06-33-09_MSK_вынести-повторяемые-пояснения-ответа/материалы/запуски-проверок/17_5a8c413a-01b9-4bd6-8350-e55f85ef8183.json) содержит восемь строк с двумя точными JSON Pointer в кодеке, определении и Node-тесте. [Диагностика](../Журнал/2026-09-15_06-33-09_MSK_вынести-повторяемые-пояснения-ответа/материалы/диагностика-путей.json) сохраняет адреса строк, категории и хэш исходного журнала. Действующая политика уже использует `allow.path-validation-definition` для JSON Pointer. Штатный updater добавил точные декларации определений; тестовые строки классифицированы `allow.test-fixture`.

### FUM-СБОЙ-0138/ПРОЯВЛЕНИЕ-0002

Тот же отказ 17 содержит одну обезличенную абсолютную строку Python-фикстуры, используемую для проверки обратимости и бюджета. Она получила отдельную `allow.test-fixture` с собственным хэшем строки и содержательной причиной. Первоначальная общая причина ошибочно называла её Pointer; до проверки она заменена штатным v2-retirement и новой точной декларацией. Данные пользователя не использованы.

### FUM-СБОЙ-0138/ПРОЯВЛЕНИЕ-0003

[Повторный отказ 20](../Журнал/2026-09-15_06-33-09_MSK_вынести-повторяемые-пояснения-ответа/материалы/запуски-проверок/20_9ad33ebd-3291-4dd6-a1bc-40dff724adca.json) за 385,823750417 с выявил одну новую строку в JSON-происхождении: поздняя команда координатора продублировала обезличенный пример после адресной проверки 18. Все девять ранее классифицированных строк прошли. Полный текст команды остаётся в разделе `Текст запроса`; JSON хранит координаты исходной записи и хэши записи и точного текста, без дублирования. Это новый хвост входа после раннего сканера, не изменение измеренного кода. Прежнее ограниченное восстановление 18 не покрывало позднюю запись.

## Ожидание и классификация

Новые семантически допустимые определения и открытые фикстуры должны иметь точные типизированные декларации до дорогой приёмки. Защитный отказ соответствует действующей политике; недоработка — пропуск подготовки её конечного входа. Номер 0138 зарезервирован координатором 01a07d3d-d376-7ad2-aafc-67e4c25a67eb после сверки обеих рабочих областей.

## Механизм и системное устранение

Добавлены девять деклараций штатным updater с точными путём, хэшем строки, числом совпадений и категорией. Неизвестные соседние строки остаются нарушениями, изменение закреплённой строки требует новой сверки. Код сканера и семь исходников итогового измерения не менялись. [Адресный повтор 18](../Журнал/2026-09-15_06-33-09_MSK_вынести-повторяемые-пояснения-ответа/материалы/запуски-проверок/18_791cca5d-4e04-466f-ac45-16f2c89a4f38.json) завершился кодом 0; повторный профиль не нужен при неизменных измеренных байтах.

## Связанные шаги

- [FUM-STEP-0165](../Планирование/карточки-шагов/🟡-FUM-STEP-0165-собирать-рабочий-контекст-задачи.md) — основания FUM-СБОЙ-0138/ПРОЯВЛЕНИЕ-0001 и FUM-СБОЙ-0138/ПРОЯВЛЕНИЕ-0002. Ранняя проверка новых Pointer и фикстур включена в приёмку ограниченной передачи.

Наблюдение 0003 возвращает карточку в активное состояние. Требуется повторяемое подтверждение отсутствия позднего содержательного хвоста между заключительным сканированием и приёмкой. Разовая очистка JSON и новый успешный сканер восстанавливают текущий вход, но не доказывают общую меру.

## Критерии закрытия

Все девять наблюдённых строк классифицированы по фактической роли точной политикой, без общей льготы каталогу или формату. Полный адресный сканер возвращает 0, исходные данные и исходники измерения сохранены, прежний отказ остаётся доступен.

## Историческое подтверждение ограниченного восстановления

Адресный повтор 18 прошёл; JSON Pointer и фикстура различены, декларации имеют девять отдельных точных селекторов. Подтверждено ограниченное восстановление этих входов. Общая поддержка произвольного JSON Pointer и полная приёмка всего этапа этой карточкой не заявляются.
