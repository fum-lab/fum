# Компиляция численных автоматизаций в тензорный граф

Этот Swift-прототип проверяет узкий путь от декларативного численного подмножества [языка автоматизаций FUM](../../Глоссарий/язык-автоматизаций-FUM.md) до типизированного SSA-графа и детерминированного текстового кандидата StableHLO/MLIR. Встроенная функция `mul_add` принимает три тензора `tensor<4xf32>`, вычисляет `left * right + bias` операциями `multiply` и `add`, после чего два независимых CPU-пути сравнивают результаты.

Результат не является подтверждённым StableHLO-модулем и не исполняется на ускорителе. Проверка наблюдает наличие `stablehlo-opt` в `PATH`, но никогда не выдаёт его наличие за выполненную валидацию. Target provider не настроен, target-исполнение имеет статус `not_performed`, а выбранным исполнительным путём остаётся версионированный эталонный CPU fallback. Прототип проверяет контракт и наблюдаемую границу отказа, но не заявляет ускорение.

## Проверяемый контур

```mermaid
flowchart LR
    source["Канонический JSON-DSL mul_add"] --> compiler["Строгая проверка формы и SSA"]
    compiler --> graph["Внутренний типизированный граф"]
    graph --> text["Текстовый кандидат StableHLO/MLIR"]
    source --> direct["Независимый direct CPU"]
    graph --> executor["Исполнитель typed-graph CPU"]
    direct --> compare["Сравнение f32 с допуском"]
    executor --> compare
    text --> target["Target provider: not_configured"]
    target --> fallback["FUMTensorGraphCPU/1"]
```

JSON — только прототипный носитель ограниченного DSL, а не окончательный синтаксис языка автоматизаций FUM. Компилятор принимает только статические непустые формы `f32`, технические ASCII-имена, уникальные SSA-результаты и ссылки на уже объявленные значения. Все входные и вычисленные значения должны быть конечными. Динамические формы, broadcasting, изменение состояния, ввод-вывод, строки, ветвления, циклы, редукции и внешние операции не поддерживаются.

`DirectCPUReference` вычисляет `mul_add` непосредственно по трём массивам. `TypedGraphExecutor` независимо интерпретирует две операции с поиском SSA-значений. Обе публичные границы повторно проверяют тип, число элементов и конечность каждого значения до индексирования; создание внутреннего typed graph доступно только компилятору. Совпадение CPU-реализаций проверяет внутренний граф, но не эквивалентность с внешним StableHLO-провайдером, поскольку он не настроен.

## Фикстуры и трасса

- `Sources/FUMTensorGraphCompiler/Фикстуры/mul_add.json` — канонический JSON-сценарий версии `1` с формой `[4]` и конечными значениями;
- `Sources/FUMTensorGraphCompiler/Фикстуры/mul_add.expected.mlir` — точный ожидаемый текст экспортёра;
- оба файла входят в ресурсы library target и являются единственным читаемым источником fixture: `verify`, `export` и тесты загружают их через `Bundle.module`, а отсутствие или расхождение ресурса приводит к отказу;
- команда `verify` возвращает JSON-отчёт с `source_sha256`, `ir_sha256`, версиями compiler/runtime-контрактов, абсолютным и относительным допусками, обоими CPU-результатами, обезличенной средой, наблюдаемой доступностью validator, `not_performed` для target-операций и выбранным fallback;
- команда `trace` возвращает только публикационно чистые свойства среды: числовую версию macOS, архитектуру, число процессоров, доступное число процессоров, объём памяти и ограниченное compile-time-наблюдение версии Swift. Hostname, пользовательские каталоги и абсолютные пути не собираются.

Compile-time-наблюдение вида `compiler_6_4_or_newer` не заменяет точную версию toolchain. Точную фактически использованную версию Swift, Clang, Xcode и SDK рабочая сессия фиксирует отдельно результатами команд проверки.

## Как запустить

Без аргументов launcher выполняет безопасную детерминированную проверку:

```bash
./Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/запустить.sh
```

Доступны явные режимы:

```bash
./Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/запустить.sh verify
./Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/запустить.sh export
./Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/запустить.sh trace
./Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/запустить.sh --help
```

Benchmark launcher намеренно собирает release-конфигурацию:

```bash
./Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/запустить.sh benchmark
```

Он до создания массивов ограничивает число элементов, прогревов, выборок, итераций и их суммарную работу, затем измеряет оба CPU-пути монотонными наносекундами и возвращает медиану, p95 и checksum. Временные значения зависят от хоста и нагрузки, не входят в детерминированную фикстуру и не используются как нестабильный тестовый порог. Сравнение direct CPU с graph CPU показывает цену внутреннего представления, а не преимущество ускорителя; поле `acceleration_claim` остаётся `not_measured_no_target_provider`.

## Проверки

```bash
swift test \
  --package-path Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф
swift build \
  --package-path Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф \
  --product FUMTensorGraphProbe
swift format lint \
  --configuration Инструменты/fum-kompleksnaya-proverka-repozitoriya/swift-format.json \
  --strict \
  --recursive \
  Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/Package.swift \
  Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/Sources \
  Прототипы/компиляция-численных-автоматизаций-в-тензорный-граф/Tests
```

Автономные тесты проверяют resource-backed exact-экспорт, байтовую стабильность канонического JSON, независимую CPU-эквивалентность, строгую форму, обратные SSA-ссылки, уникальность имён, короткие и неконечные публичные значения без trap, неизвестные JSON-поля, SHA-256, связную трассу, явный fallback и ограниченный benchmark без требования скорости.

## Структура

- `Sources/FUMTensorGraphCompiler/` — контракт DSL, строгий компилятор, типизированный граф, два CPU-пути, экспортёр, ресурсы fixture, отчёты, fallback, трасса и benchmark;
- `Sources/FUMTensorGraphProbe/` — безопасные режимы `verify`, `export`, `benchmark`, `trace` и справка;
- `Tests/FUMTensorGraphCompilerTests/` — автономная проверка без сети, секретов и внешних зависимостей;
- `Sources/FUMTensorGraphCompiler/Фикстуры/` — сохранённый вход и точный целевой текст, упакованные SwiftPM как library resources;
- `Package.swift` — самостоятельный SwiftPM-пакет без внешних зависимостей;
- `запустить.sh` — POSIX-точка входа, независимая от текущего каталога.

## Граница применимости

Прототип подтверждает только компиляцию одной конечной elementwise-функции в собственный типизированный граф, воспроизводимый текст и два согласованных CPU-результата. Исходный JSON уже задаёт упорядоченный SSA-подобный список из `multiply` и `add`; компилятор проверяет его, выводит типы результатов и строит отдельный типизированный граф, но не проверяет parser более высокого синтаксиса, оптимизацию или автоматическое преобразование произвольного выражения. Прототип также не подтверждает соответствие текста конкретной версии спецификации StableHLO, приёмку внешним parser/verifier, исполнение через MLIR/IREE/XLA, численную эквивалентность после внешних оптимизаций, работу GPU/NPU, выигрыш времени, памяти или энергии, переносимость за пределы macOS, полноценную грамматику языка автоматизаций либо безопасность произвольных программ.

Для настоящей target-проверки нужен отдельно зарегистрированный воспроизводимый offline-контракт provider/validator/runtime. До этого `stablehlo_mlir_text_candidate`, `provider = not_configured`, `validation_status = not_performed`, `execution_status = not_performed` и `cpu_reference` являются частью результата, а не временно скрытой ошибкой. `swift_compiler_observation` фиксирует только compile-time-диапазон; точная версия Swift сохраняется отдельно в отчёте рабочей сессии.

Статус: действующий ограниченный проверочный прототип с CPU fallback; target validator/runtime и ускорение не подтверждены.
