# Живой одноагентный эпизод

Этот SwiftPM-прототип проверяет версионные паспорт, события и чистый редуктор одного живого одноагентного эпизода [FUM](../../Глоссарий/FUM.md). Он отделяет продолжающуюся model-only-работу от ожидающего подтверждения внешнего перехода и воспроизводит оба состояния без файлового, Git- или provider-ввода-вывода в core-target.

Прототип является узким контрактным стендом. Он не представляет готовую [коробочную реализацию FUM](../../Глоссарий/коробочная-реализация-FUM.md), не выполняет реальное внешнее действие и не доказывает межпроцессную долговечность.

## Состав пакета

SwiftPM-пакет `FUMLiveSingleAgentEpisode` предоставляет библиотечный продукт и target `FUMLiveEpisodeCore`. В core находятся типы паспорта, событий и состояния, строгий разбор намерения, бюджетное решение `request-or-checkpoint`, чистый редуктор и типизированные отказы.

Исполняемый продукт и target `FUMLiveEpisodeProbe` строят автономную константную фикстуру, применяют её события к core и печатают наблюдаемый итог. Probe не является provider-адаптером: модельные ответы и внешние свидетельства в нём заранее заданы как данные тестового сценария.

Target `FUMLiveEpisodeCoreTests` проверяет положительную фикстуру и закрытые отрицательные сценарии. Core не зависит от соседних SwiftPM-пакетов; проверяемое переиспользование чистого модельного шага и воспроизводимой памяти относится к следующей FUM-STEP-0110.

## Событийный контракт

Каноническая identity события — `fum.live_single_agent_episode.event`, версия — `1`. Она намеренно не продолжает и не переименовывает `fum.agent_cycle.trace`: схемы и фикстуры трассы версий `1`–`3` остаются отдельным совместимым контуром.

Паспорт закрепляет цель, контекст, provider identity и режим, раскрытие данных, шесть бюджетов, allowlist действий, критерии проверки, контрольные точки и терминальные исходы. Редуктор ведёт независимые модельную ось и ось внешнего перехода. Каждое внешнее свидетельство связано с точной пятёркой `(episode_id, transition_id, schema_version, object_id, expected_effect_sha256)`; внутренний `selected_in_model` не подменяет подтверждение, авторизацию, preflight, исполнение или наблюдение.

Автономная фикстура прорабатывает не менее двух вариантов от общего предка и сохраняет происхождение каждого. Внутренний выбор выводится только из сохранённого model-only-ответа и строго разобранного намерения. Если резервируемая стоимость следующего вызова не помещается хотя бы в один применимый бюджет, core возвращает решение создать контрольную точку без нового запроса. Нулевой денежный остаток допускает только доказанно бесплатный локальный вызов при достаточности остальных бюджетов.

Повтор точного события идемпотентен. Повтор object identity с иным содержанием, неизвестная версия, нарушенный порядок, подмена identity, cross-transition-свидетельство, недоверенное поле действия, выбор без model-only-события и ложное повышение статуса дают типизированный отказ. После терминального решения модельной оси новые модельные события закрыты, но уже объявленный ожидающий переход может пройти позднюю строгую цепочку собственных свидетельств.

## Запуск

Из корня репозитория безопасный автономный probe запускается без перехода в каталог:

```bash
./Прототипы/живой-одноагентный-эпизод/запустить.sh
```

Тот же продукт можно запустить средствами SwiftPM:

```bash
swift run --package-path Прототипы/живой-одноагентный-эпизод FUMLiveEpisodeProbe
```

Обе команды используют только встроенную фикстуру. Они не читают пользовательские файлы, не вызывают Git, модель, сеть или внешние сервисы.

## Проверка

Автономные тесты запускаются локально без секретов, сети и живой модели:

```bash
swift test --package-path Прототипы/живой-одноагентный-эпизод
```

Тестовый набор проверяет полный допустимый порядок модельных и переходных событий, двухвариантное продолжение, строгий вывод `selected_in_model`, исчерпание каждого бюджета, бесплатный локальный вызов при нулевом денежном остатке и идемпотентное воспроизведение. Отрицательные тесты отклоняют неизвестную версию, перестановку событий, подмену identity, несовпадающее свидетельство, недоверенное действие и любое повышение внешнего состояния без отдельного точного события.

## Границы

Core-target не выполняет файловых, Git-, workspace-, provider-, сетевых или GUI-эффектов. Probe только демонстрирует редукцию сохранённых в программе значений. Заявленный `state_sha256` поколения здесь проверяется только по форме и границе последовательности; каноническое вычисление и долговечное подтверждение появятся в FUM-STEP-0110. Результат не доказывает работу живой модели, канала пользовательского подтверждения, авторизатора, preflight-адаптера, исполнителя действия, наблюдателя или постоянного хранилища.

[FUM-STEP-0110](../../Планирование/карточки-шагов/🟡-FUM-STEP-0110-реализовать-подтверждённое-хранилище-и-безоконные-интерфейсы-эпизода.md) должна расширить этот пакет подтверждёнными поколениями, версионными headless-командами и межпроцессным возобновлением, переиспользуя отдельно проверенные пакеты [чистого модельного шага](../чистый-модельный-шаг/README.md) и [воспроизводимого пополнения памяти](../воспроизводимое-пополнение-памяти/README.md).
