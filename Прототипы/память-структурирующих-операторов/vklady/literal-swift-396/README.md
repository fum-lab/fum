# FUMA → Swift: воспроизводимый внешний вклад

**Задача [#396](https://github.com/fum-lab/fum/issues/396) · поставка [#426](https://github.com/fum-lab/fum/pull/426) · собственные материалы — CC0 1.0**

Программа на FUMA строит Swift-исходник, который компилируется и работает без интерпретатора FUMA. Текущий пример — массив строковых констант, а не универсальный AOT-компилятор. Поставка остаётся внешним предложением: оператор ещё не установлен в принимающий модуль.

## Проверить самостоятельно

Для архива со снимками исходников, из его корневого каталога:

```sh
bash bundle/proverit.sh --snapshot snapshot /новый/каталог/результатов
```

Для локального клона с обоими закреплёнными коммитами, из каталога этого вклада:

```sh
bash proverit.sh --repo /путь/к/клону /новый/каталог/результатов
```

Только сверка пакета и самопроверка контроля результатов:

```sh
bash proverit.sh --check-package
```

Нужны Swift 6.2.1 с Swift Testing, Git, Bash и стандартные `shasum`, `awk`, `sed`, `grep`, `cmp`, `tee`, `mktemp`. Проверенная среда — Linux x86_64; macOS отдельно не проверялась. Скрипт не скачивает зависимости и не обращается к GitHub. Режим `--repo` сохраняет прежнюю границу: полный реальный клон в этой среде не использовался. Выходной каталог должен быть новым и находиться вне входного клона, снимка и каталога вклада.

## Что именно проверяется

| Проверка | Свидетельство |
|---|---|
| Состав пакета, размеры, SHA-256 и Git blob | `manifest.json` реально читается до сборки исходников FUMA |
| Отсутствие оператора на исходной базе | Ожидаемый отказ, отдельный каталог сборки |
| Поведение подключённого оператора | 13 функций Swift Testing; сверяются их имена, начало и завершение по JSONL-событиям |
| Корректность контроля результатов | 11 отрицательных сценариев: нулевой набор, пропуск, повтор, ошибка, незавершённость и несовместимая версия |
| Кодирование и размеры | Все 1 112 064 допустимых отдельных Unicode-скаляра |
| Исполняемая программа FUMA → Swift | 665 строк; отдельная компиляция и запуск результата |
| Байтовая эквивалентность | `cmp` и закреплённый SHA-256 результата из 22 197 байт |

Число успешных тестов больше не печатается константой. Машинный итог `logs/tests.result.json` создаётся только после подтверждения всего ожидаемого набора. Пропущенные тесты, неизвестные события и неполный поток приводят к отказу. Профиль событий ограничен проверенной версией 0 Swift Testing; несовместимая среда требует явного обновления проверяющего кода, а не молчаливого принятия.

Результаты ошибок и успешных запусков разделены; старые каталоги не очищаются и не переиспользуются. Проверяющий код компилируется во временном каталоге перед проверкой манифеста. Поэтому манифест — **контроль целостности выбранной поставки, не доказательство её безопасности или авторства**. Доверенный Git-коммит и содержимое исполняемых исходников выбираются отдельно. Согласованная подмена файлов вместе с манифестом этой проверкой не исключается.

## Контракт оператора

```json
["литерал-Swift", "произвольная строка", 65536]
```

Первый аргумент — строка. Второй — неотрицательный целочисленный предел байтов **Swift-исходника**. Общий бюджет **JSON-результата** проверяется независимо. Все Unicode-скаляры экранируются; вход не превращается в интерполяцию. Нормализация текста не выполняется. Сохраняются типизированные отказы, проверяемое сложение размеров и остановка по callback.

`literal-swift.swift` и существующие патчи подключения не изменены при этой полировке. Проверяется адресный набор настоящих исходников графа, а не полная сборка FUMA или `AutomationExecutor`.

## Ориентиры для приёмки

База: `01186131ab4fa0622279ddcabedf90525267f130`. JOIN для отдельного лабораторного опыта: `e41906c6e71f6b1418f226cd838f8c111220a976` из #398; его использование не означает приёмку этого PR.

`podklyuchenie.patch` адресован базе; `podklyuchenie-na-398.patch` — JOIN-кандидату. Локальный координатор выбирает ровно один подходящий вариант, переносит реализацию и тесты в существующий модуль и выполняет каноническую приёмку. Простое слияние каталога `vklady/` примитив не внедряет.

История первой поставки, включая неуспешные запуски, остаётся в [README.txt](README.txt). Изменения текущего этапа и его фактические результаты — в [otchyot-polirovki.json](otchyot-polirovki.json). Не заявляются общий AOT, ускорение системы, рабочий архив RAW, R2 или Telegram.

## Знание без владельца-разрешителя

Этот вклад следует цели [#246](https://github.com/fum-lab/fum/issues/246): передавать не доступ к закрытому сервису, а исходники, проверочные входы, способ воспроизведения и возможность независимого продолжения. Запуск полученной копии не требует связи с автором или его сервером.

Собственные материалы FUM/FUMA сохраняют выбранную проектом CC0 1.0; [LICENSE](LICENSE) — точная копия корневого файла из закреплённой базы. Происхождение и хэши нужны для воспроизводимости, а не как право запретить дальнейшее использование. Проверка старого манифеста не запрещает менять код: новая редакция получает новый манифест и собственные результаты. Это не DRM и не сервер лицензирования.

Swift, Foundation, Swift Testing, Git и другие внешние инструменты не включены в пакет и сохраняют свои условия. Частная память, токены, рабочие RAW и закрытые переписки сюда не входят. Никакие дополнительные требования обязательного указания авторов или возврата изменений для собственных CC0-материалов не вводятся.
