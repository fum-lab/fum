Результат

Предлагается общий примитив ["литерал-Swift", строка, пределИсходника]. Он кодирует все Unicode-скаляры через обычные Swift Unicode-escape-последовательности. Исходные строки не нормализуются, содержимое не становится интерполяцией. ПределИсходника — целое неотрицательное число байт выходного Swift-литерала. Отдельно до выделения итогового буфера проверяется общий JSON-бюджет графа. Возвращаются существующий ОшибкаИсполнения и коды тип-JSON, диапазон-JSON, предел-литерала, предел-результата, переполнение-JSON; ошибка вызывающего callback сохраняется.

literal-swift.swift — предлагаемая реализация для существующего Sources/FUMStructuringOperatorMemory. proverki-literala-swift.swift — 13 Swift Testing функций для существующего proverki. podklyuchenie.patch — адресная регистрация и вызов примитива относительно 01186131ab4fa0622279ddcabedf90525267f130. podklyuchenie-na-398.patch — та же дельта относительно e41906c6e71f6b1418f226cd838f8c111220a976, только для совместного лабораторного опыта с ещё не принятым JOIN. Патчи не применяются к рабочему репозиторию самим этим вкладом.

Сохранённые отказы

Первый сквозной запуск скрипта остановился при сборке однофайлового генератора корпуса: требовался -parse-as-library. Скрипт исправлен, повтор в новом каталоге прошёл. Дополнительная искусственная мутация JSON-оценки 5→4 вызвала 10 диагностик в граничном тесте. После возврата исходных байтов инкрементальный запуск ещё воспроизвёл результат мутанта; причина отдельно не доказана. Финальная сборка с новым --scratch-path дала 13/13. Исходный отказ не назван успешной проверкой. Для мутационных опытов использовать изолированные каталоги сборки.

Воспроизведение

Требуются Swift с Testing, Git, Bash, shasum, awk, sed и cmp. Сеть и сторонние пакеты не нужны.
  bash proverit.sh --repo /путь/к/клону /новый/каталог/результатов
В клоне должны существовать оба точных коммита, иначе команда остановится. Исходный клон используется только для git show. Все сборки, патчи и файловые эффекты идут в новый каталог, существующий каталог не принимается.
В прилагаемом автономном архиве есть проверенные исходные снимки:
  bash bundle/proverit.sh --snapshot snapshot /новый/каталог/результатов
