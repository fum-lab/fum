## Воспроизведение

Клонируйте FUM, выберите опубликованный коммит и подготовьте зависимости по [руководству приложения](macOS/README.md). Оно содержит обычные команды SwiftPM, Xcode, Python, Swift-профиля и C-профиля. Задайте абсолютный `FUM_BUILD_ROOT` вне Git; каталог должен существовать. Для сборок использованы два рабочих потока. Кэши, конфигурация SwiftPM и DerivedData также вынесены в этот каталог:

```sh
swift test --package-path Приложения/FUMA/macOS --scratch-path "$FUM_BUILD_ROOT"   --cache-path "$FUM_BUILD_ROOT/cache" --config-path "$FUM_BUILD_ROOT/config"   --security-path "$FUM_BUILD_ROOT/security" --jobs 2
swift build --package-path Приложения/FUMA/macOS --scratch-path "$FUM_BUILD_ROOT"   --cache-path "$FUM_BUILD_ROOT/cache" --config-path "$FUM_BUILD_ROOT/config"   --security-path "$FUM_BUILD_ROOT/security" --jobs 2 -c release
```

Для этой приёмки дополнительно использована внешняя `sandbox-exec`, запрещающая чтение прежних локальных каталогов источников. Отказ чтения реально существующего исходного файла проверен отдельно. Это ограничение чтения, не общий запрет записи, сети или системных IPC. Сама сборка выполняется из клона с системными SDK и mpv.

Внутри внешней песочницы SwiftPM получает `--disable-sandbox`, а Xcode — отдельный аргумент `OTHER_SWIFT_FLAGS="-Xfrontend -disable-sandbox"`. Они отключают только вложенную песочницу запуска инструментов; внешний запрет чтения остаётся. SwiftPM также получил совместимый с прежними проверками `--build-system native`; наблюдённый Swift предупреждает, что этот флаг устаревает. Обычная сборка без внешней песочницы этих параметров не требует.

Первый Xcode без параметра для макросов завершился кодом 65: `swift-plugin-server` не смог применить вложенную песочницу и макросы SwiftUI не загрузились. Неуспешный запуск сохранён. Повтор с документированным локальной справкой frontend параметром выполнен в новом DerivedData и завершился `BUILD SUCCEEDED`, кодом 0. Исходники и проект не менялись. Xcode регистрирует собранный bundle в LaunchServices; приложение не запускается.

## Граница поставки

Среда: macOS 27 arm64, Xcode 27 beta, Swift 6.4, Homebrew mpv `0.41.0_9`, клиентский API mpv `2.5`. [Ограничения платформы и лицензий](macOS/README.md) сохраняются: установленный bottle требует macOS 26, динамические зависимости не включены в автономный bundle, поддержка старых macOS и Intel не проверена. SwiftPM и Xcode предупреждают об устаревшем OpenGL и несовпадении целевой macOS 14 с установленной библиотекой.

Эта проверка подтверждает воспроизводимость исходников на наблюдённой среде. Установка, подпись, launchd, выдача разрешений, реальные сенсоры и исполнение MCP-команд остаются отдельными действиями. Пакеты ещё не подключены к приложению.
