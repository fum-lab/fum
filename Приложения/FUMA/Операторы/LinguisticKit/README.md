# Контекстная ячейка LinguisticKit на FUMA

Первый срез выбирает одну русскую ячейку транслитерации графом JSON v2 настоящего `AutomationExecutor`. Вход содержит ровно три поля: `буква`, `слева`, `справа`. Цель — одна современная строчная NFC-буква; сосед — такая же буква либо `null`, означающий границу. Область включает 33 буквы и 40 исходных ячеек. Потоковая строка, регистр, NFD, старые буквы и другие языки требуют отдельных срезов.

Граф определения [контекстная-ячейка.json](Определения/контекстная-ячейка.json) выполняет классификацию соседей и выбор ячейки. Swift-код в `проверки/` служит harness и независимым oracle. Выход содержит результат, классы соседей, нулевой индекс в полном исходном массиве из 53 ячеек и выбранные условия. Например, `{"буква":"ъ","слева":"б","справа":"а"}` даёт `yh`, индекс 48.

Классы взяты из первой исходной ячейки буквы: `й`, `ь`, `э` относятся к `vowel`; `е`, `ё`, `ъ`, `ы`, `ю`, `я` — к `other`. Это значения закреплённого исходного контракта. Генератор использует таблицу CC0 и проверяет её SHA; независимые фикстуры он не читает.

## Подтверждённый результат

Настоящий интерпретатор прошёл 58 положительных и 16 отрицательных фикстур, включая точные ошибки, канонический JSON и связи трассы; повтор harness сохранил всё наблюдение. Все 38 148 допустимых сочетаний цели и соседей побайтно совпали с прямым Swift oracle на закреплённом gitlink. Реальный macOS-продукт `fum` собран; replay после удаления приватных файлов определения и входа воспроизвёл полное наблюдение и сохранил префикс контейнера.

Компактная сериализация уменьшила определение с 29 892 до 15 009 байт при одинаковом JSON-содержимом. В последовательных волнах профиля медиана разбора снизилась с 12,50 до 5,57 мс. Тёплый набор из 40 ячеек занимает около 252 мс у FUMA и около 1 мс у прямого oracle. FUMA включает более широкий протокол проверки и наблюдения; это сравнение разных API. Ускорение исполнения не заявлено. [Все замеры и границы](профиль/сравнение.json) сохраняют шесть пар на каждую форму, память, происхождение и реальный replay.

Срез сохраняется контрольной точкой. Общая финальная приёмка, интеграция и воспроизведение поставки в независимом чистом клоне остаются координатору.

## Воспроизведение

Из чистого клона FUM подготовьте объявленные зависимости штатным порядком репозитория. Oracle требует чистый полный checkout зарегистрированного `Зависимости/LinguisticKit` на gitlink `837e2ce107b97ee7b9d3344c9fe99142281fe393`; при отсутствии закрыто отказывает. Подготовка и сборка не входят во время исполнения.

Из корня FUM, с физическим приватным `рабочий_каталог` вне любого Git-предка:

```sh
python3 -B Приложения/FUMA/Операторы/LinguisticKit/проверки/собрать-определение.py --проверить
swift build --package-path Приложения/FUMA/Операторы/LinguisticKit/проверки --scratch-path "$рабочий_каталог/build" --jobs 2 -Xswiftc -enable-testing
python3 -B Приложения/FUMA/Операторы/LinguisticKit/проверки/проверить-и-измерить.py фикстуры --исполняемый "$рабочий_каталог/build/debug/ПроверкаТранслитерации" --каталог-работы "$рабочий_каталог"
python3 -B Приложения/FUMA/Операторы/LinguisticKit/проверки/проверить-и-измерить.py oracle --исполняемый "$рабочий_каталог/build/debug/ПроверкаТранслитерации" --каталог-работы "$рабочий_каталог"
python3 -B Приложения/FUMA/Операторы/LinguisticKit/проверки/проверить-и-измерить.py полный-домен --исполняемый "$рабочий_каталог/build/debug/ПроверкаТранслитерации" --каталог-работы "$рабочий_каталог"
python3 -B Приложения/FUMA/Операторы/LinguisticKit/проверки/проверить-и-измерить.py профиль --исполняемый "$рабочий_каталог/build/debug/ПроверкаТранслитерации" --каталог-работы "$рабочий_каталог"
swift build --package-path Приложения/FUMA/macOS --scratch-path "$рабочий_каталог/build-fum" --product fum --jobs 2
python3 -B Приложения/FUMA/Операторы/LinguisticKit/проверки/проверить-и-измерить.py CLI-replay --исполняемый "$рабочий_каталог/build/debug/ПроверкаТранслитерации" --fum "$рабочий_каталог/build-fum/debug/fum" --каталог-работы "$рабочий_каталог"
```

Это вложенные команды: проектные проверки проводятся под штатной отчётной обёрткой текущего Журнала. Для `CLI-replay` нужен свежий рабочий каталог без `runtime-журнал`; приватный контейнер создаётся с правами 0700. macOS-продукт использует объявленную libmpv; текущая сборка выдала предупреждения устаревшего OpenGL и версии macOS библиотеки, завершилась успешно.

[План профиля](профиль/план.json) определяет границы. Для двух волн используйте разные приватные рабочие каталоги и отдельные `--выход <до.json>` и `--выход <после.json>` внутри соответствующего каталога: driver записывает каналы по фиксированным именам. Сохраните каналы первой волны до второй. До/после воспроизводится тем же harness с `--определение <приватная копия в рабочем каталоге>`: исходная pretty-форма получается `json.dumps(json.loads(компактные_байты), ensure_ascii=False, indent=2) + LF` и имеет SHA из сравнения.
