# Векторный видеомонтаж FUM

`*.fumcut.json` — редактируемый документ монтажа, а не готовый видеофайл.
Он хранит ссылки на исходные медиа и набор операций: дорожки, клипы, обрезки,
позиции на таймлайне, громкость, трансформы, эффекты, переходы, подписи и
маркеры. Такой документ можно пересобирать, менять и проигрывать как live-
композицию без экспорта MP4/MOV.

## Принципы

- Исходники не копируются и не перекодируются: документ использует URI со схемой
  `file`, `https`, `fum` или другой схемой.
- Монтаж неразрушающий: `sourceRange` описывает фрагмент исходника, а
  `timeRange` — место этого фрагмента в композиции.
- Видео, аудио, субтитры, HTML-сцены, векторные элементы и сгенерированные
  ассеты представлены единым списком `sources`.
- Визуальные изменения живут как параметры: `transform`, `crop`, `opacity`,
  `effects`, `transitions`, `text`.
- Рендер в файл не является частью формата. Если позже понадобится экспорт,
  он должен читать этот документ как исходный векторный граф.

## Связь с памятью и презентациями

`*.fumcut.json` — выходная сторона памяти FUM. Если RAG-заметка хранит
ссылку на источник, локальный путь, субтитры и таймкоды, то векторный монтаж
должен уметь превращать эту ссылку в показываемый фрагмент: цитату,
видеовставку, титр, поясняющий overlay или часть презентационного рассказа.

Это нужно для двунаправленной памяти: источник превращается в заметку, а
заметка может вернуться в рассказ о FUM с проверяемой ссылкой на первичный
материал и неразрушающим видеомонтажом.

## Верхний уровень

```json
{
  "schema": "fum.video.vector-cut",
  "version": 1,
  "title": "Example",
  "canvas": { "width": 1920, "height": 1080, "backgroundColor": "#000000" },
  "playback": { "frameRate": 30, "duration": 120, "previewTime": 42 },
  "sources": [],
  "timeline": { "tracks": [] },
  "markers": [],
  "notes": {}
}
```

## Источники

Каждый источник имеет стабильный `id`, тип `kind`, человекочитаемое имя и URI.
Поддерживаемые `kind`: `video`, `audio`, `subtitle`, `image`, `vector`, `html`,
`text`, `generated`, `remote`.

```json
{
  "id": "video-...",
  "kind": "video",
  "uri": "https://media.example.invalid/example.mp4",
  "displayName": "example",
  "role": "embedded video",
  "language": null,
  "mediaType": "mp4",
  "duration": 120,
  "fileSize": 123456789
}
```

## Таймлайн

Таймлайн состоит из дорожек. Дорожка задает слой/роль, а клипы внутри нее
задают конкретные фрагменты.

```json
{
  "id": "track-video-main",
  "kind": "visual",
  "name": "Main video",
  "muted": false,
  "locked": false,
  "clips": [
    {
      "id": "clip-video-main",
      "kind": "media",
      "sourceID": "video-...",
      "timeRange": { "start": 0, "duration": 12 },
      "sourceRange": { "start": 35, "duration": 12 },
      "speed": 1,
      "opacity": 1,
      "transform": {
        "x": 0,
        "y": 0,
        "scaleX": 1,
        "scaleY": 1,
        "rotation": 0,
        "anchorX": 0.5,
        "anchorY": 0.5
      },
      "effects": [],
      "transitions": []
    }
  ]
}
```

## Первый runtime-контур

Во вкладке Video FUM уже умеет:

- сохранить текущий выбранный ролик, аудиодорожку и субтитры как
  `<name>.fumcut.json` в выбранном каталоге видеодокументов;
- открыть существующий `*.fumcut.json` как активный документ;
- раскрыть активный документ в Finder;
- логировать операции в `video-player/events.jsonl` внутри внешнего `FUM_MEMORY_ROOT`.

Следующий слой — live-проигрывание документа целиком: несколько клипов,
несколько источников, overlay-дорожки, титры и переходы без экспорта
видеофайла.
