# Проверка общего пакета из сетевого клона

Проверяемый публичный снимок — `e7bdf6595e057961a480d28d8de016b882ddbaba` ветки `codex/android-runtime-01a0a633`. Он включает единый Package.swift, общие Sources/Tests/сценарии, платформенные условия macOS и ограниченный повторно применимый объединитель.

Получены успешные 156 XCTest, 33 Swift Testing, 34 Python-проверки, Xcode FUMA.app, реальный macOS оператор и семь Android сценариев. Дерево клона после запусков осталось чистым.

[Отчёт проверки](../../Журнал/2026-09-15_22-47-21_MSK_проверить-общий-пакет-из-клона/отчёт.md) фиксирует фактические результаты. Клон получен по сети без shared objects и без копирования исходников из рабочего дерева. Кэши SwiftPM и сборки созданы отдельно. Это не чистая машина: Xcode, системные SDK/mpv и открытый Android toolchain уже установлены. Кэш ОС не очищался.

## Воспроизведение

Задайте `КЛОН` новым каталогом, `СБОРКА` отдельным новым каталогом вне клона. Требуются Git, Python, Swift 6.4/Xcode, системные mpv/pkg-config; зависимости mpv описаны в [руководстве macOS](macOS/README.md).

```sh
git clone --single-branch --branch codex/android-runtime-01a0a633 \
  https://github.com/fum-lab/fum.git "$КЛОН"
git -C "$КЛОН" checkout --detach e7bdf6595e057961a480d28d8de016b882ddbaba
cd "$КЛОН"
python3 -B Инструменты/fum-proverka-git-zavisimostej/scripts/proveritj-git-zavisimostj.py init \
  --repo-root . --path Зависимости/swift-crypto
python3 -B Инструменты/fum-proverka-git-zavisimostej/scripts/proveritj-git-zavisimostj.py init \
  --repo-root . --path Зависимости/swift-asn1
export SWIFTCI_USE_LOCAL_DEPS=1
swift test --package-path Приложения/FUMA --scratch-path "$СБОРКА/host" \
  --cache-path "$СБОРКА/cache" --config-path "$СБОРКА/config" \
  --security-path "$СБОРКА/security" --build-system native --jobs 2
python3 -B -m unittest discover -s Приложения/FUMA/сценарии/проверки -p 'test_*.py'
```

Python-проверка происхождения macOS требует историю исходного коммита, поэтому clone не должен быть shallow. LinguisticKit не входит в зависимости этого Swift-пакета и для данной проверки не инициализируется. Native SwiftPM выбран из-за наблюдённого отказа подписи кириллического XCTest bundle в другом backend; предупреждение об устаревании native сохраняется.

Реальный macOS оператор запускается из собранного продукта:

```sh
КАТАЛОГ_БИНАРНИКОВ="$(swift build --package-path Приложения/FUMA \
  --scratch-path "$СБОРКА/host" --build-system native --show-bin-path)"
python3 -B Приложения/FUMA/сценарии/проверить-исполнение-оператора.py \
  --бинарник "$КАТАЛОГ_БИНАРНИКОВ/fum" --профиль-выход "$СБОРКА/оператор.json"
```

Xcode оболочка использует те же исходники и общий package reference:

```sh
xcodebuild -project Приложения/FUMA/macOS/FUM.xcodeproj -scheme FUM \
  -configuration Debug -derivedDataPath "$СБОРКА/xcode" -jobs 2 \
  FUM_MPV_INCLUDEDIR="$(pkg-config --variable=includedir mpv)" \
  FUM_MPV_LIBDIR="$(pkg-config --variable=libdir mpv)" CODE_SIGNING_ALLOWED=NO build
```

Штатный Xcode build регистрирует bundle в LaunchServices, но не запускает приложение. Для Android используйте [подготовку и единую команду семи сценариев](Android/README.md), задав новый scratch-кэш и новый каталог результатов. Системный Swift SDK и NDK могут оставаться ранее установленными; такой прогон не доказывает холодную установку среды.

## Граница

Проверка относится к точному указанному OID и наблюдённой платформе. Она не подтверждает интеграцию в master, готовность всех продуктов на Android, app UID/JNI, tvOS/visionOS/iOS simulator, новый Metal/Vulkan интерфейс, подпись, разрешения или установку приложения. Полная проекция и общий smoke-check остаются отдельной приёмкой координатора.
