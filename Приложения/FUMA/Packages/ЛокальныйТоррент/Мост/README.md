# Граница C ABI локального торрента

Отдельный SwiftPM-пакет `Мост` содержит чистый C-интерфейс и C++17-границу исключений. Производственная цель `МостЛибторрента` экспортирует версию 1 и opaque-операцию с атомарной отменой. Создание torrent через libtorrent ещё не подключено.

`ГраницаИсключений.hpp` вызывает всю переданную операцию внутри `try`, перехватывает отмену, `std::bad_alloc`, стандартные и неизвестные исключения. Результат имеет код и фиксированный буфер 512 байтов, копируется не более 511 байтов и добавляется NUL. В обработчиках исключений нет нового выделения памяти. Заголовок C при включении из C++ размещается внутри `extern "C"`; C++-типы в Swift не импортируются.

Цель `ПробыМоста` — отдельная тестовая фикстура. Шесть сценариев проверяют синхронный callback и версию, стандартное и неизвестное исключение, нехватку памяти, отмену с повтором и длинное сообщение. Swift читает сообщение в пределах известного буфера. Эти проверки доказывают границу исключений; они не доказывают метаданные, infohash, отмену работы libtorrent или готовность backend.

## Владение операцией

`создать_операцию_торрента()` получает адрес holder, изначально равного NULL. Проверки и выделение памяти выполняются внутри границы исключений. Non-null holder закрыто отклоняется и сохраняет прежний handle. Создание одного holder не выполняется конкурентно. Новая операция начинает с отсутствующей отмены.

`отменить_операцию_торрента()` и `запрошена_отмена_торрента()` используют самостоятельный монотонный atomic-флаг. NULL считается отменённым; отмена и уничтожение NULL допустимы. Уничтожение живой операции выполняется ровно один раз после завершения всех её обращений, включая check/cancel, будущие callback и onCancel. Сам C ABI не удерживает handle.

Два новых адресных теста (109 RED, 110 GREEN) проверяют независимую новую попытку, повтор отмены, отказ создания в занятый holder с сохранением handle и NULL-семантику. В исходниках восемь методов; вся серия после расширения не повторялась. 111 подтвердил пустой C++17/Swift-инвентарь с фактическим SDK Xcode.
