# Общий сценарий runtime

Компонент теперь входит в [общий пакет FUMA](../../Package.swift). Команды ниже выполняются из `Приложения/FUMA` с `export SWIFTCI_USE_LOCAL_DEPS=1`; прежний самостоятельный манифест сохранён в материалах переноса.

Пакет соединяет существующие `AutomationExecutor.выполнить` и `Сегмент`, не вводя второго интерпретатора. Библиотечный вход `СценарийRuntime.выполнить(вход:корень:определение:)` возвращает реальные байты выхода, повторного исполнения и отдельный профиль. Неверный вход отклоняется до открытия контейнера.

Продукт `сценарий-runtime` принимает четыре позиционных аргумента: файл определения JSON, входной бинарный файл, существующий приватный корень контейнера и существующий каталог результата. Корень контейнера должен иметь физический путь без символических ссылок. Выходные файлы: `выход.bin`, `повтор.bin`, `профиль.json`. stdout содержит JSON `fum.сценарий-runtime.1`, stderr — ошибку; успех имеет код 0, отказ — 1. Временные каталоги создаёт вызывающая оболочка.

Определение передаётся из канонического файла `Приложения/FUMA/Sources/FUMStructuringOperatorMemory/Определения/UTF-8-в-UTF-32LE.json`. Библиотечный вызов без явного определения использует существующий ресурс пакета; Android CLI передаёт файл явно и не полагается на размещение bundle.

Синтетический пример: `0041d191f09f8ebb` → `000000004100000051040000bbf30100` (hex). В контейнере сохраняются исходное определение и две записи `вход`/`выход`. Затем писатель закрывается, открывается читатель, сохранённый вход исполняется снова и оба выхода сравниваются побайтово. Другой вход в том же корне даёт конфликт идентификаторов; для нового опыта нужен новый корень.
