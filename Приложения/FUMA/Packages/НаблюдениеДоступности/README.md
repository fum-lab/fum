# Наблюдение доступности macOS

Самостоятельный SwiftPM-пакет сохраняет один ответ `AXIsProcessTrusted()` для текущего процесса. Намерение и ответ — две отдельные типизированные записи в [КонтейнереНаблюдений](../КонтейнерНаблюдений/README.md). Адаптер вызывает только функцию без параметров: системный запрос разрешения отсутствует.

## Порядок и состояния

Намерение содержит UUID попытки, операцию, оператора, версию графа, время и PID исходного процесса. До системного вызова контейнер подтверждает commit намерения с синхронизацией файла и каталога. Затем ответ сохраняет полное намерение, исход «доверен» или «недоверен» и монотонную длительность вызова. Новое подтверждение ответа выдаётся после его отдельного commit и обеих синхронизаций.

| Состояние | Основание |
| --- | --- |
| `ответ(..., .новаяФиксация)` | Писатель подтвердил обе записи; повтор подтверждает те же байты без нового вызова AX |
| `ответ(..., .историческоеЧтение)` | Полная проверенная пара прочитана без записи; прежний fsync и актуальное состояние macOS не доказываются |
| `неизвестно(намерение)` | Намерение есть, ответа нет; невозможно установить, был ли вызов до прерывания |
| `отсутствует` | В существующем проверенном сегменте нет этой попытки |
| Ошибка | Нет файла, нарушена связь/схема/метаданные, повреждены данные, есть частичный хвост или отказал контейнер |

Для свежего наблюдения нужен новый UUID. Повтор прежнего UUID с другим оператором или графом отклоняется. Вход с готовым `НамерениеДоступности` также требует полного равенства прежних времени и PID. Удобный вход по UUID и CLI повторно используют исходное намерение, сохраняя время и PID первого процесса. Незавершённая попытка автоматически не вызывает AX повторно.

Читатель открывает сегмент с `запись:false, создать:false`, проверяет порядок намерение→ответ, канонические JSON-байты, схему и точное описание каждой записи. Он не получает функцию AX и не ремонтирует хвост. Полностью видимая пара после отказа fsync может читаться только с историческим основанием. Ошибка записи не превращается в `false`.

## Воспроизведение из чистого checkout

Минимум, объявленный в manifest: macOS 14 и Swift 6. Проверенный срез: arm64, Apple Swift 6.4, macOS 27. Локальная зависимость — соседний пакет контейнера в том же FUM. Для сборки этого пакета сетевые SwiftPM-зависимости не нужны. Всё временное хранится вне Git.

Из физического корня чистого checkout FUM передайте шесть явно проверенных входов как позиционные параметры оболочки. Все пути абсолютные и физические; каталоги данных новые, приватные и находятся вне Git. Первый вход — выбранный пользователем обычный исполняемый файл Swift, его версия проверяется отдельно.

| Параметр | Вход |
| --- | --- |
| `$1` | Проверенный Swift |
| `$2` | Внешний каталог сборки |
| `$3` | Текущий пакет наблюдения в чистом checkout FUM |
| `$4` | Новый каталог первого наблюдения |
| `$5` | Новый пустой каталог данных профиля |
| `$6` | Новое имя выходного JSON профиля |

Сначала собирается Release CLI, затем тесты запускают именно этот результат. `SHELL` должна обозначать проверенную исполняемую оболочку для автономных фикстур; отсутствие объявленных входов даёт отказ теста.

```sh
"$1" build -c release --package-path "$3" --build-system native --jobs 2 --scratch-path "$2"
env "ФУМ_КОМПИЛЯТОР=$1" "ФУМ_КОМАНДА_ДОСТУПНОСТИ=$2/release/наблюдать-доступность" "ФУМ_ИСХОДНИКИ_ДОСТУПНОСТИ=$3" "$1" test --package-path "$3" --build-system native --jobs 2 --scratch-path "$2"
```

На проверенном Swift 6.4 флаг `--build-system native` ещё работает с предупреждением об устаревании. Все результаты текущего среза получены этим проверочным путём.

Каталог runtime должен уже существовать, принадлежать пользователю, иметь режим 0700 и физический абсолютный путь без символических компонентов. Пример первого запуска и чтения:

```sh
mkdir -m 700 "$4"
"$2/release/наблюдать-доступность" наблюдать --каталог "$4" --попытка 218bb5c1-fd5b-447c-a4f6-e74a3b3d4df9 --оператор проверка-доступности --версия-графа неподключён
"$2/release/наблюдать-доступность" прочитать --каталог "$4" --попытка 218bb5c1-fd5b-447c-a4f6-e74a3b3d4df9
```

Точный повтор команды `наблюдать` подтверждает сохранённую пару без AX. Для нового ответа заменяется UUID. CLI печатает JSON состояния; неизвестность и отсутствие имеют отдельные значения, ошибка — stderr и код 2. Сырые записи остаются в `сегмент.fumobs` приватного каталога.

## Проверки и профиль

Прежние 15 тестов подставляют одну функцию `() -> Bool`. Проверяются оба ответа, порядок до AX, прерывание между записями, отказы write/fsync файла и каталога, четыре синхронизации завершённого повтора, отказ повторного подтверждения, сохранение первичного происхождения в новом процессе, конфликт, строгие метаданные/байты/порядок и чтение без изменения файла. Семь дополнительных тестов запускают собранную CLI: отсутствие/неоднозначность инструмента, неверное назначение без fallback, полный разбор PATH, версия и два пути к одному исполняемому файлу, а также настоящий Swift.

Профиль схемы `fum.профиль-доступности.2` сначала один раз измеряет выбор и SHA-256 исполняемого файла, затем один раз — запуск и чтение `swift --version`. Проверки выполняются до создания попыток и AX. Явная переменная среды `ФУМ_КОМПИЛЯТОР` требует абсолютный путь к обычному исполняемому файлу; неверное значение отклоняется. Без назначения полностью проверяется PATH: пустые/относительные компоненты отклоняются, пути к одному каноническому файлу объединяются, отсутствие и несколько кандидатов дают отказ. Версия требует код 0 и строку версии Swift; предел — 10 секунд и 8192 байта stdout. Версия и хэш файла характеризуют объявленный вход; происхождение сборки подтверждает отдельная квитанция её выполнения.

Затем профиль измеряет запись намерения, AX, запись ответа и воспроизведение с объявленным числом повторов. Каждая запись включает JSON и fsync файла и каталога; воспроизведение — открытие, сканирование, проверку пары и закрытие. Создание корня и заголовка сегмента исключено. В каждую строку входят длительность, исход и глубина. Сохраняются все измерения, медиана, процентиль 95, минимум/максимум, версия компилятора и SHA-256 11 собственных исходников. Режим сборки определяется компиляцией. Кэш ОС не очищается.

Для повторения нужны новый пустой приватный каталог, новое имя выходного JSON и абсолютный путь текущего пакета в `--корень-исходников`:

```sh
mkdir -m 700 "$5"
env "ФУМ_КОМПИЛЯТОР=$1" "$2/release/наблюдать-доступность" профиль --каталог "$5" --повторов 30 --выход "$6" --корень-исходников "$3"
```

[Профиль первого среза](Профили/первый-срез.json) содержит 30 реальных вызовов без подставной функции и без сырых ответов, PID, UUID и локальных путей. Проверка профиля дополнительно сравнивает сохранённую и воспроизведённую пару и байты сегмента до/после чтения. Доказательство общего runtime FUMA, чтения AX-дерева и связи со скриншотом требует последующих срезов.

[Профиль подготовки путей](Профили/подготовка-путей.json) сохраняет отдельные измерения подготовки и 30 новых реальных наблюдений. Исторический профиль остаётся исходным свидетельством; различие времени между двумя запусками не доказывает ускорения.
