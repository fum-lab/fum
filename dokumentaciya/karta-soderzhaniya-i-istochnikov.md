### Политика переноса без потери

- Целевой basename сохраняется: `Документация/<имя>` → `dokumentaciya/<имя>`, только если точный target-путь свободен. Массового переименования и normalizer нет. Для каждого будущего перемещения полный manifest закрепляет source commit/path/mode/blob/bytes/SHA-256, а reviewer — exact/semantic status и входящие ссылки.
- Каждую пару классифицировать как свободная цель, точные одинаковые байты, отличающаяся версия, семантическое пересечение, самостоятельный материал или `UNKNOWN`. Свободный путь получает неизменённые исходные байты с provenance. Точный дубликат не копируется повторно: сохраняются обе идентичности и link mapping. Разные blob не перезаписываются и не сливаются по сходству имени; обе версии остаются до решения семантического владельца.
- Менять ссылки в своих документах только после pin целевого файла и учёта всех inbound edges. Старые источники не удалять до покрытия ссылок; Git history сохраняется. ROOT `README.md` может менять ROOT-owner либо отдельный точный packet, но не этот writer.
- Неизменённые Tools inputs не требуют republication: ROOT-reported `cb0d` report (полный pin остаётся в ROOT inventory) и A12C `f1262c5e301bb5387971fe5c961e38714ee16347:Документация/минимальный-срез-артефактов-01a17797.json`, 8921 байт, SHA-256 `1cca7eeabb07ac2ac47d1ad973b17cd4e69091fc599c0f19215560433a43374b`.
