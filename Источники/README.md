# Источники

Этот каталог хранит канонические скачиваемые источники с устойчивой идентичностью, прежде всего [прикрепляемые материалы](../Глоссарий/прикрепляемый-материал.md) с URL, на которые могут ссылаться разные [исходные запросы](../Глоссарий/исходный-запрос.md) в [памяти FUM](../Глоссарий/память-FUM.md).

Материал с устойчивым URL используется как один источник, даже если на него ссылаются несколько запросов. Такая папка размещается по цепочке URL: `Источники/URL/<scheme>/<host>/<path...>/`. Например, расшаренный чат `https://chatgpt.com/share/<id>` хранится в `Источники/URL/https/chatgpt.com/share/<id>/`. Если query или fragment меняют содержание источника, они добавляются к пути как хэшированные сегменты, чтобы не раскрывать возможные секреты в имени папки.

Материал без устойчивого URL и с одним доказанным владельцем сохраняется не здесь, а в `материалы/источники/<описательное-название>/` соответствующей [папки запроса](../Глоссарий/папка-запроса.md). `запрос.md` содержит ссылку на материал и, когда полезно, на отчёт об извлечении или основные извлечённые файлы. Внутри сохраняются доступные исходные данные, машинные потоки, извлечённый текст, структурированные данные, отчёты об извлечении и другие публикационно чистые слои исходного материала.

Секреты, cookie, токены, локальные IP, геометаданные запроса и другие непубликуемые значения редактируются перед коммитом, а факт редакции фиксируется в отчёте об извлечении.

## Научные статьи и библиография

Используемые научные статьи и препринты, включая arXiv, сохраняются с точной версией и происхождением. [Протокол научных источников](../Инструменты/fum-materialyi-zaprosov/научные-источники.md) также предусматривает экспорты Mendeley и отдельно полученные PDF и аннотации. Он различает сохранённую библиографию, фактическое получение полного текста и результат извлечения. Автоматический импорт Mendeley и PDF ещё не реализован; текущий общий архиватор принимает HTML.

Права на внешний текст сохраняются. Бинарный оригинал в файловом хранилище и его публикационно допустимая запись в Git имеют отдельные статусы доступности.
