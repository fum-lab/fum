# Источники

Источники требований:

- [исходный запрос 2026-06-23 17:37:29 MSK](../Запросы/2026-06-23_17-37-29_MSK.md)
- [исходный запрос 2026-06-23 17:45:40 MSK](../Запросы/2026-06-23_17-45-40_MSK.md)
- [исходный запрос 2026-06-23 18:43:31 MSK](../Запросы/2026-06-23_18-43-31_MSK.md)

Этот каталог хранит скачиваемые источники и другие [прикрепляемые материалы](../Глоссарий/прикрепляемый-материал.md), которые относятся к конкретным [исходным запросам](../Глоссарий/исходный-запрос.md) в [памяти FUM](../Глоссарий/память-FUM.md).

Материал с устойчивым URL используется как один источник, даже если на него ссылаются несколько запросов. Такая папка размещается по цепочке URL: `Источники/URL/<scheme>/<host>/<path...>/`. Например, расшаренный чат `https://chatgpt.com/share/<id>` хранится в `Источники/URL/https/chatgpt.com/share/<id>/`. Если query или fragment меняют содержание источника, они добавляются к пути как хэшированные сегменты, чтобы не раскрывать возможные секреты в имени папки.

Материал без устойчивого URL сохраняется в папке `Источники/<YYYY-MM-DD_HH-MM-SS_MSK>_<описательное-название>/`: префикс совпадает с именем файла запроса в `Запросы/` без расширения `.md`, а суффикс кратко описывает источник. Файл запроса в `Запросы/` содержит ссылку на папку источника и, когда полезно, на отчет об извлечении или основные извлеченные файлы. Внутри сохраняются URL, заголовки, тело ответа, машинные потоки, извлеченный текст, структурированные данные, отчеты об извлечении и другие публикационно чистые слои исходного материала.

Секреты, cookie, токены, локальные IP, геометаданные запроса и другие непубликуемые значения редактируются перед коммитом, а факт редакции фиксируется в отчете об извлечении.
