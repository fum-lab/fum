# Снимок GitHub comments перед разбором

Источник: [https://api.github.com/repos/fum-lab/fum/issues/comments?per_page=100](https://api.github.com/repos/fum-lab/fum/issues/comments?per_page=100). Полный ближайший к сырому [stdout CLI](response.body.json) сохранён побайтно после успешного `gh api --paginate`; [наблюдение](request-observation.json) содержит время, длину, длительность и SHA256. Оба исходника сначала сохранены и fsync выполнен в приватном постоянном хранилище, затем выполнен структурный подсчёт.

Всего в двух ответах: 132 Issues (131 открытых, 1 закрытый), 15 PR и 51 комментарий, из них 42 относится к Issues. Исходные массивы не фильтровались.

Побайтовый HTTP-транспорт, Link, ETag, коды и границы отдельных HTTP-страниц не наблюдались. Число JSON-массивов не является числом HTTP-страниц. Удалённые, скрытые и недоступные записи этим чтением не восстанавливаются. Публичное представление не содержит найденных известных шаблонов ключей или локальных путей; такая проверка не доказывает отсутствие всех возможных секретов. Предыдущий снимок сохранён. Сохранение не означает принятие или выполнение Issue.
