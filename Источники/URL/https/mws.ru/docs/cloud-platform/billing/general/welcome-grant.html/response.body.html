Приветственный грант

Приветственный грант — это грант, который могут получить пользователи MWS Cloud Platform при первом пополнении баланса биллинг-аккаунта.

Размер гранта для физических лиц — 3000 бонусов, для юридических лиц и ИП — 10000 бонусов. Грант можно использовать в течение трех календарных месяцев для оплаты любых сервисов MWS Cloud Platform, за исключением сервиса Content Delivery Network (CDN). После окончания срока остаток бонусов сгорает.

Условия получения

Заголовок раздела «Условия получения»

Приветственный грант предоставляется пользователю только один раз:

  • Если пользователь — владелец нескольких организаций, он может получить грант только в одной из них.
  • Если пользователь — владелец нескольких биллинг-аккаунтов, он может получить грант только при первом пополнении баланса одного из них.
  • Если пользователь уже получил грант как физическое лицо, он не может получить грант второй раз как юридическое лицо или ИП.

Грант начисляется автоматически при первом пополнении баланса на сумму от 500 рублей.

Важно

Если вы пополняете баланс как ИП или юридическое лицо, ИНН плательщика должен совпадать с ИНН владельца биллинг-аккаунта — иначе начислить грант не получится.

Полные условия акции: Специальные условия Акции MWS «Приветственный грант на сервисы MWS Cloud Platform».

Если у вас возникли вопросы по получению или использованию гранта, обратитесь в техническую поддержку.
