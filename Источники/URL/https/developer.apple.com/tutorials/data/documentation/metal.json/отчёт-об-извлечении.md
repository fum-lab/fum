# Доступность публичного API Metal

Получен официальный JSON документации Apple. Тело сохранено побайтно; его SHA-256, время, HTTP-статус, ограниченный набор заголовков и извлечённый массив платформ находятся в [отчёте](извлечение.json).

В массиве metadata.platforms указаны iOS, iPadOS, Mac Catalyst, macOS, tvOS, visionOS. watchOS в этом массиве отсутствует. Это граница объявленной доступности данного публичного API, а не измерение устройств и не доказательство невозможности любого графического пути на watchOS.

[Оригинал](https://developer.apple.com/tutorials/data/documentation/metal.json).
