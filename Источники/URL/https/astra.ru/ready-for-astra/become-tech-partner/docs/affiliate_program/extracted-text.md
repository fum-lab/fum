воспроизведение операционной системы специального назначения "Astra Linux
Special Edition" (далее - ОС Astra Linux) для целей разработки программного

на основе ОС Astra Linux для использования в составе программного обеспечения
Технологического партнера, функционирующее в среде ОС Astra Linux.

3 Статус Технологического партнера
3.1 Статус Технологического партнера присваивается компании разработчику
ведущей разработку программного обеспечения или программно-аппаратных
изделий (далее по тексту - Изделие) для публичной реализации на рынке,
принявшей оферту и успешно прошедшей испытания совместимости
с операционной системой специального назначения "Astra Linux Special
Edition" (далее по тексту - ОС Astra Linux) и/или любым другим продуктом «Группы
Астра» (https://astragroup.ru/software-services/) по программе Ready For Astra или
компании разработчику ведущей в настоящий момент разработку изделий
с использованием продуктов «Группы Астра».
3.2 Согласно партнерской программе партнеру может быть присвоен один/
несколько из следующих статусов:
3.2.1 Технологический партнер.
3.2.2 Привилегированный Технологический партнер.
3.2.3 Технологический партнер Разработчик.
3.2.4 Коммерческий Технологический партнер (является дополнительным
статусом).
4 Порядок присвоения статуса
Технологического партнёра
4.1  Заполнить анкету на сайте https://astra.ru/ready-for-astra/become-tech-
partner/ и принять оферту (принимая оферту партнер принимает условия
партнерской программы и соглашается на получение новостных рассылок).
4.2 Получить доступ к личному кабинету https://lk.astra.ru/.
4.3 Пройти успешные испытания совместимости изделия с ОС Astra Linux и/или
любым другим продуктом «Группы Астра» по программе Ready For Astra.
4.4 Первоначально доступ к дистрибутивам ОС Astra Linux дается на 30 дней
с возможностью дальнейшей пролонгации.

6 Сертификационные испытания
по программе Ready For Astra
6.1 Типы сертификатов
6.1.1 Сертификат «Ready for Astra Certificate» – тестирование проводится
на стороне «Группы Астра».
6.1.2 Сертификат «Ready for Astra Self-Certificate» – тестирование проходит
на стороне партнера.
6.1.3 Сертификат «Ready for Astra Certificate Wine» – тестирование изделий
написанных под ОС Windows с использованием технологии Wine.
6.1.4 Сертификат «Ready for Astra Certificate Hardware» – тестирование
аппаратной части изделия.
6.2 Сертификация
6.2.1 Любой из вышеперечисленных сертификатов совместимости
предоставляется партнеру бессрочно на ту версию изделия, которая проходила
испытание совместимости по программе Ready For Astra.
6.2.2 При выходе новой версии изделия партнера и/или продуктов «Группы
Астра» требуется повторное прохождение испытаний совместимости
обновленных версий.
6.2.3 Все испытания совместимости могут проводиться как силами технических
специалистов «Группы Астра», так и партнером самостоятельно.
6.2.4 В случае когда тестирование изделия проходит на стороне «Группы Астра»,
партнер обязуется предоставить дистрибутив/лицензию актуальной версии
продукта, полный комплект технической документации, а так же оказывать
техническую поддержку на протяжение всего процесса тестирования.

6.2.5 Если программное Изделие состоит из программной и аппаратной части
(ПАК) для подтверждения совместимости оба изделия должны пройти испытания
совместимости по программе Ready For Astra.
6.2.6 В случае если тестирование программно-аппаратного изделия проходит на
стороне «Г руппы Астра», партнер за свой счет передает оборудование в «Г руппу
Астра» для проведения испытаний совместимости.
6.2.7 Для прохождения испытаний совместимости программных изделий
имеющих только версии под ОС Windows с использованием технологии Wine,
партнеру необходимо предоставить специалистам «Группы Астра» дистрибутив
актуальной версии программного изделия и техническую документацию. После
чего Технологическому партнеру предоставляется соответствующая сборка Wine
и инструкция по ее развертыванию. Каждая сборка является уникальной и
создается индивидуально с учетом особенностей программного изделия
партнера.
6.2.8 В случае если программное или программно-аппаратное Изделие требует
адаптации или доработки для достижения совместимости каждый запрос
рассматривается в индивидуальном порядке.
6.3 После прохождения сертификации по программе Ready For Astra
•«Группа Астра» публикует информацию о совместимости на сайте
https://astragroup.ru/ready-for-astra/companies-partners/;
•Партнеру предоставляется сертификат совместимости
(может быть как в электронном виде, так и на бумажном носителе);
•По обоюдному согласию может быть выпущен пресс-релиз.
