# Извлечение субтитров истории координации агентов

Получены автоматические дорожки `ru-orig` и `en-orig` в JSON3. Русская дорожка содержит 1294 непустых событий; весь её текст разобран. Английская использована для выборочной сверки. Ручные субтитры в полученных метаданных отсутствуют. Аудио и видео не скачивались и не просматривались.

Извлечение уже выполнил отдельный исполнитель после прямого человеческого запроса. ROOT принял сохранённые байты по точным SHA-256; повторный сетевой запрос к YouTube не выполнялся. Поздний запрос в ROOT является отдельным экземпляром сообщения, его оригинал сохранён в Журнале. Поздняя отмена ошибочной отправки в дочернем чате не отменяет запрос ROOT.

Исходные JSON3 сохранены без изменения; SRT сформирован алгоритмически из временных полей и строк сегментов, без исправления распознавания. Русская дорожка доходит до конца ролика; последняя фраза обрывается. Названия и термины могут содержать ошибки ASR. Получение английской автоматической дорожки не доказывает независимый человеческий перевод.

В открытом снимке метаданные ограничены идентичностью материала, длительностью и языками. Рекламное описание и ссылки не перенесены в производный разбор; полный полученный файл остаётся приватным. Оригинальные субтитры, SRT и их точные хэши сохранены; полного текста в Git нет, поскольку разрешение на открытую перепубликацию не установлено. Хэш доказывает идентичность доступных исходных байтов, но не позволяет восстановить их из одного открытого снимка.
