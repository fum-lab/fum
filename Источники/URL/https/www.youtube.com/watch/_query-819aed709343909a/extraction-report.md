# Граница сохранения материала

5 октября 2026 года yt-dlp 2026.08.19 получил метаданные ролика. Русские автоматические субтитры ru-orig реально получены как JSON3: HTTP 200, 398160 байт, 1206 событий, SHA-256 `398545996c43007304dfbc945450f2ad8ec4274975a0fce93c4d5dcb84c37744`. Метки в разборе обозначают начала глав описания, а не первые произнесённые упоминания.

Полные исходные метаданные, JSON3 и извлечённый текст сохранены в приватном долговременном слое вне Git. Публичный слой содержит выбранные библиографические поля, главы, хэшовую квитанцию и краткий смысловой слой. Видеопоток, аудиопоток и HTML не сохранялись. Страница и разговорный текст целиком из этого клона не восстанавливаются. Отсутствующие части не сочиняются.

Подписанные временные адреса транспортов, служебные поля полного вывода yt-dlp и полный текст субтитров не включены в публичный снимок. Метаданные являются выборкой полей, а не нетронутым полным ответом API. Авторская орфография названия сохранена.

Получение метаданных воспроизводится командой `yt-dlp --ignore-config --skip-download --no-cache-dir --dump-single-json` с исходным URL. Общий HTML CLI не поддерживает JSON3 как самостоятельный снимок; этот ограниченный набор установлен отдельно, без изменения кода архиватора или расширения его контракта. Приватный оригинал не выдаётся за доступную из чистого клона публичную поставку.
