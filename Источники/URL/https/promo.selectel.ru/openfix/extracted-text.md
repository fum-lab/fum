xz
Популярная утилита для сжатия и распаковки файлов в формате LZMA. Часто используется для упаковки tar-архивов.
Использует LZMA SDK от 7-Zip.
Содержит критические уязвимости (CVE), связанные с особенностями формата хранения и недостаточным сопровождением.
Особенно известен добавленным через социальную инженерию бэкдором.
Переписывать LZMA с нуля необязательно — основные уязвимости обнаружены не в алгоритме, а в обвязке вокруг формата xz, запуске приложения и взаимодействии через API.
Достаточно переписать критические части и слинковать с С-кодом LZMA.
https://github.com/tukaani-project/xz
https://packages.debian.org/ru/sid/xz-utils
c-ares
Библиотека асинхронного разрешения DNS-имен. Используется во многих приложениях, имеет большой охват.
Создана из-за отсутствия аналогичной функции в libc.
Активно сопровождается, но есть уязвимости, типичные для кода на C. https://github.com/c-ares/c-ares/security/advisories/GHSA-6hxc-62jh-p29v
Нужно полностью переписать, желательно с использованием стандартной библиотеки Rust без дополнительных зависимостей. Результат должен быть полностью совместим с c-ares и предоставлять точно такое же API для C-программ и других библиотек.
Будет идеально, если напишете на no_std Rust с использованием только libc, чтобы минимизировать размер библиотеки.
https://github.com/c-ares/c-ares
https://packages.debian.org/bookworm/libc-ares2
libxml2
Библиотека парсера xml, хотя сам формат не очень популярен сейчас, куча старого ПО завязана на libxml2.
Уязвимости в libxml ставят под угрозу разнообразное по для десктопа, сервера и даже мобильных устройств. Библиотека активно используется в Android.
Ментейнеры не поддерживают срочные фиксы безопасности и не спешат их исправлять.
https://github.com/GNOME/ libxml2
https://packages.debian.org/bookworm/libxml2
