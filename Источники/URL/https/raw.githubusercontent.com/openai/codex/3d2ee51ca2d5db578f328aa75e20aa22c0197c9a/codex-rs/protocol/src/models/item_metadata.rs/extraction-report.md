# Получение закреплённого исходника

GET публичного raw URL через curl завершился HTTP 200 без изменения effective URL. Тело сохранено побайтно, UTF-8 проверен; оно уже является извлечённым текстом, отдельного преобразования нет. Дата ответа сервера находится в очищенных заголовках. Сохранены только HTTP-статус, Date, Content-Type, Content-Length, ETag и Last-Modified при их наличии; остальные транспортные заголовки, включая идентификаторы запроса и служебные сведения сети, исключены. В очищенных заголовках удалены завершающие пробелы строк. Тело не редактировалось.

Исходник получен по уже закреплённому в происхождении классификатора commit; внешний строковый тип допускает будущие значения и не устанавливает локальный список поддержанных аннотаций ассистента.
