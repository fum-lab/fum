# Proverka nazvanij avtomatizacij

Каноническое русское имя этой локальной автоматизации FUM — `проверка названий автоматизаций`. Она сверяет русское имя на кириллице, точный результат преобразования LinguisticKit и технический slug. Кириллическое имя остаётся смысловым источником, а латинская форма не подбирается вручную.

## Контракт реестра

Реестр `Инструменты/реестр-названий-автоматизаций.json` имеет схему `fum.automation-names.v1` и хранит:

- `linguistic_kit` — путь, адрес исходного репозитория, закреплённую ревизию, пару `Cyrl → Latn`, таблицу `ru` и состояние материализации;
- `golden` — обязательные эталонные пары `source` и `transliteration`;
- `current` — новые и переименованные автоматизации с `source`, `transliteration` и `slug`;
- `display` — названия автоматизаций без каталога, для которых нужны только `source` и `transliteration`;
- `legacy_display` — точный временный список наследуемых имён автоматизаций без каталога;
- `legacy` — точный временный список уже существующих каталогов, ещё не переименованных по новому правилу.

Для `current` slug получается как префикс `fum-` и точная транслитерация, приведённая к нижнему регистру и с заменой пробелов на дефисы. Эта нормализация — слой FUM, а не функция LinguisticKit.

## Что проверяется

Валидатор:

- проверяет схему, закреплённые метаданные и пять эталонных пар;
- сверяет `source` с результатом LinguisticKit через JSON-обёртку;
- отклоняет повторы, коллизии, недопустимые slug и ручные варианты транслитерации;
- находит `Инструменты/fum-*/SKILL.md`, требует совпадения slug с именем каталога и полем `name`;
- отклоняет незарегистрированную или исчезнувшую автоматизацию.

Если зависимость ещё не материализована, допустимо только явное состояние `blocked` с непустой причиной. В этом режиме структура, эталоны и имена проверяются, а команда явно сообщает, что живая сверка не выполнена. Появление каталога зависимости требует состояния `ready` и живой сверки.

## Команды

Проверка из корня репозитория:

```bash
python3 Инструменты/fum-proverka-nazvanij-avtomatizacij/scripts/proveritj-nazvaniya-avtomatizacij.py
```

Автономные тесты без сети и без материализованной зависимости:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover \
  -s Инструменты/fum-proverka-nazvanij-avtomatizacij/tests \
  -p 'test_*.py'
```

Тесты подменяют JSON-преобразователь локальным процессом. Они фиксируют эталоны, ошибочную транслитерацию, невалидные slug, коллизии, незарегистрированные каталоги, имена без каталога, а также режимы `ready` и `blocked`.

## Граница автоматизации

Валидатор не определяет смысловое русское имя и не решает, когда переименовывать наследуемые каталоги. Он также не устанавливает зависимость и не выбирает способ её подключения. Она лишь даёт исполнимую структурную проверку уже записанного решения.
