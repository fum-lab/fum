# Русификация кода при слиянии

Первый конечный Python-контур исполняется перед стадированием переводов и созданием merge-коммита. [Контракт](контракт-русификации.md) задаёт вход, карту, область, полное замыкание принятого переводчика и долговечную транзакцию. Первоначальная [постановка](../../Планирование/параллельные-постановки/2026-10-03/русификация-кода-при-слиянии.md) сохраняет последующие языковые и интеграционные обязательства.

Работа ведётся в своём обычном кандидате: физический корень, HEAD=L, единственный MERGE_HEAD=S, индекс без конфликтов, split/sparse и скрывающих флагов. Принимающий координатор независимо закрепляет полные OID, хэш сырых байтов индекса, область и карту с её происхождением. Полный состав Python backend выбирается в принятом L; версия собственного исполнителя отдельно закрепляется его хэшем. Эти хэши являются привязками выбранного контура, а его приёмка остаётся обязанностью принимающего процесса.

Все операционные JSON и состояние настоящей транзакции сохраняются вне checkout и общего Git-каталога. План и свидетельство выводятся в stdout; ошибки — в stderr. Из физического корня своего дерева, передавая абсолютный корень кандидата:

```text
python3 -B Инструменты/fum-rusifikaciya-koda-pri-sliyanii/scripts/русифицировать-код-при-слиянии.py план --корень-репозитория <корень> --вход <вход.json> --карта <карта.json>
python3 -B Инструменты/fum-rusifikaciya-koda-pri-sliyanii/scripts/русифицировать-код-при-слиянии.py применить --корень-репозитория <корень> --вход <вход.json> --карта <карта.json> --план <план.json> --состояние <внешний-каталог>
python3 -B Инструменты/fum-rusifikaciya-koda-pri-sliyanii/scripts/русифицировать-код-при-слиянии.py проверить --корень-репозитория <корень> --вход <вход.json> --карта <карта.json> --план <план.json> --свидетельство <свидетельство.json> --фаза перед-коммитом
```

Координатор сохраняет вывод каждой успешной команды. После применения он стадирует ровно результаты плана своим разрешённым Git-входом. Фаза `перед-коммитом` сравнивает весь индекс с исходным индексом и точным набором результирующих blob, включая неизменённые записи. Сам переводчик не выполняет Git-запись, коммит, push или изменение конфигурации.

Неизвестные объявления дают код 1 и план с `запросы`; неподтверждённый вход — код 2. Положительный план имеет код 0. После незавершённой попытки обычный повтор закрыт; явная команда `восстановить` принимает те же пять входных путей, что `применить`, и продолжает только доказанный префикс. Третьи байты, живой прежний процесс, дрейф режима, карты, контура или индекса запрещают запись. Завершённая попытка только сверяется и не переигрывается из исходных байтов.

Swift закрыт до принятого V2 и отдельного адресного подключения его замыкания; Swift V1 не подставляется. Mermaid/CJS, pattern bindings, параметры типов Python, непокрытые Unicode-имена, удаление собственных исходников и адресный выбор исторических одноимённых объявлений в этом Python-срезе закрыты. Общие merge/smoke-входы, реестры инструментов, обратный приём и мастер-допуск подключает их назначенный писатель после приёмки инструмента. Для master приёмочный код сначала принимается в исходном M; кандидат не разрешает собственную приёмку.

Адресные проверки и профиль запускаются через действующую отчётную обёртку своей пары Журнала:

```text
python3 -B -m unittest discover -s Инструменты/fum-rusifikaciya-koda-pri-sliyanii/tests -p 'test_*.py'
python3 -B Инструменты/fum-rusifikaciya-koda-pri-sliyanii/tests/профиль_русификации.py --повторов 3 --выход <новый-профиль.json>
```

Профиль сравнивает одинаковые открытые кандидаты 1×/10× и чередует порядок трёх пар. Ручная последовательность использует тот же принятый Python backend; новая процедура дополнительно проверяет delta и подтверждения. Подготовка исключена; стадийные интервалы внутри общего времени не суммируются повторно. Счётчики `Path.read_bytes` и `tokenize.generate_tokens` относятся к Python-процессу; память — Python allocations через tracemalloc, без RSS дочерних Git-процессов. Полные исходные тексты, входы, карты и результаты сохраняются. Ускорение полного слияния этот замер не доказывает.
