# Контракт Python-русификации кандидата

Публичные функции `построить_план`, `применить`, `восстановить` и `проверить` реализуют первый Python-срез [постановки](../../Планирование/параллельные-постановки/2026-10-03/русификация-кода-при-слиянии.md). Внешний координатор выбирает доверенный контур и источник карты до вызова. Свидетельство подтверждает выбранные байты и индекс; оно не является полномочием на публикацию либо доказательством научной или финальной приёмки.

| Вход | Закрепляемые поля |
| --- | --- |
| `fum.вход-русификации.1` | `принимающий`, `источник`: полные SHA-1 OID коммитов; `индекс_sha256`: хэш сырых байтов; `область`: конечные файлы/префиксы с `/`; `карта_sha256`: хэш канонических байтов карты |
| `контур` | `ревизия=L`, `хэш_исполнителя` шести собственных scripts; `файлы`: точные пути и SHA-256 всего принятого Python backend |
| `fum.карта-русификации.1` | непустое `происхождение`, `подтверждения`, один Python `пакеты`, пустые `исключения` этого среза |
| Подтверждение | точные `путь`, `язык=python`, `вид`, `имя`, `строка`, `столбец` объявления и русское `новое` имя |
| Пакет | исходный `fum.пакет-перевода-python.1` существующего переводчика; его контракты областей, связей, передач и встроенного кода сохраняются |

Канонический JSON: UTF-8, `ensure_ascii=false`, сортировка ключей, отступ два пробела и один конечный LF. Повторные поля и неизвестные поля закрытых собственных объектов отклоняются. Русское имя содержит кириллицу, цифры и `_`; для тестов допускается стандартный префикс `test_`. Unicode-латиница и коллизии NFC/casefold отклоняются. Координаты подтверждения наследуют инвентарь backend: строка от 1, столбец от 1 по byte-offset AST Python. Диапазоны замен backend — индексы Unicode-символов: связи относятся к исходному тексту, лексические привязки — к тексту после связей.

Pattern bindings, параметры типов и непокрытые Unicode-идентификаторы изменённых исходников дают консервативный отказ даже при пустой карте: отсутствие записи в прежнем ASCII-инвентаре не становится положительным допуском. Строки и комментарии с Unicode сохраняются; проверка идентификаторов использует токены Python и нормализованные имена AST, включая комбинируемые знаки исходного имени.

Полное замыкание: пять scripts существующего переводчика (`перевести-объявления-кода.py`, `пакет_перевода_python.py`, `безопасные_привязки_python.py`, `разбор_сценария.py`, `аббревиатуры_контекста.py`) и `аббревиатуры-контекста.json`. Каждый физический файл сверяется с точным обычным Git-blob принятого L и входным SHA-256. Python-модули загружаются из уже проверенных байтов; по окончании временные записи `sys.modules` восстанавливаются. Между вызовами кэша допуска нет.

План определяет изменённые имена по индексу и дереву L. Историческое объявление сохраняется только при совпавшей исходной строке, позиции и цепочке лексических владельцев: функции, классы, lambda и comprehension с закреплёнными заголовками. Перенос строки между владельцами требует нового подтверждения. Подтверждение без наблюдаемого нового объявления запрещено; карта не выводит связи по одному слову. Захват исторического одноимённого объявления закрыт до отдельного контракта выбора. Неизменённый потребитель включается лишь явной связью пакета и в разрешённой области.

`fum.план-русификации.1` содержит допуск, вход, хэш карты, запросы, исключения, весь первоначальный индекс, все рассмотренные исходники и результаты с исходными/итоговыми хэшами, режимами, связями, лексическими диапазонами и точным diff. Сырой индекс сохраняется в base64; SHA-256 связывается с независимо выбранным входом, Git checksum и собственный разбор v2/v3 подтверждают полный состав. Индекс v4, split/sparse, конфликтные и скрывающие флаги в этот конечный контракт не входят. Plan JSON настоящего кандидата остаётся приватным; опубликованные профили используют только открытые фикстуры.

Перед применением весь план содержательно воспроизводится; все пути, карта, HEAD/MERGE_HEAD, индекс, контур, исходники и режимы сверяются. Пути точны по регистру, без symlink и hardlink, без выхода в зависимости, источники, производную проекцию или Git. Удалённый собственный исходник закрывает этот срез. Строки, комментарии и wire keys сохраняются существующим backend; явная типизированная связь может изменить точный разрешённый строковый потребитель. Это подтверждённый статический контракт, а не вывод типов.

Внешний каталог транзакции получает режим 0700 и замок с PID. Намерение 0600 сохраняет исходные байты, хэши входа/карты/плана и фазу до первой замены. Файл, каталог и каждое намерение синхронизируются через fsync; замены атомарны для каждого файла с сохранением режима. Общая одномоментная атомарность нескольких файлов не заявляется. При аварии сохраняется известный префикс и требуется явное восстановление после доказанной остановки прежнего процесса. Префикс допускает только `до`/`после`; содержание исходного плана повторно выводится из закреплённого индекса. Третьи байты запрещают восстановление и не откатываются. Завершённое намерение сверяется без повторной замены.

Свидетельство `fum.свидетельство-русификации.1` связывает L, S, ожидаемый порядок родителей `[L,S]`, точный хэш плана, фазу и фактический хэш индекса. Проверяющий требует полное первоначальное свидетельство применения и заново воспроизводит содержательный план из его закреплённых исходных байтов индекса. После применения исходный индекс сохраняется; перед коммитом весь текущий индекс равен исходному с ровно плановыми результирующими blob. Blob OID вычисляется по Git-формуле в памяти. Поздний дрейф закрывает допуск. Свидетельство не доказывает создание будущего merge-коммита: его фактические дерево и родители проверяет принимающий вход после коммита.

Изоляция кооперативная: единственный писатель, выбранные доверенные входы и внешнее приватное состояние; процесс с теми же правами ОС не изолирован. Вызовы Git отключают replace, lazy fetch, hooks, fsmonitor, submodule recursion, global/system config и необязательные блокировки. Никаких изменяющих Git-команд внутри процедуры нет.
