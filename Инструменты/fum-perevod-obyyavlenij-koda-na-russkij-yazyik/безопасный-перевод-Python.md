# Безопасный перевод привязок Python

Python-ветвь переводчика выбирает заменяемые диапазоны по синтаксической роли и лексической области. Внешние атрибуты, импортируемые имена и ключевые аргументы внешних вызовов сохраняются. Например, при переводе локального `env` в выражении `subprocess.run(env=env)` меняется только значение аргумента.

Обычная карта и команды `план`/`применить` сохраняют прежний формат. Перед применением требуется просмотреть исходный и итоговый хэши, а после него проверить затронутых потребителей. Согласованное переименование одинакового имени в нескольких независимых областях разрешено обычной картой; для частичной миграции нужен отдельный выбор областей. Общий снимок исторического остатка автоматически не обновляется.

## Область действия

Вспомогательный модуль `scripts/безопасные_привязки_python.py` различает модуль, функцию, лямбду, класс и генератор. Он учитывает параметры, исключения, явные псевдонимы импортов, `global` и `nonlocal`. Импорт без псевдонима сохраняет внешний контракт. Смешение импортной и собственной привязки закрывает преобразование отказом.

AST задаёт точные диапазоны исходного текста; байтовые столбцы переводятся в символьные. Исходный текст не пересоздаётся через `ast.unparse`. Комментарии, обычные строки и всё вне выбранных диапазонов сохраняются. Выражения внутри форматных строк учитываются; изменение отладочной строки с выводимой меткой запрещено. Исходник и итог компилируются без исполнения, чтобы выявлять ограничения, которые один `ast.parse` не проверяет.

Именованные аргументы переводятся только для разрешённого прямого вызова собственной функции или простого конструктора с собственным инициализатором. Передача функции с изменённой сигнатурой другому потребителю требует явного разбора. Собственные поля поддержаны только у непосредственного, не перепривязанного получателя метода; `сам.tmp.name` не становится собственным полем по одному префиксу `сам`.

Позиционные параметры до `/`, имена `*args` и `**kwargs` не задают перевод ключей переданного словаря. Сигнатурный риск передачи относится к действительно принимаемым по имени параметрам; локальное имя собираемой распаковки само по себе вызываемую сигнатуру не меняет. Прямая lambda и её единственная неперепривязанная именованная привязка согласуются с собственными вызовами. Декоратор функции либо класса не доказывает вызываемую сигнатуру. `global` учитывается во всех промежуточных функциях; `nonlocal` пропускает пространства классов.

Неизвестный владелец своего поля, неограниченный импорт, неоднозначный вызов, динамическое пространство имён, строковые аннотации и перечни имён, рефлексия, сопоставление образцов и присваивание в выражении требуют отдельного допуска. Отказ означает, что нужно уточнить проверяемую карту либо расширить автоматизацию через RED/GREEN. Он не разрешает ручную серию замен.

Это ограниченный статический анализ одного файла. Он не доказывает полноту межфайловых импортов, строковых потребителей и внешних вызовов. Готовность миграции требует отдельного перечисления этих связей, проверки исходных хэшей и адресных регрессий. В частности, переименование собственной функции `git` должно учитывать `patch.object(module, "git", ...)`.

## Пакет связанных файлов

Команда `scripts/пакет_перевода_python.py план --корень-репозитория . --карта <карта.json> --выход <план.json>` готовит весь пакет без записи исходников. Команда `применить` с теми же аргументами повторно проверяет все входы и применяет подготовленные диапазоны. Выход плана должен быть отдельным файлом. CLI пересоздаёт и перезаписывает этот выход, поэтому сам не сравнивает его с прежним просмотренным результатом. Вызывающий сохраняет просмотренные байты отдельно; для строгой сверки использует функции `подготовить`, `описание` и лишь после равенства вызывает `применить` того же модуля. CLI не обновляет общий снимок объявлений.

Схема `fum.пакет-перевода-python.1` содержит список файлов. Каждый файл задаёт точный относительный путь, SHA-256 исходных байтов без префикса, карту `переводы`, выбор `области`, перечни `связи` и `передачи`. `области: null` выбирает все собственные привязки; объект ограничивает перечисленные имена координатами их лексической области. Пара `(0, 0)` означает модуль. Необязательные `имена_областей` задают отдельное русское имя для точной тройки «строка, байтовый столбец, прежнее имя».

Связь закрепляет поставщика, выражение владельца, старое и новое имя и точное количество. Поддержаны атрибут и простая строка имени в `.object(владелец, "имя", …)`. Смысл связи и полноту списка подтверждает ревью; совпадение AST и счётчика не выводит тип объекта. Встроенный Python допускается только через `код` с координатой и хэшем полного строкового значения. Обычные строки автоматически не превращаются в код.

`передачи` содержит точные координаты Name либо lambda, обозначенной `<lambda>`. Это проверенный человеком контракт позиционного вызова потребителем, а не вывод сигнатуры внешней функции. Допускаются непосредственный аргумент вызова и явно выбранное значение lambda по умолчанию; получатель в `callback.__call__` допуском не считается. Неизвестные или неиспользованные селекторы отклоняются.

Необязательное поле `исполнения` содержит пары «строка, байтовый столбец» прямых `exec`/`eval` с двумя или тремя позиционными аргументами. Это явное подтверждение проверенной человеком отдельной тестовой среды; автоматизация не доказывает отсутствие мутаций или алиасов словаря. Пустой словарь сам по себе допуска не даёт. Координаты закрепляются исходным хэшем, переносятся через правки связей и обязаны обозначать ровно поддержанный вызов. Для отдельно просмотренного модуля допускается также пространство `имя_модуля.__dict__`; принадлежность конкретному вновь созданному модулю подтверждается человеком по точным байтам, а не выводится по одному имени атрибута. Неявное исполнение в локальном пространстве не поддержано. После выбора индивидуальных имён областей дополнительно запрещается слияние разных прежних имён в одну эффективную цель.

Необязательное поле `внешние_вызовы` задаёт координаты прямых вызовов простого имени, чья внешняя принадлежность установлена вручную. Например, в профиле это сохранённый исходный `subprocess.Popen` с неизменённой передачей `*args, **kwargs`. Селектор и хэш закрепляют точное вызываемое имя, форму вызова и источник; имя локального псевдонима само по себе внешнего контракта не доказывает. Без селектора и для неизвестной координаты прежний отказ сохраняется.

Пакет запрещает повторные пути, неверный регистр, символические ссылки, несовпадение входных хэшей, коллизии и неизвестные поля. Перед заменой перечитываются все исходники. Запись каждого файла атомарна; пакет не обещает общей файловой транзакции при аппаратном сбое или ошибке ОС во время последовательных замен. Требуется один писатель дерева.

Исторический пример с классификацией и командами воспроизведения — [миграция унаследованного Python в принятом коммите](https://github.com/fum-lab/fum/blob/f80bdf424350a6c07fb5e5acf25e5b252cfd03be/Инструменты/fum-perevod-obyyavlenij-koda-na-russkij-yazyik/миграция-унаследованного-Python.md). Его карты и дополнительные миграционные утилиты не входят в минимальное подключение этой ветки.

## Проверка и профиль

Адресный набор — `tests/test_безопасный_перевод_python.py`. Он проверяет внешние API, затенение импортов, области генераторов, собственные ключевые аргументы, строковые связи и отказы при потере владельца. При запуске в рабочей сессии используется обязательная отчётная обёртка.

Сценарий `tests/измерить_безопасный_перевод_python.py --выход <файл.json>` выполняет пять последовательных повторов на 400 функциях без исполнения входного кода. Результат содержит хэши входа, результата, исполнителя и сценария, версию Python и монотонные длительности стадий. Параметр `--функций` задаёт размер. Повторы сравниваются только при одинаковых входе, сценарии и результате; перекрывающиеся проверки не складываются с календарным временем этапа.
