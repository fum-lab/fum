## Исторический профиль

Файл `Журнал/2026-09-10_20-23-26_MSK_проверить-слияние-после-допуска/материалы/продвижение-до-оптимизации.py` сохранён побайтно: 17446 байт, SHA-256 `c8695da01383f3c131d8eb82dc9df90d43adbe7ebcbf54661349ec6199002fce`. Новый [адаптер](../fum-otchyotyi-o-zapuskakh-proverok/scripts/адаптер_исторического_продвижения.py) сначала проверяет этот хэш и выдаёт шесть прямых ссылок на известные экспорты и стандартный модуль `subprocess` для счётчика процессов.

Фикстура использует позиционные аргументы и неизменённый keyword `наблюдатель`; новые русские keyword для исторических функций не обещаются. Адаптер не оборачивает функции и сохраняет их `__globals__`. Его создание и проверка хэша исключены из измеряемого интервала. Полные регрессии проверяют настоящий мигрированный модуль: подмена экспортов адаптера не меняет внутренние глобальные ссылки исторических функций.

Живой профиль запускается обычной командой:

```sh
python3 -B Журнал/2026-09-10_20-23-26_MSK_проверить-слияние-после-допуска/материалы/измерить-продвижение.py
```

Семь чередующихся пар и семантическое сравнение результатов сохранены: медианы 452,296 мс и 41 Git-процесс для исторической версии, 399,738 мс и 36 процессов для мигрированной. Получение экспортов через пространство имён адаптера остаётся частью вызовов фикстуры; его отдельная стоимость не измерена, нулевой накладной расход не обещается. Два измерителя остаются обычным собственным исполняемым кодом: 41 собственная запись живого профиля и четыре записи `измерить-совместимость-подготовки.py` пока не переведены. Во втором материале нет доказанной связи с мигрированными экспортами; координатор сохраняет его в классификации. Всего 45 собственных записей — открытый остаток, а не внешнее исключение по месту хранения. Защищённый before отдельно содержит 116 исторических записей прежнего сканера и пять дополнительно обнаруженных параметров lambda/исключений. import subprocess
import sys
import tempfile

исходник = корень / 'Журнал/2026-09-14_20-41-53_MSK_перевести-унаследованные-привязки-Python/материалы/безопасные-привязки-до-оптимизации.py'

    (временный / 'scripts').mkdir()
