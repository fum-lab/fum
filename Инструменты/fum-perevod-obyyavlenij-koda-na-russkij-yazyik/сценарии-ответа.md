# Закрытый формат сценариев ответа

[Инвентарь объявлений](SKILL.md) поддерживает восемь обычных UTF-8-файлов CommonJS: пять прежних сценариев ответа и два точных компонента [моста полного ответа узла](../fum-svyaznostj-rabochej-sessii/мост-полного-ответа-узла.md). Дополнительно поддержан точный незапускающийся [шаблон нативной подготовки](../fum-svyaznostj-rabochej-sessii/нативная-подготовка-базиса.md). Конечный набор путей хранится в `пути_сценариев` модуля [разбора](scripts/разбор_сценария.py). Историческая политика братиславской проекции сохраняет прежний набор пяти сценариев; новые три файла этими этапами в её вывод не добавляются. Символическая ссылка в любом компоненте пути, иной регистр, вложенный двойник и соседний файл закрывают допуск. Суффикс `.cjs` сохраняется; байты исходника не переводятся.

Разбор потребляет весь поток токенов, включая тела вложенных функций, значения по умолчанию и обе стороны выражений. Учитываются объявления `const` и `let`, имена функций, параметры, вложенные объектные и массивные связывания, остаточные параметры, стрелочные функции, параметры `catch`, переменные циклов, поля объектов и именованные присваивания. Запись содержит имя, роль, класс, источник исключения и координаты в точном тексте. CRLF считается одним переводом строки; CR, LF и оба разделителя Unicode завершают строчный комментарий.

Подъязык включает блоки, условные операторы, `while`, `for` с объявлением, обработку ошибок, возврат и выброс, вызовы, чтение полей и индексов, обычные литералы, массивы, объекты и применяемые арифметические и логические операции, а также побитовые `&`, `|`, `^`, побитовое отрицание, `<<`, `>>`, `>>>` для точного SHA-256 нового моста. Обязательные точки с запятой записываются явно. Автоматическая вставка после `return`, перевод строки после `async`, классы, генераторы, методы объектов, метки, шаблонные строки, экранированные идентификаторы, многострочные строковые продолжения, строковые и вычисляемые ключи объектов, деструктурирующие присваивания и циклы без объявления не поддержаны. Неизвестный токен или конструкция закрывают допуск целого файла.

Вычисляемая запись по индексу с идентификатором описывает динамический ключ; она не объявляет статическое имя поля. Запись по литеральному индексу, включая скобки вокруг литерала, закрыта. Анализ не исполняет программу и не доказывает значения динамических ключей, поведение `require` или вызываемых функций. Это ограниченный синтаксический инвентарь; самостоятельная проверка поведения сценариев сохраняется.

Внешнее имя не разрешает одноимённое собственное связывание. Для полей литерала объекта исключение требует полной формы из конечного набора `формы_внешних_объектов`, без повторных ключей и незарегистрированных развёрток. Формы относятся к [контракту ответа](../../Проекты/рабочий-контекст/контракты/описание-ответа.json), [контрактам среды и приватного кэша](../fum-svyaznostj-rabochej-sessii/компактный-ответ-задачи.md) и именам параметров стандартных API Node.js. Для нового моста отдельно разрешены только полные формы команды с `cmd`, `workdir`, `tty`, `max_output_tokens`, `yield_time_ms` и отпечатка с `байты`, `sha256`. Одноимённое `tty` в иной форме остаётся собственным полем. Чтение ключа при деструктуризации отделено от нового связывания. Исключения присваиваний `module.exports` и `process.exitCode` требуют именно этой полной цепочки от известного корня; одноимённое поле результата вызова не получает исключения.

Поля `симулированный_api` и `живые_api` остаются точными ключами уже опубликованного профиля версии 1. Их отдельный класс `закреплённый-контракт` связан с материалом коммита `2e01e5dc9a130ea0fb2f6c10514d7db56817361b`; это не разрешение вводить новые латинские собственные имена. Реестр форм и источников конечен и находится в модуле разбора. Добавление формы требует конкретного контракта и регрессии, а неизвестная форма сохраняет поля в собственном остатке.

Нативный шаблон отдельно разрешает только полную host-форму `cmd workdir shell login max_output_tokens yield_time_ms`. Поля `argv` и `env` эту форму не расширяют. Значения `/bin/sh`, `login: false`, число вызовов и неизменный outer await проверяются exact-композицией моста; языковой инвентарь этих свойств не доказывает. Tracked CJS заканчивается точным `;\n`; generated async module не подаётся CommonJS-барьеру.

Второй синтаксический барьер — отдельный процесс Node.js с проверкой CommonJS через стандартный ввод. Сценарий не исполняется; из окружения не наследуются параметры загрузки Node. Ограничения входа: 262 144 байта UTF-8, 65 536 токенов, 64 уровня скобок, 10 секунд на проверку Node. Сбой внешнего процесса не превращается в успешный разбор. Строки диагностики исходного кода наружу не передаются.

Переименование поддерживает связывания с явной картой и проверенным хэшем. Ключи полей, member-доступ, строки и комментарии защищены. Сокращённое связывание сохраняет исходный ключ через явный псевдоним. Переименование собственных полей и сокращённых внешних полей отклоняется до записи: для него нынешний разбор не доказывает владельца каждого употребления. Новый результат снова проходит оба синтаксических барьера.

[Прежние адресные регрессии](tests/test_сценарий_ответа.py) и [регрессии новых компонентов](tests/test_сценариев_полного_ответа.py) проверяют опасные и допустимые формы. [Малый профиль](tests/измерить_сценарий_ответа.py) измеряет синтаксические стадии отдельно от проекции; точные границы текущей схемы описаны ниже. Исполнение адаптера этими измерениями не охватывается.

## Допуск живого восстановления

Девятый точный CJS-путь — `Инструменты/fum-svyaznostj-rabochej-sessii/scripts/мост_живого_восстановления_писателя.cjs`. Только этот профиль и два AST-локатора, перечисленные в [навыке](SKILL.md), добавляют `continue;` без метки в цикле и префиксные `++`/`--` с проверяемой левой частью. Прежние восемь сценариев сохраняют прежний подъязык. Регулярные выражения, деление и побитовые операции не получают нового общего синтаксиса.

Новые конечные формы объектов — `threadId hostId turnLimit includeOutputs maxOutputCharsPerItem`, `threadId hostId prompt model thinking` и четыре метода инструментов `exec_command write_stdin mcp__codex_app__read_thread mcp__codex_app__send_message_to_thread`. Только полное множество без повторов и развёрток защищает внешние ключи. Неизвестные поля и собственные привязки остаются в инвентаре. Сокращённое собственное поле может сохранять прежний ключ при переводе одноимённой локальной привязки; явно записанные собственные поля не мигрируются.

Малый профиль схемы `fum.профиль-сценариев-ответа.2` отделён от проектора. Без аргументов выбора он читает восемь прежних файлов. Для закреплённых незавершённых входов используются вместе `--манифест`, `--sha256-манифеста` и `--карта`; `--выход` всегда задаёт новый файл. Манифест проверяет SHA и размеры ровно CJS и Python-хоста; три JS-текста проходят полный разбор без исполнения. Профиль сохраняет точные SHA реализации, входов, отдельных вставок, карты, план схемы `1`, наблюдаемый остаток и семь монотонных замеров каждой стадии. Применение проверенного плана происходит только в собственном временном корпусе. Чтение, импорт, подготовка корпуса и запись JSON исключены из таймеров; перекрывающиеся стадии не суммируются. Для сравнения повторяемости запускайте три свежих процесса через отчётную обёртку. Готовность узла и ускорение полного процесса не выводятся из этих измерений.

Проектор, его контракт и baseline не изменяются; новые пути его историческую политику не расширяют.
