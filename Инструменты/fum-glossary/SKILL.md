# FUM Glossary

Эта локальная копия инструмента используется при добавлении, переименовании, разделении или обновлении терминов в глоссарии репозитория FUM.

Локальная копия имеет приоритет над внешним `fum-glossary`, если внешний инструмент требует ASCII-транслитерацию русских имен файлов или указывает на каталоги вне этого репозитория.

## Файлы

- Индекс: `/Users/fum/Projects/FUM/Глоссарий/README.md`
- Каталог статей: `/Users/fum/Projects/FUM/Глоссарий/`
- Один термин хранится в одном Markdown-файле.

## Рабочий порядок

1. Перед изменениями выполнить `git status --short` в `/Users/fum/Projects/FUM`.
2. Создать или обновить файл статьи в `Глоссарий/`.
3. Начинать каждую статью с заголовка `# <Термин>`.
4. Держать статью короткой и документационной: сначала значение термина в FUM, затем внешние или исторические примечания, если они нужны.
5. Добавить или обновить ссылку в `Глоссарий/README.md`.
6. Сохранять алфавитный порядок ссылок в разделе терминов, если локальный порядок не требует другого.
7. Сохранять существующие термины, если пользователь явно не просит переписать, разделить или удалить их.
8. При изменении производной документации расставлять ссылки на каждое содержательное употребление уже заведенного термина, если ссылка помогает восстановить смысл.
9. Ссылать склоняемые формы терминов по правильной форме в тексте, но вести их на файл статьи термина в именительном падеже.
10. Коммитить только осмысленные изменения текущей сессии и не включать посторонние грязные файлы.

## Имена файлов

Имена файлов статей глоссария подчиняются правилам `AGENTS.md`: русские слова и описания пишутся кириллицей.

- `Сознание` -> `сознание.md`
- `Орган FUM` -> `орган-FUM.md`
- `Фоновый авто-коммит памяти` -> `фоновый-авто-коммит-памяти.md`
- `FUM` -> `FUM.md`
- `FUM-узел` -> `FUM-узел.md`

Используй дефисы между словами и расширение `.md`. Не используй ASCII-транслитерацию для русских слов. Название `FUM`, технические идентификаторы, команды, форматы и аббревиатуры сохраняются в их принятом написании.

Если термин уже связан из `Глоссарий/README.md`, используй существующее кириллическое имя файла, если пользователь не попросил переименовать его.
