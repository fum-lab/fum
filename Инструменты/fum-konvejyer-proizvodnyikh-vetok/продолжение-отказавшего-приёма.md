# Связать отказ с новым завершённым ходом

`scripts/продолжение_отказавшего_приёма.py` получает полные байты native ребёнка,
локатор прежней остановки, корневой UUID, точный текст нового поручения,
разобранные send/postwait и локатор завершённого CLI. Это чистая функция:
она не читает файлы, не вызывает Git и не устанавливает терминал поколения.

В остановленном префиксе проверяются граница завершённой строки, SHA256,
метаданные ребёнка и наличие прежнего конечного хода. Настройки после него
обязаны принадлежать тому же UUID и физическому корню. В новом хвосте допускается
ровно одно адресное поручение от корня и один завершённый ход. Он совпадает
с собственным postwait, отличается от прежнего и окружает выбранное исполнение
CLI: получение поручения → CLI → `task_complete`. Байтовый порядок send/wait
и их runtime-интервалы проверяются раздельно; CLI может выполняться во время
send или wait, но обязан оставаться внутри их общей временной границы.

Поддержаны `direct` и `saved-wrapper` из [первичных читателей отказа](первичные-отказы-приёма.md).
Сохранённый вариант получает точные байты stdout и локатор артефакта. Результат
сохраняет исход прежнего слияния `unknown` и `повтор_эффекта_разрешён: false`.
Неопределённость не превращается в разрешение повторить эффект.

Вызывающий обязан независимо получить send/wait из полного корневого native,
проверить первоначальное назначение и остановку, физические источники,
владение, архив сохранённого писателя и квитанции FS/Git. Перед одним терминалом
`.9` эти свидетельства повторно сверяются под замком координатора. Переданные
данные и их совпадение не заменяют этот общий допуск.

Транспортный читатель `прочитать_рамки_входа` строит рамки внутри того же
проверяющего прохода по исходным bytes; внешний кэш разобранных записей
не принимается. Прежний API `прочитать_байты_входа` сохраняет форму результата.
Таким образом, для связи нужны два полных JSON-разбора вместо трёх; SHA конечной
строки вычисляется непосредственно по выбранным исходным байтам.

Из чистого клона, из физического корня FUM:

```sh
python3 -B -m unittest discover -s Инструменты/fum-konvejyer-proizvodnyikh-vetok/tests -p test_продолжения_отказа.py -v
python3 -B Инструменты/fum-konvejyer-proizvodnyikh-vetok/tests/профиль_продолжения_отказа.py --выход /private/var/tmp/новый-профиль-продолжения.json
```

Необязательный словарь `профиль` получает монотонные времена транспорта,
сопоставления ходов и CLI. Поле `всего` охватывает проверяющий контур до
построения результата: заключительный SHA полного источника и упаковка
возвращаемого объекта в него не входят. Открытый профиль содержит два варианта
по семь повторов, размеры и SHA одинаковых входов около 1,64 МБ. Подготовка
фикстуры и файловый вывод исключены. Он не измеряет ROOT, FS/Git, установку
терминала, LLM, токены или полный цикл конвейера.
