# Наблюдённая область дочернего писателя

Команда `область` читает назначение из коммита постановки C, повторно проверяет
настоящую дочернюю задачу и возвращает снимок её области. Она помогает обнаружить
выход за назначенные каталоги до подключения записи Журнала и допуска коммита.
Экспорт имеет `разрешение_записи=false`: действующие правила и обычные проверки
коммита продолжают применяться без исключений.

## Закрепить назначение

Дополнительный JSON-файл входит в тот же манифест C, что и
[план двух слоёв](запуск-двух-слоёв.md). Он содержит ровно четыре поля:

| Поле | Содержание |
| --- | --- |
| `схема` | `fum.назначение-областей-слоёв.1` |
| `задача` | Корневой UUID координатора |
| `план` | Точный относительный путь плана в манифесте |
| `журналы` | Объект: идентичность каждого слоя → точная `Журнал/<stem>/` |

Папки Журнала различаются и отсутствуют в C. Все предметные и журнальные области
проверяются на пересечение с учётом NFC и регистра. Каталог и ref берутся из плана;
произвольного поля для расширения области нет. Подмена рабочего JSON-файла после C
не меняет закреплённое назначение. Не входящий в манифест файл отклоняется.

## Получить читающий снимок

После сохранённого наблюдения настоящего ребёнка координатор вызывает:

```text
python3 -B Инструменты/fum-konvejyer-proizvodnyikh-vetok/scripts/запустить-слои.py --корень-репозитория . --задача <корневой-UUID> область --запуск <ключ> --слой <ID> --назначение <путь-в-C> --источник <первичный-JSONL-ребёнка>
```

Вывод с локальными путями сохраняется приватно вне Git. Назначение, начальный C,
UUID исполнителя, физическое дерево, ref и нативное поручение перепроверяются по
сохранённому запуску и первичному JSONL. Корневой UUID и UUID исполнителя имеют
разные поля; один не подменяет другой. Координатор может продвинуться дальше C в
той же ветке при неизменном исполняемом наборе. Ребёнок обязан сохранять C предком
своей вершины. Повтор не создаёт запуск, папку Журнала или новую квитанцию.

Схема ответа — `fum.наблюдённая-область-писателя.1`. Она связывает базу, назначение,
наблюдение и хэш снимка. Снимок отдельно учитывает C → HEAD, HEAD → индекс,
индекс → рабочие файлы и неигнорируемые untracked. Rename рассматривается с обеих
сторон. Символические ссылки, неподдержанные флаги и конфликтные стадии индекса
дают отказ. Чтение явно учитывает подмодули и executable-бит, отключает fsmonitor; настройки Git не ослабляют эти границы. Байты затронутых рабочих файлов также входят в снимок. Перед возвратом
повторяются чтение снимка, первичного подтверждения и состояния координатора.

## Граница доказательства

Это наблюдение Git-состояния при кооперативной работе единственного писателя.
Оно не изолирует произвольный shell, не блокирует изменение после возврата и не
доказывает отсутствие кратковременной записи между двумя чтениями. Итоговая дельта
C → HEAD не проверяет внесённые и затем отменённые изменения промежуточных коммитов.
Игнорируемые runtime-файлы не входят в эту область наблюдения. Полная побайтовая
приёмка индекса, фильтров и всех файлов вне области остаётся задачей допуска
коммита; этот экспорт её не заменяет.

Следующий стык должен использовать тот же подтверждённый контракт перед записью
генераторов и при создании коммита. Отложенная общая навигация и индекс потребуют
отдельного изменения канонических правил. До этого реальный пилот двух пишущих
задач и обратная merge-доставка не объявляются выполненными.

## Проверка и профиль

Зависимости экспорта загружаются только командой `область`; недоступность этой части не мешает прежней команде `состояние`. Исполняемые файлы экспорта сверяются до и после чтения.

`tests/test_области_писателя.py` и `tests/test_границ_области.py` используют настоящий временный Git, linked worktree
и синтетические нативные JSONL. Прежний допуск совпадения всего исполняемого checkout
с C подменяется только в фикстуре; внешний Codex Desktop не вызывается.

`tests/профиль_области_писателя.py --выход <новый JSON>` измеряет первое и повторное
чтение, затем отказ при изменении чужого файла. Создание временного Git исключено.
Профиль сохраняет хэши исходников; малая фикстура не доказывает производительность
на полном FUM.
