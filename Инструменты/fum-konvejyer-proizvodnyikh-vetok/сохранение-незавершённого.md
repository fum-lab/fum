# Сохранение незавершённых результатов

Пакет сохраняет изменённые файлы назначенных каталогов остановленного писателя,
в том числе различные версии рабочего файла и stage-0. Исходный checkout, индекс,
ref и HEAD остаются только для чтения. Пакет не восстанавливает дерево и не даёт
полномочий завершить поколение или запустить нового писателя.

`scripts/пакет_незавершённого.py` предоставляет `собрать(корень, задача, база,
каталоги)`. База — точный SHA-1 коммит C, равный HEAD. Результат — описание
`fum.пакет-незавершённых-результатов.1` и словарь SHA256 → исходные bytes.
Одинаковые байты хранятся один раз. Описание содержит владельца снимка, C,
назначенные каталоги, хэши Git-границ, режимы и независимые состояния рабочего
файла и индекса. Отсутствие файла явно отличается от отсутствия stage-0.

Перед сбором и после него сравниваются снимки области; при чтении индекса
дополнительно сверяется его хэш. Проверяются полный состав вложенного описания,
SHA256 байтов и Git blob OID с заголовком. Чужие пути, конфликтные стадии,
неподдержанные режимы, ссылки и наблюдённый сдвиг дают отказ.

`scripts/хранилище_незавершённого.py` предоставляет `сохранить(цель, описание,
данные)` и `прочитать(цель, ожидаемый_sha256)`. Цель — новый каталог вне Git
в существующем приватном каталоге текущего UID с правами 0700. Каталоги пакета
имеют 0700; `описание.json` и `объекты/<sha256>` — 0400. Объекты записываются
исключительно через создание нового файла, затем fsync; описание записывается
последним. Синхронизируются каталоги, пакет перечитывается полностью.

Повтор для того же целого пакета сохраняет байты и inode, заново выполняет fsync
файлов и каталогов и перечитывает результат. Поэтому предыдущая ошибка fsync
не подменяется успехом одного чтения. Неполный, повреждённый, иной или лишний
состав не перезаписывается. Остаток прерванной записи остаётся свидетельством;
автоматического удаления или достраивания частичного пакета нет.

Граница: кооперативная работа остановленных писателей одного пользователя.
Снимок не блокирует позднее возобновление и не обнаруживает любую кратковременную
правку с возвратом прежних байтов. В пакет не входят игнорируемые runtime-файлы,
пустые каталоги, расширенные атрибуты или внутренний бинарный файл Git index.
Он сохраняет содержимое и режимы изменённых обычных файлов поверх доступного C.
Происхождение назначения и подтверждение остановки проверяет отдельный переход.
Успешный fsync — наблюдение API ОС, а не испытание оборудования отключением питания.

Адресные тесты: `tests/test_пакета_незавершённого.py` и
`tests/test_хранилища_незавершённого.py`. Профиль:
`tests/профиль_незавершённого.py --выход <новый-JSON>`, через отчётную обёртку.
Открытые фикстуры проверяют отдельные версии, удаления, бинарные данные,
прерывание, повреждение, повтор и ошибки fsync; не запускают Codex Desktop.
