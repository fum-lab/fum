# Предложение восстановления поручения

Чистая функция `предложить(документ, поручение)` в
`scripts/восстановление_поручения.py` принимает два значения bytes с UTF-8, LF
и последним LF. Возвращает пару: предлагаемые байты документа и свидетельство
`fum.предложение-восстановления-поручения.1`. Функция не читает хранилища,
не пишет файлы или Git и всегда возвращает `разрешение_записи=false`.

Поддерживается единственная известная ошибка старого распознавателя свежести
из `5419ed11bfbe484baa6d133dc5bd0c574a89d794`: удаление первого совпавшего
блока меток внутри дословного поручения. Точный старый распознаватель нужен
только для вычисления этого кандидата; для обновления свежести он не применяется.

Функция требует единственный внешний заголовок «Текст запроса». Ограждённые
цитаты маскируются общим читателем, длина канонической ограды берётся из
генератора Журнала. Всё поле должно побайтно совпасть с оригиналом либо
с результатом известного удаления; следующий раздел — «Идентификатор сеанса
Codex». Незнакомая правка, неоднозначность, незакрытая ограда или иной перевод
строк дают отказ. Исправленный документ повторно возвращается без изменений.

При восстановлении добавляются только удалённые байты. Свидетельство содержит
SHA256 до и после, SHA256 поручения, точное байтовое смещение, размер вставки,
число LF и хэши неизменных префикса и суффикса. Наружная свежесть сохраняется
буквально и здесь не пересчитывается.

Происхождение поручения, полномочия писателя, привязку к C, состояние индекса
и применение должен отдельно проверить вызывающий контур. Предложение
не заменяет такой допуск, не удостоверяет исходные остальные байты и не разрешает
запуск исправленного инструмента R в старом дочернем назначении C.

Адресные проверки: `tests/test_восстановления_поручения.py`.
Профиль на открытых фикстурах: `tests/профиль_восстановления_поручения.py
--выход <новый-JSON>`. Обе команды запускаются через отчётную обёртку этапа.

Основание и наблюдаемые результаты — в [этапе восстановления](../../Журнал/2026-09-24_00-17-39_MSK_подготовить-восстановление-поручений-писателей/запрос.md).
