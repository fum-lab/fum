# Прочитать файлы исторического отказа

`scripts/прочитать_исторический_отказ.py` читает прежнюю квитанцию `.2` через
`прочитать(описание, текст, источник, профиль=None)`. Описание содержит точный путь
и SHA конверта, SHA намерения и SHA квитанции. Остальные адреса выводятся из
канонического поручения и сохранённого основания; произвольный набор файлов
не принимается. `источник` — ожидаемый адрес native ребёнка, его содержимое
этот слой не проверяет. Адрес выводится как `приёмы/<ключ>/нативный/источник.jsonl`;
реестр — строковый путь `приёмы/<ключ>/владельцы.json`, как в историческом входе.
Его байты и первоначальный `вход.json` сверяются с опубликованным конвертом.

Читатель проверяет готовый конверт, намерение и метку начала, legacy-привязку
получателя и активного плана, квитанцию, сохранённые параметры коммита. Каждый
JSON должен иметь канонические байты. Файлы принадлежат текущему UID, являются
обычными приватными файлами без hardlink; ссылки и неправильный регистр в пути
отклоняются. Предел одного свидетельства — 1 МиБ, файла legacy-замка — 32 КиБ.
Чтение проверяет inode, режим, размер, время изменения и SHA до возврата.
Открытие неблокирующее: подмена обычного файла на FIFO между `lstat` и `open`
должна вызвать отказ при проверке дескриптора, а не зависание читателя.
Каталоги сравниваются по идентичности и правам; изменение времени каталога
соседней задачей само по себе не является подменой.

Подготовка коммита, квитанция результата, маркер Журнала и назначенный каталог
Журнала должны отсутствовать. Проверка использует `lexists`: висячая ссылка
не считается отсутствием. Это условие проверяется до дорогих вызовов Git.
Получатель должен оставаться чистым на H своей единственной ветки, без
незавершённой Git-операции; учитываются ignored/untracked файлы. Приёмка A и
цепочка C → H → S сверяются по неизменяемым Git-объектам. В конце повторяются
файловая и Git-сверки.

Результат сохраняет `unknown` и `повтор_эффекта_разрешён: false`. Читатель
не создаёт файлы, не захватывает legacy-замок и не вызывает Git-эффект.
Наличие файла замка не доказывает, что он свободен. Этот слой не создаёт
атомарного снимка нескольких хранилищ и не доказывает допуск терминала `.9`:
вызывающий отдельно проверяет native, остановку писателей, историю и повторяет
сверку перед записью терминала под своим замком. Исход неизвестной доставки
не переобъявляется отсутствием эффекта.

Открытая фикстура использует реальные C, H, S, A, но синтетический native.
Воспроизведение адресных тестов:

```sh
python3 -B -m unittest discover -s Инструменты/fum-konvejyer-proizvodnyikh-vetok/tests -p test_чтения_исторического_отказа.py -v
python3 -B Инструменты/fum-konvejyer-proizvodnyikh-vetok/tests/профиль_чтения_исторического_отказа.py
```

Необязательный словарь `профиль` получает времена первичного чтения, Git и
приёмки, повторного чтения и заключительной сверки. Профиль не содержит
исходных приватных сообщений. Семь повторов измеряются после одного первого
вызова; построение фикстуры исключено. Отдельно измеряется ранний отказ без
Git. Это не парное сравнение версий и не замер полного цикла конвейера.
