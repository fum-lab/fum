# Снятый барьер задач Git-ветки

Прежняя hook- и POSIX-зависимая автоматизация снята. Этот каталог не содержит `SKILL.md` и не является активным навыком. Файл оставлен как цель исторических ссылок и точка объяснения перехода.

Активный контракт сериализации работы закреплён в `AGENTS.md` и [переносимой FIFO-очереди](../fum-ocheredj-zadach-git-vetki/SKILL.md). Минимальный `scripts/branch-task-gate.py` только безвредно завершает уже кэшированный старый loader в открытой задаче; новые задачи его не используют.
