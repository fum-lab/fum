# Снятый барьер задач Git-ветки

Прежняя hook- и POSIX-зависимая автоматизация снята. Этот каталог не содержит `SKILL.md` и не является активным навыком. Файл оставлен как цель исторических ссылок и точка объяснения перехода.

Действующий контракт ручной последовательной работы закреплён в `AGENTS.md`; [переносимая FIFO-очередь](../fum-ocheredj-zadach-git-vetki/SKILL.md) также снята с активного маршрута и сохранена как история. Минимальный `scripts/branch-task-gate.py` только безвредно завершает уже кэшированный старый loader в открытой задаче; новые задачи его не используют.
