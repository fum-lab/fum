# Ограниченная инвентаризация связанного дерева

Незавершённый синтетический прототип для macOS и Swift принимает абсолютные пути worktree, его gitdir и common Git-dir. Через `openat` и `O_NOFOLLOW` он сверяет точные записи `.git`, `gitdir` и `commondir`, читает ограниченные файлы HEAD, index, config с проверкой метаданных и печатает их размеры и хэши. Для `config.worktree` отдельно сообщает об отсутствии или читает файл; действие `extensions.worktreeConfig` остаётся UNKNOWN до установления полной эффективной конфигурации. Проверяет отсутствие некоторых известных атрибутов и alternates. Git не запускается; результат при штатном окончании всегда UNKNOWN с кодом 3, отказ — HOLD с кодом 2.

Сборка: `xcrun swiftc main.swift -o /путь/частной/сборки/inventory`. `фикстура.sh` предназначена только для новой пустой частной директории с подпапками `home` и `tmp`; запускать её с `env -i`, отдельными HOME и TMPDIR, `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_ATTR_NOSYSTEM=1`, отключёнными hooks и явным PATH. Для прототипа передать три абсолютных пути синтетической фикстуры. На фактическом worktree инструмент не применялся.

Прототип не проверяет принадлежность и режим каждого промежуточного каталога, удержание имён каталогов после открытия, полные includes, вложенные attributes, refs и objects, семантику index, expected HEAD/ref, исполняемый Git и зависимости. Он допускает только точную синтетическую форму связей и может отклонить другую корректную topology. Наблюдение файлов не исключает ABA и другого писателя; custody и эквивалентность diff UNKNOWN. Guard закрыт.
