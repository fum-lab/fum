# Синтетический снимок linked worktree

Незавершённый исследовательский срез для macOS: фиксированная фикстура содержит один изменённый файл и три loose object. Программа проверяет известные конфигурацию, связи и некоторые отсутствующие источники, читает фиксированный набор файлов с `O_NOFOLLOW`, создаёт частную копию с `O_EXCL` и обратным чтением и переписывает ссылки linked worktree для новой директории. Программа сама Git не запускает.

В частной фикстуре setup с `env -i`, `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=/dev/null` и `GIT_ATTR_NOSYSTEM=1` завершился с кодом 0. Программа создала 11 файлов, затем отдельный Git diff вернул код 0 и пустой stderr; stdout совпал с заранее заданным diff изменения `original` на `changed`. Изменённый локальный config с фильтром и символьная ссылка вместо `work/.git` в отдельных копиях привели к коду 2 до создания снимка; Git для этих случаев не вызывался. Это сравнение не устанавливает общую эквивалентность производственному маршруту.

Для воспроизведения нужны macOS, Swift и Git. Создайте отдельную пустую частную директорию с подпапками `home` и `tmp`; в ней запускайте `фикстура.sh` только с явным `env -i`, путём `/usr/bin:/bin`, отдельными HOME и TMPDIR и перечисленными выше настройками Git. Исходник собирается `xcrun swiftc main.swift -o /путь/частной/сборки/snapshot`; аргументы — абсолютные пути подготовленной fixture и ещё не существующей директории снимка. Тестовые копии не должны ссылаться на рабочие данные.

Ограничения: исходник не гарантирует общую неизменность или атомарность источника, не исключает ABA и гонки, полностью не инвентаризирует возможные источники конфигурации, атрибутов и объектов и не закрепляет исполняемый Git и его зависимости. Проверка отсутствия вложенных путей не удерживает все промежуточные каталоги; нет ограничения времени и вывода Git и синхронизации всех каталогов снимка. Отказ после создания снимка может оставить частичные файлы. Результат не является production custody, допуском Git или открытием guard.
