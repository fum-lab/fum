# Синтетическая проверка трёх каналов

Незавершённая проверка macOS/Swift создаёт три заранее заполненных и закрытых pipe, читает их одним `poll` до срока, сохраняет до четырёх байтов каждого и отдельно отмечает переполнение. Режимы `small` и `overflow` проверены по одному разу с кодом 0. Сборка: `xcrun swiftc main.swift -o /путь/частной/сборки/poll-check`; запуск — исполняемый файл с одним аргументом `small` или `overflow`.

Это не клиент witness: живого производителя, декодирования кадров, идентичности, обратного давления, команды остановки, терминальной очистки и тайм-аута процесса нет. При переполнении проверка продолжает читать до EOF. `EINTR` вызывает HOLD; при ошибке все дескрипторы явно не закрываются. Уход потомков из группы и production custody не доказаны, guard закрыт.
