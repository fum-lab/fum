# Модель защищённого Git diff

`FUMGitPlan` только строит argv, окружение и параметры потоков для защищённой ветви одного working-tree diff при явно переданных настройках Git. На проверенной macOS `os.defpath` равен `/bin:/usr/bin`. HOME, глобальный файл и системные настройки задаёт вызывающий; стандартная Python-настройка использует домашний каталог учётной записи и `system=true`, а synthetic fixture — другой явный профиль. Модель также вычисляет максимум `min(30, remaining)` и проверяет переданные код завершения, stderr и свежий остаток. Она не читает часы, окружение или файловую систему и всегда возвращает `admission=unknown`.

Входные пути — намеренно более узкое каноническое UTF-8 подмножество, чем нормализация Python. Физический `Path.resolve`, достоверное monotonic время до и после запуска, реальный процесс, UID, Darwin, identity бинарников, контроль источников и execution authority обеспечиваются отдельно. Строки session передаются в Git pathspec без дополнительного экранирования, как в исходной команде. Cached diff, HEAD, submodules, untracked framing и полный fingerprint не моделируются.

Исходная Python-обёртка не импортирует Swift-модуль. Helper-процесс или динамическая библиотека потребуют отдельного контракта и проверки семантики; этот модуль не подключён к production и не открывает guard. Проверка из корня пакета: `swift test --filter FUMGitPlanTests` с частным `--scratch-path`; нужны macOS и Swift 6.
