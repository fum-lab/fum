# Пути в копии связанного Git-дерева

Синтетическая фикстура создаёт собственные Git-репозиторий и linked worktree, копирует их и меняет конфигурацию исходного репозитория. Абсолютная ссылка `.git` в копии ведёт к исходному gitdir: контрольный diff исполняет тестовый filter и создаёт marker. Diff с явными gitdir и worktree внутри копии marker не создаёт. Оба вывода совпали, потому что тестовый filter передаёт байты через `cat`: совпадение не доказывает эквивалентность конфигурации или поведения.

В двух отдельных вариантах отсутствие marker и подмена локальной переменной статуса control приводят к коду 1 без PASS. Это симуляции отказа проверок после действительного успешного Git diff, а не настоящие ошибки Git. Скрипт запускается только в новой пустой частной директории: `/bin/sh /путь/к/фикстура.sh` с `env -i`, отдельными HOME/TMPDIR, `GIT_CONFIG_NOSYSTEM=1`, `GIT_CONFIG_GLOBAL=/dev/null`, `GIT_ATTR_NOSYSTEM=1` и явным PATH `/usr/bin:/bin`; зависимости — macOS и Git.

Копия не является неизменяемым snapshot. Полные config/includes/attributes, привязка исполняемого image, внешние ссылки и production custody не доказаны; guard остаётся закрытым.
