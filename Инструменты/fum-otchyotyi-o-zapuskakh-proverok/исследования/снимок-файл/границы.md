# Исследование копирования файла

Незавершённая синтетическая проверка: открываются каталоги и один обычный файл с `O_NOFOLLOW`, копия создаётся через `O_EXCL`, данные и каталог синхронизируются, результат перечитывается. Режимы `replace-file` и `replace-dir` намеренно меняют только переданную тестовую фикстуру. Использовать только в созданной для этого частной директории.

Пример сборки: `xcrun swiftc main.swift -o /путь/к/частной/сборке/copy-check`. Аргументы исполняемого файла: абсолютный путь частной фикстуры и один из режимов `normal`, `replace-file`, `replace-dir`. Фикстура содержит каталоги `source` и `destination`, файл `source/file`, для подмены файла — `source/replacement`, для подмены каталога — `replacement-dir`. Нужны macOS и Swift с модулем Darwin.

Это не снимок linked worktree и не допуск Git. Проверка не исключает ABA, гонки и смену предков исходного корня, не изучает конфигурацию Git, фильтры, атрибуты и исполняемый файл Git. Исключительное владение источником на время копирования не доказано. Ошибка после создания копии может оставить частичный файл; такой исход следует считать HOLD. Производственный guard остаётся закрытым.
