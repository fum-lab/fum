# Проверка Git-зависимостей

Автоматизация материализует внешнюю Git-зависимость как полноценный клон и Git submodule либо автономно проверяет уже подключённое состояние. Форк должен находиться у того же GitHub-владельца, что и публикационный `origin` актуальной рабочей копии FUM; оригинальный репозиторий сохраняется отдельным remote `upstream`.

Автономная проверка не обращается к сети. Она сверяет точные URL и роли remote, путь и URL в `.gitmodules`, сохранённый `fumUpstream`, detached `HEAD`, отсутствие shallow-режима и локальных изменений, достижимость выбранной ревизии из полученных refs форка, режим `160000` и SHA gitlink. Линия форка в GitHub, его синхронизация с родительским репозиторием, лицензия и публикационная допустимость остаются отдельными внешними предпосылками.

## Добавление зависимости

До запуска GitHub-форк уже должен существовать и быть синхронизирован с оригиналом. Мутирующий режим принимает только явные значения:

```bash
python3 Инструменты/fum-proverka-git-zavisimostej/scripts/proveritj-git-zavisimostj.py add \
  --repo-root . \
  --fork-url <публичный-HTTPS-URL-форка> \
  --upstream-url <URL-оригинала> \
  --path <относительный-путь-submodule> \
  --revision <полный-Git-OID>
```

Перед изменением основного репозитория команда клонирует оба источника во временный каталог и подтверждает, что выбранный коммит достижим из обычной ветки полученного форка. Несвязанные изменения основного репозитория сохраняются; конфликтующий путь, gitlink, раздел `.gitmodules` или остаточный Git-каталог закрывают добавление. Повторный точный вызов проверяет уже существующую зависимость и завершается без нового изменения.

## Проверка зависимости

Для LinguisticKit используется команда:

```bash
python3 Инструменты/fum-proverka-git-zavisimostej/scripts/proveritj-git-zavisimostj.py check \
  --repo-root . \
  --fork-url https://github.com/fum-lab/LinguisticKit.git \
  --upstream-url https://github.com/Roman-Kerimov/LinguisticKit.git \
  --path Зависимости/LinguisticKit \
  --revision 837e2ce107b97ee7b9d3344c9fe99142281fe393
```

Код `0` означает полное совпадение локальной Git-топологии и gitlink с контрактом. Код `1` сопровождается русской диагностикой каждого обнаруженного расхождения.

## Автономные тесты

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover \
  -s Инструменты/fum-proverka-git-zavisimostej/tests \
  -p 'test_*.py'
```

Тесты создают временные локальные bare-репозитории FUM, форка и upstream. Они проверяют успешное добавление, идемпотентность, допустимость несвязанных изменений, принадлежность форка владельцу актуального FUM, достижимость выбранного коммита из ветки форка, роли remote, `.gitmodules`, gitlink, точный `HEAD`, чистоту клона и CLI-режим без сетевых запросов.
