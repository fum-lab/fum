# Московское время рабочей сессии FUM

Получай обе формы времени одним вызовом:

```bash
python3 Инструменты/fum-moskovskoye-vremya-rabochej-sessii/scripts/get-session-time.py --format both
```

Скопируй значение `prefix` без изменений в имя папки запроса и связанные временные идентификаторы материалов. Используй соответствующее значение `label` в заголовках и текстовых ссылках. Не выводи MSK-время из локальных часов среды и не заменяй `Europe/Moscow` текущей зоной хоста.

Для воспроизводимой проверки конкретного момента передавай ISO 8601 с `Z` или явным смещением:

```bash
TZ=Europe/Saratov python3 Инструменты/fum-moskovskoye-vremya-rabochej-sessii/scripts/get-session-time.py \
  --at 2026-07-17T07:07:09Z \
  --format both
```

Ожидаемый результат:

```text
prefix=2026-07-17_10-07-09_MSK
label=2026-07-17 10:07:09 MSK
```

## Проверка

Запускай автономные тесты без сети и секретов:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover \
  -s Инструменты/fum-moskovskoye-vremya-rabochej-sessii/tests \
  -p 'test_*.py'
```

Тесты закрепляют преобразование UTC-момента в `Europe/Moscow`, независимость от зоны хоста, согласованность двух форм и отклонение неоднозначного времени без зоны.

## Граница автоматизации

Скрипт только вычисляет канонические формы одного момента. Создание папки запроса, навигация, журналирование и проверка ссылок выполняются автоматизацией структуры папок запросов и последующими шагами рабочей сессии.
