# Декомпозиция правил агентов

Автоматизация удерживает `AGENTS.md` в пределах всегда передаваемого контекста и доказывает, что тематическая загрузка не теряет исходные правила. Codex автоматически обнаруживает только файлы семейства `AGENTS.md` по иерархии каталогов; обычные Markdown-ссылки не становятся инструкциями, поэтому обязательность полного чтения тематических файлов закреплена положительным корневым маршрутизатором.

Машинный инвентарь связывает исходный Git-снимок, побайтовые исходные единицы, стабильные идентификаторы правил, их области, приоритеты, триггеры и единственные целевые якоря. Сам исходный текст повторно не хранится: он воспроизводится из точных `commit` и `blob`.

Команда `маршрут` сначала проводит полную структурную проверку, а затем возвращает безопасное объединение путей для всех переданных триггеров. Команда `проверить` проверяет структуру целиком. Обе команды read-only.

## Состав

- `SKILL.md` — обязательный порядок изменения структуры;
- `scripts/проверить-декомпозицию-правил.py` — валидатор и вычислитель маршрута;
- `tests/test_декомпозиция_правил_агентов.py` — положительные и отрицательные TDD-фикстуры;
- `Правила/агентов/инвентарь-правил.json` — канонический машинный инвентарь.
