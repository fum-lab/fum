# Декомпозиция правил агентов

Используй этот навык при изменении `AGENTS.md`, файлов `Правила/агентов/`, машинного инвентаря или самого валидатора декомпозиции. Навык не даёт полномочий на запись: право записи определяется всегда загруженным корневым ядром и действующей рабочей сессией.

## Обязательный порядок

1. До первой записи выбери триггер `правила` по корневому маршрутизатору и полностью прочитай все возвращённые тематические Markdown-файлы, `Правила/агентов/инвентарь-правил.json` и этот `SKILL.md`.
2. Сохрани стабильные идентификаторы существующих правил. Новому правилу назначь новый идентификатор, область, приоритет, триггеры, семантический ключ, единственное назначение и проверяемое основание.
3. Не меняй исторический снимок задним числом. Исходный `AGENTS.md` воспроизводится из точных `commit` и `blob`; `исходные_единицы` должны без разрывов и перекрытий покрывать каждый его байт.
4. При изменении тематического файла пересчитай его `sha256_содержания` без служебного блока `FUM-MD-RECENCY`. Не копируй одну активную норму в несколько файлов.
5. Развивай валидатор через TDD: сначала добавь отрицательную либо положительную фикстуру и наблюдай RED, затем реализуй поведение и наблюдай GREEN.
6. Каждый прямой запуск теста или валидатора в пишущей сессии проводи через локальную автоматизацию отчётов о запусках проверок с путём текущего `запрос.md`.

## Команды

Маршрут для одного или нескольких триггеров вычисляется без изменения файлов:

```sh
python3 Инструменты/fum-dekompoziciya-pravil-agentov/scripts/проверить-декомпозицию-правил.py \
  --корень-репозитория . маршрут \
  --триггер изменение \
  --триггер документация
```

Полная структурная проверка выполняется так:

```sh
python3 Инструменты/fum-dekompoziciya-pravil-agentov/scripts/проверить-декомпозицию-правил.py \
  --корень-репозитория . проверить
```

Автономные тесты:

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover \
  -s Инструменты/fum-dekompoziciya-pravil-agentov/tests \
  -p 'test_*.py'
```

Валидатор только читает структуру. Он закрыто отклоняет отсутствующий путь, неверный регистр, любой symlink-компонент, выход за checkout, подмену содержания, повтор идентификатора или активной семантики, неполное исходное покрытие, некомпактный корень, несогласованный маршрут и включение исторических полномочий в обычный маршрут.
