# FUM Request Materials

Этот навык фиксирует прикрепляемые материалы как часть памяти FUM, сохраняя связь:
исходный запрос -> папка материалов -> производная документация или инструмент -> коммит.

## Основной протокол

1. Создай или обнови файл исходного запроса `Запросы/<YYYY-MM-DD_HH-MM-SS_MSK>.md` по правилам `AGENTS.md`; текст запроса сохраняй дословно.
2. Для материалов текущего запроса создай папку `Запросы/<YYYY-MM-DD_HH-MM-SS_MSK>/`, то есть с тем же именем, что файл запроса, но без `.md`.
3. Сохраняй источник максимально сыро: URL, HTTP-заголовки, тело ответа, встроенные JSON/потоки приложения, извлеченные сообщения или текст, отчет об извлечении.
4. Не коммить секреты и локальные служебные данные. Redact `Set-Cookie`, токены, локальные IP/геометаданные запроса, сессионные идентификаторы и другие значения, не являющиеся содержанием материала. Каждую редакцию фиксируй в отчете.
5. Если материал влияет на требования, документацию, глоссарий или инструменты, укажи папку материалов и конкретные извлеченные файлы в разделе `## Повлиял на файлы` или отдельном разделе `## Прикрепляемые материалы` файла запроса.
6. Перед коммитом выполни `git status --short` и включи только осмысленные изменения текущей сессии.

## ChatGPT share

Для расшаренных чатов ChatGPT используй скрипт:

```bash
python3 Инструменты/fum-request-materials/scripts/archive-chatgpt-share.py \
  "https://chatgpt.com/share/<id>" \
  --request-file "Запросы/<YYYY-MM-DD_HH-MM-SS_MSK>.md"
```

Скрипт сохраняет в папку материалов:

- `source-url.txt` - исходная ссылка.
- `chatgpt-share.headers.txt` - HTTP-заголовки с редактированными cookie.
- `chatgpt-share.html` - HTML-ответ с редактированным локальным bootstrap-состоянием.
- `chatgpt-share.script-XX.txt` - крупные скриптовые блоки и потоковые данные приложения.
- `chatgpt-share.initial-state.json` - редактированное начальное состояние страницы, если оно найдено.
- `chatgpt-share.react-router-stream.txt` - извлеченный поток React Router.
- `chatgpt-share.decoded-data.json` - распакованные данные диалога, если формат распознан.
- `chatgpt-share.messages.json` и `chatgpt-share.messages.md` - извлеченные сообщения в порядке диалога.
- `extraction-report.md` - отчет о способе извлечения, количестве сообщений и редакциях.

Если скрипт не смог извлечь сообщения, оставь сырой HTML, заголовки, потоковые блоки и отчет с причиной. Не выдумывай отсутствующий текст диалога.

## Другие материалы

Для нераспознанного формата сохраняй наиболее близкий к сырому слой, который реально получен:

- для URL - заголовки, тело ответа, effective URL, код ответа и дату извлечения;
- для файлов - оригинальный файл без нормализации и отдельный отчет о происхождении;
- для динамических страниц - HTML, скриншот или текст DOM, если они доступны, плюс описание ограничения.

Если материал невозможно получить из-за доступа, истечения share-ссылки или защиты, зафиксируй это в отчете и в файле запроса.
