# Измерение подготовки Git-фикстуры

Из корня FUM через отчётную обёртку своего этапа выполните:

```text
python3 -B Инструменты/fum-reyestr-planirovaniya/tests/профиль_подготовки_доставки.py --выход <профиль.json> --повторы 3
```

Принимается от 1 до 20 повторов. Импорт test_обратная_доставка измеряется один раз; создание Фикстура и удаление её временного каталога — отдельно на каждом повторе. Тела тестов не исполняются. Выход содержит исходные интервалы, медианы успешных стадий, версии Python/Git и хэши исходников. Ошибка даёт ненулевой код CLI; первичная ошибка сохраняется при одновременном отказе очистки, обе стадии перечислены в данных.

Git-вызовы наблюдаются только внутри стадий. Их время уже входит во время стадии. Сохраняются название подкоманды, номер повтора, исход и код возврата; аргументы, локальные пути и вывод процессов не записываются. Разбор команд предназначен для существующей фикстуры, а не произвольных вариантов Git CLI.

Запуск Python, импорт измерителя и создание временной папки исключены. Стоимость меток включена, отдельно не измерена. Один профиль не является сравнением оптимизаций и не измеряет полный unittest discovery либо стоимость тел тестов. Для таких выводов нужен отдельный эксперимент.

Адресная проверка:

```text
python3 -B -m unittest discover -s Инструменты/fum-reyestr-planirovaniya/tests -p test_профиля_подготовки.py
```
