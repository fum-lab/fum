# Медиапакет поддержки

Генератор создаёт локальные черновики Telegram, MAX и финансового отчёта. Он проверяет происхождение цитаты в точном Git blob, но не удостоверяет исполнение описанных действий или подлинность финансового документа. Ничего не отправляет и не выполняет платежей.

## Запуск

Из корня FUM:

```text
python3 -B Инструменты/fum-reyestr-planirovaniya/scripts/медиапакет-поддержки.py --корень-репозитория . --вход <вход.json>
```

Успех: JSON в stdout, код 0. Отказ: пояснение в stderr, пустой stdout, код 2. Повторные JSON-ключи отклоняются на любой глубине. Полный [реальный вход](../../Журнал/2026-09-16_00-48-49_MSK_исправить-медиапакет-на-Astra-low/материалы/вход-медиапакета.json) оставляет неизвестные показатели `null`.

## Контракт источника

Вход сохраняет оболочку `fum.вход-медиапакета.1`. Выход мигрирует на `fum.выход-медиапакета.2`: вместо утверждения о проверенном результате выводится цитата источника с явной границей проверки; источник финансов берётся из финансового отчёта. Старый выход не переименовывается задним числом. Прежний неструктурированный финансовый текст больше не допускается: миграция требует настоящего структурированного свидетельства, а не автоматического извлечения похожих чисел.

Каждый источник содержит ровно `коммит`, `путь`, `sha256`, `цитата`. Коммит — полный OID commit, путь — точный относительный Git-путь обычного blob; символьные ссылки и подмодули не подходят. SHA-256 относится к сырым UTF-8 байтам blob. Рабочая копия не является свидетельством.

Финансовый источник независим от источника цитаты результата. Его цитата должна совпадать со всем содержимым JSON blob. Документ содержит ровно `схема`, `валюта`, `период`, `получатель`, `операции`. Поддержаны схема `fum.свидетельство-поддержки.1` и валюта `RUB`; другие валюты требуют отдельного расширения. Период и получатель — непустые строки, точно совпадающие с полями входного отчёта.

В `операции` допустимы только `начальный_остаток`, `поступления`, `комиссии`, `возвраты`, `расходы`. Каждая запись содержит ровно `тип` с тем же именем поля, `факт: true` и `сумма` в форме `100,00`. Это рубли с двумя десятичными знаками; входной отчёт задаёт целые копейки от 0 до 10¹². Сравнение точное, без float и поиска подстроки. Цена, план, обещание, чужая операция, неверная валюта, повторные ключи и несовпадение периода/получателя отклоняются.

Нулевые показатели разрешены при явном свидетельстве. Неподтверждённое остаётся `null`; даже имеющееся свидетельство не заполняет пропуски автоматически. Конечный остаток вычисляется только при наличии всех пяти сумм. Признак `факт` является заявлением автора источника: Git и JSON не доказывают банковскую достоверность. Требуется независимое ревью происхождения документа перед использованием вне локального черновика.

## Регрессии и профиль

Оба вызова выполняются через отчётную обёртку своей сессии:

```text
python3 -B -m unittest discover -s Инструменты/fum-reyestr-planirovaniya/tests -p test_медиапакет_поддержки.py
python3 -B Инструменты/fum-reyestr-planirovaniya/tests/профиль_медиапакета.py --корень-репозитория . --вход <вход.json> --выход <профиль.json>
```

Профиль сохраняет десять отдельных монотонных замеров, SHA входа, исходников и выхода, версию Python. Подготовка измеряется отдельно, файловый кэш ОС не очищается. Это стоимость локального генератора, не модельного вызова и не всего приложения.
