# Наблюдать чтения полного доказательства

[Профильная оснастка](scripts/наблюдение_полного_доказательства.py) подключается явно в отдельном однопоточном процессе к уже загруженным модулям. Она временно оборачивает исходные функции, вызывает каждую ровно один раз и восстанавливает их при выходе. Производственные проверки, Creator, READY и их форматы не изменены; автоматического подключения нет.

Наблюдаются полное доказательство, рамки Markdown H/W, Git batch, безопасные чтения Markdown, обычные FD-чтения W, прямые `Path.read_bytes`, текстовые чтения recency и нормализация отчёта. Байты считаются по уже полученным буферам. Git batch различает пути, уникальные OID внутри пакета, полезные blob-байты и логические байты по путям. Повторные пакеты считаются заново; это не число уникальных объектов всего цикла. У текстового API исходный объём байтов остаётся `null`.

У каждой рамки есть последовательность, родитель, монотонные начало и конец и исход. Включённые времена вложенных рамок нельзя складывать. Счётчики не являются физическим дисковым I/O. Внутренние подробности создания и удаления временного Markdown-представления пока не разделены: доступна включающая их рамка H.

`полон=true` означает отсутствие наблюдённых ошибок диагностики, а не покрытие каждого системного чтения. Ошибка приёмника не заменяет результат или первоначальное исключение. Действия собственной диагностики исключены из наблюдения; иначе читающий приёмник порождал бы события о самом себе. Счётчик передачи событий охватывает только эту передачу, а не всю цену оснастки. Для большого процесса можно передать собственный приёмник и отключить накопление событий в памяти через `хранить_события=False`; сохранность внешней трассы обеспечивает вызывающая сторона.

## Малый воспроизводимый цикл

```sh
python3 -B -m unittest discover -s Инструменты/fum-svyaznostj-rabochej-sessii/tests -p test_наблюдения_полного_доказательства.py
python3 -B Инструменты/fum-svyaznostj-rabochej-sessii/tests/профиль_независимой_контрольной_точки.py --малый-цикл ROOT --наблюдать-чтения
```

Второй вызов выдаёт JSON в stdout. Для сохранения используйте отчётную обёртку и заранее выбранный новый выход захвата. Режим создаёт одну малую Git-фикстуру, выполняет прежний полный сценарий Creator и буквального повтора и не запускает полный check реального репозитория. Прежние режимы профиля сохраняются; смешивание малого цикла с полным профилем или явной реальной базой отклоняется.

[Проверки](tests/test_наблюдения_полного_доказательства.py) сравнивают точный результат proof и состояние фикстуры с исходным путём, сохраняют однократность вызова, аргументы, исходное исключение, ранний отказ и восстановление обёрток. Отдельная конечная регрессия исключает самонаблюдение. Сценарий Creator проверяет обе живые сверки готовности, один коммит и повтор без нового proof или эффекта. Два поздних вмешательства — изменение RAW и состава каталога — сохраняют штатный отказ исходного проверяющего. Эти свидетельства не доказывают ускорения рабочего узла.

Следующий полезный замер — подключение к необходимому новому ROOT Create после приёмки оснастки. Исторический Create ради профиля повторно не запускается. Межвызовный кэш, объединение или снятие проверок в данный срез не входят.
