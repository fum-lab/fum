# Оценки

`Оценки/` хранит оценочные материалы о состоянии и развитии [памяти FUM](../Глоссарий/память-FUM.md): трудозатраты, масштаб работ, возможную стоимость, сложность сопровождения и другие аналитические снимки, которые помогают понимать цену уже выполненной или планируемой работы.

Такие материалы не заменяют [исходные запросы](../Глоссарий/исходный-запрос.md), [производную документацию](../Глоссарий/производная-документация.md), [журнал работ](../Глоссарий/журнал-работ.md) или планирование. Каждая оценка должна явно указывать, что именно оценивалось, на какой снимок репозитория она опирается, какие допущения использованы и где проходит граница точности.
