# Оценки

`Оценки/` хранит оценочные материалы о состоянии и развитии [памяти FUM](../Глоссарий/память-FUM.md): трудозатраты, масштаб работ, возможную стоимость, сложность сопровождения и другие аналитические снимки, которые помогают понимать цену уже выполненной или планируемой работы.

Такие материалы не заменяют [исходные запросы](../Глоссарий/исходный-запрос.md), [производную документацию](../Глоссарий/производная-документация.md), [журнал работ](../Глоссарий/журнал-работ.md) или планирование. Каждая оценка должна явно указывать, что именно оценивалось, на какой снимок репозитория она опирается, какие допущения использованы и где проходит граница точности.

Поскольку оценки являются потенциально повторяемыми задачами, новые типовые оценки создаются или проверяются через локальную автоматизацию [fum-ocenki](../Инструменты/fum-ocenki/SKILL.md), когда формат оценки подходит под её контракт. Автоматизация фиксирует снимок репозитория, методику расчёта, диапазоны, допущения, ограничения точности и оформление результата; если оценка пока создаётся вручную, её файл должен явно фиксировать ручной статус методики и связь с ближайшим шагом к автоматизации.

## Материалы

- [Оценка выбора архитектурного подхода к реализации FUM](оценка-выбора-архитектурного-подхода-к-реализации-FUM.md) - сравнительная оценка ближайшего порядка реализации между репозиторным гиперсетевым контуром, минимальным трассировщиком агентского цикла и единым локальным приложением.
- [Оценка трудоёмкости текущей памяти FUM](оценка-трудоёмкости-текущей-памяти-FUM.md) - оценка человеко-часов, которые потребовались бы человеку для создания текущего объёма уже проделанной работы.

## Автоматизации

- [fum-ocenki](../Инструменты/fum-ocenki/SKILL.md) - локальная автоматизация сборки и проверки оценочных материалов.
- [Конфигурация оценки выбора архитектурного подхода к реализации FUM](Автоматизации/оценка-выбора-архитектурного-подхода-к-реализации-FUM.json) - сохранённая JSON-конфигурация ручной сравнительной матрицы.
- [Конфигурация оценки трудоёмкости текущей памяти FUM](Автоматизации/оценка-трудоёмкости-текущей-памяти-FUM.json) - сохранённая JSON-конфигурация, по которой пересобрана первая оценка.
