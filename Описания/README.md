# [Описания FUM для адресатов](../Глоссарий/описание-FUM-для-адресата.md)

Источники требований:

- [исходный запрос 2026-06-22 09:40:25 MSK](../Запросы/2026-06-22_09-40-25_MSK.md)

Эта папка хранит адресные описания [FUM](../Глоссарий/FUM.md), построенные на основе [документации](../Глоссарий/производная-документация.md), [глоссария проекта](../Глоссарий/глоссарий-проекта.md), [открытых вопросов](../Глоссарий/открытый-вопрос.md) и [исходных запросов](../Глоссарий/исходный-запрос.md).

Описание для адресата не является новым источником требований. Оно является производным слоем [памяти FUM](../Глоссарий/память-FUM.md): выбирает релевантные тезисы, меняет порядок подачи и объясняет проект языком конкретной аудитории.

## Правила описаний

- Каждый файл описания должен фиксировать адресата, цель, статус, источники, примененную [автоматизацию FUM](../Глоссарий/автоматизация-FUM.md) и ограничения.
- Описания должны ссылаться на документы и глоссарные термины, из которых выведены ключевые тезисы.
- Если описание выявляет новую проектную мысль, ее нужно отдельно внести в `Документация/` или `Глоссарий/`; само описание не заменяет эту работу.
- При изменении базовой документации затронутые описания должны пересобираться или проверяться по воспроизводимой схеме.
- Неподтвержденные факты о статусе, метриках, внедрениях, юридических обязательствах или коммерческих результатах нельзя добавлять ради убедительности адресного текста.
