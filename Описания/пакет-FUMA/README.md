# Расчёты и содержание пакета FUMA

Здесь находятся открытые входы и исполняемые определения языка FUMA. Предметную арифметику и сборку содержания выполняет интерпретатор внутри основного Swift-бинарника. Python используется для проверки запуска и для последующего экспорта форматов документов.

## Что посчитано

- [Содержание и аппаратная смета](содержание.json) проходят через [граф пакета](оператор-пакета.json). Он собирает восемь представлений, разрешает ссылки на источники и считает денежные величины в целых копейках и центах. Неизвестные цены остаются `null`; общий итог при неполноте не выдаётся.
- [Вход рюкзака](вход-рюкзака.json) проходит через [граф энергии и массы](оператор-рюкзака.json). Он проверяет диапазоны и рассчитывает девять сочетаний батареи и нагрузки. Время округляется вниз до секунды явно выбранным примитивом; деньги этим округлением не обрабатываются.

Максимальные конфигурации выбраны для каждого включённого типа устройства. iMac добавлен самостоятельным узлом, Studio Display XDR сохранён. Клавиатура с Touch ID и цифровым блоком и трекпад входят в выбранную комплектацию iMac; цена отдельного комплекта показана как альтернатива, без двойного начисления. Собственная клавиатура, датчики пальцев и батарейный рюкзак относятся к проектированию, их стоимость пока неизвестна.

## Воспроизведение

Из корня FUM после подготовки зависимостей [основного приложения](../../Приложения/FUMA/macOS/README.md):

```sh
: "${FUM_BUILD_ROOT:?Задайте каталог сборки вне Git}"
: "${FUM_CALC_OUTPUT:?Задайте новый каталог результатов вне Git}"
swift build --package-path Приложения/FUMA/macOS --scratch-path "$FUM_BUILD_ROOT" --jobs 2 -c release --product fum
FUM_BIN_DIR="$(swift build --package-path Приложения/FUMA/macOS --scratch-path "$FUM_BUILD_ROOT" -c release --show-bin-path)"
python3 -B Приложения/FUMA/macOS/проверки/операторные-расчёты.py \
  --корень . --FUMA "$FUM_BIN_DIR/fum" --набор рюкзак --выход "$FUM_CALC_OUTPUT/рюкзак"
python3 -B Приложения/FUMA/macOS/проверки/операторные-расчёты.py \
  --корень . --FUMA "$FUM_BIN_DIR/fum" --набор пакет --выход "$FUM_CALC_OUTPUT/пакет"
```

Проверка запускает реальный бинарник, сохраняет его ответ и профиль, затем трижды повторяет исполнение из его долговечной памяти. Она сверяет весь объект наблюдения, хэши исходников и контрольные результаты. `результат.json` содержит вычисленный JSON, `проверка.json` — происхождение и время, `память/` — исходные байты, определение и наблюдения. Внешние публикации и покупки не выполняются.

Исполнение возможно и непосредственно через `fum --выполнить-оператор`; [контракт CLI](../../Приложения/FUMA/macOS/docs/исполнение-оператора.md) описывает аргументы. MCP для расчёта не требуется. Существующий MCP-шлюз пока не предоставляет операторного вызова.

## Границы результата

На 23 сентября 2026 года FUMA получил $23 594 для шести оценённых устройств Apple и $2 400 за 12 месяцев подписки при входном допущении $200/месяц. Это не полная стоимость проекта. Российский итог неизвестен: нет всех КП и принятого валютного курса. Указанная рублёвая веб-цена DGX Spark также не является согласованным предложением поставщика.

Для батареи 500 Вт·ч расчёт даёт массу 10,6 кг и 12 000 / 6 545 / 3 555 секунд при суммарной нагрузке 120 / 220 / 405 Вт. Использованы допущения 80% доступной энергии, 100 Вт·ч/кг для всего батарейного узла и 2 кг каркаса, охлаждения и кабелей. Комфорт, охлаждение и фактическое потребление FUMA ещё не измерены; эти величины меняются во входе, а не скрыто внутри исполнителя.

Release-запуск рюкзака занял 752 мс впервые и 73–76 мс при повторных процессах; участок исполнения — 1,7–1,9 мс. Пакет занял 97–103 мс на полный вызов. Полное время включает запуск процесса и долговечную запись; эти замеры не изолируют стоимость IPC. Для текущей частоты расчётов дополнительная оптимизация алгоритма не обоснована. Постоянный процесс и MCP можно сравнить отдельно при частых вызовах; ускорение без такого сравнения не заявляется.

Экспорт PDF/PPTX/DOCX/XLSX остаётся незавершённой частью этапа: прежний адаптер ещё требует подключения к вычисленному пакету. Наличие графа и JSON-результата не означает готового комплекта презентаций.
